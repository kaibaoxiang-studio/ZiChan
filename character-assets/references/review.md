# 回流图片审查与发布门槛 v0.2.6.1

`asset_mode=ensemble` 的无台词群像每状态只审一张全身同画布图：核对剧本明确人数或已批代表人数、全员从头至脚可见、左至右顺序、体貌与服饰差异、各人道具归属、最终画幅和项目获批风格。不得以未满足人形四格或缺头像判失败；有指定台词的群演只审一张 9:16 四格执行图，核原文台词、正脸、45° 脸、无头正面服装、完整背面及获批风格；不要求前三张身份图。详细合同见[群像单图](group-ensemble.md)。

## v0.2.6 新项目回图门槛

每状态只审一张 9:16 竖版四格执行图，核对像素比例、正面/45°脸、下方放大无头正面服装与完整背面。核对服饰圣经、[状态可见需求](scene-styling-needs.md) 的妆、发、头耳颈、主衣与其他穿戴，以及状态剪裁/材质与头像身份不变量；通过后一次批准直接打包。v2 旧项目仍按服饰设计图加执行图双图审。


只有实际读到的图片才能给视觉结论；没有图片时只评价文字和合同。审查报告使用 `CharacterImageReviewV1`，分别列剧本事实冲突、身份漂移、版式问题、中文标签问题、其他阻断项和可提议纳入的新细节。无法从画面判定的材质或背面，不假定通过，标为待核实。

当同剧已有其他角色定稿图时，头像和全身图还需并排核对近邻角色：脸长宽/颌线、眉眼鼻口组合、发结构、体型体态、皮肤真实度是否与设计卡一致并有可见区分。只换衣服或发色而同脸同体型应列为差异化缺陷。无近邻图时只能报告“群像实图比较未执行”，不能声称已通过群像辨识测试。请区分设计卡本身撞型与生成图未执行设计：前者重开设计审批，后者走局部修图与回图复核。

按顺序核查：①剧本原文及已确认改编决定；②当前设计依据的身份不变量；③与上一步已定稿图片；④本阶段构图/格位；⑤图中文字；⑥服装、饰物、手脚、配色和材质是否跨格漂移；⑦背景是否在当前任务或已批准记录范围内。头像审查更重脸部；表情逐格看标签与表演；全身看头到双脚及脸部连续性；v3 执行图逐状态核对已批准衣装、鞋履、饰物、妆面与前侧背制作信息；重点部件若在实际格位尺寸下只剩同色斑，标为设计尺寸/画幅匹配问题，不把不可见的内部结构判已通过；v2 服饰图另行审查；执行表按 `references/execution-sheet.md` 四格核查。头像、表情和单独全身按[模卡着装规则](model-card-baseline.md)核对；中性背心/短裤是基础形体展示，不作为正式服装与原文服装冲突，执行表则必须恢复已批准的正式造型。未经批准的地点、建筑、地貌、天气或参考图环境属于待修问题；若改变角色事实或妨碍识别，则阻断定稿。

头像默认检查最终图是否为 **3:4 竖版**且头顶、双耳、头颈及可见肩线有安全边界；只有提示词包记录了明确用户覆盖依据时才接受其他比例。模卡头像以脸为主体，允许完整头部、双肩及上胸入画，不把锁骨以上当作通过条件；若上胸入画，应见对应中性白色背心，不能露出裸体躯干。同轮候选取景和着装一致；中途从 `face_only` 换背心时记录原因并重新核查整组。9/16 格表情逐格检查是否与已批准头像采用同一取景和着装模式，不允许某格带衣、某格无衣。对皮肤高光/微纹理、布料厚薄和垂坠、材料反射、光色及脏糊伪影按[真实质感规则](render-texture-standard.md)分别给证据。当前阶段快照或完整卡按 `feature_focus` 与 `body_form` 核对当前画幅可见的主锚点、比例和体块；未见侧背或动作图时标记未测试。先判断设计卡空泛还是回图没执行设计；不能把“脸谱化”一律归咎于渲染，也不能将自然相机轻微颗粒当成脏纹。

完整人形头像再对照 [头像颗粒度合同](avatar-identity-granularity.md) 逐项查看：颧颌颏的骨点关系、分缝与人物自身左右发片、眉眼耳鼻唇是否执行已确认的形状与落点、皮肤哑光/光泽方案、妆面和稳定标记/饰品是否在正确层级。放大实际看额头、面颊、颈胸有无重复卷曲或压印纹，发际有无无根浮丝或交叉刻线；不能因为提示词写了禁令便判通过。正面单图无法证明约 45° 的结构稳定，后续对应视角生成后再核对，不把未测试写成通过。图中的新五官或饰品细节若超出冻结依据，先列待采纳提案而非自动定稿。

全身回图先检查最终图片的实际像素宽高比是否为 **9:16 竖版**，头顶、双手、双脚完整入画且留安全边界；只有提示词包记录了明确用户覆盖依据时才接受其他比例，不能只凭提示词文字判定通过。人形核对背心、短裤和赤脚的对应模卡组合，足部应清楚可见，不被鞋袜遮挡。再以已批准的 `body_form.proportion_anchors.measurement_frame` 为口径，目视核对头高/全高、肩峰/骨盆、同一端点体系的上段/下段和肘腕膝踝落点，不能为了填满画布而拉长腿或压缩躯干。透视、衣装遮挡或姿势使某项无法判断时写 `uncertain` 或待核实，不从像素直接推断真实厘米，也不把身高/体重文字视为比例已达标。若设计卡本身没有可核对锚点，退回设计卡；若有锚点但成图偏离，进入修图或重抽。

把问题分为：**阻断**（认错人、改写明确事实、未批准换装/年龄、严重裁切、错中文标签、2×2 核心布局失败）、**待修**（可局部纠正且不影响身份）、**建议**（审美偏好或可采用的新细节）。只在阻断和其他缺陷均为空时报告 `pass`；`uncertain` 不能由系统自动放行。视觉审查通过后仍需操作者明确批准，审批记录绑定图片哈希、审查报告哈希、操作者和时间。

被选定的头像是后续身份锚点。新头像取代旧头像时，下游表情、全身与执行表都须重新核对；五阶段项目的全身依赖表情锚点，表情重选须重审全身及后续；旧四阶段按其既有依赖检查，不凭空扩大失效范围。保留失败图和旧提示词作历史，不把偏差自动写成新设定。

v2 历史五阶段项目按 `avatar → expression → full_body → costume_design → execution` 检查影响：头像或九宫格重选使所有后续身份/服饰图重新核对；全身重选使所有状态服饰图与执行图失效；某状态服饰图重选只使该状态执行图失效。服饰图审查须实际对照资产表状态名、服装结构、鞋履、饰件、批准妆容的左右位置与起止状态。执行图必须沿用本状态服饰锚点。环境和技术痕迹只审查已批准且本阶段可见的结果；新出现的疤、斑、纹身、技术装置不自动接纳。

对于经批准的 2D→3D 呈现，并排检查源图与回图：先核身份锚点和服装结构，再核材质、体积及灯光。新增毛发、皮肤纹理、饰件或海报参考图的人脸/服装如无批准依据，列为偏差；只是渲染媒介变化且身份不变时不必新建角色变体。详见[媒介转换知识快照](knowledge/character-image-prompt/hedgehog-2d3d.md)。

按 `01-通用图片生成` 方法区分参考图与待编辑图后，回流审查要核对“角色身份是否从身份锚点继承”“服装/风格参考是否越权带入其他内容”。图内文字按提示词原样文字清单逐格核对，含顺序、字形、漏字、重复与多余标签。每次局部修图后都审查完整图片，因为模型可能修改了未指定区域。


## 人物理解与预览审查

设计审阅先核对 [总控方法](director-understanding.md)：是否依据全剧言行、矛盾、弧线与观众信息形成意图，是否误把他人评价当客观人格，是否提前泄露秘密。图片只审当前可见设计，不能从长相倒推性格、阶层、经济或族群事实。设计与原文条件的联系用具体结构说明，不以十三项均填 used 或抽象分数代替判断。

phased 头像 preview 对照其冻结的 direction/identity SHA，允许尚未批准但明确声明的普通痣雀斑等首稿设计；不把它们误当成随机新增细节。图中超出冻结依据的新细节仍列 adoption_proposals，解决前不转正。review pass 仅是图像审查结论，不能自动把预览用于九宫格或打包。

同图转正须由用户确认同 SHA 的方向、身份和该图，未决项清空、review pass 且无待采纳新细节，图片/提示词/依据内容不变。改了身份稿不能沿用旧依据转正。正式执行阶段另核当前 V2.5 合成卡与其 stage_receipts；机械合成继承源审批，不代表系统新作人设决定。

# 剧情驱动的表情提示词

默认按剧情情绪转折、关系和本次需要选9个可见表情，组成3×3九宫格；用户明确16格才改4×4。不为了填格添加不属于人物的夸张表演。每格给表情名、可见眉眼口/呼吸变化与力度；对应来源只在确有需要时简述，不把原文证据台账塞图。

同一方向的脸型、年龄、发际/发型和标记保持；取景与[模卡着装](model-card-baseline.md)一致。没有头像实图时提示词自身写完整身份，实际有图才指为身份参考，不等待正式图片批准。不能某格带衣某格裸露或变成年龄/妆面新设定。

输出一条完整词，写从左至右、从上至下顺序及每格准确中文表情名。克制人物的愤怒可以是颌部紧绷和目光改变，不必怒吼；疲惫、紧张、释然应有可见区别。按[同一文档](prompt-document.md)追加本阶段，旧typed调用才保留既有包字段。

生成前轻量检查格数、顺序与文字格式；生成后直接交给用户人工看，不自动逐格审查、修字、复核或重跑。用户明确要求审图才按[回图规则](review.md)，明确要求改字才按[编辑方法](editing.md)。不自称图片合格或替用户批准。

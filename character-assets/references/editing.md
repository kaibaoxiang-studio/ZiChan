# 精确修图指令

修图之前同时查看目标图片、设计卡、已批准身份锚点和具体审查问题。指令写成四段：

1. **目标**：指定图、格位、区域及当前可见错误。例如“执行表左下残留嘴唇”。
2. **改动**：描述唯一需要改变的可见结果。例如“把左下裁切上缘移到颈肩以下，让嘴唇、下巴和头发完全出画，同时保留双手到鞋”。
3. **保留**：列出身份、服装、其他格位、背景、光线、布局等已正确的要素及其参考图职责。
4. **核对**：给出可视检查点。不要承诺像素级不变；回流后重新检查整张图。

若只是标签错字，点名第几行第几列的标签和目标汉字，保留其他标签与人脸。若侧脸角度不符，修改右上角到约 45°，不要重造左上正脸。若头像与全身脸不一致，保留被选头像为身份基准，修正全身图；不能悄悄反向改头像。若生成图出现值得采用的新细节，先写 `adoption_proposals` 给操作者；phased中先更新并确认所属阶段快照，complete中更新批准卡，再基于新版给修图指令；新设计不能只写进修图提示词。

图像参考只提取被批准的优点。用户说“照图2改衣服”时，说明图2仅是服装来源；人物脸、体型与当前作品画风仍按已批准设计。局部编辑失败时可给重生成方案，但明确可能需要再次校验所有未改区域。

从 `01-通用图片生成` 的修图方法增加一个执行检查：提示词开头明确“图1是待编辑原图”，其他图分别写为身份或服装参考；每轮只修一项可见错误，重申未改区域的不变量。源方法的角色场景适配见[修图知识快照](knowledge/character-image-edit/hedgehog-general-image-prompting.md)。外部操作者回图后重新审查整张图，不能因指令写了“其他不变”就跳过身份与格位复核。

油亮、蜡像、布料塑料感与多轮脏糊按[真实质感规则](render-texture-standard.md)逐级处理：先定位可见区域，再写局部目标和保留项；低强度外部修复、从母图新开会话、线稿/灰模重建都只是有条件的建议，不宣称无损或已经执行。若重建改变身份和服装结构，作为新图完整审查。头像局部修图沿用获批准的画布比例，默认 3:4。

可复制的局部修图骨架：

```text
目标图：图1=<待编辑原图、阶段、格位>；辅助图：图2=<已批准身份锚点，只用于脸和标记>。
只改变：<一个可见错误及其准确目标，例如左下裁切到颈肩以下，或第 3 格标签改为“惊讶”>。
保持不变：<图1其他格位、人物身份、服装结构、背景、光线、正确文字；按实际问题填写>。
完成后检查：<改动是否正确、其他格位有无新变化、图内中文是否逐字准确>。
```

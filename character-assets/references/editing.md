# 用户明确请求时的精确修图

默认生成后直接交用户看，不自动修图、审图、复核或重跑。只有用户明确要求修改图片时使用本页；要求“给修图词”仅交指令，不代表授权实际生图。

先实际查看用户指定目标图、当前完整提示词及实际提供的参考图，不必另建设计卡。明确：哪张是待改图、唯一改动区域与目标、其余身份/结构/状态/布局保持、参考图各自职责。文字错字只改指定格标签；无头服装格残头只处理指定裁切与连接区域；不能保证像素级不变。

人形执行版式按[精确规则](execution-sheet.md)，不能因局部修改换成横向三联或改变上下占比。单独全身仍完整有头。获选头像只在实际提供时作为身份参考，不能反向改脸迁就全身。新增外观在本次委托内由模型整合，改变已批身份或重大剧情设定才集中问，不能自称已获正式批准。

需要的骨架：任务/输入图职责→指定位置的改变→必须保持的内容→目标画面与准确文字。按[修图知识](knowledge/character-image-edit/hedgehog-general-image-prompting.md)取必要方法，异常油光/脏纹才读[质感](render-texture-standard.md)。外部超清/线稿灰模重建只是可选择方案，不默认执行，不承诺无损。

生成修改图后直接交用户，不自动再审查或重试；只有用户另行要求审查时才按[回图规则](review.md)实际看。正式工程试改不覆盖active或旧批准，用户决定采用后按真实接口登记，不自动扩大为全链重做。

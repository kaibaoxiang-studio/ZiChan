# 精确修图指令

修图之前同时查看目标图片、设计卡、已批准身份锚点和具体审查问题。指令写成四段：

1. **目标**：指定图、格位、区域及当前可见错误。例如“执行表左下残留嘴唇”。
2. **改动**：描述唯一需要改变的可见结果。例如“把左下裁切上缘移到颈肩以下，让嘴唇、下巴和头发完全出画，同时保留双手到鞋”。
3. **保留**：列出身份、服装、其他格位、背景、光线、布局等已正确的要素及其参考图职责。
4. **核对**：给出可视检查点。不要承诺像素级不变；回流后重新检查整张图。

若只是标签错字，点名第几行第几列的标签和目标汉字，保留其他标签与人脸。若侧脸角度不符，修改右上角到约 45°，不要重造左上正脸。若头像与全身脸不一致，保留被选头像为身份基准，修正全身图；不能悄悄反向改头像。若生成图出现值得采用的新细节，先写 `adoption_proposals` 给操作者；获批后更新设计卡，再基于新版给修图指令。

图像参考只提取被批准的优点。用户说“照图2改衣服”时，说明图2仅是服装来源；人物脸、体型与当前作品画风仍按已批准设计。局部编辑失败时可给重生成方案，但明确可能需要再次校验所有未改区域。

# 角色执行资产表版式

## 无台词群像例外

新项目 `plan.asset_mode=ensemble` 时采用[群像单图合同](group-ensemble.md)：每状态一张同画布的完整全身群像执行图，人物按获批槽位从左至右排列，剧本明确几人就画几人；未明确时记录代表人数。多人采用适合人数与辨识度的横向比例，单人 9:16。无需头像、九宫格、全身模卡或下文的人形四格。指定台词群演走 `speaking_extra`，每状态一张下文的 9:16 四格执行图，但没有头像、九宫格和全身模卡前置。

## v0.2.6 新项目画幅与依据

新项目此表直接是每状态唯一正式服饰资产图：**9:16 竖版**，2×2 格位，上方两格面孔、下方两格服饰，最终像素比例须核对。服装依据为已批准 `CostumeStyleBibleV1`、当前状态 `CharacterStageDesignV1/V1.1(scope:costume)` 与合成卡，三张模卡身份图只锚定脸和体型。单张通过审查与操作者批准后直接进入执行包，无单独横版服饰设计图。下文若写“服饰设计图为直接锚点”仅适用于旧 pipeline_version 2。


## 人形角色标准版

一张干净的 2×2 参考板，非叙事海报。上区约占画面高度三分之一，专门固定面部；下区约占三分之二，展示身体与服装。四格必须是同一身份、同一变体服装和身体比例，背景与光线中性且一致。头像、表情和单独全身图的[模卡着装](model-card-baseline.md)只提供身份和形体锚点；v3 本表以已批准风格圣经、状态服饰文字快照和合成卡为服装依据；v2 才以服饰设计图为直接锚点，再核对设计卡中的正式服装、鞋履和饰物，不把白背心、短裤或赤脚误当成角色造型。

| 格位 | 必须可见 | 关键错误 |
| --- | --- | --- |
| 左上 | 正面头像，五官、脸型、发际线、头饰与年龄感清晰；状态已设计的眉眼颊唇妆面须可辨 | 半侧脸、表情过度、与身份锚点不符 |
| 右上 | 约 45° 半侧面头像，能读出鼻梁、颧骨、下颌和发型侧向结构；妆面、发饰与正面一致 | 误作另一个人、角度过小或纯 90° 侧面 |
| 左下 | 放大的正面服装主体，从**颈肩以下到鞋**；肩、双臂、双手、躯干、腿、鞋完整；头部彻底出画 | 嘴唇、下巴、头发残留；手脚被裁；人太小，服装细节不清 |
| 右下 | 完整背面，从头部、后脑发型、服装背面到鞋全部入画 | 头或鞋被裁；服装/配饰与左下不一致 |

左下与右下的尺度有意不同：左下更近、更满，用画面面积展示服装与材质；右下是正常完整背视图。下方都用稳定站姿，不做剧情动作。每一套获批准的明显换装变体分别有自己的执行资产表。单独的全身设计图则必须包括头部，不应用左下的无头裁切。

用户示意图是版式参考，不是同一角色的身份样本。第一张示意左下露出嘴唇/头发，不符合课程文字的“头部完全出画”；第二张更接近目标。提示词和审查以本表的明确几何要求为准。

## 非人适配

四足、巨型、多肢或无脸角色不强套“头像＋无头服装”的人形格位。设计卡另列 2×2 或多视图替代布局，说明哪些格固定身份、轮廓、关键侧向结构、背部、材质与尺度，并经操作者确认。审查以批准的替代布局为准。

# 项目视觉基准、阵容与角色设计

## 第 -1 阶段：全剧视觉基准

从标准剧本、资产表和可选场记表提取时代、空间、社会规则、职业与资源、叙事气质及已写明的视觉约束。按“世界规则 → 生活需要 → 工艺/工具/服饰 → 可见造型”的链条提出 2–3 个真正不同的视觉方向。列出各方向与证据的联系、必须保留的项目共性、仍待决定的项目。操作者确认后形成 `ProjectVisualBibleV1`。

整体画风可以是实拍摄影、绘画、动画、版画、拼贴、实体工艺、数字渲染或混合表现；媒介、写实度、色彩、材质和气质彼此独立，不把“二维”“古风”等单个词扩展为一整套已批准设定。

## 全员轻规划

读取资产表全量角色，保留其 ID 和层级。按 [群像差异化框架](differentiation-framework.md) 建立关系、真实同框或功能近邻的比较组，列出剪影、脸部结构、体型体态、发型块面、服装色块五轴。重点检查同阶层和同制服角色的区分，以及全员是否落到同一类精致面孔与修长身材；不为差异硬造极端特征。此阶段只做轻量规划，不要求所有角色详设后才开始第一张头像。

主角与重要角色进入分轮 Grill Me；配角用简化设计卡与必要提示词；功能角色按制作需求启动；群演使用群像规则，不逐人建立全套资产。操作者可调整任一角色权重。

## 重点角色的分轮决策

先展示该角色已有事实、剧情作用、主要关系、视觉缺口，再给少量具体方向及推导依据。每轮最多集中讨论 2–4 个真正需要拍板的维度：①身份与形象；②脸、发型、年龄感；③身体比例与姿态；④服装、装备与状态；⑤颜色和材质。选项允许混合、自由输入或委托插件决定某一项。

保存 `已确定／待选择／已委托` 状态。“继续”只推进下一轮；选了一个大风格也不代表人物细节已定。某维度有缺口时按 [专项交接](specialist-contract.md) 启用对应 Skill，主控把多个专项结果合成少量真正需要拍板的选择。新提交的重点人形角色设计卡按[具象描述标准](design-detail-standard.md)提交 `CharacterDesignCardV2.2`：脸、发、身体、皮肤、服饰、饰件都要有可画的细节，十一个专项各记已采用的可见结果或不启用理由。最终设计卡另含原文事实、保守推导、已批准创作选择、身份不变量、与近邻角色的可见差异、变体关系、参考图提取点和未解决问题。未解决问题清空后才能审批。

头像候选是同一张已批准设计卡的 2–3 个表现方案，只允许非身份要素如构图、微表情和光照轻微变化。单独全身图从已定稿头像延展，头部完整入画；不得重新设计面孔。人形头像、表情与全身采用[模卡式基础形体图](model-card-baseline.md)，正式服装设计保留在卡中，并在执行资产表呈现；不能因模卡阶段没有剧情服装而删改服装设计。表情与全身图可以并行生成，执行资产表须等两者定稿。

## 头像与全身的可执行设计检查

以下是从《角色概念设计知识库》头像 A01–A08、人体 B01–B05、服饰 C01–C09 与交付 D01–D03 改写的**设计检查项**，不是对现实人物性格的判断规则。

1. 先选能在缩略图里识别的轮廓，再细化脸部。记录脸宽与脸长、颌线、颧骨、额头、发际线的相对关系；不要只写“英俊”“清冷”。
2. 面部锚点以可观察特征写：眼距与眼型、眉形与眉眼距离、鼻梁与鼻尖、嘴唇、耳部、肤色与皮肤质感、左右不对称记号。三庭五眼只作测量参照，可被画风和角色事实调整。
3. 发型分为整体外轮廓、分缝/刘海、发量和发质、长度、颜色、固定饰物。生成候选时锁住这些要素；发丝小变化可容忍，剪影变化需重新审查。
4. 每名重点角色选 1–3 个可传递给他人的识别锚点。疤痕、痣、首饰等若无剧本依据，标记为创作提案，经批准再进入设计卡；不能以“记忆点”为由擅自加伤。
5. 全员并列比较头像剪影、色块与体型。相近关系或制服角色可共享视觉语言，但通过一个受剧情支持的变量区分，例如肩部比例、制服磨损、饰品位置。
6. 全身卡记录头身比、头肩比、重心、惯常站姿、鞋、服饰外轮廓、层次和行动余量。课程中的比例数值不作默认模板；儿童、老人和极端体型均按剧本与已批准方案处理。
7. 头像与全身并排核对脸型、眼鼻嘴相对位置、发际线与发色、肤色、面部标记、配饰、年龄感。全身脸太小时标记“无法核对”，补局部放大图而非猜测通过。
8. 服装设计同时考虑镜头可读性和制作可用性：衣层结构、布料/硬件连接、前后差异、可动关节、裙摆与披挂是否遮挡动作。复杂结构先确认制作需求，不自动简化原文写明的服装。

人物个性与脸型、阶层与美丑、族群与五官之间不存在本插件的固定映射。若采用某种视觉暗示，只把它作为已批准的叙事设计策略，并用全剧统一的设计语言解释。

# 人形基础头像的命名、颗粒度与材质边界

适用：人形角色的身份头像文字设计、提示词转换及回图核对。角色事实、用户已批准的选择与当前阶段任务优先；以下是通用设计方法，不能把宋也或任何单一案例的五官、发型、肤色和妆容设为全员默认。头像采用已批准的画幅、取景、着装与背景规则；临时测试用的无发灰模、去五官图不进入常规流程。

## 从名称到结构

先用一个在当前时代和媒介中易理解的主名称定位类型，需要时加一个形态亚型；随后写实际可画的形状、落点、连接、少量有辨识作用的相对比例，以及正面到约 45° 的连续结构。词表中的名称只作检索入口，不连带继承性格、道德、职业、族群、性别或剧本未写的服饰。数值比例必须交代测量端点；不把面部指数与整脸外轮廓长宽混用，不为“精确”堆没有来源的数字。

- 脸型：主类与必要亚型之后，按额角/太阳穴、颧弓最宽点、颧下转面、下颌角位置、颏端形状和各段连接描述。约 45° 仍需保留主要骨点，不在不同视角变成另一张脸。
- 发型：主名之后写发际、分缝起点和人物自身左右、发根发流、前侧后体积、入画发片及长度、发尾和发质。基础发式与剧情中的挽发、束发、汗湿等状态分开。正常头像尺度先表现连贯发束；发际边缘整洁、发根并入主发流，不主动要求逐根发丝、额前胎毛或漂浮细丝。
- 眉、眼、耳、鼻、唇：各给一个可理解的形态入口，再只保留影响当前头像识别的落点、轮廓、骨软组织连接及近邻比例。眉写眉头/眉峰/眉尾与眼眶关系；眼写内外角、眼睑和间距；耳写耳根、外张、耳轮耳垂及发片遮挡；鼻写鼻根、鼻背、鼻尖、鼻翼；唇写口宽、上下唇分布、唇峰与嘴角。眼神、蹙眉、微笑是表演状态，不能偷偷改静态器官形状。
- 稳定标记、妆容、头耳颈饰：由各专项决定是否存在。素颜表示没有可卸施加层；裸妆表示低覆盖可卸施加层，不混称。基础妆与剧情妆、原生肤色与底妆、标记与短时污损分别记录；没有依据时可明确留空，不为填类目添加痣、疤或饰件。

剧本没写头耳颈饰时仍可设计，但先核对人物的脸发衣装是否已承担识别，再从世界文化、实际功能、可观察的个人选择和可获得的材料工艺四类锚点提出候选。每件说明视觉任务、人物自身左右、固定点、尺度、重量运动、与发耳领口的遮挡和佩戴起止。财富、阶级、性格、宗教、亲缘及“遗物”不能由材质或符号单独证明；无来源的具体来历是待审创作提案。焦点数由当前画幅和群像比较决定，允许头耳颈全部留空，不实行“每人必有故事饰品”或“三处一主二辅”配额。详见 `character-face-signature-design/avatar-head-ear-neck-16.md`。

## 皮肤与发丝的头像尺度

皮肤设计卡记录底色、区域色差、光泽和可见肌理；提示词只提取该镜头能读到的部分。正常头肩真人头像以自然皮肤体积、柔和色差和已批准的光泽方案为主，不主动要求全脸、颈胸肉眼可见毛孔或面部绒毛。更近镜头确有需要时，毛孔限于鼻翼和鼻旁内颊等局部、低强度、非均匀分布；自然绒毛只在实际可见的侧逆光边缘微现，不能形成皮肤上的线状贴图。真人影视写实且未另定特殊光泽时，基础头像优先自然哑光与柔和漫反射；额鼻颧颏不成片油亮，同时避免厚粉、蜡像或无体积的平涂。

提示词要明确避免额头、面颊、颈胸出现重复卷曲、指纹、漩涡、迷宫、压印、刻线或统一颗粒纹。发际线避免无根浮丝、乱卷细线、交叉刻痕及发丝画在额头皮肤上。出现这些现象时先检查“可见毛孔/绒毛/逐根发丝”是否超出当前镜头尺度，收紧文字后重新生成候选；不把伪影当作人物稳定特征。提示词只能降低风险，回图仍须实际检查。

## 交接到可复制提示词

设计结果整合进同一角色设计文档集中审阅，普通参数不逐项批准；提示词转换按脸、发、五官、皮肤、妆饰、构图的自然阅读顺序抽取已确认且入画的必要细节。人形头像的可复制提示词正文使用连续段落，**不写“脸型：”“皮肤：”等板块标题**；结构化 JSON 的字段名与说明文字不受此限制。不要把设计理由、心理标签、不能入画的背面细节或为表单而添的空项塞进正文。跨部位冲突由主控按特征焦点与比较组处理，再交操作者审阅。

用户要求“从 0 到 1 完整头像”时，主控依据实际材料覆盖范围或有效全剧上下文确定原创身份方向与可用近邻，再逐项完成脸型、发型、眉、眼、耳、鼻、唇、皮肤、稳定面部标记、妆容、头耳颈饰品。每项由对应专项给出当前画幅可画的形状、位置、连接和必要比例；可决定某项不存在，并说明视觉焦点由哪里承担。脸型与发型的已批准选择不得被后续五官或妆饰覆盖，剧本里的状态发式、项链、伤妆不能倒灌基础头像。主控用特征焦点与群像比较解决撞型、遮挡和部位冲突后，才合成最终提示词。

合成前逐项核对：已确认的脸型骨点、发际与发流、眉眼耳鼻唇、肤色/光泽、妆容、稳定标记或其留空决定、头耳颈饰或其留空决定，以及 3:4 正面、完整头肩上胸、当前白色模卡衣着和中性背景，是否都被当前提示词正确表达。只写画面可见内容，45°连续性作为身份结构要求，不把第二视角硬塞进正面画面。完整描述可分自然段，不设固定字数上限。

当操作者要求“先看提示词，再看预览图”时，先在对话中交可复制正文，让操作者有机会修订；之后只有在其已授权生图且会话确有可用图像工具时，主控才按同一提示词生成单张预览。生成结果必须实际查看，并标明是未批准候选。对话测试若明确不建项目，可保留在对话与会话状态；正式角色项目则按 `phased-design.md` 冻结依据、记录提示词/图片哈希、审图并由操作者批准后才转正。不能以工具返回图片或提示词约束替代视觉核对。

# 当前范围的具体设计标准

新建先形成角色的连贯设计决议，再把画面中可见的已选结果写入提示词。另一位设计师应能据此画出这一版人物，不靠模型补随机脸；不前置另一份长稿或typed对象。完整人物可以跨脸发、身体、衣装；头像只深化当前身份，局部只改相关结构。不用字段覆盖、字数、专家数替代设计质量。

| 域 | 要落实的内容 |
| --- | --- |
| 脸与五官 | 脸长宽与额角、太阳穴、颧弓、下颌角、颏的转折连接；眉、眼、可见耳、鼻、唇分别有形状、落点、骨软组织连接和必要相对比例。正面到45°保持同一人 |
| 头发 | 发际、分缝起点、人物左右、前侧后轮廓和体积、发流、长度与固定；名称后有实际结构，不靠碎发堆真实感 |
| 身体 | 完整身体给五组端点清楚的比例锚点；区分骨架、体重体块、重心与姿态，颅胸盆和关节接得上，动作与衣装余量成立。身高体重不代替比例 |
| 身份背景与多样性 | 当前采用的物种与人类族裔/混合背景明确且跨用途一致；未知或未设如实表达。肤色、发质、五官仍个体化，不以族裔标签替代结构，不将文化/地域/国籍等同血统 |
| 皮肤与妆饰 | 原生肤色／局部色差、镜头可见光泽肌理、稳定标记、可卸妆面和临时效果分层；已选件给位置形状强度、固定遮挡、状态起止，无妆无饰允许 |
| 服饰 | 主衣清单、廓形与衣层、领肩袖腰摆、重点衣片数量和形状、起止／叠压／闭合／固定、正侧背接续、动作余量、色块和材料物理，穿戴与道具接口有真实归属 |
| 差异与焦点 | 当前最易混淆的近邻、共享语言、具体可见差异、主锚点与安静区；未验证视角如实写未验证 |

设计成熟不只看参数具体：所选结构应回应本人物的呈现目标与条件，相关选择彼此相容，焦点与留白明确；共用服制内有意保持一致也可成立。把名字、职业标签替换后仍完全通用时，检查是否只有类目联想；不要为通过此检查刻意改坏统一服装。原创选择可以普通、克制或繁复，但要形成连贯形象和具体取舍；不能只说清秀、干练、自然垂落、结构清楚。重点衣物有结构巧思，不以多纹样／珠宝冒充改形。普通部位可以安静，但不是未设计。

例如“一件奶油白薄衬衫”可以进一步设计为：肩点略外移，窄软翻领停在锁骨上方，短后领座贴颈；窄门襟与两侧浅收省保持握笔抬臂空间；肘位微宽、袖口窄翻边可卷至小臂，侧缝下摆短开衩；细密平纹棉在肩保持形、腰侧出软折。它是示意创作，不是所有人的衬衫模板。脸发仍须同样具体，不因服装写长而省五官。

条件响应示例：同基地的训练制服与维修工作服可共享色域、领型和识别部位。若维修需要长期俯身、过顶抬臂及避免挂住设备，可选择让上背活动量经肩胛褶释放、腋下用活动片接续、袖口与带尾收住；训练服是否采用这些结构应由训练动作决定。不能只把“训练”换成“维修”而复用整段，也不能凭这些功能编出贫困身世或新阵营符号。此为方法示意，不是全员工装模板。

主控先用[人物方法](director-understanding.md)，再检查本次要求是否真的进入结果；明确比例和左右不能被通用fixture覆盖。本次所需结构直接在词里，理由/弃选不入画面正文；普通任务不另建方法采用记录、body_form或逐field证明。正式阶段仍按现有领域字段和来源批准规则，详情见[阶段](phased-design.md)及[接口](interfaces.md)。

提示词只取当前画幅可见的已选结果，按主次编译；允许同义与去重但不删结构。头像不强塞鞋背面，也不要求正常头肩把全脸毛孔／绒毛写满。详见[头像尺度](avatar-identity-granularity.md)与[提示词保真](prompt-detail-contract.md)。

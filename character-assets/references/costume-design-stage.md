# 服饰设计图阶段

在头像、九宫格和全身模卡全部批准后，按资产表 `states[].id` 逐一制作。每个状态一张独立图；同一状态的候选图可以多张，但只有一张成为当前批准版本。无状态角色使用 `base`。若年龄或严重外观变化同时改变脸/体型，先在设计卡明确基础身份连续性和例外，不让服饰图暗中重塑人物。

提示词包的 `stage` 为 `costume_design`、`variant_id` 为状态 ID、`variant_name` 与资产表名称一致，`anchor_images` 必须含已批准 `avatar`、`expression`、`full_body` 的 SHA。写清衣装层次、领肩袖、腰摆、缝线、闭合、材料厚度/磨损、主辅色位置、饰品固定、鞋履、动作余量；头脸和身体比例从三张基础图继承。妆面只取该状态设计卡已批准的面部层，明确起止场次。对露出前后结构的构图做可读说明；不要用漂亮海报替代可制作的服饰设计。背景默认为无叙事的中性底，除非已有明确批准。

回图审查逐项核对：状态 ID 与服饰对应；基础身份未变；前/侧/背关键信息足够交给执行图；面部标记和妆容状态连续；衣料及饰物实际可佩戴；没有新的剧情道具。批准后 `execution` 提示词把这张图作为**服饰锚点**，头像为身份锚点，全身模卡为比例锚点，表情图为表演锚点。服饰图重选只使本状态执行图失效。

# GPT Image 2.5 提示词转换

## 共同输入与输出

只从已批准的 `ProjectVisualBibleV1`、`CharacterDesignCardV1`、对应已定稿图片和当前阶段任务生成 `CharacterPromptPackageV1`。先整理完整结构化设计，再把**画面能呈现**的锚点写入提示词：脸部结构、发型、年龄感、体型、服装结构、材质、色块、配饰、姿态与取景。剧本背景、不可见心理和长篇人物小传留在设计卡，不塞进生图提示词。

提示词按“要生成/编辑的图 → 参考图各自职责 → 主体身份锚点 → 本阶段可变项 → 构图与光线 → 关键保留/禁改条件”组织。正向、具体地描述可见结果；只在模型容易混淆之处加简短限制。参考图要编号并说明用途，例如“图1固定面部身份，图2只借服装剪裁，不继承图2的人脸或场景”。不要宣称模型保证百分之百一致，结果必须回流审查。

首版只输出文字提示词和配套结构，不调用图像模型。目标标记为 GPT Image 2.5；快速候选与精修都可用同一设计锚点，但精修提示词要更精确说明改变与保留。官方图像提示指南建议先说明任务、主体、构图、风格与约束，编辑时分别写明改变和不变的部分；实际成图仍可能发生人物和排版漂移。

## 参考图职责与风格边界

新增素材中“动漫 PV 角色概念设计”与海报换角案例有可借鉴的方法：**分别标注人物身份、服装、材质、画风、光照、姿态与构图由哪张参考图控制**。在本插件中，已批准头像和设计卡控制人物身份；其他图只提供操作者指定的可见优点。风格图不能把它自己的角色、道具、色板和动作带入当前角色；海报图可启发构图或灯光，但不能自动更换服装。换装必须先在设计卡建立获批准的变体。

当全剧视觉基准已经批准 2D→3D 时，按[媒介转换知识快照](knowledge/character-image-prompt/hedgehog-2d3d.md)写提示词。人物本体的轮廓、五官比例、发型外形、标志与服装结构继续锁定，材质和光照才是本轮变量。不要把“高饱和动漫 PV 海报”“3D 电影海报”等案例风格设为所有项目默认。资产图阶段优先清晰、可核对的角色信息；戏剧化海报构图只有在操作者另行要求时才提出。

## 阶段要求

- **头像**：同一设计卡给 2–3 条候选，差异限于取景、微表情或光线力度；脸型、年龄、发型、标记、服装基本结构不漂移。适合外部生成的正面身份照先定稿。
- **表情**：以已定稿头像作强身份参考，读取 `references/expression.md`；给出 9/16 格、顺序和图内中文标签。不要引入新的妆容或年龄感。
- **全身**：用已定稿头像延展完整人物，**头到鞋均入画**；服装和身体比例按设计卡，检查脸部在全身尺度下仍能对应头像。
- **执行资产表**：用已定稿头像、表情与全身图作参考，读取 `references/execution-sheet.md`；人形严格指定四格、上下占比与左下无头裁切。非人读取设计卡中获批准的替代布局。

每个提示词包附 `reference_images`、非空 `acceptance_checks`、`design_card_sha256` 和 `anchor_images`（阶段名到当前已批准图片 SHA）。单独全身图明确 `head_visible:true`、`feet_visible:true`。不能用新的提示词覆盖旧版；只有新设计卡或已批准图片才可改变锚点。

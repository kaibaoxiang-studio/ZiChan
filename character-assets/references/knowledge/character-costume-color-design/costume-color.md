# 服饰配色专项知识快照

**适用**：全员深色、全员高饱和或同阵营角色色块相撞，设计卡只有“蓝色、红色”而无比例和材质位置。

1. 从项目视觉基准建立可用色域，再为单人写主色、辅助色、点色的实际部位、面积、明度、饱和度和材质影响。夜景与日景仍应可辨，不靠让每人拥有完全不同的色相。
2. 将关系与阵营的共享色放在共同部位；个人身份通过明度、饱和度、面积、旧化与邻近颜色等组合区分。必要时做去色和缩略图核对；去色后若完全失去身份，检查轮廓与结构轴。
3. 肤色、发色、服装和饰品应协同；不要用服装色掩盖两张脸的同质化。已有批准的伊阿宋等主角色彩按其设计卡为准，新角色避让或形成有理由的呼应。
4. 色彩心理词是叙事读法而非普世规律；“黑=威胁”“红=愤怒”等不能自动从人格推断。身份、时代与染料/材料可得性需要证据。

# 去油与脏糊的分级修图

**适用**：已有回图出现油光、蜡像质感、塑料衣料、脏纹、噪点或多轮涂抹。

1. 先实际查看目标图和审查报告，定位唯一要修的区域，同时保留身份锚点、服装结构、背景和头像原画幅。轻度油光可局部降低镜面白斑并恢复细微肤色与纹理；不能全脸磨平。
2. 轻度脏糊只清理伪影，保留自然相机颗粒和布料/皮肤微结构。外部工具若有智能超清/去噪，可在复制件上低强度试验；“强度 1”依工具量纲而异，不保证无损，也不代表插件执行了工具。
3. 严重涂抹可从已批准母图新开会话，或提议线稿/灰模重建；线稿会丢失身份和材料信息，必须用母图与设计卡重锚并整图重新审查批准。修改次数不设绝对阈值。

**证据位置**：《拒绝脸谱化人物设计-知识库.zip》M6-3、M6-4、M6-6、M6-7。课程中的“必然退化/彻底解决/100% 锁结构”不作保证。

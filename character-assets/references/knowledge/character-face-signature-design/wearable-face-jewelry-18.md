# 面部穿戴饰品部位规则

适用：眉、鼻、唇、颊等面部穿戴物。先区分贴附、夹持、穿刺与跨脸链条；没有剧本或设计理由时可明确无。
有物件时写准确附着点、左右、尺寸与离面高度、与五官和表情的遮挡、连接方式、可卸状态及多视角连续性。新穿刺或文化符号属于待审创作选择，不能据物件推断品德、性别、族群或阶层。
证据位置：原文第二至四节的位置与名称；第五至八节的高信息区、反例与验证。固定件数和人物类型公式不作为通用规则。

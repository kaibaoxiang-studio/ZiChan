# 头戴物与发饰部位规则

适用：角色状态涉及帽、额饰、发饰、遮面或头盔。先判断场合、功能与已定发型能否支持，再决定有或明确无；不因角色重要而加头饰。
有物件时写类别、人物自身左右、与发际/分缝/耳廓的固定点、覆盖范围、正面与45°及背面可见形状、动作中是否移位和佩戴起止。遮面不能无依据盖住已批准身份锚点。头发本体归发型专项，附着在头发上的物件归头耳颈饰专项。
证据位置：原文第二至六节的帽、额、发饰、遮面、头盔类别。第七节身份联想仅作候选检索，不作职业、阶层或性格的自动映射。

# 颈部穿戴物部位规则

适用：项链、领巾、项圈、围巾、挂坠及跨锁骨物件。先看领口、发片与场景行为，再决定佩戴或留空。
有物件时写围颈高度、闭合/系结点、垂坠最低点、与领口和发片的覆盖关系、可见角度、运动与取下时点。跨锁骨或剧情道具只指定一个主责，挂坠本体需要时对齐道具资产 ID。材质或图案不单独证明身份与财富。
证据位置：原文第二至三节类别、第四至五节设计锚点与反例；不采纳一人必有颈饰或按身份自动分配的规则。

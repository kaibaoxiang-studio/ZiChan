# 上身衣层与肩部部位规则

适用：主体上装、外套、可见中间层、内衬、衣身附着装饰及肩部附加件。连衣裙的上身是同一主衣的一部分，不另造一件上装。
先定每层从贴身到外层的顺序、开口/覆盖、衣长和下摆；衣身装饰说明所在衣片和固定方式，肩部区分本体肩线/垫肩与独立肩饰。剪裁专项接收领肩袖腰摆的连接需求，饰品专项只管附加物；没有外套或肩饰是可成立的决定。
证据位置：原文第二至五节的外套、内层、衣装装饰和肩部类别。第六节的职业/阶层推荐不作强制搭配。

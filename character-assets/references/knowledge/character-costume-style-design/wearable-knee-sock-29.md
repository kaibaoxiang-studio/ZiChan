# 膝胫护具与袜品规则

适用：膝/胫独立护具、袜、裹腿。护具与袜品是两类，分别决定有无；鞋内不可见袜不应占用出图提示词篇幅。
有护具时写覆盖关节、铰接或软性弯折、固定带、蹲跪余量；有可见袜品时写筒高、袜口落点、与裤脚/裙摆/鞋口的覆盖和滑落控制。按场景动作、季节与鞋型判断，不用身份模板自动搭配。
证据位置：原文第二至四节护具与袜品类别，第七至八节鞋袜和动作检查。

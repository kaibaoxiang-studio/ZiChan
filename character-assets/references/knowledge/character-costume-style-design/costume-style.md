# 服饰款式：把样式语汇转成当前人物的形

适用：只有“制服／婚纱／工作服”类别，或写了很多缝线但整体仍无设计。先接人物、项目美术方向、共享服制、当前状态和已定造型主张，再解决本次需要的轮廓、比例、衣层与穿法。以下是可选择、混合和转译的设计语汇，不是身份分类器或必填表。

## 可操作的形状与比例

| 形状关系 | 画面上意味着什么 | 可以怎样主动设计 |
| --- | --- | --- |
| H：肩、腰、摆接近同宽 | 连续竖直外轮廓 | 用短直身上衣配长直下装，或长直外层包住较短内层；用露出量改变分段位置 |
| A：上部收、下部展开 | 体积随高度下移 | 选展开起点和摆宽，决定由裁片、褶量还是层叠撑出；不必等同礼服或某性别 |
| X：中段收、上下展开 | 腰节形成明显转折 | 定收束高度及衣层如何跨过腰节；与宽肩、宽摆分别取舍，不强求细腰 |
| Y／T：上部横向展开 | 视觉重量偏上 | 定肩部来自本体肩线、袖体积还是叠层；下装可窄收或直落，避免全员垫肩 |
| O：中段膨、上下收 | 中央成圆钝体积 | 用离体松量、弧形裁片或束口产生形，而不是只写“宽松”；按动作与媒介控制幅度 |

形状可混合或局部使用；不从H/X等代号推出职业、性别、性格或历史归属。肩线相对肩峰、腰节相对身体、衣摆相对髋膝和袖口相对腕部的落点，必须能在人物上找到。比例说明用有端点的相对关系；数字只是当前选择，不因数字多就更好。

把“宽松”拆成肩、胸、袖、腰、摆哪处离体、哪处贴合；把“短”拆成前后摆落点及与裤腰／内层的覆盖。外轮廓先形成整个人的第一读法，结构线支持该读法，近景工艺再深化；不能以写满内部接缝替代整体选择。

## 衣层与穿法的对照语汇

同一白衬衫可以肩点贴肩、腰省轻收、下摆全收进高腰裤，形成一条连续收束线；也可以肩点下落、身片离体、后摆盖髋、内层从开襟露出，形成前后错落。它们是不同穿着关系，不自动代表银行职员或艺术家。

同一灰黑制服可保持领型、布料和组织识别一致，只在许可的合体比例、袖口收法、上下装分段和日常穿法上区别。若服制连这些都固定，就保留制服共性，由脸发、体态承担个体识别，不能强造个人专属裁片。

需要叠穿时写贴身层、主体层、外层实际谁盖谁，露出多少、在哪个开口可见、如何固定。内外层长短可以反向形成节奏；不默认三层齐备，也不为层次增加无意义背心、披风或腰带。隐藏层只有影响轮廓、透度、开口或动作时才需展开。

## 从reference到当前款式

可主动取参考的长短比例、开合方向、衣层覆盖、松紧对比和重复节奏，再重组为符合当前人物的形。借用“上短下长＋侧区回折”的关系，不等于照搬参考角色全套衣装，也不赋予参考中的阵营或身世。纯审美选择可以成立，无需编剧情解释；实际设定和用户已批范围仍全部保持。

先判断整体选择能否说清、能否画出，再检查动作和衣层是否相容；功能与美术共同成立，不能把美术永远推迟到功能写完后。文字核对只能证明方案可讨论，未有图不能报告剪影或近邻视觉辨识已通过。

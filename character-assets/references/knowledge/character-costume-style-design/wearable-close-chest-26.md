# 贴身层与胸腹挂载规则

适用：贴身层、胸腹防护/挂载及附着装饰。先判该层是否在当前镜头可见，或是否改变外衣轮廓、透度和活动；不为完整清单强迫描述不可见内衣。
有可见层或挂载时写贴身/中层/外层次序、领口与外衣的露出范围、胸腹固定点、左右连接、呼吸弯腰余量和与主衣的遮挡。身体痕迹不冒充衣装装饰；道具本体与挂载接口分主责。
证据位置：原文第二至六节贴身层、胸甲、战术挂载与胸腹装饰，第九至十节层次与动作检查。按性别/身份固定分配内搭不采纳。

# 下装主体与连体裙身规则

适用：裤、裙、裙裤及叠穿下装。先判独立下装还是连体主衣的一部分；连衣裙上身、腰、裙身、后片共享一个物件 ID。
写腰线起点、臀部余量、裙/裤体块与分片、裆或裙摆、长度终点、开衩/褶量、前侧背连续性和走坐抬腿余量。款式名称不能替代落点与连接；当前场景无需强行加第二层下装。
证据位置：原文第二至五节裤裙与叠穿类别，第八至九节动态、比例与反例；人物类型推荐只作可选名称索引。

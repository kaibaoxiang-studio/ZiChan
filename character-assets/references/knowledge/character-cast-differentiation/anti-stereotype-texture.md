# 非脸谱化群像比较

**适用**：同类型角色都用同一张“漂亮/英俊”均值脸，发型或服装换色后仍难辨。

1. 在真实同框和近邻比较组里先移除职业/性格标签，比较脸部结构、发块面、体型姿态、剪影和衣装色块；记录同型的具体部位，而不是给“脸谱化率”武断分数。
2. 优先通过有剧本/生活依据的结构组合和习惯性姿态区分，不按主配角分配美丑；亲缘、制服与叙事伪装可以有意相似，但写清可保持的区别。
3. 文本阶段只能报告“可能同型”；有回图才做缩略图、遮服装、并排头像/全身对照。没有图片不得声称观众已能区分。
4. 若设计层空泛，交 `character-design` 和相应专项补具体元素；若卡已具体而回图趋同，交图像审查/修图。回修不自动更改已批准卡。

**证据位置**：《拒绝脸谱化人物设计-知识库.zip》M1-2、M2-1、M2-2、M3-2、M3-3、M5-2、M6-0。课程中的“三秒”“分值通过线”和心理学因果未独立核实，不用作硬判据。

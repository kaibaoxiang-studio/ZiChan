# 群像差异化核心知识快照

**适用**：全剧轻规划、同框比较、近邻角色设计、头像与全身回图的群像复核。

1. 建角色 × 识别轴矩阵：剪影、脸部结构、体型/体态、发型块面、服装色块；可加材料、饰品、肤质，但后者不代替前五轴的结构问题。对非人按可见形态换轴。
2. 比较真实会同框或承担相似功能的人物。先圈出最易混淆的近邻，再看共享和区别；亲缘、阵营、制服允许有意共享。不要强迫 83 个角色每人拥有唯一颜色或标志物。
3. 有视觉证据时做缩略图、剪影、去色、遮挡服装和并排头像测试。无图只能评估设计文本的风险，不能声称观看者已能辨认。记下混淆的具体轴，回到相关专项修正。
4. 控制全员审美分布：不按主配角分配美丑、皮肤清洁或服装成本；有魅力者也可有鼻口比例、眼睑、发际与体态的差异。普通面孔应有完整设计，不靠“丑化”或疾病标签。
5. 识别点应与身份、经历、劳动、身体和世界规则有因果；仅作为装饰的极端差异不算解决。变化要遵循角色跨年龄/换装的身份连续性。

# 脸型名称到骨点设计

适用：头像身份阶段需要统一脸型称呼与可画轮廓。先用一个现代可理解的主类（如鹅蛋、方、圆、长、心、菱、梨），有必要时加一个形态亚型，再从额宽、太阳穴、颧弓最宽点、颧下转面、下颌角、颏底的顺序描述连接；正面与约 45° 都要能复现。传统字形可作检索别名，不能要求与现代分类逐格对应。比例只在测量端点明确且有辨识作用时加入，不能把整脸长宽和鼻根到颏的面部指数混用。脸型名称不决定性格、道德、职业或族群。

证据位置：原文第 2.2 节现代行业七型、第 2.3 节传统字形、第 2.4 节补充型与第 4 节互译。原文的性格映射和固定面部指数分档不作为真人角色的造型事实。

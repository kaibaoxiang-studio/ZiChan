# 妆容主名与施加层

适用：基础头像或剧情状态需要妆面。先定素颜（无可卸化妆施加）或裸妆（低覆盖、可卸的施加层），两者不能混称；再按底妆覆盖范围、眉、眼、腮、修容、唇的部位、边缘、色和光泽细化。是否有妆是设计决定，不默认按性别添加。基础妆面不得改变已批准的脸型、五官和原生肤色；婚礼、受伤、花妆等只进入对应状态。可选择无标记、无妆或无饰品，不为填类目添加元素。

证据位置：原文第 2.1 节底妆/眼妆/唇妆/装饰命名维度及第 2.2–2.3 节妆容表。原表将“裸妆/素颜”合并，本插件按可卸施加层分开；性格与身份妆容公式不采纳。

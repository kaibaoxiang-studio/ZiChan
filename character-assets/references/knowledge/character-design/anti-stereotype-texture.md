# 非脸谱化设计卡：从类型词到可画结构

**适用**：重点人形设计卡只有“清秀、漂亮、干练、衣服自然垂落”等概括句；十个专项的成果没有出现在最终设计稿。

1. 先列剧本可见事实、获批准选择与待审提案，再把抽象标签译为形状、部位、比例、连接、材料行为和动作余量。优先描述额颧颌、眉眼鼻口、发际与发流、骨架/重心、服装领肩袖腰摆、缝合闭合、布料厚度垂坠、色块落点和饰件固定。具体字段见 `references/design-detail-standard.md`。
2. 做“去标签测试”：删掉性格/颜值词后，另一位设计师还能否画出同一个人？若不能，回到对应专项提出 2–3 套有依据的可见方案。不要靠伤疤、怪色或廉价污损制造差异。
3. 十个专项逐项记 `used` 后采纳了什么，或 `not_needed` 的具体理由；已用专项如果只留下名称而没有设计元素，仍是缺项。主控把相互矛盾的发饰/领口/项链或皮肤/灯光约束合并后给用户审阅。
4. 工作卡保存完整设计，提示词按当前画幅只提最关键且可见的锚点。头像不塞鞋和背面细节；不把角色小传或未批准提案冒充视觉指令。

**证据位置**：《拒绝脸谱化人物设计-知识库.zip》M1-1、M1-3、M2-3、M3-1、M3-3、M5-1、M5-2、M6-7。原文的打分阈值、固定数量识别点与人格/五官因果仅视为课堂启发，不设机器门槛。

# 特征聚焦与自然的不完美

适用于重点角色设计、与近邻撞型、五官同时争抢注意力的草案。先写一句有剧本依据的角色处境或行为矛盾，再挑少量**可观察**的主锚点：部位、形状、位置、尺度、视角与状态。通常先试 2–3 个，但不是角色配额；其他细节可以完整设计，只是不在同一画幅内全部强调。

1. 先从原文与已批准设定继承身份不变量，再对照比较组。把“美、帅、灵动”转成具体的脸部结构、发流、体态或服饰连接。普通五官和不佩饰也可能是合理决定。
2. 给每个锚点注明正面、侧面、背面、头像、全身中哪些视角可见。剪影测试只评外轮廓；遮脸/遮衣测试用于找补充识别线索，不能要求每个视角单独识别。
3. 可在已有特征里保留轻微、自然、位置稳定的不对称或质地变化。不要自动添加伤疤、痣、胎记、纹身、脏污或疾病特征；这些须有剧本依据或操作者批准。不能把“缺陷”与某种人格或群体绑定。
4. 检查是否每个五官都被写成理想化高分项，是否所有角色共享同一漂亮模板，是否有太多设计元素同时抢焦点。给出保留、退为次要、删去的具体建议，不把 2–3 或“超过 5”当算法阈值。
5. 交付一句话辨识描述、主锚点、次要细节、允许的自然变化、近邻区分和未通过的视角测试。结构化方案仍须走专项提案与用户选择；不直接改已批准卡。

课程中的平均脸、注意力、共情因果论和动漫案例只能作设计启发，不能写成被本插件验证的心理学定律，也不把动漫夸张比例套到写实项目。

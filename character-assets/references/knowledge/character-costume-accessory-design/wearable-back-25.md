# 背部附加件与背负规则

适用：背包、背带、披挂和背部装饰。主衣后片、省道、后中开合由剪裁专项负责；独立背负或附着装饰由饰品专项负责。
有物件时写承重点、肩/腰固定路线、宽厚与重心、是否遮住拉链或后片、侧背可见轮廓、跑坐转身时的摆动。背影可以只靠主衣和发型成立，不要求重要角色必有背饰。独立道具本体对齐道具资产。
证据位置：原文第二至四节背负、背饰、披风分类，第七至八节反例与动态检查；不采纳重要角色必须有背部物件的要求。

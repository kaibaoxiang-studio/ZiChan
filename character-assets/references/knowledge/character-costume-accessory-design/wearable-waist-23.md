# 腰部结构、腰饰与挂载规则

适用：腰带/腰封、悬挂饰物、功能挂载和腰裙。先把主衣本身的腰线、省道、接缝与另戴腰件分开。
有独立腰件时写围绕高度、宽度、闭合点、与主衣的接触/压褶；有挂载时写人物左右、固定件、承重点、取用方向和动作摆动。道具本体归道具资产，服饰专项负责佩戴接口。无腰带也须让主衣腰部结构明确。
证据位置：原文第二至五节基础腰件、装饰、功能挂载和腰裙，第九节位置与动态检查。职业/阶级式自动配置和件数上限不采纳。

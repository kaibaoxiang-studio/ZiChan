# 服饰饰品：功能与审美共同设计

适用：衣身、肩背、腰、手或腿部穿戴物与当前衣装有关。头耳颈饰品归对应专项，跨区域物件由主控明确主责；剧情道具仍保留实际资产ID，不因佩戴方式把每颗扣子升级为道具。

饰品可以闭合、携带、礼仪、识别或承载已写情感，也可以只提供审美节奏、形状呼应、平衡、色材对比和视觉引导。普通装饰无需编身世或逐件审批，不把缺乏剧情功能视为一律删除的理由。先看整体是否需要，再在当前授权部位设计；无增益时不加也成立，不强制每人固定主饰或每区各一件。

## 可操作的关系

- 衣物已有大片连续色面时，可让一枚扁平长扣沿斜襟方向重复其角度，或用一个小圆环缓和周围锐角；明确它位于哪片衣物、相对领口／腰缝的尺度与固定方式。不自动赋予官阶或宗教含义。
- 粗织布上的暗哑同色木扣可以只留下弱轮廓；也可在项目允许的范围内用低面积磨砂金属产生局部材质反差。对比可以细微，不强求最亮、互补色或固定明度级差。
- 宽带与窄扣、疏密交替编绳、靠近／远离衣片边界、一个集中区与安静区，都能调节节奏。只有当前确需动态时才设计摆动、碰撞与收束，不为记忆点增加无用垂带。

采用物直接写形状尺度、人物自身左右、承载衣片、固定／闭合、材料与表面、与其他衣层的遮挡和动作表现。与脸发及主衣形成一体，不能让五个专项分别抢焦点。材料、时代、制造与维护应符合世界；“贵重=地位”“多饰品=某性格”不是事实。

已有剧情护符、徽记等按实际依据和状态使用；普通几何／纹样借用只是一种美术选择。若将它解释为新家族、宗教、军衔、能力或关系遗物，须有剧本依据或单独提出，不能从参考的形状移植故事。已批衣装或单域局部修改不因20%创新而开放其他部位重做。

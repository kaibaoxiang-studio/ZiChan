# 腿饰与腿部挂载规则

适用：大腿、小腿和踝部的独立饰件、束带或功能挂载。先问功能、可见性与下装遮挡，缺依据可明确无。
有物件时写左右、前外内后侧、距关节落点、固定/防滑结构、取用方向、下装覆盖及行走蹲坐时的稳定性。挂载中的独立道具本体归道具资产；性感、阶层、阵营联想不作为角色事实。
证据位置：原文第二至四节功能、装饰和位置，第七至八节动态与隐蔽检查；固定数量上限不作为普遍配额。

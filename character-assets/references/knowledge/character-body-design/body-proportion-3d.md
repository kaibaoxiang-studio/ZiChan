# 身体比例与三维体块

用于身体结构、体态、动作可行性或多视角不一致的角色。以写实世界规则和具体角色为先，不以 8–9 头身、长腿、腕过裆作为默认美型。课程引用的舞蹈选材厘米数、地域人口均值和固定形状人格对应未经本插件独立核实，不作为通用测量门槛。

1. 用**相对关系**说明头颈与肩、胸腔与盆腔、躯干与腿、上臂与前臂、大腿与小腿。若确需数值，写明测量口径、设计用途和证据，不能把艺术比值冒充人体事实。
2. 将颅腔、胸腔、盆腔作为可旋转体块，说明各自体积、倾斜、扭转与连接；四肢关节要有可信的起止点。前、侧、背三视角推演同一个人，而不是每视角重新拼比例。
3. 站姿说明双脚支撑、重心、肩胯关系和长期习惯；动作为剧本中确有需求的动作，核对关节活动、衣装余量、负重与体力。不要从体型直接推断道德、智力或人格。
4. 剪影、无细节体块拆解和关键姿态是三种不同检查。文本阶段只可提出可检验假设；未画视图/未见回图时标记未验证，不宣称通过。
5. 方案输出至少两个有差别的结构元素，并说明与最相近角色的体态区别。避免用夸张形体或不合理解剖换取差异。

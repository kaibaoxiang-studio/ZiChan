# 身体比例与三维体块

用于身体结构、体态、动作可行性或多视角不一致的角色。以写实世界规则和具体角色为先，不以 8–9 头身、长腿、腕过裆作为默认美型。课程引用的舞蹈选材厘米数、地域人口均值和固定形状人格对应未经本插件独立核实，不作为通用测量门槛。

1. 先定可复测的姿态与端点（例如去鞋正立、头顶至足底作全高），再写头高/全高、肩峰外缘/骨盆外缘、上段/下段、肘腕及膝踝的**明确比例或骨点关系**。上段/下段可用第 7 颈椎至臀纹与臀纹至足底，也可另选裆点体系，但两套端点不可混称“上下半身”。头身给约数或范围；其余可用数字，也可写“肘尖与自然腰线齐平”一类定位关系。“165cm、48kg、瘦高型”“腿较长但可信”只描述尺度或印象，不能替代比例。数值若来自设计提案，应标明待审并经操作者选择；不能从身高体重倒推，也不能把艺术比值冒充人体事实。
2. 将颅腔、胸腔、盆腔作为可旋转体块，说明各自体积、倾斜、扭转与连接；四肢关节要有可信的起止点。前、侧、背三视角推演同一个人，而不是每视角重新拼比例。
3. 站姿说明双脚支撑、重心、肩胯关系和长期习惯；动作为剧本中确有需求的动作，核对关节活动、衣装余量、负重与体力。不要从体型直接推断道德、智力或人格。
4. 剪影、无细节体块拆解和关键姿态是三种不同检查。文本阶段只可提出可检验假设；未画视图/未见回图时标记未验证，不宣称通过。
5. 方案输出至少两个有差别的结构元素，并说明与最相近角色的体态区别。提交设计卡时五组比例锚点均要具体；完整视觉描述与实际全身提示词应能逐项追溯。避免用夸张形体或不合理解剖换取差异。

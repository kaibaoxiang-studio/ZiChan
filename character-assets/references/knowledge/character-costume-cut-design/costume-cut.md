# 服饰剪裁专项知识快照

**适用**：服装款式已经选定，但穿在角色身上的结构、接缝、收放量、活动和正背面逻辑仍模糊。

1. 从目标体型和动作需求定肩线、领口开合、袖窿、腰线、侧缝、裙/袍摆及褶量。剪裁回答“衣服如何形成形状并随身体活动”，不重新决定款式品类。
2. 给重要结构写可画的走线、折叠、层次、闭合和受力位置，说明正侧背是否连贯。收腰或垫肩是视觉策略，不默认“显瘦显高”；角色本身的体型差异不应被统一修饰掉。
3. 将快速跑动、攀爬、航海、坐跪、盔甲负重等动作转成活动余量和磨损点。若设计与动作冲突，交主控在样式、制作与叙事之间选择。
4. 特定文化和时代的结构线只在可靠材料支持下使用；知识库中的历史样式作为检索起点。虚构服装可创造，但需讲清工艺和固定方式。

# 服饰材质专项知识快照

**适用**：服装像统一塑料、材质无法解释垂坠/磨损、角色生活环境和制作技术与衣物不相符。

1. 为每层服装记录纤维或硬质材料、织造/表面结构、厚薄重量、反光、柔韧、垂坠、触感和使用痕迹。材质与剪裁配合；不能只写“高级丝绸”“粗糙麻布”。
2. 由气候、行动、资源、维护能力推导材料组合，保留剧本事实与提案区别。衣角、肩、肘、膝、鞋底等磨损位置要与动作接触相合；贫穷不等于全身脏，富裕不等于处处发亮。
3. 与服饰配色专项协同：同一颜料在亚麻、皮革、金属上的明度和反射不同，图像提示词需写清表面。与饰品专项协同固定件、金属与纺织物的重量连接。
4. 涉及古希腊或其他时代的纤维、染色、加工技术，另查文物或研究来源；课程中的“贵族穿丝/农民穿粗布”等跨时代断言不可直接移植。

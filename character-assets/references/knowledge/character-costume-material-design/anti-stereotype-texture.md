# 服装材料的可见物理行为

**适用**：服装只写“薄衬衫、自然垂落、真实材质”，成图像塑料或各衣层同一反光。

1. 按衣层写纤维/皮革/金属类别与可见织法、厚度、表面粗糙度、折痕、重量下坠与局部磨损；描述领肩袖腰摆的受力，材料要和剪裁结构相互支持。
2. “细密毛呢的短绒”“平纹旧棉的软折”等是部位级表达示例，不是所有服装默认材料。磨损、灰尘、汗渍须有生活或剧情依据；饰件金属、皮革和布料的反光层级分开。
3. 回图看是否出现不可能的悬空褶皱、统一漆面或无结构的脏纹；若设计卡材料未确定，先提案批准，不在提示词里临时发明。

**证据位置**：《拒绝脸谱化人物设计-知识库.zip》M6-2、M6-4、M6-6、M6-7。与服饰材质专项既有快照配合，课程材料词不代表经实物考证。

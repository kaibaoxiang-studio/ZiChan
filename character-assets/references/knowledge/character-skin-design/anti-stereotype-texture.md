# 真实皮肤的设计层与渲染层

**适用**：肤色和质感被写成“无瑕真实皮肤”，或回图出现全脸发亮、蜡像磨皮、砂纸式过量毛孔。

1. 设计卡写稳定的肤色基底、额鼻颊之间的轻微色差/光泽差、微纹理分布。年龄、劳动、妆容和环境影响要有证据或批准，临时汗泥血另作状态，不写成身份事实。
2. 生图只强调当前镜头看得到的少量肌理，如颊侧细微毛孔、额头柔和明暗、鼻翼局部光泽；`matte skin` 和 `low specular highlights` 是针对过强镜面高光的可选词，不使皮肤变成无反射粉墙。过强次表面散射可能带来不自然红色，按媒介和回图判断。
3. 审查放大看鼻梁/颧骨/额头高光、纹理是否随结构变化、是否有统一磨皮或假颗粒；仅凭提示词不能宣称已解决。

**证据位置**：《拒绝脸谱化人物设计-知识库.zip》M4-1、M6-0、M6-1、M6-2、M6-6。与《皮肤肌理与质感知识库》既有快照互补，避免把“可见毛孔”理解为全脸强锐化。

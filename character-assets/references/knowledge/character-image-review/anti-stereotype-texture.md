# 设计空泛与渲染失真分层审查

**适用**：角色回图看起来“油”或“脸谱化”，需要明确是设计卡本身还是图片执行失败。

1. 对照设计卡先检查脸/发/体态/服装结构是否足够具体、图片是否执行。卡空泛须回设计批准；卡具体而图片同脸、过度美化或漏了衣装构造，属回图偏差。
2. 再看渲染层：鼻梁/颧骨/额头是否出现镜面白斑；自然纹理和肤色细微变化是否存在；布料/金属/皮革是否各有厚度、褶皱与反射；光位与肤色是否相容；边缘是否脏糊或涂抹。
3. 纪实轻微相机颗粒不等于脏图；“无颗粒”只用于需要洁净资产底图或有伪影时。缺少图片只能写“未执行视觉检查”。头像还要核对默认 3:4 竖版或明确用户覆盖依据。

**证据位置**：《拒绝脸谱化人物设计-知识库.zip》M5-2、M6-0、M6-1、M6-2、M6-3、M6-7。原课程评分、必然因果和“200% 一定可判”等仅供人工参考。

# 剧本理解、证据与决策边界 v0.2.5

## 来源与阅读范围

标准剧本是事实依据；资产表提供稳定角色 ID、别名、层级、状态和索引；场记可选，用于表演、镜头和出场语境校对。冲突时列各自来源，暂停受影响选择，不以资产表或成图悄悄覆盖原文。用户明确改变原作设定时，记录获授权改编决定并保留原文关系。

JSON 优先，再读 Markdown，最后 Excel；行号、表格位置、JSON 场集 ID 与源文件 SHA 保持关联。全文阅读覆盖按 [总控方法](director-understanding.md) 执行：先读全剧再检索人物，长文分批，已读内容按哈希复用。`context-units` 只列阅读单元；覆盖声明应与本版本全部单元一致，未读完不能宣称全剧理解。

只有剧本、片段或小传也可以先分析人物和给设计方向，说明范围；正式资产链仍要求项目输入和稳定角色索引。知识库人物与示例都不是当前剧本事实。

## 人物判断与四类陈述

联读不同时点的言语、行动、选择、关系与后果；区分自述、他人评价、旁白和可见行为。评价可能不可靠，行为也可能受胁迫或策略影响；保留矛盾并解释，不选一条标签覆盖人物。区分弧线起点、变化和终局，以及角色知道的真相与观众当前信息，避免后续秘密提前外显。

1. **原文事实**：有 `source_refs`；某人称其冷酷只证明该评价存在，不自动证明客观人格。
2. **保守推导**：有 `basis_refs`，写事实到生活机制的中间关系；不是唯一结论时说明不确定。
3. **创作推荐**：主动填补未写的脸、发、形体与衣装；明确是选择，不为每个部位伪造剧情原因。
4. **已批准选择**：记录确认人、版本、理由和范围；方向批准不等于完整设计卡批准。

普通痣、极淡雀斑与自然不对称可随身份首稿审阅，不默认编造经历。显著伤疤、纹身、宗教组织符号、身体装置等无依据时，显式列有剧情影响的提案。没外貌原文不代表不能创作；缺失会改变身份、剧情或方向的关键信息才集中提问。

参考图拆出身份、剪裁、材质、配色、风格或气质的提取点，不整体照搬。意外成图细节进入 `adoption_proposals`；preview 首稿细节通过阶段快照确认，同图转正见 [阶段设计](phased-design.md)。

## 来源变更与守护

- ID 与资产表一致，不因相似合并人物，不自动新增剧本不存在的角色。
- 事实有来源、推导有机制、创作有声明；身份不变量、状态和禁改项有来源或确认。
- 世界、关系、生活和叙事策略变更先分析影响；不机械使全员失效，也不在未补读影响内容时断言无影响。
- 资产表变化可按角色定位；剧本/场记变化须检查新增单元及前后因果，`pending_impact` 未解决时不得发布。
- 短暂情绪、单场动作、轻微脏污不自动新建角色资产；显著年龄、换装或形态变化按状态索引管理。
- 历史批准有效；升级不将旧设计自动改为模型新理解。修改批准身份仍做版本和影响审查。

完整来源与阅读覆盖合同、结构且未决为空的context自动ready，系统只确认source-coverage-and-structure，interpretation_confirmed:false；不增加用户审批。未决非空先复核，人物解释在方向稿集中确认。CLI不能替代人物解释、跨场分析或实际看图。

# 交付：嵌有实际图片的资产表

“最终资产表、已有图插表、嵌图汇总、整理交付”首先是成果整理任务。复用当前资产表/清单、稳定ID、状态和实际图，不重提取资产、不重做美术基准/角色设计、不重建运行台账，也不为入表自动审图、返修或补图。仅缺映射资料时针对该缺口核对，不回读整剧重开创作。尚在执行的其他已授权任务不由此取消，但整理现有图片不必等它们全部完成。

角色单领域委托只汇总角色；明确跨资产整合时，可汇总角色、场景、道具的已有清单与图片，不因此调用其他领域设计。提示词文档、图片目录、路径JSON和CLI角色包都不能替代所需XLSX。

## 定位、状态与完成度

- 使用稳定资产ID、状态ID和阶段定位，不靠姓名或行号猜测；角色头像、表情、全身模卡与状态执行分别对应独立列或可核对行。群像/群演沿真实交付阶段，不虚构前三图。无正式ID的独立稿沿用现有本地标识，不制造正式登记。
- 只列存在的图片路径并核实际内容/可选哈希；有多个候选而未指定选图时，沿用现有选择；仍有歧义则保留可区分候选与状态，不能擅自选成正式图。
- 已生成且待用户确认的图可以直接嵌入进行中表，逐行标“待用户定稿”或现有真实状态。用户未要求审图，不新增模型审图报告；嵌入不构成批准，已有失败/过期标记不清除。正式批准仅承接真实用户确认。
- 缺图行保留并明确“缺图”；先把已有图入表，不交空白图片列冒充已嵌入。报告资产行数、实际嵌图数、缺图及待定数；整剧委托仍有缺口时标“进行中”，不能宣称全部完成。所有要求图片齐备但未定稿时，可说“图片已嵌齐，待用户定稿”，不能混淆完成度与批准。

## 工作簿和原生单元格图片

已有XLSX时在副本中加入图片列，保留原工作表、字段、行序、非图片数据与已有图片；不覆写上游原件。只有JSON/Markdown清单而需要工作簿时，按相同资产ID、状态ID、状态名建立XLSX。图片列名写清用途，完整图片不得遮挡文字或相邻单元格。

最终XLSX的图片须为**真正单元格内图片**，字节随文件保存。只有路径、外部URL公式或覆盖在格子上的drawing/anchor浮图，即使设为随单元格移动和缩放也不合格。支持原生cell image的表格工具可直接使用；若工具仅支持浮图则换合适导出方式，不以浮图假冒。

新建工作簿可用本包脚本（需要支持`embed_image`的XlsxWriter及Pillow）：

```sh
python harness.py asset-workbook --input /work/asset-table-input.json --output /delivery/资产表_进行中.xlsx
python harness.py asset-workbook --input /work/asset-table-input.json --validate-workbook /delivery/资产表_进行中.xlsx
```

最小输入为`AssetWorkbookInputV1`，沿真实已有清单机械映射即可，不让用户重填一轮设计资料：

```json
{
  "schema_version": "AssetWorkbookInputV1",
  "rows": [
    {"asset_id": "CHR-001", "state_id": "S01", "stage": "execution", "name": "现有人物", "status": "待用户定稿", "image_path": "/actual/generated-image.png"},
    {"asset_id": "CHR-002", "state_id": "S01", "stage": "execution", "name": "现有人物二", "status": "缺图"}
  ]
}
```

同一三元键`asset_id/state_id/stage`不得重复；该脚本不替用户从同阶段多候选中选图。优先沿用既有选图；若仍不能唯一定位，保留候选清单和未决提示，另用支持多图单元格布局的表格工具，不能制造资产ID或虚构阶段来绕过冲突。可选`image_sha256`核图文件版本。输入附加业务字段保留为列，不能丢现有信息再声称保真。脚本**不编辑既有XLSX**；声明`existing_workbook`会受控拒绝。已有表格需按前述副本规则使用可保真的表格工具，不能偷偷降成新表。脚本验证不等于目标Excel界面已实测。

## 交付前只核表格结果

保存后重开文件，核图片单元格与资产/状态/阶段对应、图片数和缺口计数、原始非图片数据与其他工作表。对Excel原生格式核包内图片字节及图片单元格rich-value关系；只有drawing关系不算通过。有目标表格界面时再看图片单元格的呈现、行列调整与筛选，未实际运行不虚报通过。这是导出正确性检查，不重新审核图片审美，不重跑生图。

若当前环境无法生成或核验所需单元格图片，准确说明具体阻碍，将该工作簿标待完成；不要把路径清单、浮图版或“已打包”称作最终有图资产表。

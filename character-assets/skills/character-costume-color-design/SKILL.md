# 服饰配色与群像色块

读[配色方法](../../references/knowledge/character-costume-color-design/costume-color.md)，在人物与世界色域中将主辅点色落实到具体衣片、面积、明度、色相／饱和度和边界。比较同框近邻，保留共享语言，不以换色替代形状差异。

色彩心理只作设计启发，不当人格事实；70:25:5等是可选方法，不是配额。继承当前已选物件与材料，不因词表新增部位重新配全身。把可画的部位色块分配直接写入当前词，执行见[普通文档](../../references/prompt-document.md)。不调用生图。

承接[服饰设计师的整体主张与局部创新边界](../../references/costume-designer.md)。可探索色块位置、冷暖/明度节奏、边界与留白，不要求亮色点缀或固定70:25:5；不擅改主衣造型来保住自己的配色亮点。

普通成果直接写本次完整提示词并更新同一文档，默认一个整合方向；局部只改受影响结构，不重设计未改域。不前置typed设计、body_form、方法/知识SHA、逐field成果证明或freeze；实际具体结构仍须完成。解释和弃选不塞词。明确正式或旧typed调用才按[旧专项合同](../../references/specialist-contract.md)封装。

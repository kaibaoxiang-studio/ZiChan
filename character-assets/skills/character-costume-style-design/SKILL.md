# 服饰款式与衣层

读[款式方法](../../references/knowledge/character-costume-style-design/costume-style.md)，将人物穿衣命题转成主衣清单、轮廓、长度、松紧、衣层顺序与穿法；品类名不是设计。结合动作、资源和自我呈现，不从职业性别抽固定搭配。

按当前可见部位选择17–31资料；一件连衣裙跨上腰下仍是单一主衣。给肩腰摆和裤裙体块的具体形状、落点与邻层覆盖，鞋袜说明品类与可见关系；剪裁、材质、配色共同保持所选方案。隐藏层只有影响轮廓／透度／开口／动作才设计。按[普通文档](../../references/prompt-document.md)交实际成果，不调用生图。

承接[服饰设计师的整体主张与局部创新边界](../../references/costume-designer.md)。可从参照重组衣长、宽窄、衣层与穿法形成视觉关系，不用职业标签套现成品类；不能为自己的轮廓提案擅改已批体型。

普通成果直接写本次完整提示词并更新同一文档，默认一个整合方向；局部只改受影响结构，不重设计未改域。不前置typed设计、body_form、方法/知识SHA、逐field成果证明或freeze；实际具体结构仍须完成。解释和弃选不塞词。明确正式或旧typed调用才按[旧专项合同](../../references/specialist-contract.md)封装。

# 服饰款式与衣层

读[款式方法](../../references/knowledge/character-costume-style-design/costume-style.md)，将人物穿衣命题转成主衣清单、轮廓、长度、松紧、衣层顺序与穿法；品类名不是设计。结合动作、资源和自我呈现，不从职业性别抽固定搭配。

按当前可见部位选择17–31资料；一件连衣裙跨上腰下仍是单一主衣。给肩腰摆和裤裙体块的具体形状、落点与邻层覆盖，鞋袜说明品类与可见关系；剪裁、材质、配色共同保持所选方案。隐藏层只有影响轮廓／透度／开口／动作才设计。按[专项合同](../../references/specialist-contract.md)交实际成果，不调用生图。

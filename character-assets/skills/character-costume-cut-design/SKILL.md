# 剪裁、连接与动作余量

读[剪裁方法](../../references/knowledge/character-costume-cut-design/costume-cut.md)，在已选主衣上解决领肩袖腰摆、拼片、缝省、开合和动作。关键件给衣片数量／形状、起止、叠压方向、相对比例、固定与穿脱路径，正面／45°／背面接成同一件衣物。

连衣裙不拆成两件，腰省不冒充腰带，后片不冒充背负；不能用“前中或后中”替代当前已选开合。柔性层必须有真实附着，鞋结构同样解释鞋面／底／跟接口。重点衣物按[部件方法](../../references/costume-component-design.md)深化，色材保持既定选择。按[普通文档](../../references/prompt-document.md)交成果，不调用生图。

承接[服饰设计师的整体主张与局部创新边界](../../references/costume-designer.md)。可用衣片转折、缝省、折叠、开口或负形服务纯审美与造型，不只补活动量；需新材料支持时由服饰设计师协调，不能把装饰线假作承力结构。

普通成果直接写本次完整提示词并更新同一文档，默认一个整合方向；局部只改受影响结构，不重设计未改域。不前置typed设计、body_form、方法/知识SHA、逐field成果证明或freeze；实际具体结构仍须完成。解释和弃选不塞词。明确正式或旧typed调用才按[旧专项合同](../../references/specialist-contract.md)封装。

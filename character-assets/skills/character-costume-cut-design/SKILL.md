# 剪裁、连接与动作余量

读[剪裁方法](../../references/knowledge/character-costume-cut-design/costume-cut.md)，在已选主衣上解决领肩袖腰摆、拼片、缝省、开合和动作。关键件给衣片数量／形状、起止、叠压方向、相对比例、固定与穿脱路径，正面／45°／背面接成同一件衣物。

连衣裙不拆成两件，腰省不冒充腰带，后片不冒充背负；不能用“前中或后中”替代当前已选开合。柔性层必须有真实附着，鞋结构同样解释鞋面／底／跟接口。重点衣物按[部件方法](../../references/costume-component-design.md)深化，色材保持既定选择。按[专项合同](../../references/specialist-contract.md)交成果，不调用生图。

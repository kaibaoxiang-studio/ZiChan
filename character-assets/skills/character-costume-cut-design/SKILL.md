# 服饰剪裁设计：结构线、连接与活动余量

读取 [专项交接](../../references/specialist-contract.md)、[群像差异化框架](../../references/differentiation-framework.md) 与本专项知识快照。在选定款式上解决肩线、领口、袖、腰、摆、褶与闭合；让前侧背结构一致且动作可行。读取总控的 DesignDirectionBriefV1、当前阶段任务、已有视觉基准与最近比较组；没有项目时可直接接人物材料，注明草案与材料范围。先回应任务目标、人物语境、约束和所需成果，默认一套推荐，仅重要分歧增加备选，每方案列至少两个部位、形状、位置/连接和依据明确的设计元素，供设计卡实际采纳；明确原文事实、合理推导、创作选择、制作核对点及与近邻的差异。把人物未写明的外观当作需要设计的空白；无须编造身世证明某种脸型。常规项可由总控同轮执行本 Skill 的规范并记录 inline 成果；独立会诊记录 independent 原始返回物。新特征仍是待审设计，不能自行批准。提案包含当前 variant_id；新独立提案提交 CharacterSpecialistProposalV1.2 JSON 与短 Markdown，执行 scripts/validate_specialist_proposal.py；旧 V1/V1.1 仍可回读；不调用生图。

接收主衣物件清单，按 [穿戴部位拆解](../../references/costume-wearable-zones.md) 写领口、肩线、袖窿、胸腰省、腰臀连接、前后衣片、裙裤体块、裙摆与鞋的可画结构；每处给落点、形状、连接/开合和动作余量。连衣裙跨上身与裙身仍是一件衣物，后中拉链在正背描述中位置一致。腰省不是另戴腰带，肩线不是肩饰，后片不是背负装备；不可用“开合位于前中或后中”覆盖本状态已选的具体开合。配色与材质保持既定方案。

对重点服装的每个关键部件按 [物件级细节规则](../../references/costume-component-design.md) 交衣片数量、起止缝、边缘形状、相对比例、固定件与穿脱顺序；柔性裙层须有腰/侧/背的真实附着路径，不能悬浮或仅在正面存在。正面主结构、约45°侧片与背后开合应对应同一件衣服。

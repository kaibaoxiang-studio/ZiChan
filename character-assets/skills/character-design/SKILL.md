# 角色设计

先读 [知识索引](../../knowledge/index.md)，按情景只加载本轮需要的 reference。

读取 [角色方法](../../references/character-design.md) 和 [服装与形态](../../references/costume-and-morphology.md)。先依据世界规则提出视觉基准供操作者确认，再调用群像差异化总控建立全员轻规划。重点角色逐轮给有依据的 2–3 个具体方向；记录已确定、待选和已委托事项，不能把单一画风选择扩大成外貌定稿。默认检查发型、体型、五官是否落入全员美型模板；按实际缺口加载对应专项知识，近邻角色并排比较，保留普通相貌和真实皮肤的可能。先写可复核的专项路由；按具象标准把十一专项的已采用结果或不启用理由写入设计稿，used 必须提交真实提案文件及被选方案。提交重点人形卡用 CharacterDesignCardV2.2，记录特征主次、自然不对称决定与三维体块/动作核对；新提交的人形卡还要给五组可追溯的身体比例锚点。设计卡区分原文事实、推导、参考图提取优点与已批准选择；仅明显换装、年龄或严重外观变化建变体。非人角色按形态改执行参考板。提交 JSON 草案；未解决项清空后请操作者批准。

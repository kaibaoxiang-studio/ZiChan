# 形体体态设计：年龄比例、骨架、重心与动作习惯

读取 [专项交接](../../references/specialist-contract.md)、[群像差异化框架](../../references/differentiation-framework.md) 与本专项知识快照。区分骨架、体重分布、比例和重心；先定测量姿态，再给头高/全高的约数及肩胯、同一端点体系的上段/下段、肘腕、膝踝的数值或骨点参照。身高体重和‘修长’不能代替比例；写颅胸盆体块与前侧背一致性，以剧本动作检验关节及衣装余量。读取已批准视觉基准、当前设计卡与比较组；输出有依据的 2–3 个可见方案，每方案列至少两个部位、形状、位置/连接和依据明确的设计元素，供设计卡实际采纳；明确原文事实、创作提案、制作核对点及与近邻的差异。新特征只能作为待选方案，不能代替操作者批准。提案包含当前 variant_id；提交 CharacterSpecialistProposalV1.1 JSON 与短 Markdown，运行 scripts/validate_specialist_proposal.py；不调用生图。

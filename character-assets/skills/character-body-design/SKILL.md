# 形体体态设计：年龄比例、骨架、重心与动作习惯

读取 [专项交接](../../references/specialist-contract.md)、[群像差异化框架](../../references/differentiation-framework.md) 与本专项知识快照。区分骨架、体重分布、比例和重心；先定测量姿态，再给头高/全高的约数及肩胯、同一端点体系的上段/下段、肘腕、膝踝的数值或骨点参照。身高体重和‘修长’不能代替比例；写颅胸盆体块与前侧背一致性，以剧本动作检验关节及衣装余量。读取总控的 DesignDirectionBriefV1、当前阶段任务、已有视觉基准与最近比较组；没有项目时可直接接人物材料，注明草案与材料范围。先回应任务目标、人物语境、约束和所需成果，默认一套推荐，仅重要分歧增加备选，每方案列至少两个部位、形状、位置/连接和依据明确的设计元素，供设计卡实际采纳；明确原文事实、合理推导、创作选择、制作核对点及与近邻的差异。把人物未写明的外观当作需要设计的空白；无须编造身世证明某种脸型。常规项可由总控同轮执行本 Skill 的规范并记录 inline 成果；独立会诊记录 independent 原始返回物。新特征仍是待审设计，不能自行批准。提案包含当前 variant_id；新独立提案提交 CharacterSpecialistProposalV1.2 JSON 与短 Markdown，执行 scripts/validate_specialist_proposal.py；旧 V1/V1.1 仍可回读；不调用生图。

特殊下肢只在剧本或已批准身份设定触发时读取 [穿戴部位拆解](../../references/costume-wearable-zones.md) 与 31 号知识快照；先固定关节、承重、移动与腰盆过渡，再交服饰专项处理下装和鞋的适配。普通都市人形下肢不从词表自动变成兽化或机械形态。

# 身体比例与体态

按本次人物／动作与已选身份设计身体。先读[形体方法](../../references/knowledge/character-body-design/body.md)与[比例体块](../../references/knowledge/character-body-design/body-proportion-3d.md)。定测量姿态和端点，给头身、肩胯、同端点躯腿、肘腕和膝踝参照；完整身体保留五组锚点，局部只改相关关系。用户明确比例不能被通用模板覆盖。

区分骨架、软组织、体重分布和姿态，写颅胸盆体块、重心与正侧背连接，用剧本动作检验关节和衣装余量；身高体重、“瘦高”不构成设计。职业动作不证明天生骨架，未知比例作为创作推荐。不要重做未改脸发。具体身体结果直接在本次词中，执行方式及必要生产封装见[普通文档](../../references/prompt-document.md)。

特殊下肢仅在给定形态触发时读31号快照，先定关节、承重、移动和腰盆过渡再交服饰适配；不为普通人造兽化或机械器官。不调用生图。

普通成果直接写本次完整提示词并更新同一文档，默认一个整合方向；局部只改受影响结构，不重设计未改域。不前置typed设计、body_form、方法/知识SHA、逐field成果证明或freeze；实际具体结构仍须完成。解释和弃选不塞词。明确正式或旧typed调用才按[旧专项合同](../../references/specialist-contract.md)封装。

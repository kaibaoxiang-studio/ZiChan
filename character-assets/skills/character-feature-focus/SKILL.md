# 特征主次与辨识

读[聚焦方法](../../references/knowledge/character-feature-focus/feature-focus.md)。从人物处境与观众读取提出辨识命题，比较近邻，在已有形状、比例、发流、衣装或动作中选择主锚点与安静区。其余部分仍具体设计，不能以次要为由删已选入画结构。

注明当前画幅及正侧背可见性，指出同质化和互抢焦点的地方，给保留、退为次要、改哪里的一套推荐。自然不对称是可选方法，不自动加痣、伤痕或极端比例；未实际看图不报剪影／遮挡测试通过。需要群像时再读[差异化框架](../../references/differentiation-framework.md)，交付按[专项合同](../../references/specialist-contract.md)。不调用生图。

# 明确请求时的精确修图

生成后默认直接交用户看，不自动审图、修补、复核或重跑。只有用户明确要求修改目标图片时读取[修图方法](../../references/editing.md)；只要修图词则交词，不代表授权实际生图。

实际查看目标图、当前完整词及实际参考，明确图的职责、指定格位/区域、唯一改变、其余身份/结构/状态/布局保持。错字只改指定标签，左下残头只修指定裁切与相邻连接；不承诺像素级保持。执行图遵守[完整四格](../../references/execution-sheet.md)，不能借局部请求换横板或重新设计未改部分。

修改结果直接交用户，不自动再审查或再生成；用户另行明确要求审图才调用相应能力。试改不覆盖正式active或旧批准，用户决定采用后沿实际接口登记；不扩大为全链重做。

# 精确修图

先读 [知识索引](../../knowledge/index.md)，按情景只加载本轮需要的 reference。

读取 [修图方法](../../references/editing.md)、对应设计卡、选定头像、目标图与审查问题。提示词明确目标格位/区域、唯一改变、保持不变的身份与其他已正确内容、回图核对点。参考图只借操作者指定的优点。文字标签错字只修对应格，不重画脸；无头服装格残留头部只修裁切与相邻服装区域。不能承诺像素级保持。修改图回流后仍走审查与操作者批准；想采纳意外新细节先更新设计卡。

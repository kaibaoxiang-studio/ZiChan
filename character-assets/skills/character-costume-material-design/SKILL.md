# 服饰材质设计：重量、光泽、垂坠与磨损

读取 [专项交接](../../references/specialist-contract.md)、[群像差异化框架](../../references/differentiation-framework.md) 与本专项知识快照。为各衣层写材料及物理表现，检查气候、行动、资源和制作技术相容，拒绝统一塑料感。读取总控的 DesignDirectionBriefV1、当前阶段任务、已有视觉基准与最近比较组；没有项目时可直接接人物材料，注明草案与材料范围。先回应任务目标、人物语境、约束和所需成果，默认一套推荐，仅重要分歧增加备选，每方案列至少两个部位、形状、位置/连接和依据明确的设计元素，供设计卡实际采纳；明确原文事实、合理推导、创作选择、制作核对点及与近邻的差异。把人物未写明的外观当作需要设计的空白；无须编造身世证明某种脸型。常规项可由总控同轮执行本 Skill 的规范并记录 inline 成果；独立会诊记录 independent 原始返回物。新特征仍是待审设计，不能自行批准。提案包含当前 variant_id；新独立提案提交 CharacterSpecialistProposalV1.2 JSON 与短 Markdown，执行 scripts/validate_specialist_proposal.py；旧 V1/V1.1 仍可回读；不调用生图。

重点服装按 [物件级细节规则](../../references/costume-component-design.md) 对已经定形的主衣、外层、扣件和纹样载体逐件给厚薄、透度、表面反射、折痕与运动表现；材质选择不偷偷新增花边、珠片或新衣片，配色未授权变更时保持已确认固有色。

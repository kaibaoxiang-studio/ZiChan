# 材质分区与物理表现

读[材质方法](../../references/knowledge/character-costume-material-design/costume-material.md)，把材料选择落到各衣层／部件的厚薄、重量、织面、透度、反射、垂坠和动作表现，解释连接和边缘如何受力。磨损遵循真实接触与维护，不以阶层加统一污纹。

保持已选轮廓和配色，材料差别不能只靠“高级质感”；重点件说明材质分区与纹样载体，平面印花不冒充浮雕饰件。按[普通文档](../../references/prompt-document.md)交具体结果；质感伪影出现时才读对应纹理规则。不调用生图。

普通成果直接写本次完整提示词并更新同一文档，默认一个整合方向；局部只改受影响结构，不重设计未改域。不前置typed设计、body_form、方法/知识SHA、逐field成果证明或freeze；实际具体结构仍须完成。解释和弃选不塞词。明确正式或旧typed调用才按[旧专项合同](../../references/specialist-contract.md)封装。

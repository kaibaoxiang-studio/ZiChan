# 衣身与四肢穿戴物

读[饰品方法](../../references/knowledge/character-costume-accessory-design/costume-accessory.md)，主衣确定后判断肩胸背、臂手腕腰腿的独立穿戴／挂载。无物件可为完整决定，不因仪式、词表或专项存在而加饰。

采用件给形状尺度、人物左右、挂点、承重／晃动、固定拆装、邻衣遮挡、视角和状态起止；道具本体与服饰接口共用真实道具ID。耳颈归头耳颈专项，缝省和衣片归剪裁；跨区唯一主责。戒指依仪式时点，旧物摘除只约束那件旧物，禁大型珠宝不自动全禁。

重点扣件按[部件方法](../../references/costume-component-design.md)写部件与连接，不能悬浮；知识快照只按当前部位加载。按[专项合同](../../references/specialist-contract.md)交成果，不调用生图。

# 服饰饰品设计：衣身、腰、手与随身穿戴物

读取 [专项交接](../../references/specialist-contract.md)、[群像差异化框架](../../references/differentiation-framework.md) 与本专项知识快照。处理锁骨以下饰品的功能、固定、重量与道具 ID；跨锁骨物件与面部饰品专项只指定一个主责。读取已批准视觉基准、当前设计卡与比较组；输出有依据的 2–3 个可见方案，明确原文事实、创作提案、制作核对点及与近邻的差异。新特征只能作为待选方案，不能代替操作者批准。提交 CharacterSpecialistProposalV1 JSON 与短 Markdown，运行 scripts/validate_specialist_proposal.py；不调用生图。

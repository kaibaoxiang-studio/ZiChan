# 环境与技术外貌设计：世界压力、资源与可达技术

读取 [专项交接](../../references/specialist-contract.md)、[群像差异化框架](../../references/differentiation-framework.md) 与本专项知识快照。先核对世界与角色接触证据，再提出能在身体、护理、装备或材料上看到的影响；不得把气候、族群或阶层直接映射成固定五官和人格。读取已批准视觉基准、当前设计卡与比较组；输出有依据的 2–3 个可见方案，每方案列至少两个部位、形状、位置/连接和依据明确的设计元素，供设计卡实际采纳；明确原文事实、创作提案、制作核对点及与近邻的差异。新特征只能作为待选方案，不能代替操作者批准。提案包含当前 variant_id；提交 CharacterSpecialistProposalV1.1 JSON 与短 Markdown，运行 scripts/validate_specialist_proposal.py；不调用生图。

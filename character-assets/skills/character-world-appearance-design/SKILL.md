# 世界条件到外观机制

读[世界外貌方法](../../references/knowledge/character-world-appearance-design/world-appearance.md)，接人物意图、实际接触环境、材料技术、资源和维护选择。把机制转为具体护理、装备、连接、保护或材料行为，说明位置与影响；没外貌原文仍可提出标明性质的创作选择。

用户提出多人种方向时，按[人物方法](../../references/director-understanding.md)协助总控主动设计新建虚构角色的族裔/混合背景与个体外貌，而非只留下限制。区分物种/形态、人类族裔、文化地域背景；采用的背景在各独立词里明确，肤色、发质和骨相仍具体。剧本未写可作原创选择，未知或作者不设可如实写未设，不编精确国籍血统。气候不决定族群五官，阶层不决定美丑，技术不要求全身发光；不把族裔绑定善恶、职业、服饰或能力，不编人物经历。保留世界共享语言并检验个人如何遵从或偏离。机制转成当前词的可画结果，不把创作选择伪称原文，按[普通文档](../../references/prompt-document.md)整合，不另造知识采集工程。不调用生图。

普通成果直接写本次完整提示词并更新同一文档，默认一个整合方向；局部只改受影响结构，不重设计未改域。不前置typed设计、body_form、方法/知识SHA、逐field成果证明或freeze；实际具体结构仍须完成。解释和弃选不塞词。明确正式或旧typed调用才按[旧专项合同](../../references/specialist-contract.md)封装。

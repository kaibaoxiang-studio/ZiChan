# 发型设计：发流、体积、轮廓与跨视角连续性

读取 [专项交接](../../references/specialist-contract.md)、[群像差异化框架](../../references/differentiation-framework.md) 与本专项知识快照。建立发际、发流、发量、前侧后体积和束发结构；与最相近角色比较发型块面，核对生活方式及背面结构。读取总控的 DesignDirectionBriefV1、当前阶段任务、已有视觉基准与最近比较组；没有项目时可直接接人物材料，注明草案与材料范围。先回应任务目标、人物语境、约束和所需成果，默认一套推荐，仅重要分歧增加备选，每方案列至少两个部位、形状、位置/连接和依据明确的设计元素，供设计卡实际采纳；明确原文事实、合理推导、创作选择、制作核对点及与近邻的差异。把人物未写明的外观当作需要设计的空白；无须编造身世证明某种脸型。常规项可由总控同轮执行本 Skill 的规范并记录 inline 成果；独立会诊记录 independent 原始返回物。新特征仍是待审设计，不能自行批准。提案包含当前 variant_id；新独立提案提交 CharacterSpecialistProposalV1.2 JSON 与短 Markdown，执行 scripts/validate_specialist_proposal.py；旧 V1/V1.1 仍可回读；不调用生图。

头像身份阶段按 [头像命名与颗粒度规则](../../references/avatar-identity-granularity.md) 从发型主名细化发际、分缝、人物自身左右和发束体积；正常头像尺度不把逐根碎发与额前胎毛设为必须可见的身份特征。

剧情服饰状态按 [状态可见需求](../../references/scene-styling-needs.md) 单独决定打理与盘/束发：保留已批发际、长度和发色，交前侧发片、收束位置、后脑体积、固定结构和正面/45°/背面连续性。头纱梳、发夹与发束的接口要与头耳颈专项核对；仪式需要固定时不能只复制基础披发句子。

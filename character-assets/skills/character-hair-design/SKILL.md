# 发型结构与打理

读[发型方法](../../references/knowledge/character-hair-design/hair.md)，从人物行动、维护与自我呈现选择前侧后体积。把发型名落到发际、分缝起点、人物左右、发流、发片长度、后脑轮廓、固定与耳颈遮挡；与近邻比较块面，不靠换发色制造差异。正常头像先表达连贯发束，不强加逐根碎发和胎毛。

剧情状态只改变获授权的打理／盘束方式，保留未改发际、长度和发色；与头饰核对固定、遮挡及动作连续性。必要时读[头像尺度](../../references/avatar-identity-granularity.md)或[状态需求](../../references/scene-styling-needs.md)。

已批人物试改后脑或后颈时，交具体差分与接续，脸和分缝按原约束保留；草稿只写artifact，不submit覆盖active或使原图提前失效。正式采用由用户确认；不因此默认审图、修补或重跑下游图。普通更新与只读继承见[普通文档](../../references/prompt-document.md)。不调用生图。

普通成果直接写本次完整提示词并更新同一文档，默认一个整合方向；局部只改受影响结构，不重设计未改域。不前置typed设计、body_form、方法/知识SHA、逐field成果证明或freeze；实际具体结构仍须完成。解释和弃选不塞词。明确正式或旧typed调用才按[旧专项合同](../../references/specialist-contract.md)封装。

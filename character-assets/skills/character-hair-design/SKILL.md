# 发型结构与打理

读[发型方法](../../references/knowledge/character-hair-design/hair.md)，从人物行动、维护与自我呈现选择前侧后体积。把发型名落到发际、分缝起点、人物左右、发流、发片长度、后脑轮廓、固定与耳颈遮挡；与近邻比较块面，不靠换发色制造差异。正常头像先表达连贯发束，不强加逐根碎发和胎毛。

剧情状态只改变获授权的打理／盘束方式，保留未改发际、长度和发色；与头饰核对固定、遮挡及动作连续性。必要时读[头像尺度](../../references/avatar-identity-granularity.md)或[状态需求](../../references/scene-styling-needs.md)。

已批人物试改后脑或后颈时，交具体差分与接续，脸和分缝按原约束保留；草稿只写artifact，不submit覆盖active或使原图提前失效。正式采用后相关图片按既有影响复核。实际方法与成果记录见[专项交付](../../references/specialist-contract.md)。不调用生图。

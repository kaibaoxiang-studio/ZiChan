# 群像差异化总控

读取 [差异化框架](../../references/differentiation-framework.md)、[专项交接](../../references/specialist-contract.md) 和群像知识快照。从真实同框及功能近邻建立比较组，生成角色 × 识别轴矩阵；指出重复的结构组合和全员美型偏差。按文本阶段或已收到的图片明确证据等级；需要回图判断时实际打开图片。不能因差异化硬造疤痕、怪发或极端体型，不自动改已批准卡。给主控具体修订点与应启用的专项，问题经操作者选择后才写入正式设计卡。

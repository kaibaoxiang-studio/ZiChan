# 面部装饰与妆容设计：稳定、施加与临时状态

读取 [专项交接](../../references/specialist-contract.md)、[群像差异化框架](../../references/differentiation-framework.md) 与本专项知识快照。按稳定原生痕迹、主动施加的妆面和临时状态分层；每项写位置、形态、叙事依据和起止状态，无需求可不设计。逐状态妆造不得改变已批准脸型和五官比例，不采用性别固定妆面套路。读取总控的 DesignDirectionBriefV1、当前阶段任务、已有视觉基准与最近比较组；没有项目时可直接接人物材料，注明草案与材料范围。先回应任务目标、人物语境、约束和所需成果，默认一套推荐，仅重要分歧增加备选，每方案列至少两个部位、形状、位置/连接和依据明确的设计元素，供设计卡实际采纳；明确原文事实、合理推导、创作选择、制作核对点及与近邻的差异。把人物未写明的外观当作需要设计的空白；无须编造身世证明某种脸型。常规项可由总控同轮执行本 Skill 的规范并记录 inline 成果；独立会诊记录 independent 原始返回物。新特征仍是待审设计，不能自行批准。提案包含当前 variant_id；新独立提案提交 CharacterSpecialistProposalV1.2 JSON 与短 Markdown，执行 scripts/validate_specialist_proposal.py；旧 V1/V1.1 仍可回读；不调用生图。

基础头像按 [头像命名与颗粒度规则](../../references/avatar-identity-granularity.md) 明确素颜与低覆盖裸妆的区别，分别描述已选妆面在眉、眼、颊、唇的覆盖和光泽；未添加稳定标记或头耳颈饰时可直接留空。

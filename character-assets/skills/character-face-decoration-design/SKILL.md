# 标记、妆面与临时表面

读[面部装饰方法](../../references/knowledge/character-face-decoration-design/face-decoration.md)。按稳定原生标记、可卸妆面、短时效果分层，逐项给位置、形状／边界、颜色／强度、状态起止；素颜与低覆盖裸妆不能混称。当前任务可明确无妆无标记，不强加故事痕迹。

状态需要妆面时，落实底妆覆盖／光泽、眉填色、眼部范围、颊与唇的颜色边缘及45°连续；不能用“清透妆感”代替结构。婚礼只是评估场合，不自动添妆。状态妆不得更改已批骨相、肤色或五官。按需读[状态需求](../../references/scene-styling-needs.md)及state-makeup／13号快照。

彩绘只在人物世界或当前方向触发时设计，写载体、面积、左右、可卸或稳定性质；新增宗教阵营或经历含义集中提出。交付见[专项合同](../../references/specialist-contract.md)。不调用生图。

# 头耳颈识别与穿戴

读[头耳颈方法](../../references/knowledge/character-face-signature-design/avatar-head-ear-neck-16.md)。先看脸发是否已承担辨识，再按世界、功能、个人选择与资源判断是否需要头戴、发饰、耳饰、面部穿戴或颈饰；全部留空也是完整设计，不设件数／部位候选配额。

采用物逐件给人物左右、形状尺度、固定／开合、重量运动、与发耳领口遮挡、正侧背可见及佩戴起止。头发本体归发型，彩绘归面部装饰，锁骨以下归服饰饰品；跨区物件指定一个主责。新家世、宗教／组织含义须作为重大创作选择提出，不从材质推定。

仪式只核禁令准确范围与旧物摘除时点，不能从禁大件扩大到全禁，也不能反向强加小件。重点接口按[部件方法](../../references/costume-component-design.md)深化；其他知识按部位加载。交付见[专项合同](../../references/specialist-contract.md)。不调用生图。

# 群演单图与群像设计

按给定台词、人数、行动、道具和形态识别本次分支，不从资产名中的其他数字猜人数。正式工程用plan.asset_mode核对：speaking_extra有指定台词、每状态一张9:16执行图；ensemble无台词群像、每状态一张完整全身同画布图。两者不套头像／九宫格／模卡／穿衣圣经前置。独立文字请求可先交具体设计，不强建工程。

读[群演方法](../../references/group-ensemble.md)中当前分支及[差异化方法](../../references/differentiation-framework.md)。人数、槽位和物件归属正确只是开局，不能代替人物设计。明确人数照数，未明确才选代表人数并标创作选择。

本组含人形脸发、身体和衣装时，实际读取并inline采用[脸部](../character-face-design/SKILL.md)、[发型](../character-hair-design/SKILL.md)、[形体](../character-body-design/SKILL.md)以及[款式](../character-costume-style-design/SKILL.md)、[剪裁](../character-costume-cut-design/SKILL.md)、[材质](../character-costume-material-design/SKILL.md)的相关方法，按问题再取其知识；不只读群像排位规则就声称已执行专项。同一组的方法读一次并复用，不逐人重读或各开一套岗位；已有具体设计只补当前缺口，配色、妆饰等按真实需要加载。

先把全组共享衣装的廓形、衣层、前后衣片／领肩袖连接、开合、动作余量和材料行为设计一次；再逐成员设计额颧颌颏与五官组合、发际分缝和前侧后体积、胸盆体块和重心、实际穿法差异。主名称后必须有当前画幅可读的形状、落点和连接，“长椭圆脸／短发侧梳”“宽肩／敞开外套”不能独立充当完整结果。成员沿用共同结构但写清具体差异，不靠换色或加疤痕区分。

人形有台词者一张9:16四格；非人先采用[形态方法](../../references/costume-and-morphology.md)中适用的部件、承重、移动、关节／附着与表面逻辑，再沿已选morphology_details和execution_layout，不补人脸毛发／无头衣服。混合群像分开处理人形衣装与非人壳体材料，不把同组色调当成相同构造。无台词群像完整全身同画布，不重叠裁脚，比例依人数与辨识；不用参考文档画风替代当前世界视觉语言。

交付前既核数量／物件，也核共享衣装能否接成前侧背同一件、各成员脸发和体块能否按文字画出区别、动作是否接在同一骨架／机械结构上。缺结构只补缺处；不增加每人全卡、完整比例表、会诊收据或字数门槛，后台只留实际方法及其形成的具体成果。

完整设计／修改结果与当前prompt维护同一人用文档，后台保留真实对应合同。正式执行前文字和风格获实际批准，提示词保真，回图实际看后审查批准并打包各自单图包。候选不免具体设计，也不自动继承正式批准。不自行生图。

# 原创脸与五官

先读[原创面部方法](../../references/knowledge/character-face-design/original-face.md)，围绕人物意图与近邻设计原创轮廓→比例→五官主次→表面。写额颧颌颏转折、软组织、眉眼距等少量有作用的比例，固定正面和45°的同一结构；不能用性格／阶层推定脸型。

完整头像分别落实眉、眼、可见耳、鼻、唇的形状、落点与连接，即使字段合并也不漏部位；用[头像规则](../../references/avatar-identity-granularity.md)控制尺度。选主锚点，其余保持安静但具体；不复制真人全脸，也不堆没有端点的数字。术语快照只按当前缺口读取。

直接在当前词落实一套可画推荐，不把新增外观伪称剧本事实。常规inline，冲突才会诊；[普通文档](../../references/prompt-document.md)说明实际成果与生产封装。无工程可独立做，已批局部试改不覆盖正式记录。不调用生图。

普通成果直接写本次完整提示词并更新同一文档，默认一个整合方向；局部只改受影响结构，不重设计未改域。不前置typed设计、body_form、方法/知识SHA、逐field成果证明或freeze；实际具体结构仍须完成。解释和弃选不塞词。明确正式或旧typed调用才按[旧专项合同](../../references/specialist-contract.md)封装。

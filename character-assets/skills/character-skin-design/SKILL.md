# 皮肤色差与表面

读[皮肤方法](../../references/knowledge/character-skin-design/skin.md)，区分稳定底色／局部色差、可见光泽肌理、施加妆层和临时污损；生活痕迹须有实际接触机制，不能以职业阶层自动加脏污、斑疤。

设计稿可保存细部，当前提示词只提镜头能读到的部分。正常头肩先表现肤色体积、柔和区域差和已选光泽，不强制全脸毛孔／绒毛；异常油光、压印纹再读[头像尺度](../../references/avatar-identity-granularity.md)与对应质感快照。不同媒介不套真人微纹理。

交具体部位、范围、强度及连续性，不能只写“真实自然”；执行和来源见[专项合同](../../references/specialist-contract.md)。不修改未授权骨相，不调用生图。

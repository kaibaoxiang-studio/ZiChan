# 皮肤色差与表面

读[皮肤方法](../../references/knowledge/character-skin-design/skin.md)，区分稳定底色／局部色差、可见光泽肌理、施加妆层和临时污损；生活痕迹须有实际接触机制，不能以职业阶层自动加脏污、斑疤。

所需设计直接写进相应阶段提示词，当前镜头只取可见部分，不另建长设计稿。正常头肩先表现肤色体积、柔和区域差和已选光泽，不强制全脸毛孔／绒毛；异常油光、压印纹再读[头像尺度](../../references/avatar-identity-granularity.md)与对应质感快照。不同媒介不套真人微纹理。

交具体部位、范围、强度及连续性，不能只写“真实自然”；执行和来源见[普通文档](../../references/prompt-document.md)。不修改未授权骨相，不调用生图。

普通成果直接写本次完整提示词并更新同一文档，默认一个整合方向；局部只改受影响结构，不重设计未改域。不前置typed设计、body_form、方法/知识SHA、逐field成果证明或freeze；实际具体结构仍须完成。解释和弃选不塞词。明确正式或旧typed调用才按[旧专项合同](../../references/specialist-contract.md)封装。

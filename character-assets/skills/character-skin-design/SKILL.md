# 皮肤肌理设计：年龄、环境与真实表面

读取 [专项交接](../../references/specialist-contract.md)、[群像差异化框架](../../references/differentiation-framework.md) 与本专项知识快照。写自然毛孔、局部光泽、纹理、色沉及有依据的生活痕迹；区分稳定肌理与临时污损，避免磨皮。读取已批准视觉基准、当前设计卡与比较组；输出有依据的 2–3 个可见方案，明确原文事实、创作提案、制作核对点及与近邻的差异。新特征只能作为待选方案，不能代替操作者批准。提交 CharacterSpecialistProposalV1 JSON 与短 Markdown，运行 scripts/validate_specialist_proposal.py；不调用生图。

## 自行复核

使用Python3.12+及requirements.lock中的依赖，在整个插件目录运行：

```sh
python harness.py validate --plugin .
python -m unittest discover -s tests -v
```

不要只拿蓝图交给不同版本的旧生成器重建；安装和审查使用完整目录与随包运行时。

## 未消除的风险与覆盖边界

- Windows正式写入仍依赖Unix fcntl；调度锁探活仍采用POSIX语义。Git换行为CRLF可能影响锁定知识字节。中文进程编码已修，但这不等于原生Windows已通过。
- 一些辅助专项的独立Harness成功仍仅证明文件返回。正式设计采纳要经人物总控及stage严格验收，不能把辅助节点的succeeded当作设计已完成。
- 最终有图资产表仍需真实表格工具制作、嵌入单元格和重开核验，CLI角色打包不自动完成这一步。
- 未逐项对22种能力进行真实模型调用，未执行新图审美、完整图像资产生产和Windows真机验收。
- 真实设计耗时是单例，未做同输入同设置的新旧版本性能A/B；不能据此承诺平均耗时、吞吐或成图质量。

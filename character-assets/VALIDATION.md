- 22 个能力入口；58 份锁定知识快照与 v0.2.15 逐字相同，来源登记、原始归档清单不变。
- Python 3.12.14 与 3.14.10 各运行完整 259 项 unittest（含18项特征聚焦发布回归），均通过。包含真实本地子进程、CLI、临时项目及文件比对；不是相同数量的模型设计或图像审查。
- 检查空文件／假路径／空摘要拒绝、任务不能自行降为讨论、独立来源和纯文字来源、当前画幅、数值左右和状态保护、正式父依据、局部试改隔离、基底继承、旧项目读取及同源 JSON/TXT。
- 已复现并修复实际发现的旧发型混入新稿、明确 1:1 被默认 3:4 覆盖、本地完整基底未传给候选词、冻结误绑邻近旧 design.md，以及 API 严格输出 schema 的问题。
- 新 Python 环境实际安装原哈希锁定依赖成功；独立发行版 venv 初始化方式已作真实创建测试，未取消依赖哈希检查。
- 默认用户 Python 3.14 的启动器真实调用通过；三个真实离线 venv 用例覆盖同一基础解释器的环境切换与防递归。
- Windows 写入锁及调度恢复探活改用平台标准接口；13 项模拟 Windows API／实际临时文件控制流检查通过，不调用危险的 Windows signal-0 探活，不宣称真机验收。

## 性能与未验证项

已减少主入口与索引重复、按任务加载规范、共享群像方法，以及自动覆盖已原样出现的细节；同义改写才需额外对应。单个合成例的重复映射由 26 项降至 3 项，不能据此推算整体模型成本或审美提升。

旧版对照有超时，新版某次调用有模型容量错误，且真实调用含网络连接重试。因此不据这些样本宣称普遍提速或完成严格性能 A/B。没有新增图片、跨模型盲评或 Windows 真机验证。

正式群演／群像仍读取既有已验证的字段覆盖合同；不能把独立候选的表达编辑策略冒充为所有正式旧合同均已迁移。

打包工具在交付时执行源码重建字节一致、ZIP 校验、独立解包验证与回归；具体 archive SHA、文件清单及结果由包外 manifest 记录，避免把未运行的打包步骤预写成通过。

## 发布前五人文字实测

本机真实完成五位定位不同的角色设计：从同版本全文理解出发，深化脸发肤、五组身体参照、体块和一套代表衣装，再绑定冻结稿生成五条3:4头像候选词。来源、可见结构、JSON/TXT与单一人用文档同源检查通过。独立审读发现并修正了权限归因用语、肘腕落点与裆点矛盾，以及头像描述夹入正式衣领的问题。这些是文字和结构复核，不是已批准人物或图像审查。原始剧本、人物稿和本机审计材料不随插件公开。

本次发现独立设计的特征聚焦结果触发字段映射错误；发行前以未改动的原触发材料重放验证通过，并新增18项合成回归，覆盖inline及受scope限制的独立提案采纳、真实文本叶字段、错误范围/未采用结果拒绝和既有必需专项。Python3.12.14与3.14.10各259项完整回归通过；包外manifest记录解包后的再次检查。不得把附加记录中的绕行结果当作原报错分支的验证证据。

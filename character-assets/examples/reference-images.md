# 模卡参考的职责与边界

本页记录作者验证用参考图的职责与版式要求；图片不随安装包分发，不要求使用者访问作者本机文件。实际项目只使用操作者提供且可访问的参考，只借已指定版式、模卡着装和光线，不复制示例人物身份。

- 头像：作者提供的头像取景示例（未随包分发）。3:4 竖版，完整头部、双肩及上胸入画，脸为画面主体；女性白色运动背心、灰色中性底。这张图只控制**取景范围和中性着装**，不复制示例人物的脸、年龄或其他身份特征。上胸入画可直接采用背心模式，不以先做锁骨以上的图为前提；无服装设计指无剧情造型，不能表现裸体躯干。
- 九宫格：作者提供的九宫格版式示例（未随包分发）。3×3 同脸、同发、同背心和中文标签；表情强度随角色剧情确定。
- 全身：作者提供的全身模卡示例（未随包分发）。同一身份、白色运动背心、黑色短裤、赤脚、灰色中性底；身体比例必须依据本角色批准卡，不能照抄示例人物。
- 旧 pipeline2 的服饰设计图仍按原合同读取。新 pipeline3 以已批准状态文字设计及身份基准直接生成每状态一张9:16四格执行图，不新增横向服饰图。

# 手动验收建议

1. 现实内景：原文无超现实元素时，设计卡与提示词不出现仙宫、悬浮建筑或凭空人物。
2. 已批准中式幻想：一场有明确巨型门阙与云海的剧本，设计卡列来源、主结构、尺度参照、留白和通行动线；提示词不包含固定女性仙人人数或 Midjourney 尾参。
3. 参考图越权：外部风格图里有陌生角色，提示词只借已批准画风，回图若带入陌生角色须标问题。
4. 场景变体：同一地点雨后/破损版保留共同结构，变化单独记录，不生成竞争的场景 ID。
5. 回图错误：建筑形变、尺度失真、遮挡通道或与剧本时段冲突时，报告 `revise`；操作者未批准时不能打包。
6. 上游改版：修改输入文件后旧版审批应被状态检查阻断，不静默复用。

图片是否达到制作要求由操作者逐阶段判断；结构检查只证明文件与接口完整。

# 全剧视觉基准与场景设计

先把剧本时代、类型、世界物理规则、场景清单与可选风格板的**可观察事实**列出；与设计推导分开。提出 2–3 个有证据的视觉方向，指出各方向对建筑/地形、材料、色彩和光线的影响，待操作者批准 `ProjectVisualBibleV1`。如上游已给带哈希与审批的视觉基准，核对后复用。

每个 `SceneDesignCardV1` 必须写清：剧情用途、地点事实、主要空间结构、人物/道具活动所需的可用空间、前中后景、尺度参照、光源与时段、材料、连续性不变量、未解决项。设计卡只固定已证实或已批准内容；未知背面、不可见结构或历史工艺标待定。现实场景可有视觉张力，不能强加超现实元素。若同一地点有明确状态改变，用同一场景 ID 的变体，记录变化与共享不变量。

当全剧视觉基准明确批准中式幻想方向时，读取[尺度知识](knowledge/chinese-fantasy-scale.md)：以一项主要空间规则、一处主要空间主体和可辨的尺度关系组织场景，再用可查的建筑/材料线索使其自洽。这里的“一项/一处”是控制画面主次的设计起点；剧本明确多主体或复杂空间时以剧本为准。人物数量、性别与服装必须来自剧本和角色资产，不采用来源案例的固定仙人配方。

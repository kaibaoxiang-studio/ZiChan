# 场景静帧提示词

输入只取已批准视觉基准、已批准场景设计卡、当前场景的剧本证据及获批准的参考图。输出 `ScenePromptPackageV1`，供操作者在外部工具使用。参考图编号并说明各自负责建筑结构、地形、色彩、材质、光向或角色身份中的哪一项；不得把参考图的无关人物和道具带入。

建议顺序：`产物与用途 → 地点/时间事实 → 主空间结构与允许的空间规则 → 活动区域和尺度锚点 → 前/中/远景与取景 → 材料、光线和色彩 → 各参考图职责 → 不变量及禁止新增 → 回图核对点`。具体设计卡已足够详细时只做清晰整理，不补虚构地理或建筑史；缺关键构造时先给有理由的选项请操作者批准。

中式幻想仅在设计卡标记适用时加入[尺度知识](knowledge/chinese-fantasy-scale.md)。不要直接复制来源 Midjourney 尾参、固定“女仙人”、固定画幅或不适合本项目的负面词。人物若出现，用角色资产包的身份和服装锚点；场景插件不重画角色设计。每条提示词列 `acceptance_checks`，至少包含剧本事实、场景连续性、空间尺度和不得新增的内容。

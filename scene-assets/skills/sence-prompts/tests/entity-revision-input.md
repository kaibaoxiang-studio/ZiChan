# 文字基准：修表店

原资产 EC-R｜现代修表店｜内｜日。采用完整旧稿：灰米白墙面、平整顶面、哑光浅灰地面；中部深木棕L形柜台长边朝顾客，右端短边向后延伸，左端有员工开口；后墙壁柜；柜后另有独立维修台，电子工具收置在该台；后墙左端有一只关闭的落地保险柜。右墙玻璃展示柜，米白牌写“维修接待”，简洁深灰印刷字。柜后通道连接左端开口与保险柜。日光从摄影机左后方进入，顶面中性工作灯补充柜后；摄影机位于入口内顾客区偏左，站立视高平视斜向后柜的整店全景，无人，不预摆顾客腕表或保管盒。

请把维修区整合到同一组柜台右侧短边，替换独立维修台，相关工具随工作区调整。其他装修、标识、保险柜数量、配色、基础光源和机位保留。给可独立使用的完整生成提示词，不是在原图上编辑，不要流程说明和色卡。

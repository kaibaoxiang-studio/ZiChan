# 固定文字回归用例

全部为合成测试资料，不属于任何真实项目。更新技能时选受影响用例；普通生成不必读本文件。先让执行者只读原始资料及相应请求并产出结果，再按判定条件检查。措辞、构型和字数不要求匹配示例；主执行者自测不能称独立评测，文字通过也不代表出图通过。

## 用例 A：新建合议室

请求：“按完整测试表和 P01，设计 S01。采用会议开始前、无人且桌面无道具的状态。需要有空间辨识度，不添加徽记和新陈设。”

判定：保留两短墙、窗墙与实墙关系、长桌双侧坐席、壁龛；形成具体主形与空间组织，而非通用长桌加金边；入口、两侧坐席后撤与壁龛前停留区可兼容；印盒不在场；材料色、漫射窗光与主视点一致；交付一条自足生成稿，新增造型统一标提案。没有新尺寸／画幅事实。

## 用例 B：同项目不同用途

请求：“沿用共用设定，按 P02 新建 S02，只生成校图室。与合议室共享工艺语言，但按取图、校图和取卷关系形成自己的空间。”

判定：地图墙、书桌、座椅、沿墙书架、右窗成立；取用路线与桌侧操作面清楚；可与 A 比较共同材料、连接和加工，差异来自主形与用途；不移植壁龛、双侧会议坐席或印盒，不靠换滤镜制造区别。保留已有地图。

## 用例 C：极暗自然空间

请求：“生成 S03 的无人夜景，保持当前光源和障碍，不美化成明亮景点。”

判定：无月光、灯火、晶体、人形、脚印或新增出口；洞口附近有限可读，深处允许隐入暗部；湿滑岩面与右侧落石阻断保留，不磨平、加栏杆或开绕行通道；布局功能检查不能反过来要求所有细部亮起。

## 局部迭代的可靠文字基准

```text
架空前工业时代的写实概念绘画，陈设完整的无人阅卷角，日间。入口在近端短墙，左长墙中部有一扇深窗洞，远端短墙是固定书架，右长墙为素面浅灰石墙。深褐橡木书桌居中偏右，长边平行左窗墙；座椅在桌的右侧，面朝窗墙，椅后至右墙留有连续空地，桌左侧通道连接入口和书架。桌面素净，无散放道具。书架采用与桌架相同的黑铁内嵌连接，深木表面为哑光细纹，石墙主体粗面、窗洞接触边细磨。左窗的日间漫射光照亮桌面左部，在右墙与书架下层逐渐衰减，无其他光源。机位位于入口内靠左、正常视高，斜向远端书架，画面右侧可见桌前端与座椅，左侧可见窗洞及沿桌通道，背景保留书架和右墙交界。
```

## 用例 D：没有全表的文字纹理迭代

请求：“针对 S10 v1，只修复桌面木纹过于塑料的问题，其他照旧。我需要完整提示词。”

判定：不索取全表；交付合并后的完整生成稿；只改善同一橡木的纹理／粗糙度和合理反射，不换色、加金属包边、换木种或添磨损故事；入口、窗、桌椅、书架、机位和光源均保留；不能输出‘其余同上’或伪称已经编辑图片。

## 用例 E：无图换视角

请求：“按 S10 v1，改到入口内靠右，朝远端书架取景；其他空间和状态不变，给完整生成提示词。”

判定：只换机位与投影；桌椅仍在既定相对位置，窗不移动到右墙；明确桌体和座椅的遮挡，允许不能同时看清全部通道；不镜像全房间，不在未见区域加门；沿用未确认布局及配色的提案身份，无需重配色或重交全表。

## 用例 F：关键状态未知

请求：“生成 S01 来访者刚入室时的无人背景，印盒按剧本处理。”

判定：P01 无法确认刚入室时印盒已放上桌，且本请求未沿用 A 的‘桌面无道具’状态。只询问印盒此时已落桌还是仍随身；不交含擅自判断的正式稿，不以‘美术提案’绕过事实。可先处理不依赖此状态的固定设计。若用户随后明确允许探索稿，标明暂定单一状态后再交付。

## 用例 G：请求编辑但缺少实际图像

请求：“把 S10 的原图桌面改得不塑料，给我用原图编辑的指令。”本用例实际只有上述文字稿，没有图片。

判定：说明没有实际原图，请补充用于编辑的基准图；不声称看过图、不编造图片编号。可说明已有文字足以另做完整生成稿，但不能把它冒充用户要求的原图编辑成品。用户后续提供真实图像后，再交修改与相关保留项完整的编辑指令，无需复述全房间。

## 用例 H：保存与恢复连续性

请求：“将 S10 v1 保存为本测试项目的连续性记录，标记来源和未确认设计；然后按记录恢复并说明能否直接作为用户已确认的布局。”保存仅限隔离的测试工作目录。

判定：实际生成可读取记录，分开入口／左窗／书桌／书架等原表事实与位置、朝向、配色等提案；不记录虚构的用户确认；恢复时可作为本轮基准，不升级确认等级。保持固定布局、状态和本次视点分开，不写入通用知识库。测试无真实图片，不记录成图验证成功。

## 用例 I：后续人物入画的实体定位

请求：“按完整测试表和 P02 生成 S02 的无人日景，后续要让人物在桌侧校图、地图墙前停留、书架旁取卷。请用场景本身帮助定位，给一条完整提示词，不另交站位图。”

判定：实际生成完整提示词，以既有桌端、地图墙边界、书架端部及其邻接关系明确相关停留区、朝向和连接通路，而非只写‘中央留白’或屏幕左右；重复书架段可区分，目标机位中相关区域有可辨参照，考虑入画人物遮挡，不要求所有锚点同时可见。保留桌面原有地图与既定光源，不新增标志道具、人形、编号、站位线或视频动作，不声称模型已稳定执行定位。

关联回归：重新生成 C，检查以洞口边缘或岩层转折提供有限可读参照，保留深暗和落石阻断，不添灯、清障或要求所有停留面清晰；重新生成 D 或 E，检查没有为满足锚点要求改变既有桌椅位置、开口或光源。仅补写锚点名称不算通过，须检查它与实际停留面和可见范围的对应关系。


## 用例 J：门按重要性选写

请求一：“按完整测试表与 P02 生成 S02 的无人日景，门没有重要作用，不要描述门；保留桌侧、地图墙前和书架旁的定位关系。”

判定：完整提示词保留地图、既定材料与光源、桌侧通道及实体定位；不展开门框、门扇、开向或门槛，不强制门框入画，也不写‘无门’或改变已有布局。可按必要性简写入口关系，不以此重新扩写门。

请求二：“仍按 S02 与 P02，补充已确认条件：入口门牌是此场识别地点的关键，门牌写‘校图室’，位于门洞上方中央。生成无人日景。”

判定：保留必要门洞与门牌内容、位置及可读呈现，不因精简删掉地点识别信息；不顺带增加无关门构造、开启方向或门外新空间。其余资产与状态不变。

## 用例 K：导演调度先于布局与锚点

请求一：“按完整测试表及 P01 设计 S01，会议开始前、桌面无道具的无人日景。让布局支持双方在长桌两侧交流，并能到达壁龛前；门没有重要作用，不描述门，不另交导演分析或分镜。”

判定：实际生成完整提示词，将双方交流转为相对的使用面与互见关系；用桌端、桌沿或壁龛边界对应主要停留区与接近通路，座椅后撤和通向壁龛的路线相容。主视点能读到必要互动面及参照，不只罗列锚点或中央留白。不擅加高台、屏风、围堵、印盒、人物动作或镜头序列；保留原有墙面、材料与窗光，不扩写门。内部调度判断不变成外发长报告。

请求二：“按完整测试表及 P03 生成 S03 的无人夜景，只使用现有剧情，不补人物关系。”

判定：按已知抵达与停留需求选择洞口边缘或岩层转折作为有限可读的参照，不强造对峙双方、主从高低位或多区调度；保留湿滑、落石阻断及原有极暗光照，不以调度为由清障、补光或加出口。关联重跑 D，确认仅修木纹时不重排桌椅、锚点或机位。

## 用例 M：居住用途与生活信息

独立合成完整资产表：M01 为当代年轻女性租住的普通私人房间，内、日，含沙发和生活陈设，其他相对布局未定。共用设定为写实电影场景图、有限居住面积、维护整洁；家具款式、配色、光源与主机位未定，无兴趣爱好、特殊职业用品或情感物件设定。

PM01：两人在沙发上并坐交谈，随后靠近。目标为人物入场前的无人常态背景，无事件痕迹或携入道具。

请求：“按完整资产表和 PM01 生成 M01 的场景提示词，作为首次建立的场景图。”

判定：依据私人居住用途设计适当的休息、收纳等支撑，不把“含沙发”当作唯一家具清单；首次主视点能建立房间整体布局和主要区域连接，沙发作为其中的互动重点，不能仅以床角或柜边代替主要生活区。日用品、家具组合与局部使用痕迹具体但有主次，主要互动面和通路清楚；不凭广角扩大房间，不规定唯一家具清单、位置或性别配色。新增方案标为提案，无虚构兴趣、情感道具或事件。历史项目反馈只作为问题类型参考，本合成用例不证明真实项目的成图修复。

边界变体：同表请求改为“严格只使用表中明确的沙发，其他陈设不补全，只要沙发交谈区的局部背景”。应遵从范围，不强制增加床柜、日用品或扩大取景。另沿既有用例 C 检查自然环境不因生活感规则新增人物用品。

## 用例 FR：首次整室与局部取景

独立合成项目，完整资产表只有 FR01“租客房间”：现代城市住宅中的单间，内、日，维护整洁；现有长沙发、床、衣柜、梳理柜及一扇窗。房间为长方形，入口在近端短墙，窗在远端短墙；沙发沿左长墙，床沿右长墙靠深处，衣柜与梳理柜沿右墙近端，中央通道连接各使用区。不存在其他房间、隔断或剧情道具。

共用已确认设定：真人实拍写实风格，米白墙、浅木地板与柜体、陶土橘沙发、灰蓝床品；远端窗提供日间漫射光，无其他光源。家具尺度普通，精确尺寸、画幅与模型未知，已有材料色可用，不重新检索配色。

PFR01：两人在沙发并坐交谈，随后一人在沙发侧站起。目标为人物入场前的常态无人环境，无携入道具与事件痕迹。

请求 FR-A：“根据完整资产表和片段，首次生成 FR01 场景提示词。”

请求 FR-B：“根据同一完整资产表和片段，首次只要沙发交谈区的局部背景，床和衣柜不用入画。”

隔墙变体 FR-C：将唯一资产改为 FR02“租客住处”，现代整套住宅；起居室含同样的沙发与窗，卧室在右侧实体隔墙后，厨房在近端另一实体隔墙后，通过既有开口相接。床与衣柜在卧室，梳理柜也在卧室，其余材质和光照设定相同；不拆墙、不新增开口。片段仍为沙发交谈，目标时刻相同。请求：“首次生成住处场景提示词，只交一张主场景全景。”

先按各请求保存完整提示词，再判定：FR-A 的观察点在房间内可行，实际取景同时交代沙发、床、收纳梳理区和中央连接地面，沙发仍可为视觉重点；仅写“整室全景”而正文只露床角不通过。FR-B 聚焦授权的沙发区域，不强制床柜入画、全景套图或重排家具。FR-C 以合理主区域全景及既有开口交代邻接，隔墙后允许画外，不把整套住宅挤成单间或用穿墙／鸟瞰剖面展示。三项均保留真人实拍画风、已定材质、窗光、状态和围合，不加人物、道具或精确尺寸事实。

# 测试选择索引

仅用于维护／验证技能。先按修改对象选一行；跨多个模式或改变阶段交接时再加连续流程，不默认全套运行。证据层次与报告边界沿[验证规则](../references/verification.md#分清验证层次)。

## 按修改影响选例

以下为建议起点，不是固定通过清单；新增问题另保留真实输入。旧[用例资料](cases.md)混排输入与判定，执行时只取相应基准、共用设定及请求，输出后再看判定。

| 修改对象 | 建议用例 | 主要检查 |
| --- | --- | --- |
| 入口路由／读取量／设计框架 | [A、B](cases.md#用例-a新建合议室)、[C](cases.md#用例-c极暗自然空间)、[D](cases.md#用例-d没有全表的文字纹理迭代) | 主动设计与用途差异；自然与局部任务不被室内新建规则覆盖；必读及专题触发完整 |
| 功能、定位与门 | [I 至 L](cases.md#用例-i后续人物入画的实体定位) | 实体定位、接近与互见；普通门省略不改入口，必要门牌保留 |
| 生活／公共体系及补全权限 | [M、N](cases.md#用例-m居住用途与生活信息)、[Q、R](cases.md#用例-q世界观体系选择与运作关系) | 用途设施真正成立；严格清单、技术例外与未知能力边界 |
| 生成／编辑交付与信息密度 | [D、E](cases.md#用例-d没有全表的文字纹理迭代)、[G](cases.md#用例-g请求编辑但缺少实际图像)、[PD](cases.md#用例-pd密度校准不改变任务) | 无图完整生成稿、有图依赖关系；精简后关键设计仍可还原 |
| 打光、开关与材料色 | [RL](cases.md#用例-rl第二步光影氛围)的 A、B、C、G，[MIX](cases.md#用例-mix同一场景合并多项修改) | 授权例外不被保留项抵消；无图边界；多项修改合并 |
| 色卡、配色或相关脚本 | [CP](cases.md#用例-cp色卡与打光联合交付)的 A、B、C；配色相关既有用例按[配色验证](../references/verification.md#代表性文字用例)补选 | 默认／免绘卡、本色例外与职责；检索、绘卡须实际执行，不用文字替代 |
| 反打、普通角度与新露出区域 | [MA](cases.md#用例-ma第三步多角度与反打)的 B、F、G、H、I，[E](cases.md#用例-e无图换视角)，RL-G | 对面观察点、明确角度优先；未知背面、夜晚交接；没有打光或局部退化 |
| 版本／确认等级／保存恢复 | [HR](cases.md#用例-hr轻量交接与派生影响)、[连续流程](chain-inputs.md) | 真实文件恢复、提案身份和旧角度影响；非当前角度不接力成为共用基准 |
| 状态与批量缺项 | [F](cases.md#用例-f关键状态未知)、[BATCH](cases.md#用例-batch批量缺项与独立交付)及其整批变体 | 未知关键状态不被定案；独立条目与整批偏好各自成立 |
| 反馈诊断／仅审查边界 | [FB](cases.md#用例-fb反馈证据与审查边界)的 A、B | 用户报告不冒称图像观察；矛盾定位正确且不越权改稿 |
| 文件检查器或引用 | [检查器单元测试](test_check_skill_files.py)与[文件检查](../references/verification.md#可复用文件检查) | 正反例、当前引用；有完整修改前快照时另核对变更范围 |

只有相关脚本、依赖数据、输入／输出格式、运行依赖及影响其使用的交付规则均未变化，且本次问题不涉及该路径时，才可省略其专项测试。脚本未改但配色数据、输入格式或色卡交付规则变化，仍按影响范围实际运行检索／绘卡。只改测试导航可检查引用、选例准确性及所新增用例的实际执行，不借此声称所有行为回归通过。

## 连续流程与真实图片

[连续流程输入](chain-inputs.md)串联新建、夜间打光、两个角度、局部材料色更新及从文件恢复；[验收条件](chain-assertions.md)在结果保存后读取。步骤有依赖，使用本轮实际完整输出，失败时保留失败稿，不换成手写正确基准掩盖问题。

MA-D、CP-D、FB-C 是需要另行取得真实图片的测试方向，并非已附图片的可执行夹具。没有图时记“未运行：缺真实图片”；模板文字检查另报，不计为图片通过。场景生成及外部服务仍需本次授权。

## 最小结果记录

在本轮工作目录记录技能版本／快照、选例及理由、实际输入与输出文件、执行者及验证层次、通过／失败／未运行和具体证据。链路记录每一步采用的主稿版本、确认范围及角度依赖；实际保存与重读的文件须能定位。失败修正后保留首轮结果并重跑受影响项，不能以表格勾选或检查脚本通过替代提示词生成与人工关系检查。

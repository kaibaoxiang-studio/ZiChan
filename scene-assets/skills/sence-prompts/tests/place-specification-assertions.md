# 场所规格验收

实际完整输出保存后才读取。SP-K／Y是提取泛化的场次描述；通过不证明完整原文件解析或原项目成图修复。检查具体关系，不按固定材料、桌数、修饰词或篇幅评分。

## SP-K

- 厨房生产、皇宫归属与整体规格共同成立：构造／围护、设施或陈设有相称组合，不只靠食材、金色物件或“宫廷”标签；允许工作区域的装饰低于礼仪空间，不要求豪华大厅。
- 药膳锅灶、食材取放、操作面与收置组织相容；食材有堆放但不把每个可用面铺满。跪候、入内、一侧坐席与到桌边的永久关系在空场中可定位，不画动作或凭空扩成新房间。
- 身份、工艺及普通数量保持提案；保留单一时刻，不加入后续大金锅、竹篮或穿越食品。相称维护不强造整片湿地、烟熏脏墙，也不禁止已有正常烹调蒸汽。

## SP-Y

- 保留雕梁画栋、金丝绣边桌布及银筷玉盏，整体围护、构件与陈设落实高端接待，不只堆金边或照抄普通饭厅布局。
- 处理一家就席、主位、四周宾客与拍桌／互见的空间关系；不因“雅”断言原文为小型私包，不因群体复制大量同级独立散座桌，也不清除全部宾客接待与桌面条件。数量、形状是提案，不固定唯一解。
- 不引入另外大堂资产的楼层、栏杆与比试灶台；交自足生成稿，不锁失败图，不靠“不要多桌”省略正向布局。

## SP-M

- 简易棚、旧台与矮椅保持朴素和有限预算；有合理构造、用品取放／收置及维护关系，而非高端化、废墟化或清成无人即无用品。
- 已有物品与人行联系能从整体取景定位；不填每角杂物，不加招牌、机器、特定鞋单、人物或故事状态。

## SP-O

- 相称规格落实到顶棚承托、长椅、信息面、路缘和人行联系，体现普通公共候车用途；不普遍贵重化、不套室内装修／散桌模板，也不弱化成孤立椅子特写。
- 无车无人仍保留设施与运作条件；维护不等于做旧，信息板不编造新专有文字。实际机位及原资产范围相容，不扩城或新增商业内容。

## 共同

事实、普通提案和关键未知分清，画风与状态正确；肯定设计落实范围，否定不抵消有效要求。文字可复述相称性但不称实测或成图成功；关联自然、局部、纹理与打光的用例遵从各自验收，不以本规则重做未授权空间。

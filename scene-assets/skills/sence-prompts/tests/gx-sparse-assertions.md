# 布局未定场景的验收条件

对应[执行输入](gx-sparse-inputs.md)的 GX-D／E。先保存实际提示词，再用本文件检查；原始请求未指定整体取景，不能向执行输入补入期望的布局、边界、机位或“全景”要求。

## GX-D：主动建立目标场景

- GX11 应依据私人居住用途，提出有边界的房间形式与生活功能关系，让沙发所在起居区及必要休息、收纳等区域在一个可行主视点中可读。家具、布局和窗位可以合理提案，不指定唯一床柜清单或位置，不借完整性扩成整套住宅。只露沙发并以床角、柜边代替主要生活区不通过。
- GX12 应提出活动广场的主要地面、边缘与接近关系，石凳及交谈面嵌入广场整体取景。允许与小区用途相容的普通边缘环境提案，不要求固定矩形、楼数或绿化配置；只有石凳、邻近地面和虚化背景的局部图不通过。不得扩建为整个小区、增加活动项目或另造剧情功能。
- GX13 应提出溪水、岸线、地形与岩块旁停留面的整体关系，主视点交代一处可读溪岸的范围与纵深，不规定唯一弯折、植被或岩壁形态。岩块近景配模糊水面不通过；不要推定整条溪流、流域地图、未知林后区域或人工设施。

上述判断以实际机位、相对位置、可见面积和连接关系为依据，不因正文出现“全景”判通过。普通补全集中标为美术提案，不升级为资产表事实或用户确认，不通过添人物、箭头、标线、极端广角或缩小主体来证明空间。

## GX-E：明确局部优先

聚焦用户指定的石凳区域，交代凳体、旁侧停留面与必要接近关系即可；其他广场区域可在画外，不强制全广场或多视角套图。本请求未采用 GX-D 成品，不要求复刻其尚未确认的整体布局。

## 结论边界

四条实际输出均保留原资产 ID、对应状态、画风及普通采光；只描述无人静态环境，不加入携入道具、事件痕迹或人物表演。记录输出中的具体空间证据及越界／缺失项。执行者知悉问题或验收条件时标为知情自测，不称盲测或独立评测；文字通过只证明该次文本落实所检关系，不证明成图执行、真实项目问题修复或普遍稳定性。

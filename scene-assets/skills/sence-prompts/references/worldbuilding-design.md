# 世界观统一与场景特征设计

用于解决器物脱离世界观，以及场景虽有纹理却缺乏辨识度的问题。先确定项目可复用的设计规则，再深化当前资产；不要把某个测试项目的西幻王宫规则变成所有题材的默认设置。

## 项目共用美术约束

从用户要求、资产表与已提供的剧本中建立一份简短共用设定。使用全表和剧本理解世界，但只对本次目标场景生成提示词，不提取新资产。项目已有美术设定时直接沿用。

每个维度记录“明确依据”和“暂定设计”即可，未知的不强行填满：

| 维度 | 要明确的设计关系 |
| --- | --- |
| 世界及技术范围 | 写实或风格化；现实历史、架空、科幻等；材料加工与能源水平；已出现的技术例外 |
| 文化与场景归属 | 时代地域、阵营、阶层、用途；哪些图案是本地纹饰，哪些来自外交、入侵或角色个人物品 |
| 建筑与材料 | 构造轮廓、门窗、石材或其他主材、结构连接、装饰用材及维护状态 |
| 器物与制作工艺 | 容器封口、金属铸造或锻接、木石加工、器柄和支架、纺织、书写与标识 |
| 色彩与照明 | 共用主材色、允许的局部色、自然光或人工光；哪些特殊光源已有依据 |
| 财富与陈设密度 | 王宫、宗教、民居、荒野等用途对应的规格；庄严、奢华、实用或简陋的理由 |

同一项目保持同一文化和工艺体系；不同阵营、空间用途和时期允许有依据的差异。共用设定是项目资料，不把某项目的造型写死进通用 skill。

五维框架中的统一美学是共用规则和差异的统一，不是所有空间相同。维护程度、新旧状态可因用途、环境和已有经历不同；不能为了同年代一致把一处已定破败或崭新的空间统一改旧。明确的跨风格创作意图优先，不用“写实／写意”标签机械禁止用户已要求的混合语言。

材质、空间和建筑专题按主入口的任务模式选读，不因这里的互链加载无关文件。同文化场景复用构件家族、材料及加工方式，但按用途改变围合、开口与主陈设，不将所有房间复制为同一套宫殿。

## 从世界约束发展视觉语言

时代、地域和用途须通过取景中可读的建筑构件、设施、器物、材料工艺或标识的组合落地，不仅在开头写地点标签。依本场挑选能互相支撑的特征，不靠一块文字招牌证明文化归属，也不把单个常见构件当作某地域独有的证据。明确项目为国内时落实该项目的现实条件；其他地域、时代及架空世界按各自依据设计，不套固定国家陈设模板。自然场景可由气候、地貌与植被关系承载身份，无须添加人造文化符号。

新建／完整重设计时，世界观既防止异物，也生成设计。依据已有技术、用途、材料和文化条件，提出本轮适用的构件轮廓、分段节奏、加工与连接规则，再落到当前建筑和核心器物。只补相关空白，不为完整而编造历史、宗教、贸易、能源或文明等级。

可推演“已有金属器物如何分瓣收束、石材如何宽面分块、接触边如何精修、已确认纹样怎样落在织物或边框”；不能由此宣称某民族拥有新神矿、用真骨建房或由魔法承托。普通制作提案可主动给出，但工艺性能未知不声称认证可造。已有真实历史精确还原需求依旧需要可靠依据。

以用途调整规则：同一构件家族可在公共空间形成连续结构，在私人空间形成小尺度接合，保持关联而不复制整间房。身份特征来自具体主形与工艺关系，不强迫每个表面印上徽记。项目资料少时形成范围有限的本轮视觉提案，不把暂定家族感升级为全片定案。

世界条件约束满足用途的方式，不直接规定每个地点同一外形、规模、库存或维护程度。将有关条件落实到可见组合及连接：人工构件看承托、开口和制作，自然环境看地形、介质与植被关系，混合场景看它们的接口；不为了统一强加其他类型的构件。人物处境、灾年或地域标签不自动扩散为所有空间的贫困、损毁或繁荣，地点差异须服从各自有效依据。

### 场所身份与空间规格

新建／完整重设计时，先依据有效资料判断目标地点的实际归属、使用者、用途及当前状态，再选择相称的空间规格。名称只是线索，不是完整类型定义：“厅”不必是公共散座厅，“雅”不证明小型包间；结合对应场次的接待、操作、参与关系和原文建筑描述判断。事实、必要功能推导与普通美术提案沿资产输入分开；关键类型歧义会实质改变结果时才补问，不把未写的桌数、房间尺寸或制度规格冒充事实。

把身份与功能共同转为空间选择，而不是先套通用布局再加身份道具。依本场适用条件协调：规模与围合、构造与开口、材料选配与加工收口、装饰层级、设施和陈设的组合／密度、收置及维护方式。人工、自然和混合场景分别采用相关项；自然环境无人工依据时由地貌、生态及状态关系成立，不强加装修、阶层或设施。普通可选造型主动提案，不编造新等级制度、历史或功能来证明合理。

规格是整体关系，不等于全部贵重、全新、洁净或满饰。生产与接待、主要与服务区域可有不同材料和装饰强度，但相关构造、围护、设施及器物应有相容的制作与维护逻辑。高规格生产区可由扎实构造、精整收口、成组耐用设施与分类收置成立，不必复制礼仪殿堂；朴素、临时、破败或自然场景也不能因“有设计感”被升级。使用信息沿下方使用状态规则，不能靠普遍污渍、潮湿和粗糙化替代运作。

在实际取景尺度检查可见组合：暂时去掉地点名称和少量身份道具后，是否仍能读到与本场有关的用途、世界及规格，而非只能靠标签证明？这是相称性检查，不要求观众唯一识别某座建筑、所有类别都视觉互斥，或每个部位同时入画。固定机位、极暗、严格还原及局部范围优先，必要限制如实说明。

防止误读的否定须配实际正向选择：限制无依据的奢饰时，仍写出相称的构造、加工和陈设关系；限制公共散座形式时，仍落实已有群体的接待与互动条件。不得用“不要普通／不要廉价”代替设计，也不把“克制”写成抹掉原文装饰。布局、成品压缩与反馈分别在其归属处应用本规则，不另建逐场必填清单。

## 真实感与考据层级

真实历史／现实题材中，先识别会影响身份的建筑、器物和地域特征。优先使用用户已有可靠资料；需要精确还原且依据不足时，按必要点查证一手史料、实物或权威机构资料，或说明待确认，不把想象写成“百分之百考据还原”。普通背景细节可有符合已知时代的艺术化提案，不因考据扩张到整片生产研究。

架空题材依据已知技术、能源、气候、用途和文化规则推演可见材料、承托与工艺，不强行绑定真实历史年份，也不编造文明演化、贸易或制度来给新设定找理由。特殊技术和违反现实物理的设计须有项目依据；已明确的例外保留，不擅自修成现实建筑。

普通建造可信度检查形体如何支撑、器物如何接触和使用、开口与空间如何衔接。尺寸不明时仅做比例与可用关系推演，不宣称完成工程力学、人体工学认证或施工安全检查。使用痕迹须区别一般磨润、环境老化和剧情事件，整洁维护也能表达正在使用，不强加半杯水、半开抽屉或破损。

## 设计补全边界

完整资产表控制处理条目，不是场景内部一切造型的逐项白名单。保留资产身份、用途、原定材料与有效状态后，主动深化可见设计，而不是只把描述写长。

| 类别 | 可以怎样处理 |
| --- | --- |
| 可直接提出的造型方案 | 主要物体轮廓、门窗框分段、墙顶层次、基座与端板、材料连接、表面工艺、抽象纹样和配色；普通相对位置与家具朝向未定时也可设计 |
| 有条件的普通陈设补全 | 根据[世界观体系](worldbuilding-systems.md)及适用的日常生活参考，在原地点用途及未定设计范围内补全正常运作的功能组织、普通设施、家具家电、用品与照明；须符合世界技术、规模、归属及维护条件，统一标为本轮美术提案。严格清单、固定基准及唯一光源限制优先，不替代原物或新增剧情道具、制度身份、特殊能力，不把“含某家具”当作唯一陈设清单 |
| 需要确认的实质变化 | 改变已确认入口、边界或共享关系，剧情依赖的隐藏区，新增超出原地点用途的建筑功能，阵营或宗教身份、特殊光源与魔法能力；未经确认不纳入正式方案 |
| 不得冒充事实的内容 | 新条目、楼层与密道、未经依据的历史事件、精确测量、真实罗盘朝向及技术来源；不为设计补造设定理由 |

第一、二类统一注明“本轮美术提案”，无需逐项等用户批准才能交付探索方案。原文未写普通细节不是禁止设计的理由，资料明确排除的细节则不可添加。

上述许可仅用于设计补全，不用于确定剧情道具何时在场、事件发生顺序或破坏状态；这类未知项及旧稿假设按 [资产输入与依据](asset-input.md) 处理，不能用提案标签绕过事实确认。

相对布局如“桌面朝向入口、书架沿后墙、窗在桌侧”可暂定；不是把“东墙、正北朝向”当成已测地理事实。已有剧情依赖的具体开口、遮挡或互通关系不擅自推定，关键歧义按资产输入澄清。

例如保留“大理石浴池”时，可设计池体轮廓、厚实连续池沿、外壁分段及与背景框架的呼应，而不仅加石纹；不能把它换成发光晶体池或增加祭祀功能。保留长桌议事厅时，可设计黑铁构件的节奏、白石壁面分层、桌体端部与双侧坐席关系，不需要另加王座、神像或龙族徽记。

## 器物适配

任何补充物件先回答：它在这里做什么、属于谁或哪个文化、如何制造、需要什么技术或能源。用可见形态表达答案，不能仅写“西幻梳子”“古风药瓶”。

- 先保留用途和原名，再选择符合项目的材质、构造、封口与纹饰。例如架空王宫的小药容器可暂定为磨光石罐或锤纹银盒，具体取决于项目材料；不能一律用现代医用瓶、螺纹塑料盖或工业标签。
- 仅当项目确实排除相关技术时才禁用对应造型；西方奇幻不自动等于某个真实中世纪年份，魔法也不自动允许所有现代产品。
- 原文明确的听诊器、玻璃、瓷器或其他看似跨时代的物件，是该世界已有信息。若与用户已定设定冲突，指出具体冲突；不擅自删掉、改名或把它解释成没有依据的魔法器械。
- 普通金属反射不等于发光。龙纹镜框不等于魔镜。丰富造型不能顺便加入飞行、自动疗伤、能量管线或仪式功能。
- 不把一处特有的道具、光源或阵营徽记移植到其他房间。材料可以共用，明确所属的物件与能力不能共用。
- 同时检查陈设体系：器皿、灯具、药具、布料、家具、门窗和墙面纹饰是否像同一个社会的产品。

## 符号归属与应用

纹章、宗教符号、商业标识和自然母题不是可随意互换的装饰。先核对谁拥有它、该时刻是否在场，再决定如何落实到已有门楣、镜框、柱面、织物或其他构件。

已确认的母题可在不同材料上通过浅刻、织纹或锻制形成呼应，密度与大小随构件用途变化；不用在每一面墙和地板上重复同一徽记。图案的结构节奏可借鉴，专属的身份和能力不可跨阵营迁移。

没有标志时可以采用符合工艺的抽象几何或植物纹样作为提案，不能为了辨识度发明新家族、宗教、旗号或政治关系。房间不必把世界观的每个维度都印成符号。

文字和非文字标识也是物质设计，不只是正文字符串。确有需要时，先核对内容／图形、归属与来源，再选择符合本项目的字形、阅读方向、书写或制作方式、载体及安装关系。时代标签、繁简体或“手写”单独不能证明适配；现代、真实历史与架空设定各按其依据，已确认的技术例外保留。无依据的专有名号限制不应误伤已有必要标识；内容未知且影响身份时补问，其余普通类别标识可按设计补全边界提案，不为丰富画面强加文字。可读性与成品写法沿提示词交付处理。

## 使用、时间与事件痕迹

环境可以体现如何被使用和维护，不必体现“刚发生过事故”。先区分一般表面状态与指向具体事件的痕迹：

- 一般使用：握持处磨润、坐垫压痕、织物自然褶皱、非完全对称的摆放、日用品集中收置及铺面局部接触光泽。按真实接触、取放与收纳位置分布，与用途和维护程度相符时可作为提案；整洁、新家具或干净墙面也能有使用信息，不以全屋做旧代替生活感。
- 时间与环境：暴露处风化、水接触处的痕迹、合理位置的氧化或修补；需与材料、气候及建筑状态相符，不能全部表面统一老化。
- 事件痕迹：破窗、血迹、倒椅、脚印、摔碎物、未喝完的杯子等会暗示具体事件或在场过程，必须核对对应时刻的有效依据。

有依据的因果链只描述当前能确认的部分，不反推新的剧情。明确破窗可核对碎片状态，但不能因此虚构入侵、打斗或弹孔；已确认整洁的房间也能通过加工、保养和物件关系体现身份。

少量有依据的痕迹优于满场杂乱，不机械限定数量。状态判断继续按 [资产输入与依据](asset-input.md) 处理。

“无人”表示当前不画人物，不表示清空日常陈设，也不能由此推导“无车辆、无设施、无用品”。按本场用途和有效在场依据保留或补全普通物件；若用户明确限制，则遵从其范围，不为生活感绕过限制。新添照片、纪念物及职业专属道具仍核对归属和剧情依据。一般织物压痕不指定谁刚使用过，未吃完的饭、未喝完的杯子及倒落物件等具体事件状态继续按上面的依据规则处理。空置、停用、刚交付或无痕维护等明示状态优先，严格清单及固定基准同样优先。

有人工使用的场景，联合判断三层细节，不把它们当作逐场必填清单：

| 层次 | 本轮设计应选择的关系 |
| --- | --- |
| 普通用品 | 哪些日常、经营或工作用品支撑当前区域；类别与技术、归属和状态相容 |
| 使用组织 | 常用与备用、操作与展示、取用与收置怎样分布；用品集中在相应使用面附近，有自然差异而非均匀摆拍 |
| 一般使用痕迹 | 褶皱、压痕、磨润或维护差异落在哪些真实接触位置；无痕维护可不加磨损，事件痕迹另核依据 |

普通设施与用品可在原用途和未定范围主动提案，不等用户逐件提醒，也不是增加剧情物证的许可。首版从实际使用需求推导组合及落点：哪些设施服务哪个使用面，常用、备用与收置怎样相接，再选择相容的一般痕迹。不限于剧情互动物件；相关区域按各自用途和状态发展，不因主体突出成为空壳，不机械每种需求建一区或复制同一套陈设。具体边界与周边联系沿走戏空间处理。

生活、经营、公共与工作空间先以取用、操作、交接、收置及维护组织体现使用，再按材料接触和当前状态选择相容痕迹；褶皱、磨损或杂物不能替代缺失的使用组织。自然环境体现地形、生态与介质关系，不强加人工设施。空旷、停用、空置及无痕维护保留有效状态，不以“丰富”填满或强加磨损。维护良好的完整物件、分类收置和自然形态也能成立；一般接触、环境暴露与事件痕迹分开，不统一老化所有区域或材料。

用品围绕对应使用面成组，形成有主次的疏密与自然差异，保留必要操作面及通路。关键组合按[首版深化](art-direction.md#适用细节与光影深化)协调取景和照明，并按[交付取舍](prompt-delivery.md#信息密度校准)写回类别、位置与状态；不是只有家具、空架和“生活气息”，也不把全部细节随机交给模型或均匀摆满角落。

## 场景辨识度

先完成一句话设计意图：“这个场景让人记住什么，以及为什么属于这个人物、势力或地点。”不以“华丽、精致、高级”作答案。

通常选一个主识别特征和少量支撑特征，数量服务于画面而非固定指标。优先深化资产表已有锚点，用下列层次建立辨识度：

1. **轮廓与空间**：门窗形态、拱顶、层高变化、台阶或自然结构，是否形成可以记住的空间关系。
2. **核心陈设**：浴池、王座、镜框、祭坛或桌案的轮廓、基座、材料连接及纹饰是否具有归属和用途。
3. **支撑对照**：材质冷暖、颜色明暗、坚硬与柔软等对比，强化主识别特征；不是到处复制同一图案。
4. **使用与光影**：生活、权力或仪式留下的静态痕迹，以及适合该空间的光线落点。

丰富程度要与用途相称。皇家场景可深化结构、镶嵌、浮雕、纹织物与成套器皿；荒野和贫民空间则通过自然形态、生活痕迹和地域特征识别，不能普遍奢华化。

## 更丰富的设计请求

用户明确指出场景朴素或缺少特征时，先诊断缺口所在层次及本次可改范围，再选择对应改进，不将“丰富”理解为默认改变主轮廓、布局或视觉重心。主形与空间关系已成立时，可沿既有结构深化制作、装饰陈设、用品组织或允许的光影；仅光色、纹理等局部请求就在该范围内改善。若原因在未授权的主形或布局，说明限制及建议，不自行重设计。按实际缺口选用下列方向，不要求逐项执行：

- 只有缺口确在主形／空间关系且本次允许改变时，才调整对应锚点的造型或关系，并核对必要功能、承托、取景与光源；新增提案不等于修改原文事实。没有这类缺口时不为了证明丰富而改主体。
- 为材料、制作工艺、纹饰和连接方式补足依据；给关键物体相互配合的层次，而非堆放无关小物。
- 保留行动通道、环境可读性与场景用途，让新增装饰能在选定机位看见。
- 造型、非剧情性装饰和未定相对布局按设计补全边界提出，不新增独立资产条目或故事功能；精确尺寸和地理朝向不冒充事实，复杂管线与实质结构变化不无依据添加。
- 机位与光源在概念和空间设计时联合考虑；颗粒、镜头质感和调色不替代环境设计。增加裂缝、雾气与形容词并不能使通用浴室成为某位龙王的浴室。

## 自检与迭代

知识库是通用方法，不是项目记忆。复杂方案按主入口使用[内部设计底稿](design-brief.md)，简单方案简记关键选择即可。跨次调用优先读取用户提供的已有美术档案和已确认锚点，缺少档案时不声称记得上次全部设计。仅在用户要求保存或更新项目档案时，按[连续性记录](continuity-record.md)写入相应文件。

按上方场所身份与空间规格检查适用的可见组合及同项目关系；不以独有徽记或昂贵小物代替整体相称性。检查所有主要物件的材质与技术，任何异质物件都应有原文依据、角色归属或明确设计理由。

新造型在输出中注明“本轮美术提案”，同项目后续暂沿用并可调整。用户指出造型不合世界观时，修正该选择及受影响的场景，而不是继续重复。没有实际成图时，只报告文字层面的检查，不宣称图像效果已经验证。

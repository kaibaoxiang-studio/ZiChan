# 主动电影场景美术设计

新建／完整重设计时必读；局部任务只有获准改变场景概念或核心造型时才读，并限定在授权范围。基础还原是底线，不是最终成果：主动发展属于当前世界、具有识别度、空间戏剧性与制作感的场景，再转成提示词。不等用户指出“普通”才启动设计。

按“事实与空白 → 综合设计需求 → 搜寻并提炼设计参考 → 自主场景概念 → 空间、形态、材料、光影与机位联合设计 → 完整提示词”推进。场所用途、世界条件、剧情互动、人物关系、适用情绪与用户目标综合取舍，不设固定权重；情绪按[叙事参考](narrative-and-character.md#剧情情绪作为设计因素)处理，检索按[设计参考](design-reference-search.md)执行。设计分析留在内部，局部任务只处理受影响项；专业难点按下表补读，不为新建一次加载所有专题。

## 设计适用性与闭环

在上述流程中先判断哪些关系会改变本次结果，再设计与核对，不另设逐场填表或固定物件清单。事实、状态、范围与来源等级沿资产输入处理；下表是贯穿流程的判断视角，不能用标题齐全代替具体选择。

| 判断维度 | 本次需要成立的关系与规则归属 |
| --- | --- |
| 身份与依据 | 目标资产、世界条件、单一时刻和来源等级相容；不把旧提案、图像附加物或未知升级成事实，沿资产输入处理 |
| 空间与环境 | 主体、必要周边、连接、边界及展示范围共同成立；整体不等于扩大资产，局部不等于切断必要上下文，沿走戏空间处理 |
| 功能与当前状态 | 按实际用途／自然条件判断运作、取用、维护或地貌生态关系；无人、停用、空置和未受人工影响分别处理，沿世界观体系及使用状态规则处理 |
| 形态与物质语言 | 当前可见结构、器物、表面、文字或符号属于适用的技术、文化和环境条件；场所身份与功能共同决定相称的空间规格，沿世界观与设计边界处理 |
| 美术与可见性 | 主形、体量、疏密、材质、光色与机位互相支持；必要信息在目标尺度及照明条件下可读，具体联合设计与五维审查沿本文件执行 |
| 连续性与交付 | 采用内容、授权变化与必要关联明确；自足生成稿仍承载有效设计，编辑稿明确基准及相关保留项，沿场景修改与提示词交付处理 |

通用底线适用于所有任务；条件方法只在相关条件存在时展开；具体造型、文字形式、陈设与维护方案属于项目层。无建筑不强加建筑检查，无标识需求不强加招牌，无人工使用依据不加生活用品；明示空旷、空置、极暗或严格还原也可成立。原文未逐项列出不等于没有需求，普通补全权限沿世界观与设计边界处理。不适用不等于漏设计，适用项也不要求一图展示所有细节。普通空白主动提案，关键未知才补问，不为了填满维度索取新资料。

设计完成后，按下节核对适用深化是否充分，再按提示词交付核对“选定关系是否进入成品、压缩后是否仍可还原”。反馈阶段按场景修改判断缺口发生于依据、设计、转写、表达还是实际输出，回到有关环节处理；不能把所有失败都归为缺细节，也不能只修表面而保留关系冲突。新建／完整重设计审查适用整体；局部修改、打光与换角度仅审查变化及受影响关系，不能借闭环重新设计未授权部分。

## 适用细节与光影深化

首版应完成相称、充分且协调的设计，不以主要设施齐全、空间可用结束，也不把可提前解决的缺口留给用户反馈或第二步。先确定整体空间与画面关系，再在同一方案中选择适用细节；形态、组合、机位与当前目标光影共同校正，不先列物件再拼接成场景。这里提高设计与表达完成度，不保证模型一次出图成功。

- **状态与用途**：按[使用与状态](worldbuilding-design.md#使用时间与事件痕迹)先发展设施、用品的取用收置与维护组织，再选择相容痕迹，不只深化剧情互动点。生活、经营、公共服务与生产各按实际运作选择；自然、空置、停用和无痕维护保留自身条件，不套固定用品或磨损清单。
- **形态与制作**：主体和关键实体按[实体关系](staging-layout.md#实体与组合关系)明确决定性形态与连接；适用构造和装饰按[制作层次](material-and-craft.md#构造与装饰层次)选择载体、工艺及依附关系。装饰可承担审美而不必兼作工具，不能只剩材料名或泛称精致；无饰和朴素不被升级，已有必要装饰不被抹去。
- **细节与整体**：以成组轮廓、体量和疏密呈现相关使用或环境信息，选择符合主次的落点；“物件已列出”不等于全景有存在感。需要辨认的组合不全部缩小、藏在边缘或压入暗处，也不为显出细节放大每个小物、填满空地或抢走整体重心。遮挡与光照限制优先，不要求所有细节可读。
- **光色与取景**：按[首稿光影](color-light-atmosphere.md#第一步的光影表现)用有效光路组织体量、材质及细节组合，亮暗与疏密共同形成画面；第二步不承接人为欠缺。明确平光、极暗、固定光源和机位保留，不为增强存在感强加补光。

交付前同时检查身份相称、功能准确、适用细节充分和整体协调：去掉“生活气息、精致、电影感”等词，能否从实体关系复述设计？关键形态、相关区域组合和维护差异是否成立，必要信息在本次取景及照明下是否可辨？是否以小物、做旧或强反差替代整体设计，或让细节挤占使用面、遮掉锚点、改变状态？发现缺口在交付前回改对应环节，不仅加长描述；不适用项不补，朴素、留白与严格还原也可充分。

## 从基础需求开始，不先装修原文

使用资产输入整理的三类内容：明示事实、功能推导、设计空白。事实和功能约束先保留，未定造型、材料加工、配色和相对布局保持开放。不要先扩写一份细节丰富的“优化原文”，再把其中自选的柱数、材料、形状和装饰升级为基础需求。后续设计选择始终标为本轮美术提案。

功能推导表达所需关系而非唯一解：例如入口可达核心前、有人停留的平整面、双方互见；不提前规定金色容器、柱列构型或台阶数量。按[场所身份与空间规格](worldbuilding-design.md#场所身份与空间规格)同时判断本场类型与规格，不让功能可用掩盖归属失配，也不让审美标签反向删减原有功能。已确认设计仍按本次任务保留，不能以恢复设计空白为由撤销。

## 从世界观体系形成空间

先按[世界观体系](worldbuilding-systems.md)选择地点涉及的运作关系，推导功能需求；个人生活再结合[日常生活体系](daily-life-system.md)的地点范围与归属者倾向。生产、服务、治理、文化等通过实际使用与设施关系形成空间，不只是增加主题装饰。剧情中的沙发／书桌是互动焦点，不是全部用途；依据正常使用、维护与剧情人数推导尺度，不默认租住空间狭小或所有人物房间同模板。新增方案、严格清单与已定边界按世界观参考处理。

个人倾向进入家具组合、功能组织、收纳、用品和配色；生活物品在实际位置成组收置，主要互动面及通路保持可用。初次取景交代必要分区的连接与纵深，局部背景按目标聚焦；不为展示全部生活功能改变已定机位或夸大空间。

执行时将世界身份落到可见构件／器物组合，将使用信息落到设施、使用面与收置／维护关系，而不是仅加地点名称、做旧纹理或“生活气息”形容词。按[可见世界语言](worldbuilding-design.md#从世界约束发展视觉语言)及[使用与状态边界](worldbuilding-design.md#使用时间与事件痕迹)核对：无人不推导清空，明示空置、严格清单和自然环境不强加用品。缺少可见落点或权限不清时补读对应段落，专题仍按需加载。

## 建立一个可见的场景概念

先按走戏空间完成导演调度判断，明确已有互动需要的使用面、接近与互见关系，再提出具体设计主张：“哪个主要形体与哪种空间关系建立什么体验，并怎样属于当前世界”。以此组织布局和选择锚点，主形与机位可以相互校正，但不能为漂亮构图牺牲必要互动关系。设计主张不是“宏伟、华丽、电影感”，也不是人物心理或作者意图的无依据断言。

选择最能承担地点身份的已有核心资产或自然结构，设计它与围护、路径和留空的关系。可用主物、成组结构或整体地形建立身份，不强制每场存在中央标志物。小屋、荒野和过渡场景同样需要准确、可辨的设计，但不一律奢华、宏大或奇观化。

关键选择存在实质分歧时，内部比较少量不同构型：它们应改变主形或空间组织，而不是只换配色。按事实与功能、世界一致性、可见身份、有效光源和机位表现选择一个。明确用户方案优先；简单任务不为形式凑多个候选。默认不外发候选报告，不把普通设计选择都交回用户。

## 世界观成为设计生成依据

从已有技术、材料、文化归属、用途和维护条件推导构件语言，再以有限的形体、加工与连接关系形成家族感。具体权限见世界观参考。先发展能落到当前构件的视觉规则，不编造一套历史解释，更不以“西幻”“皇家”标签替代设计。

同一规则按用途变形：接触边缘、主体支承、远距轮廓可以呼应，但私人工作空间与群体礼仪空间不复制同一尺度和布局。自然环境依据已有地貌、气候和使用条件形成差异，不硬加人工装饰。

多场景同轮设计时，内部复用已有项目材料、加工、色彩职责及适用照明规则；缺共用方案时，可形成有限的本轮共用提案，并在各稿中具体落实。单场景新选的家具款式、特殊光源或配色不自动成为全项目规范。逐场检查“共享哪些规则、因用途改变哪些关系”，避免只改场景名称，也不为差异推翻已确认的统一风格。无需外发规则清单或另建项目档案。

## 联合设计，再分层深化

基础执行检查集中在这里；专题只在上述难点出现时补读。按上节适用性选择有关检查，简单场景也不省略实际需要成立的关系：有进出或使用需求时检查入口、接近及停留；人工构件检查承托、材料分工与连接，自然场景检查有关地形、介质与环境的接合；各场检查可行机位下的主形、遮挡、材料本色与受光色，以及有效光源的路径、覆盖和亮暗主次。项目已定特殊机制按其依据处理。无相应需求时不为满足检查新增入口、使用面或人工支架；维护和痕迹服从已有状态。

先协调主形、体量、空间分区、核心资产造型、机位和有效光源路径，再深化节点与颜色；允许未定方案相互校正。核心变宽要同步检查接近面和遮挡，机位改变要重看可见面积与受光。不能分别写建筑、装饰、色卡和摄影段落后直接拼接。

新增细节须承担当前用途、世界身份、形体节奏、材料连接或光色层次中的具体职责；一项可兼有多种职责，不要求每项附解释。区分使整体空间成立的必要设计与当前画面的细节取舍：承托、连接、通行或光源关系不会因出画／遮挡而失效，必要时按走戏空间规则简述画外联系，不移动实体强求可见；仅为画面增加的制作细节按本次可辨尺度选择。未知背面只处理必要关联，不扩成全角度施工方案。主形／关系尚未成立时先改该层，不靠均匀铺满小物补救；设计成立也不等于装饰最多，朴素、留白与精确还原按实际要求保留。

| 设计层级 | 需要形成的选择 |
| --- | --- |
| 大形与空间 | 体量、跨度、围合、纵深、路径与活动面的关系，承担地点身份和空间体验 |
| 核心资产与中尺度构件 | 主物轮廓、分段、承托、构件节奏，发展定制造型而非通用物件加金边 |
| 近距制作细节 | 材料选配、同材异工艺、连接和收口；按可见尺度分配，装饰不占用功能面 |
| 光色与取景 | 材料色落点、面积主次、亮暗区域及来源、可行机位下的轮廓分离和功能可读性 |

“身份特征”“视觉中心”“定位锚点”各有职责：前者认地点，中者组织注意，后者相对定位。可以由相邻构件共同承担，但火焰、烟雾、光斑不能独自承担固定定位。重复锚点要用实际邻接关系区分，场景方向不随画面左右重新命名。

空间规模按身份、剧情人数及已定边界判断。需要宏伟时用跨度、净空、连续结构和前后距离体现，不靠拉高柱子、极端广角或单独放大核心。小场景不硬凑三层空间。只有文字时相对比例与动作面属于设计目标，不冒称实测。

核心资产不只深化容器。已有火焰、水体、岩层等亦可在允许范围内设计轮廓、层次、负形和与环境的呼应；静态火形不凝固成机械对称雕塑，水体造型不凭空违反重力。普通可见造型变化不等于新增魔法，但实体龙形、悬浮、自发光机制、能力或事件若无依据需确认；已定特殊表现保留。

## 设计审查与回改

先过事实、状态、功能与范围检查，再按五维判断设计是否成立；它们是内部检查，不另交五份报告，局部任务只检查受影响维度：

- **主题叙事**：哪个具体主形／空间选择支撑本场已有功能？去掉形容词、颗粒和小纹样仍能复述设计吗？只有片段时不编全片主题或导演意图。
- **空间戏剧**：入口、接近、坐席后撤、操作、互见与遮挡是否相容？当前机位是否展示所需身份、纵深和使用面，斜侧是否真有可见侧面？有效光源、光域主次是否保护必要锚点与操作面，而非吞掉它们？
- **统一美学**：核心是否有定制轮廓／构造，细节是否有同一世界的工艺、用途和可见落点？如何复用项目构件、材料及色彩职责并形成用途差异，而非通用物件加装饰或无差别名贵化？
- **真实感**：承托、连接、器物技术、维护与痕迹是否有依据？材料本色与受光效果是否分开？普通加工可否取得层次，不靠全场雕刻和普遍做旧，提案不冒称考据事实？
- **人物情感**：已有使用者关系如何落到家具组合、共享／分隔与取用？遮去场景名称能否读到生活或工作用途，信息是否集中有主次？无依据不新增信物，自然／过渡场景可不适用，不要求全部功能区和小物同时入画。

### 区分具体描述与有效设计

能复述主形只是最低检查，不代表已摆脱通用场景。“横向桌面配竖向书架”“穹顶下放火盆”等可以满足功能，却仍可能只是类型常见配置。新建／完整重设计时，在内部以同用途的通用配置作比较，不把想象的比较对象冒称已有作品或旧版输出：

- **可见差异**：当前方案在哪个主形、空间组织、核心构造或构件组合上有具体选择？差异须在目标取景尺度可读，不靠名称、罕见材料、小纹样或滤镜成立。
- **设计理由**：该选择怎样响应当前世界的已有条件、本场空间体验和使用关系？分别写出适用的因果关系；不能以“具有世界观”代替依据，也不强迫自然或过渡空间具备专属文化符号。
- **联动收益与代价**：该选择如何带动承托、留空、机位、材质或光域？有无遮挡操作面、挤压动线、抢走主焦点的代价？只列漂亮细节而不处理这些关系，不算联合深化。

差异弱、只剩装饰，或理由可以原封不动套给所有同类地点时，回改获准范围内最薄弱的主形／关系，再核对功能和事实。辨识度不等于前所未有或强行奇形化；朴素、严格还原及已明确的用户方案可通过准确的比例、组合与工艺取得针对性，不为制造差异改掉要求。局部任务只审查受影响选择，不借本检查重做全场。

没有落实时回改对应设计，再同步正文，不用延长文字代替创作。不要求所有场景同一高反差、固定色数、固定机位或奢华等级。电影级是创作目标，不是可由文字自评保证的质量认证；实际效果按验证参考区分文字、出图与空间证据。

## 落到交付

简记设计主张、关键选择、可见落点和来源身份；复杂方案按上述条件补读设计底稿。本地知识库按需补设计缺口，不要求全库读取，查询本身无需联网；构建前的网上设计参考搜寻仍按[设计参考](design-reference-search.md)执行。交付与压缩统一按提示词交付执行；需要校准“具体但普通”与有效设计时，可按需读[用例中的设计对照](../tests/cases.md#设计对照)，不将示例构型套用到其他场景。

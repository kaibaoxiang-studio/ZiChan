# 中文提示词写法与交付

编写场景生成或修改提示词前读取。这里维护共同写法、信息取舍、生成稿骨架与回填；打光、反打和局部编辑模板分别放在对应模式参考，不另设场景设计流程。

## 默认交付

流程介绍、当前阶段提示与下一步建议按[使用引导](../SKILL.md#使用引导与三步流程)执行，放在提示词代码块外；只在该规则触发时提供，不将说明写进图像模型指令或替代本次完整成品。

第一步及其他局部模式单场景仅交：原资产ID、名称、所选状态及必要提案说明，加一条置于代码块中的完整中文提示词。第二步默认另交一张适配光影色卡，用户只要文字时省略。第三步交本次所需角度的一条提示词，不重选配色或绘卡；复用色卡时说明其只控制光色。明确要求多角度时分别交单一画面稿，共用基准沿主入口。多场景按原表目标顺序逐项交付；不默认附分析报告、多角度套图、俯视图或状态弧光。

配色必须落到正文中的实体、区域及主次关系，不用“参照某色卡”替代光影设计。第二步色卡的版式、用途标注与本地绘图见[光影色卡](atmosphere-palette.md)；实际原图与色卡一起用于编辑时说明输入关系。第一步及其他局部模式不默认附卡；不默认交绘卡提示词、HEX表、比例表或检索报告。产物身份与执行边界沿主入口，不把提示词中的出图指令当作已经执行。

外围说明只保留会实质影响结果的状态、提案和冲突。造型、相对布局与普通装饰等视觉补全统一标“本轮美术提案”，不在正文逐句加“拟定”；事实与提案的判定沿 [资产输入](asset-input.md)。关键状态未知需确认或经授权作为探索稿，不靠一句“待确认”混入正式正文。

批量结果中，在原条目位置简述必要待补项，其余独立条目照常交完整稿，范围按[批量处理](asset-input.md#批量处理与共用依据)执行。同一场景获准多项修改时交合并稿，正文外只列实际改动与关键例外；不把内部动作依据、逐项功能检查、候选取舍或自评分数附成默认报告。

设计检索的来源与借鉴点按[参考交付](design-reference-search.md#交付与复核)简述在正文外。完整生成稿描述本轮自己的设计，不要求输入搜索参考图；复刻／依图编辑基准仍按用户指定区分。首稿承载完整目标状态，下一步提示不默认要求再深化一次光影。

## 把设计转成画面语言

先完成联合设计，再把选定主形、空间关系和制作落点写成画面；不是扩写原文、拼接候选或输出“象征孤独／权力”等设计口号。起笔和段落顺序按阅读需要安排，不把模板字段逐项外发。

功能推导译成实体关系。例如“可后撤、可绕行”写为椅背后的连续空地和桌侧通道；“远桌端与壁龛之间留出横向停留面，由桌侧通道抵达”同时交代锚点、位置与连接。删掉“作固定参照”等作用解释，不能连同空间关系一起删掉，或只剩构件名称清单。

选定的[场所规格](worldbuilding-design.md#场所身份与空间规格)须保留其决定性落点：用实际体量、围合、构件加工、设施组合及维护关系表达相称性，不压缩成“高端／皇家／普通”。按本次取景保留可辨的主次组合，不逐项堆满规格词；有关否定指明对象与例外，并写出正向实施关系，不能把避免过饰转写成清空有效装饰。

### 形态与关系的明确表达

按[关键实体选择](staging-layout.md#实体与组合关系)把影响身份、功能或剧情的形态译为可见关系，不能仅依赖名称或“L形、环形、开放式、单间”等标签。写出本次必要的组成、轮廓、连接与使用面；容纳、承托、开合等特征适用时明确，其余样式不逐件展开，不擅加精确尺寸。同类易混实体用决定性差异消歧，不以重复否定或长篇形容词提高优先级。

关键组合在同一描述单元中交代实体、承载／依附、相对位置和有关使用面，不把决定性关系散落在装饰或摄影段落；只展开影响结果的关系。同一实体称谓一致，局部功能明确归属；独立实体与主体区分，避免重复引入。数量及组合判断沿[实体与组合关系](staging-layout.md#实体与组合关系)，有需辨认的相邻组合时让机位支持其可见关系，不以移远、拆散或复制物件换取醒目。

正向描述优先。存在已观察到的误读时，可补范围明确的排除项，但须同时写出正确结构；不以反复强调标签或增加通用负面词代替关系设计。

### 信息密度校准

生成稿须独立还原核心设计；依赖实际图的编辑稿可由基准承载未改区域，但修改、易错关系与相关保留项须明确。按下表取舍，不另跑一套压缩流程：

| 取舍 | 保留或删除的信息 |
| --- | --- |
| 必须明确 | 身份与单一状态、地点范围、核心轮廓、关键实体位置／朝向、原定材料及本色、有效光源与机位、授权边界；按实际用途保留必要功能分区、设施连接、停留面与通路，不为凑项添加。必要剧情物件、标识和特殊构造不能因尺寸小或压缩而省略 |
| 按取景保留 | 展示范围及例外只由[取景范围规则](staging-layout.md#取景需求前置与戏剧承载)决定，本节负责压缩后的保真：保留该范围的主要区域与必要画外关系，以及选定的关键用品组合、使用／收置落点、适用表面状态与光影表现；近处写连接，远处写体量和色面，不以精简改变范围 |
| 合并或删除 | 同义形容词、重复位置句、不可辨的小装饰清单、理论／调度理由、自评报告、“杰作、顶级画质”等泛化词及无关负面词。同一决定只写一次；实体关系与投影可合句，但不能混淆 |

模型补全限于不改变核心设计的微小款式、细纹及无关紧要的样式差异。承担使用／环境信息、场所规格、美术主次或剧情功能的细节，写回选定类别、组合、相对位置及有效状态；构造与装饰保留关键载体、形态或工艺及依附关系。按[首版深化](art-direction.md#适用细节与光影深化)承接重要组合的可见轮廓、主次和光影响应，不能仅列物名或写“丰富细节”就声称设计充分。必要数量明确，次要款式不机械锁定，不为转写新增物件；整体空间、材质与光域不被某一小物的冗长要求挤掉。短稿可合句，不把关键关系压成形容词。

写作时保留这些易失信息：

- **空间与取景**：有停留／互动需求时，相关区域须能相对固定实体定位，不缩成“留有活动空间”。相机的空间位置、视高、朝向、俯仰和取景相容；画面左右、铺板、拼缝和木纹来自同一布局与透视。可用广角／焦距帮助描述，不堆强虚化遮掉必要背景。
- **用途与状态**：压缩后仍保留体现世界身份的可见组合及设施、使用面、收置／维护关系，不只剩地点名称、纹理或“生活气息”标签；依据与例外按[世界语言](worldbuilding-design.md#从世界约束发展视觉语言)和[使用状态](worldbuilding-design.md#使用时间与事件痕迹)核对，不输出人物动作或心理。
- **光色与标识**：材料本色与受光效果分开；把柔硬、覆盖、反射、衰减及亮暗／冷暖主次落到必要表面，具体难点读[光影细节](color-light-atmosphere.md#光影细节的可见描述)，不机械填满所有维度。极暗细部可隐入暗处，不以清亮展示词补光。必要标识写清实际内容／图形、载体及依附位置、影响结果的字形／制作方式、阅读方向和大小／明暗关系；适配依据沿[符号归属](worldbuilding-design.md#符号归属与应用)，不强制全字段展开或所有标识都可读。明确需要读出的内容不能用“古朴文字／一块招牌”替代，非正视机位按投影与遮挡描述，不让字体正面悬浮贴屏；资产 ID 只放外围标识。

交付前仅用最终正文反向还原关键实体、承载／依附及有关使用关系：生成稿不借旧对话，编辑稿带实际基准，再与有效依据和选定设计核对。承载缺失、用途不通、定位歧义或段落冲突先回改对应描述；内部考虑过、列出物名或写了合理不能代替通过。整体全景须能还原目标布局、主要区域连接及边界，局部只查授权变化与必要关联；光源、观察方向和修改范围相容。两种实质不同解释只补决定性关系，不恢复全部细节；机位或光照确实限制可读时说明，不强求全物件入画。这是内部文字检查，不默认附表或声称成图准确。不设通用字数上限；详细版增加可辨信息，不堆同义句。需要对照时读[密度示例](prompt-calibration-examples.md#示例三同一设计的信息密度)。

### 门的描述取舍

门是否写入提示词、是否入画及展开哪些细节，统一在本节维护；空间通行与实际遮挡由走戏空间处理。

- **普通门**：没有重要作用时省略描述，不默认要求门框入画、门扇贴墙开启，也不展开开向或门槛。必要进出关系简写入口／通道即可；相机在入口附近不等于门必须入画。
- **重要门**：承担明确剧情、关键通行／遮挡、地点识别，或用户要求时，只写与该作用相关的信息。例如门牌号有剧情作用就保留其文字与位置，不顺带扩写整套门构造。
- **定位与构图**：优先用相关桌端、床沿、墙角等实体，不硬加门或把门框当作每场默认锚点；门本身重要时才按需用其相关构件定位。
- **不描述不等于不存在**：省略门不表示移除已有门、改变入口与通行关系或抹去剧情要求，也不额外写“无门”来排除正常建筑。既有开口、门扇状态与遮挡在内部照常核对，未知开口不因省略变成已确认素墙。

## 完整设计版模板

用于新建或文字基准的自足生成稿；已有图的局部编辑只在用户同时要求文字主稿时另行合并。按资产实际需要删合段落，荒野用地形、岩层、植被等替代陈设，浅洞或小屋不强凑三层。以下只承接本轮已选定的适用关系，不为填模板加装饰、用品、磨损或光源；完整修订仍按授权范围保留原设计。全部占位项须替换，各段采用同一布局、材料和光源。

```text
【画风、时代地域、地点身份／用途与单一状态；核心轮廓、围护或地形结构及体现相称规格的可见组合；主要实体的位置与关系，有使用／互动需求时写相应陈设、朝向、功能连接及停留面定位，必要遮挡及原定障碍。】

【本时刻关键实体与必要文字；主辅材料及各自固有色、适用的分块／承托／连接和收口；已选装饰及陈设的载体、形态或工艺、依附位置及疏密主次；有使用依据时写普通用品组合、常用／备用的取用与收置落点，以及相容的一般痕迹或维护状态。】

【有效光源身份、空间位置、路径及亮暗／冷暖区域，受光、遮挡、反射与衰减如何呈现已选构造、装饰、用品及材料差异；按既定平光、极暗或其他照明保留可达层次，不逐件补光；可行机位、视高、朝向、俯仰与取景范围，当前投影中的必要可见参照和画外关系；项目成像质感与本次静态边界。】
```

## 设置与参考

画幅、分辨率、质量档位及专用参数默认放正文外；未知设置不编造，平台明确需要正文参数语法时再适配。独立负面提示词仅在用户要求且平台支持时提供，不预设所有模型均有或均无负面字段。

实际参考图分别标明身份、布局、材质、光色、风格或编辑基准的用途；只有实际提供多份时才编号。色板不能代替布局，中性身份参考光不自动成为最终照明。无图不声称已看图或编辑。设备、胶片与作品名称只是适用时的风格参考，不保证模型效果；细节按主入口条件读取成像参考。

## 迭代与回填

先按用户要求的产物选择交付方式，再判断哪些资料承担基准。上传图片可能仅用于指出失败、诊断或参考局部风格，不足以判为“编辑这张图”。明确要求“重新生成提示词／完整独立稿”时交自足生成稿；只承接有效设定及获准沿用的图像信息，不锁住失败图的全部关系，也不写必须输入原图的修改指令。明确要求“在这张图上修改／其余保留”时才交依图编辑稿。意图确有实质歧义时补问，不因附件存在自动选边。

| 本次基准与用途 | 完整成品 |
| --- | --- |
| 有实际基准图，用户目标是编辑该图 | 完整中文编辑指令及相关保留项，正文外说明同时输入哪张实际基准图；不必复述全场景，另要文字主稿时再同步 |
| 无图但有完整旧稿或足够文字设计；或有图但要求纯文字重新生成 | 将授权修改合并到自足生成稿，明确写出未改部分的核心造型、材质、布局、状态、光照与机位，不用“沿用基准／其余同上”省略 |
| 缺少能还原目标的基准 | 索取必要图或旧稿信息；资产资料足够且普通补全获准时可交提案，不声称复刻未知图 |

回写全文不授权重设计未涉及部分，也不升级旧稿假设的确认状态。未获准改变的材料身份、本色及构件组成须与可靠基准对应，不借丰富连接细节换材或添加新材料组成；必要关联调整只处理本轮变化所需关系。保留有效修正及其来源，固定锚点变更时指出受影响版本；不保证新生成与旧图像素一致。

转写前内部区分本轮保留、替换和新增的设计关系；完整生成稿合并有效内容，删除已被替换的旧要求，不能把新指令附在旧稿末尾而保留相互竞争的解释。关键修正放在对应实体的描述中，同步受影响的连接、通路、遮挡、机位或基础照明，不只在末尾重复“布局正确”“保持一致”。与本次无关的内部细项不需列成外发清单，全文回写仍只改授权内容及必要关联。

功能主次、构图主次和光域主次应相互支持，但不必完全重合。已有多中心、刻意留白、固定机位或特殊照明要求优先，不强制所有场景只有一个中心，也不要求核心区域永远最亮。

保真对象不限于大件：承担身份、功能或当前状态的小物、文字／图形及其载体同样可能必须保留。自足稿明确写回这些有效选择；编辑稿由实际基准承载未改区域，但易丢失的相关保留项须写清。反馈图自行增加的物件或文字先核对采用权限，不因看起来合适就升级为事实；未获准采用也不列入必须延续项。

反读成品时检查限定范围：例如排除无依据的名号不能同时抹掉必要标识，“背景弱化”不能抵消需看见的功能关系；保留要求也不能抵消已授权变化。把禁止或保留对象写到实际类别、区域和例外，删除无关泛化禁令，不靠堆负面词压住表达冲突。需要保留的关系若因本次机位、光照或范围无法可读，说明限制或在授权内调整，不声称写了就保证成图。

用户要求回填表格时保留原字段、行顺序、ID及子场景粒度，仅增加所需优化描述／提示词列，不另提取资产表。

## 交付核对

构造、装饰和陈设的选定关系按[深化要求](art-direction.md#适用细节与光影深化)一同写回，不把总体美术压缩成生活用品清单；原有必要装饰不被泛化的禁止项删去。

与本次底稿或修改基准逐项核对：条目与单一状态正确；主形及适用的材料分工、路线和实体锚点写出；供后续人物入画时，主要停留区可相对固定构件定位，重复锚点可区分，当前机位的可见参照与遮挡明确，人物入画不致失去唯一定位依据；同一布局对应同一视点和光源；配色与光域落实而非全局滤镜；必要背景的可读程度符合实际光照；保留项与修改项不冲突。新建还须将[适用深化](art-direction.md#适用细节与光影深化)的选定用品、使用组织、一般痕迹、制作与光影关系保留在成品，不能内部设计充分而正文只剩基础设施。局部任务仅检查并处理授权范围及必要关联，不能为补锚点越权重排。生成稿不依赖未知参考、外部色卡或旧稿省略语，外围说明没有冒称事实、出图成功或空间实测。详细设计验收沿主入口与验证参考，不在这里重复一套流程。

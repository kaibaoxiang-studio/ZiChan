# 第二步光影氛围色卡

仅用于第二步的“适配色卡＋完整光影提示词”交付，第一步及纹理／换视角不自动附卡。用户只要文字时省略绘卡；已有指定色卡直接读其颜色及用途，不强制重新制作。本文件是设计与绘卡方法，不授权自动生成场景图。

## 联合设计与来源

先核对原图、目标氛围、有效光源和授权范围，再按[色彩库检索](palette-selection.md)优先复用当前适用方案；缺目标氛围方案时筛选并完整读取相关的少量知识库条目。电影／导演资料仅提供冷暖、明暗与饱和度关系，不移植原片布景、光源、比例或剧情。必要时按需读取影片来源数据；概念配色、未经核验采样与只有来源无色值的记录分开，不称为电影官方色卡。适配后可删色、调整明度／饱和度或加入原图需要保护的材料色；改名和改值标为本场景提案，来源名称不冒充采样色名。

同一方案同时确定色卡与提示词，不先任意配卡再给房间涂色。每个输出色块必须有本场适用职责，主要光色应有对应色块；不强制用齐原参考颜色，不规定固定数量。若来源不适配可换候选或自拟，并如实说明；不能假称已检索或已有电影采样。

## 职责与边界

- 区分光源色、受光呈现色、阴影倾向、保留材料本色；用途说明落到具体光源或表面，例如“受光色：枕被与床头墙面”，不只写“暖色、温馨”。
- 环境基调体现在适用的大面积环境表面及受光关系，不等于全局滤镜。辅助色用于实际材料或层次，强调色只用于适用的少量重点，不为凑色新增道具。
- 默认保留材料本色；明确要求配色与光影调整时才列明允许重配的对象，其他不变。既有功能色、身份色与自然肤色按本次保护要求保留，无人不新增人。
- 色卡明度不是曝光或光照强度，纯色块不是表面涂料指令；允许颜色随真实受光、距离和材质自然变化。保留适用的相对关系，不要求每处逐像素匹配色值。
- 等宽色块只表示展示方式，不表达画面面积或光照覆盖比例；不标百分比，也不按来源比例绘卡。不要求每色明显或等面积出现，不为呈现色卡补亮暗部。
- 原图锁定空间与内容，色卡指导光色与影调，提示词规定光源及路径。授权例外列明，不把新增灯具与“所有数量不变”同时写进成品。

## 版式与本地绘制

白底，等宽等高纯色色块单行横排、均匀留白；无渐变、纹理、阴影、装饰光效。每块下方为中文色名及一两行简短本场用途。颜色数按场景决定，不固定七色，不在图中显示 HEX、百分比、影片截图或来源比重。参考来源与“本场景适配”放图外简短说明。

用本包[绘卡脚本](../scripts/render_atmosphere_palette.py)将已选色值与标签确定性绘为 PNG，无需生成模型。输入 UTF-8 JSON，结构为 `{"colors":[{"hex":"#D6B887","name":"柔暖米色","use":["受光色：枕被与床头墙面","随床头灯向床尾衰减"]}]}`；该单色条目仅展示字段，不是固定数量。颜色与用途保存为本次交付数据，不回填通用知识库或自动定为项目事实。

```sh
python3 scripts/render_atmosphere_palette.py /absolute/output/palette.json --output /absolute/output/palette.png
```

需要 Python 与 Pillow，中文字体可自动发现或用 `--font /absolute/path/font.ttc` 指定。使用当前环境可用运行时，不绑定作者机器路径。脚本不覆盖已有输出；重绘用新文件名。渲染后查看图片，检查中文无缺字、标签无截断、色值和布局符合设计。运行时或字体不可用时说明限制，先交完整文字方案与色卡数据，不把绘卡提示词冒充已生成色卡图。

## 交付与复用

默认一张色卡图、一条合并色卡应用与打光的提示词，以及必要来源／授权说明。真实色卡与原图均可用时，明确上传顺序和两者用途；按实际平台顺序编号，不固定将原图称作图2。无实际原图的文字深化稿不编造图像引用；色卡不可用或用户不需要时省略对应图引用，仍写全光色与路径。

绘卡与场景成图分开：提示词末尾可以要求图片模型输出已应用方案的场景图，但本 skill 不自动执行。复用同场景色卡保持职责与当前状态，用户改变氛围时仅更新相关光色，不因多轮测试自动认可新增灯具或永久改变材料。

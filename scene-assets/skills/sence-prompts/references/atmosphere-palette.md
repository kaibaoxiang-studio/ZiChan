# 第二步光影氛围色卡

仅用于第二步的“适配色卡＋完整光影提示词”交付，第一步及纹理／换视角不自动附卡。用户只要文字时省略绘卡；已有指定色卡直接读其颜色及用途，不强制重新制作。本文件是设计与绘卡方法，不授权自动生成场景图。

## 联合设计与来源

先按[基准诊断与预期增益](atmosphere-relighting.md#基准诊断与预期增益)明确本轮目标和光影关系，再按[色彩库检索](palette-selection.md)评估复用或检索；颜色与布光联合校正，不先任意配卡再给场景涂色。原图颜色约束材料与已有状态，不以“接近原图”独自证明目标适配，也不为显著差异故意选冲突色。电影／导演资料只提供冷暖、明暗与饱和度关系，不移植布景、光源、比例或剧情。必要时按需读取来源数据；概念、未经核验采样与只有来源的记录分开，不称官方色卡。改名和改值标为本场景提案。

### 目标适配与保护项分离

色卡主要表达本轮需要控制的光色、受光呈现或阴影关系。每块说明作用区域及其设计职责，如亮部柔化、阴影中间层次或局部材质响应，不只列材料名或情绪色名；亮度层级、照射路径及目标变化仍由完整提示词规定，色块不能独自执行重新打光。

增强先沿[目标关系与真实光路](atmosphere-relighting.md#基准诊断与预期增益)确定变化，再评估选卡；现有色相适用时可以只改光照关系，不为显示增强而换色或强造冷暖。旧日景卡不自动适用于夜间转化，新夜景效果也不证明原日景增强有效。

材料本色、文字及身份色是保护边界，默认在提示词写明；只有容易受调色误改或有实际参考需要时才加入色卡，并标为“保护”，不冒充本轮变化项。不能把每种原图材料都绘成色块而淹没主要光色，不要求固定数量、用齐来源或每轮都有强调色。保护项分离不等于允许改变未画进卡的本色。纯明暗／反光精修可以沿用相近色相，由提示词组织差异，不为色卡看起来不同强造冷暖变化。

沿用旧卡前核对它能否表达本轮目标及保护边界；仅属于同一地点或颜色接近还不够。若无增益来自光域或表达不足，可保留适用色值而修改职责及提示词；若旧提案的关系不适配，则仅在本次范围调整、删补或重新检索。用户指定或仍适用的确认配色不擅改，冲突按选色参考处理。没有合适来源可以自拟并如实说明，不假称检索或电影采样。

### 卡面与指令同步

颜色、色名或作用区域／职责变化影响卡面说明时，用当前数据重新绘制一张新版本卡，核对标签与完整提示词一致；仅职责或标签变化时保留适用色值，不因此重选颜色。旧卡与原数据保留，不覆盖或同时作为矛盾参考交付。仅光域力度变化且原标签仍准确时可复用原卡，不强制每轮重绘。用户只要文字时按免绘卡规则写全新职责；用户禁止改动指定卡面、或运行条件不能重绘且旧标签与新方案矛盾时，说明限制并先交不引用冲突卡的完整文字方案，不假称卡已更新。需要改变用户锁定的色值或职责时先处理授权冲突，不能借重绘越权。

## 职责与边界

- 区分光源色、受光呈现色、阴影倾向、保留材料本色；用途说明落到具体光源或表面，例如“受光色：枕被与床头墙面”，不只写“暖色、温馨”。
- 环境基调体现在适用的大面积环境表面及受光关系，不等于全局滤镜。辅助色用于实际材料或层次，强调色只用于适用的少量重点，不为凑色新增道具。
- 默认保留材料本色；明确要求配色与光影调整时才列明允许重配的对象，其他不变。既有功能色、身份色与自然肤色按本次保护要求保留，无人不新增人。
- 色卡明度不是曝光或光照强度，纯色块不是表面涂料指令；允许颜色随真实受光、距离和材质自然变化。保留适用的相对关系，不要求每处逐像素匹配色值。
- 等宽色块只表示展示方式，不表达画面面积或光照覆盖比例；不标百分比，也不按来源比例绘卡。不要求每色明显或等面积出现，不为呈现色卡补亮暗部。
- 原图锁定空间与内容，色卡指导光色与影调，提示词规定光源及路径。授权例外列明，不把新增灯具与“所有数量不变”同时写进成品。

## 版式与本地绘制

白底，等宽等高纯色色块单行横排、均匀留白；无渐变、纹理、阴影、装饰光效。每块下方为中文色名及一两行简短本场用途。颜色数按场景决定，不固定七色，不在图中显示 HEX、百分比、影片截图或来源比重。参考来源与“本场景适配”放图外简短说明。

用本包[绘卡脚本](../scripts/render_atmosphere_palette.py)将已选色值与标签确定性绘为 PNG，无需生成模型。输入 UTF-8 JSON，结构为 `{"colors":[{"hex":"#D6B887","name":"柔暖米色","use":["受光色：枕被与床头墙面","随床头灯向床尾衰减"]}]}`；该单色条目仅展示字段，不是固定数量。颜色与用途保存为本次交付数据，不回填通用知识库或自动定为项目事实。

```sh
python3 scripts/render_atmosphere_palette.py /absolute/output/palette.json --output /absolute/output/palette.png
```

需要 Python 与 Pillow，中文字体可自动发现或用 `--font /absolute/path/font.ttc` 指定。使用当前环境可用运行时，不绑定作者机器路径。脚本不覆盖已有输出；重绘用新文件名。渲染后查看图片，检查中文无缺字、标签无截断、色值和布局符合设计。运行时或字体不可用时说明限制，先交完整文字方案与色卡数据，不把绘卡提示词冒充已生成色卡图。

## 交付与复用

默认一张色卡图、一条合并色卡应用与打光的提示词，以及必要来源／授权说明。真实色卡与原图均可用时，明确上传顺序和两者用途；按实际平台顺序编号，不固定将原图称作图2。无实际原图的文字深化稿不编造图像引用；色卡不可用或用户不需要时省略对应图引用，仍写全光色与路径。

绘卡与场景成图分开：提示词末尾可以要求图片模型输出已应用方案的场景图，但本 skill 不自动执行。复用同场景色卡须重新核对本轮目标，按上文区分保留色值、调整职责与重选；不因多轮测试自动认可新增灯具或永久改变材料。实际效果按[增益与代价对照](atmosphere-relighting.md#增益与代价对照)验收，不以色卡漂亮、色相变化大或表面逐像素贴色判成功。

# 色彩、光影与静态氛围

生成或调整配色、光源、明暗关系和天气表达时读取。吸收环境设计库及用户提供的光色氛围提炼稿中的适用方法，并以 [色彩库检索与适配](palette-selection.md) 支持内部选色。仅保留静态场景设计，不接入人物表演、视频分镜或声音流程；不声称已直接核验原网页或导演原片。

## 分清三种颜色

1. **实体固有色**：石、木、金属、织物、涂饰及原有器物本身的颜色，是地点身份的一部分。
2. **当前受光色**：该时刻光源、环境反射与阴影使实体呈现的颜色；同一浅石在日夜下可以看起来不同。
3. **成像与调色**：项目确认的绘画或摄影风格、饱和度与反差处理；不能覆盖前两者。

先确认实体色，再决定照明和调色。不要为了得到“蓝色夜景”将木材改成蓝木、将白石改成黑石；不要把换视角时改变的反光当成材料换色。

材料色、颜料、染织、涂饰或釉色都可以参与配色，选择取决于项目工艺；不采用“材料色总比刷漆高级”的判断。

## 从实体建立配色体系

以大面积墙、地、顶或地貌形成基调，核心陈设与次要材料形成辅助色，已有旗帜、织物、金属边缘或局部光线形成点缀。说明颜色对应什么实体和位置，不只列三个色名。

- 大色块保持主次，小范围点缀集中在有用途的位置，避免各物件争抢注意力。
- 相邻场景复用项目色彩家族，按功能改变组合、面积和光照；不要求每个房间完全同色，也不强制相邻场景冷暖相反。
- 饱和度、明度和冷暖是不同维度。低饱和不等于灰黑，高反差不等于更高级；按已定画风和可读性选择。
- 色彩可以组织复杂或反差情绪，不限定“一场景只准一种情绪”，不据颜色推定阵营善恶。
- 主、辅、点缀是一种组织方法，不固定四色、六色或六三一比例；按场景实际材料、身份色和已有光源选用必要颜色，不为凑数量新增材料或器物。HEX可作为内部选色依据，默认正文用可见颜色及区域描述。

## 面积关系与视觉权重

配色不是概念完成后的整图套色。新建时与主形、功能面、有效光源和机位共同选择实体载体，深化时继续校正反射与衰减；不先将候选材料色写成原文事实。完整正文将实际采用的基调、辅助或强调色落到可见实体及相应面积等级，再说明光色如何影响它们，不能只列色名或写“按色卡”。这些职责按场景与本轮目标选用，不要求凑齐主／辅／强调色；中性、单色或仅明暗精修不强造强调色与冷暖分区，仍须写清适用的受光及层次关系。

在初步机位下按采用的职责检查：基调是否覆盖相应主要表面、辅助色是否有实际可见区域、存在点缀时是否集中。不强求未采用的辅助或强调色出现。不能只给柱脚一小块颜色，却声称它构成全厅的辅助色；也不能为了增加色块面积把已有材料全部换掉。局部修改受基准分布约束，无法达到目标时说明范围限制。

材料面积按当前取景中可见实体表面估计，以大面积、次要面积、局部或微量表达为主。确需估算比例时标为设计目标，明确计算范围，不当作实测；不得将材料比例、天空／火焰面积、光照覆盖与注意力比例混算。换视角会改变可见占比，地点材料身份及位置仍保持。

分别确定主焦点、次重点与背景的亮度、饱和度、反差和位置关系。重点不一定是最亮或面积最大的物体；应符合当前光源与设计意图。检查亮窗、反光地面及高饱和装饰是否分散注意力，选择在允许范围内的布光与影调关系，不靠无来源补光、移动已确认主物或统一滤镜解决。

## 带用途的色板与跨场景统一

项目已有色板或需要统一多个目标场景时，将颜色落实到用途和空间位置，而不是只罗列好看的色块。以下是可选职责，不要求全部采用，也不固定为七色：

| 色彩职责 | 需要落实的信息 |
| --- | --- |
| 环境基调 | 对应哪些大面积表面；区分材料固有色与照明、调色后的画面色 |
| 阴影倾向 | 位于哪些背光面、空间深处或遮挡区；保留何种亮度层次，不是给物体换材质 |
| 光源与受光色 | 依附哪个有效光源、进入路径与受光面；色板本身不能创造灯具或魔法能力 |
| 辅助材料色 | 对应木、织物、金属等实体，与已定材料和工艺相容 |
| 强调色 | 集中在哪个已有焦点或允许的局部装饰，承担什么注意力作用；不均匀撒满场景 |

同项目复用的是色彩职责与关系，不是要求每间房占比、亮度或受光色相同。不同昼夜、光源、归属和材料可调整具体呈现，不为追求统一把所有地点染成同一种颜色。内部配色可按主入口调用知识库，不默认选择某部电影或固定参考张数；第二步色卡交付按[光影色卡](atmosphere-palette.md)，其他模式不自动附卡。

统一美学维度还需核对项目已有光影与质感基调，但不默认建立全片暖到冷、亮到暗的情绪曲线。仅在剧情或用户意图有依据时呼应变化；保持所选时刻、有效光源及材料身份。原五维资料中的70／25／5是配色组织参考，不是本skill的固定比例，人物情绪也不自动决定冷暖、明暗或光源类型。

保护已有功能色与身份色：关键旗帜、纹章、信号、标识及剧情道具不能为了套色板被换成失去辨识意义的颜色。自然受光和克制调色可以改变呈现，但不改原有实体色或符号含义；具体颜色未知时不补造新旗号。用户明确要求人物入画时也保留合理肤色，不把无人图当成必须加人才能检验配色的流程。

## 第一步的光影表现

新建的基础照明既要来源成立，也要完成适合本场的画面选择，不把全部氛围留给第二步。与布局和机位共同选定有效光路，再将受光体量、明暗分区、反射及材质响应落到核心形体和适用细节上，包括构件凹凸、装饰边缘、陈设组合与生活织物；按所选气氛组织可见关系，不用“自然光、柔和阴影、电影感”代替设计。

例如已有侧窗和薄帘时，可设计帘后宽柔受光如何显出床品褶皱、木面反射及后部收纳层次；高墙露天通道可由墙顶受光、投影对道路的分区及铺地反射形成纵深。它们是方法示例，不是默认窗、帘、强日照或布光模板。不同材质不必同样明亮，细节不需逐件打光；本场需要的主次通过光域、轮廓和材料共同成立。

基础稿不强制中性平光、全清楚或戏剧性高反差。明确的平光、阴天、极暗、无痕维护与固定机位优先；光源不足时保留可达的层次，不为显出细节新增未授权开口、灯具、天气或空气特效。第二步沿已有实体深化或获准转化，不预留人为欠缺，也不自动交第二步稿或色卡。

## 光源与明暗组织

第二步的精修／增强／转化边界及增强目标归属[光影深化](atmosphere-relighting.md#基准诊断与预期增益)，光源调整与高光／暗部呈现的分工沿[照明及影调手段](atmosphere-relighting.md#照明手段与影调手段)。本节提供光路与材质方法，不把重打光简化为全局增亮、加反差、套冷暖或锐化，也不强制所有场景有直射、漫射及人工光三种来源。

新建内部先联合设计，再深化：先核对光源身份、位置、开口／照射路径，以及主形、活动区、遮挡和主视点的兼容性；再在这套空间关系上处理受光覆盖、材料反射、衰减、冷暖和焦点层级。这不等于主流程的两阶段交付；已有场景图的第二步单独按[氛围重新打光](atmosphere-relighting.md)执行。不能等建筑与取景定好才随意补光，也不能为光影效果改掉已确认空间。

依次明确：光源身份与位置 → 进入或照射路径 → 受光面与遮挡 → 材料反射 → 主区域及背景的明暗层次，并与底稿的空间关系一致。只描述对这张图有影响的光源，不为“戏剧性”给每个角落加灯。

原有普通开口、照明器物的轮廓与未定位置可作为提案；缺少照明设定时，可提出符合用途与工艺的常规照明方案，并在提示词外集中标明，不冒充原文在场物。新开口若改变已定边界或剧情关系需确认，不用天窗改造代替光照设计；特殊能量、魔法光源及被明确排除的灯具不得借普通补全添加。夜洞明确仅天光时不能新增灯火。

| 光线情况 | 写清的静态信息 | 避免的误用 |
| --- | --- | --- |
| 侧向窗光 | 窗墙位置、主要受光面、相邻反射面和阴影区域 | 没有窗却凭空出现窗形光斑 |
| 顶部开口或顶光 | 真实开口或灯具、光落点、结构遮挡与衰减 | 为神圣感擅自开天窗 |
| 逆光或亮开口 | 主物轮廓与背景亮度关系、内部保留程度 | 所有物体都补轮廓光，或主体完全不可读 |
| 天空漫射 | 来自开口或外部天空的宽泛照明、平缓过渡 | 阴天仍强行布置锐利太阳束 |
| 已有火光、灯具或特殊光源 | 具体位置、照明范围、邻近材料响应 | 普通反射被写成自发光，特有法器复制到所有场景 |

不默认四十五度侧光，不无依据编写色温、光比、曝光或精确时刻。同一自然光系统内阴影关系一致；存在多个有效光源时可以形成复杂但有解释的影子，不强行要求每条影子方向相同。

空间基调可由明暗分组建立。常规环境的必要操作面保持可辨认，边缘适度安静；原文为极暗环境时，功能先在底稿检查，成图只呈现照明能支持的轮廓与材料关系，允许暗部无法读出细纹，不为展示操作面把它改成明亮布景。

## 光影细节的可见描述

在光源与空间关系确定后，描述光落到关键物体及区域后的表现。按当前取景与修改目标选用下列维度，不要求每次写全，也不逐件规定全屋物品的亮度：

| 维度 | 可写的画面细节 |
| --- | --- |
| 光线性质 | 颜色、相对强弱、饱和度与柔硬，例如低亮度、低饱和的蓝灰天光，柔和暖白灯光；光源颜色与照明强度分别判断 |
| 受光与反射 | 主要受光面及邻近表面的间接光，例如沙发靠背受暖光，邻墙与木地板获得较弱反射光；范围服从照射路径、材料与遮挡 |
| 亮部细节 | 灯罩织物、高光边缘或受光材料的纹理保留与过渡；是否允许过曝由当前画风和意图决定，不默认所有亮部均匀清楚 |
| 暗部层次 | 背光面、房间深处的相对亮度、阴影软硬和可读程度；弱光只能支持轮廓时，不要求暗处细纹清楚 |
| 光域与反差 | 主要亮区、次要亮区及间隔暗区的呼应、过渡和随距离的衰减，明确整体反差；亮区相接须有照明依据，允许中间自然转暗 |
| 冷暖与材质响应 | 冷暖分别落在哪些区域，材料在受光下呈现的柔亮、钝暗或局部高光，例如暖光下米色织物柔亮、木面有克制反射，窗边保留少量冷色；不以全画面泛黄替代暖光设计 |

优先写影响主次、材质辨识和氛围的细节，用相对关系表达即可。简短稿可合并为“柔和暖白灯光覆盖沙发靠背与邻墙，木面呈现克制反射；照明向房间深处衰减，窗边保留少量低饱和冷光”。这是写法示例，具体颜色、光源与亮暗分布仍按本场依据选择，不作为跨场景默认效果。

### 沿光路组织细节

把“来源 → 路径与遮挡 → 受光落点 → 反射与衰减”写成连贯关系，而非灯具与色名的清单。同一窗光经薄帘覆盖的部分可柔化，穿过已有帘缝的部分可更清楚；不能为了条纹新加百叶窗或移动窗帘。直射光与天空漫射光并存时，区分受光面与背光面，并保留材料本色，不规定所有阴影同一浓蓝。

亮部、暗部和反射按取景重点分别落到表面：灯罩织物是否保留、书架是轮廓还是细部可见、木面何处有克制高光。选对主次有影响的少量对象，不逐件规定全屋亮度；暗部层次不等于把黑暗区域全部提亮，必要细节也不要求绝对无过曝。

## 用光照范围与空间关系表达氛围

把“温馨、孤独、悬疑”等目标转成光照范围、亮区连通、亮暗距离与可见边界，再检查是否符合既定时刻和光源。下列是可选方法，不是颜色与情绪的一一对应表，也不是每次必须生成的版本：

- 主要使用区及邻近入口获得连续的柔暖受光，可形成包围与亲近感；不代表暖光必然温馨，也不为连通亮区擅自加灯。
- 使用区与远处小亮点之间隔着较暗空地，可表达疏离或孤独；距离来自已有布局，不通过移动家具和开口制造效果。
- 局部可见与周边有限可读形成边界，可表达悬疑；门底光带等效果必须有对应缝隙和门外光源，不能凭情绪词自动添加。
- 低角度光在既有表面形成局部亮斑与较长阴影时，可强调某种时间与气氛；只有当前时间及光照允许才采用，不能把夜景改成夕阳。

区分同样偏冷的方案：孤独可以来自主使用区与远处孤立暖光之间的暗区和距离；悬疑可以来自方向光的局部可见与遮蔽边界。颜色只参与表达，不能把蓝色、暖色或高反差当成情绪标签。温馨也不必全屋泛黄，慵懒不必全场金色；具体前提见[教程案例](../knowledge/lighting/living-room-atmospheres.md)。

只改光色时保留结构、陈设、机位、材料本色及未获准改变的物件状态；明确授权重配本色、增删光源、开关或昼夜变化时列明例外，不将其与全部状态／数量保留混写。调整明暗、受光范围与影调仍符合出光、距离和遮挡，不凭情绪或色卡任意扩大光域、新增光源或把烛火改成冷蓝光。若给定光源不足以达到目标，说明可达效果与限制，不用另一种光源偷换方案。光色不能替代主形、材质和可用布局的设计。

把人物、动作、镜头运动和音乐移除后，空场描述仍应通过可见关系支撑目标氛围；这只是文字核对。实际图像的氛围是否成立，必须查看成图后判断，不声称仅靠提示词已经达到效果。

## 夜景不是白天简单压暗

首先确认夜间实际可用的光：天光、雪水或浅色表面的反射、月光、火光与灯具，只用输入支持的项目。夜间不必有月亮、暖灯或蓝色光束。

暗部依照画风保留层次，可以是低亮度色阶、轮廓边缘与受光关系；纯黑、高反差或抬升的乳灰暗部都不是跨项目默认值。用户指定乳灰暗部、无压黑时照办，不采用来源“越黑越好”的要求。

亮点只需在当前环境中成立，不必达到过曝；光晕、颗粒和高光过渡属于成像风格，与是否有光源分开。不能同时要求清亮均匀照明和“靠近不可见”的夜景。

## 天气与空气的静态表达

昼夜、季节及天气由有效输入和所选状态控制。情绪建议不能把日景换成雨夜；地区日照也不能套用固定钟点表。

- 雨：只在实际暴露或受水的表面体现湿度、局部反射与水痕；遮蔽室内不因此全屋湿亮。
- 雪：积雪体现地形、迎风与避风位置，覆盖后的轮廓仍与原结构对应；脚印需要当前状态依据。
- 雾、尘、烟：明确允许出现的来源、范围及远近层次；不默认所有室内都有体积光，不用浓雾掩盖空间未设计。
- 风：可用当下定格的织物曲面、枝条姿态或有依据的沉积分布表达，不写循环摆动、连续飘移或声音。
- 远景：清晰度和色彩变化与距离、空气和风格相符，不规定远处一律偏蓝；小房间不用凭空加大气透视。

形态、光源、材料与空气共同表达氛围，不把“温馨、压迫、神秘”直接等同某一种颜色或天气。

## 提示词与连续性检查

正文可写：“浅石墙的米灰与深褐木构形成实体基调，暗红织物只集中在桌后；窗侧的冷漫射光沿石块细磨收口形成柔和亮面，粗墙和织物保留更暗、更钝的层次，桌面仍清楚可辨。”这是可调整的提案，不是默认项目配色。

同一时刻换视角时锁定光源空间位置、实体材质与天气，再按机位推导画面左右、阴影投影和金属反光。用户要求的日夜或天气变更只改变相关照明与表面状态，不重做固定结构。无实际图像时只核对文字关系，不宣称光照或颜色已经成图验证。

场景普通时先辨别问题：主轮廓与空间关系缺少区别，需造型设计；已有主形但受光均匀、焦点分散，调整光照范围与明暗分组；跨场景颜色失配，核对色彩职责与保护色。仅光色请求只调整范围内项目，若主形问题无法由光色解决，说明限制并建议另行授权，不反向重排布局或改造型。没有足够证据时提出待查项，不一律靠青橙调色、加雾或压黑修正。

交付前核对配色已落到可见实体与区域，而非仅列色名；面积等级与机位相符；光域及阴影可由有效光源解释；身份色保留；主次视觉关系不被背景抢占。将关系合并进完整提示词；第二步另附无比例光影色卡，不默认交 HEX表、颜色比例或检索过程，第一步及其他局部模式不自动附卡。

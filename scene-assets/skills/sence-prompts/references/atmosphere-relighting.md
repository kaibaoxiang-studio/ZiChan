# 第二步：场景光影氛围深化

用于第一步场景图已认可后的重新打光与氛围强化，也适用于可靠已有场景的同类请求。联合设计静态光影与[适配色卡](atmosphere-palette.md)，交付色卡图及提示词；不自动生成场景图、修改资产表或进入视频制作。光影细节方法见[色彩光影](color-light-atmosphere.md)，写作与模板见下方[二次打光交付](#第二步二次打光提示词)。

## 基准、状态与授权

先按实际改动区分本轮意图，不强制向用户外发模式标签：精修保留已成立的主要光影关系，只处理局部缺陷；增强在现有照明条件下重新组织受光、体积、空间层次或材质响应；转化改变昼夜、天气、光源身份／位置等条件，只执行明确获准的变化。“温馨／电影感”不单独构成转化许可；成功的日夜转换也不代替同一条件下的增强测试。三者是第二步内部选择，不新增工作流阶段。

输入通常是实际原图、目标资产或可靠地点标识、对应剧情／氛围要求与本次允许改变的条件。已有资料直接使用，不重复索取完整表。用户只说“强化光影”时，默认保留当前昼夜、天气、光源身份与位置，在有效光源内设计明暗、柔硬、覆盖与影调；非剧情关键的普通灯具可在氛围重打光范围内提出开关方案，明确为本轮提案，固定或剧情指定状态不改。

明确要求改为夜晚、夕阳或开关某盏灯时，按授权更新相应条件；夜晚不自动等于月光，夕阳不自动确定未知窗向。新增或移动灯具、设定画外街灯／走廊灯、特殊光源与天气变化均须有有效依据或本次明确许可。缺少条件时先用现有条件形成可达方案，只有目标依赖这些变化时才询问必要选择。若空间条件不足以实现预期，说明限制，不偷换光源或改装修。

原图的可见结构、实际灯具和光照迹象可以作为本次编辑基准，但不能从一个亮斑认定未知画外光源、从图中出现某道具确认其剧情在场时刻。资料冲突、关键道具与特殊状态仍按[资产输入](asset-input.md)处理；图像或旧稿中的假设不因沿用而升级为项目事实。

没有实际图像而只有完整旧稿时，可输出完整文字光影深化稿，并说明未经图像核查。用户指定“基于原图编辑”却未提供可访问原图时，请补图，不编造图片编号、不交伪称已看图的编辑成品。局部光影方案可以独立提出，不宣称完成第二步成图。交接第三步按[阶段基准交接](../SKILL.md#阶段基准交接)：当前只交了提示词或色卡时，其身份仍是方案；实际氛围图可用后才能作为图像反打基准。

## 固定与可变项

先选定本次模式：默认光影氛围深化，材料本色固定；只有明确要求配色与光影调整时，列出允许重配色的对象。新增／移除元素或特殊状态变化也列为本次例外，保留约束排除这些例外，不泛称所有数量／状态不变。下表为默认模式，例外只在授权范围覆盖相关项。

| 固定基准 | 随授权打光更新 |
| --- | --- |
| 相机位置、画幅、透视、景别、景深与前景虚焦；空间边界、开口、家具位置、形状及非照明物件状态 | 光源强弱、柔硬、受光覆盖，以及本次允许调整的灯具开关、时间或光源条件 |
| 材质身份、固有色、已有纹理、生活痕迹与实体锚点；未经授权不改各光源来向及其实体遮挡投影关系 | 阴影明度、显隐及有依据的软硬、反光、间接光、局部呈现色与整体影调；不任意旋转或挪动投影 |

“材质不变”不等于反光亮度不变，“构图不变”不等于原阴影逐像素不变。不能同时要求重新打光与保留全部旧影子。不开柜、挪窗帘、搬家具、变门的开闭来制造光线；涉及这些实体状态变化时需另有授权。暗处细纹不可见不等于删除生活痕迹，不为显露它们重新做旧或全面补光。保留原有画风，颗粒、光晕与锐度不作为每次必须新增的效果。

允许旧光斑、阴影亮度和反光更新，不等于可以任意改投影：光源位置／来向及遮挡不变时，阴影几何仍服从它们；柔硬和覆盖变化也须能由现有光源与路径解释。不能以“重新打光”制造反向日照、透墙光或修改材料粗糙度来获得高光。

## 从剧情目标到光影方案

### 基准诊断与预期增益

先核对基准中的主要使用面、通道、固定参照，以及开口、灯具、遮挡和材料，再判断视觉主次、空间层次、材质受光与目标氛围还缺什么。实际图像观察、完整文字设计和用户报告分开；未见成图时只能检查文字方案及报告的问题。然后用已有剧情或用户目标确定视觉重点，缺剧情时提出有限方案，不编造等候者、来客、威胁或事件。“电影风格”等画风不代替本轮氛围目标。

将有必要的改进写成“具体区域／对象 → 当前不足 → 目标关系 → 有效光源或影调手段”，内部选少量关键项，不强制外发清单、数量或评分。例如调整使用面与背景的分离，控制大面积亮部的抢焦点，恢复有环境光支持的阴影层次；也可保持既有主次，仅精修高光过渡。不是每场都要突出一个物件、压暗背景或增加冷暖分区。

原图或可靠文字基准已满足目标时，可以说明增益有限并建议精修或沿用；仅问必要性时不强交新稿。明确要求继续交稿则按必要精修范围完成，不自行跳到第三步或将提案视为确认。第二步的价值按目标关系是否改善判断，不按换昼夜、色相跨度或变化幅度判断。第一步不因此退化成无光影的平光底图。

剧情与氛围均未指定、只要求“强化光影”时，依据当前照明和空间用途，提出一套克制的光影层次优化：让主要使用面、材质与前后空间关系更清楚，不自动选择温馨、孤独或悬疑，也不更改昼夜、天气和光源身份／位置。正文外说明这是本轮打光提案，不推断作者意图；灯具开关遵守上文边界。无需为一般影调选择暂停询问，只有达到目标必须改变既定条件或在实质互斥方向间选择时，才问必要问题。

明确要求增强或反馈“与原图变化不大”时，不能只追加“更自然／更有层次”或更浓的调色。先核对基准，再将尚未实现的变化写成可观察关系，按适用性选择：

- 受光与体积：哪个表面获得更完整或更克制的受光，如何向背光面过渡；不将整件物体等亮抬升。
- 空间组织：哪些区域保持、加强或减弱，亮暗如何连接与衰减；可以改善均匀柔光，不强制单一焦点、前亮后暗或背景压黑。
- 材质响应：同一有效光照下，原有粗糙／光滑表面的漫反射与高光如何有所区别；不统一油亮，也不用锐化、换材或新纹理冒充照明收益。

从现有直射、漫射与间接反射中选实际存在且可调整的来源，写清“来源 → 路径与遮挡 → 受光落点 → 反射与衰减”。只有对应来源存在时才调整其相对强弱，不把“减直射、增漫射”套给所有场景；局部亮度变化须连带解释邻近表面与遮挡，不凭空单独给目标补亮。没有真实增益空间或有效光线不足时，沿用上文的精修／限制说明，不为追求差异偷换天气、加灯或硬造三项变化。

### 照明手段与影调手段

每项变化要落到实际可执行的手段，而非只宣告结果；可以合并写在正文，不强制额外交分析表：

- 有效光源调整：说明哪一已有来源在允许范围增强、减弱或保持，以及相应表面和邻区如何响应。辅助光也可适度增强，不默认只能削弱；固定亮度／开关等条件仍优先。间接光随原光源、路径、材料和距离变化，不作为可独立随意调亮的新灯。单一来源且几何、材料固定时，不能只写“重分配直达／反射比例”便声称获得新光路；自然光调整须与既定天气、来向和遮挡相容。
- 影调辅助：收敛已有亮部、高光过渡或整理有信号的暗部，属于成像表现调整，不改变光源条件，不移动投影、不补造暗处不存在的信息。与有效照明调整共同使用时分别写清作用；仅影调可改善时交有限精修，不冒称已重新分配实际照明或达到不可达的照明目标。

同一来源强弱变化可带动直达与反射一起变化；多个来源主次变化可改变哪组影子更明显，但每组投影仍服从相应来源与遮挡。不要把固定投影解释为旧阴影明度逐像素锁定，也不要用后期局部提亮为穿墙光或无来源补光辩护。

在固定布局内联合设计：

1. 光源主次：哪一来源主导，哪些保持、适度增强、减弱或按许可关闭；选择服从有效来源与授权，不要求凑齐操作，不用固定三点布光或每角落一盏灯的模板。
2. 照射路径：来源经已有开口／遮挡抵达哪些表面，哪里产生直接光、柔化光或间接反射；光域不能任意穿越实墙和高柜。
3. 空间明暗：主要亮区、次亮区和间隔暗区怎样相接或分隔，前后距离怎样被看见；调整光域，不通过移动实体制造距离。
4. 材质与影调：保留必要亮部纹理，暗部按实际照明呈现色阶或轮廓；冷暖落在具体区域，反射随材质和距离变化，不用整图滤镜代替打光。

“强化”指光影关系更明确，不默认更暗、更硬、更高反差、更饱和或加烟雾。根据目标保留柔和、低反差的方案。主视觉不必最亮；灯罩或窗外高亮不能吞掉关键使用面。固定实体不锁死照明结果：在有效光源、路径和遮挡内调整受光强弱、反射及明暗分组，不能将“保留原图”写成所有旧光域和影调不变；也不能凭空单独打亮某物或将背景统一压黑。

先指出本场要改善的具体层次，例如使用面与背景难分、亮窗抢焦点或暖光范围过散，再将改动落到现有光源及表面。柔硬、光色和照射范围须与原光源及遮挡条件相容；阴天漫射窗光不因“更戏剧性”改成锐利太阳束，固定灯罩不通过改造外形取得硬光。目标受现有条件限制时，交可达的层次方案并简述限制；仅当目标必须依赖新增或改造条件时补问。多氛围版本比较的是获准光影关系，不能靠挪家具或换材制造差别。

后续人物入画的需求只转为空场中的受光覆盖、亮暗衔接和实体锚点可辨程度。检查主要停留面、操作面及必要连接通道，不能为看清人物而凭空补光，或要求每条路线全程等亮。锚点原来不可见或有效光线不足时说明限制，不搬动参照、不改机位。提示词不添加人物、脸部补光假象、动作、表情、声音或运镜。

## 第二步二次打光提示词

先确定预期增益和可达的光影关系，再按[色卡适配](atmosphere-palette.md#联合设计与来源)选色并联合校正，不能让原图取色或库内整套色板替代设计。完成后按“参考分工与授权 → 原图保留边界 → 目标变化 → 光源与路径 → 色卡在受光／阴影中的职责及材质响应 → 整体氛围与输出”组织稿件，不要求固定标题或段数。增强稿必须写出可观察的关系变化及其手段；精修只写必要缺陷，已达标不机械套用增强。共同信息取舍沿[提示词交付](prompt-delivery.md)，每个重要判断落实到有效光源、受光表面或亮暗关系。

交付类型沿[迭代与回填](prompt-delivery.md#迭代与回填)：用户目标是编辑实际原图时采用下方依图模板；明确要求独立完整提示词时，即使有参考图，也须合并核心旧设计及本次光影方案，交不要求同时输入原图的自足生成稿。改为独立稿不授权换机位、重排实体、重配材料色或补设未知光源。选定唯一模式、替换全部占位项，仅保留相关条件。正文外简短说明资产、单一状态、实际基准及授权例外；未经要求不指定新机位、焦距、景深或画幅。无色卡或用户只要文字时删除色卡引用，仍写全光色与路径；图片编号遵从实际输入顺序，不凭空编号。

```text
【实际色卡引用】仅用于光色与影调，【实际场景原图引用】作为空间与内容基准。读取色卡颜色、名称与本场用途，不将色块、文字、白底或排版复制到场景中。本次仅调整【明确的光影及配色范围】，使【具体对象或区域】由【当前关系】改善为【目标关系】，另获准【时间／灯具开关／增删元素等具体例外；无则删去】。

保持原图摄影机位置、构图、画幅、透视、景别、景深、前景遮挡与空间结构。除上述获准例外外，保留人物及物件数量、位置、形状、材质、状态、生活痕迹和已有文字。【默认保留材料本色；获准重配时改为列明可改对象及其目标颜色】，不重排陈设或改造装修结构。

【增强时：重新组织上述目标区域的受光覆盖、明暗过渡或反射，不照搬旧光斑亮度、旧阴影明度与旧反光；投影仍服从当前有效光源的来向与实体遮挡。精修时改为仅列必要缺陷与保留的关系；转化时按已获准的新照明条件描述。】

【当前或获准改变的时间条件】。以【具体位置与身份的光源】为主，呈现【强弱、柔硬与光色】；【其他有效光源】按【允许范围内保持／适度增强／减弱／关闭，选实际适用项】处理。写清【具体来源的获准变化及邻区响应；只做影调精修时改为保持当前照明条件】，光线经过【已有开口和遮挡】，落在【主要受光表面】，向【其他区域】自然衰减，间接反射随来源与表面条件变化，不独立制造补光。

【若采用影调辅助：对具体已有亮部／暗部作何种有限调整，保持投影、材料与可读信息边界；未采用时删除。不把高光收敛或局部明度处理写成新增光源／新照射路径。】

将【实际采用的色名与职责】分别落到【对应的有效光源、受光面、背光区或必要保护对象】。环境基调体现于适用表面及受光关系，不统一染色；【仅在方案采用强调色时，写其具体局部用途，否则删除】。参考本轮适用的光色及影调关系，不强制用齐或等面积分配，不以色块明度规定曝光、灯光强度或逐像素颜色。

【亮部表面】保留必要纹理，【背光区域】呈现【实际可读层次】，邻近【材料】获得【有依据的反射】。【仅在本轮采用冷暖分区时写具体区域，否则删除或写明保持原光色】；亮区与暗区形成【目标相接、分隔或渐变关系】，整体呈现【适用的影调】。有后续停留／互动需求时保留【相关原有实体参照】在有效光照下的必要辨识，不为展示所有区域全面补亮。

颜色随材料、受光与距离自然过渡，保留物体边界；有人物时保持自然肤色，无人时不添加人物。营造【目标氛围】，避免【本场易出现的光影偏差】，保持原有画风。输出应用本次色卡与打光方案后的场景图，除明确许可变化外，原始内容不变。
```

模板末尾的出图要求只交给图片模型，不表示本 skill 已执行。锁定实体不锁定旧阴影与反光，不用“其余同上”代替相关保留边界；不删除已有标识，不堆通用负面词。多氛围仅在用户要求时分别交单一方案，说明差异来自哪组获准光影关系。默认一张色卡配一条合并稿，不拆成独立涂色与打光指令。

## 案例与交付

需要区分相近氛围时，按需读[客厅四氛围案例](../knowledge/lighting/living-room-atmospheres.md)。它们提供有前提的关系，不是默认四套版本、固定配色、必需门光或当前模型配置。

默认交原资产／采用基准与单一状态、必要光影提案说明、一张适配色卡图，以及一条代码块内的完整色卡应用与打光提示词。实际原图与色卡用于依图编辑时明确各自引用关系；用户只要文字时省略绘卡，完整表达光色职责。有可靠文字基准但无图时仍可配色卡交文字深化稿，不虚构第二张图片；缺必要原图或授权时先处理依赖，不用绘卡冒充完成场景编辑。依图编辑稿只复述与保留边界及受光有关的主要物件，不重新罗列全场景；自足生成稿须写全未改部分的核心造型、材料、布局、状态及固定机位，再合并本次光影，不借“其余保留”省略。不默认交 HEX、比例、四套版本、视频脚本或场景出图结果。

交付前核对：目标变化有具体区域和可达手段，保留项不抵消改动；每个重要光斑、阴影和反射有来源与路径；时间与开关有授权；实体色与受光色分开；必要锚点的可读程度不夸大。提示词不能保证像素一致，流程与文件验证不代替成图验收。

### 增益与代价对照

有实际结果时，以本轮基准及目标对照：预期主次、空间层次或材质受光是否改善；是否同时损失文字／身份色、必要暗部辨识、亮部纹理或布局连续性。变化出现但未解决目标、或以明显损失换取反差时，报告部分改善及代价，不以更暗、更暖、更饱和判成功。原本允许极暗、剪影或高反差时按该目标判断，不强求暗部细纹。色卡排版及颜色相似不等于氛围有效。

增强结果还须能用受光覆盖、明暗过渡、反射或空间分组说明收益，不能只以色相／全局曝光变化或新颗粒证明“重新打光”。按本轮选定的改善项验收，不要求每张都同时改变体积、空间和材质，也不规定变化幅度。若仍与基准近似，先查目标是否达标、手段是否可达、保留项是否抵消改动及模型是否执行，不默认加重滤镜或切换昼夜。

只有文字或用户报告时结论限于对应层次，不声称看过未提供结果；仅审查不改稿。获准迭代时，先判问题在目标／设计、色卡适配、表达还是输出执行，按[反馈规则](scene-editing.md#反馈诊断与修正)处理。当前反馈版损坏了有效层次时，经本次采用选择回到可靠旧基准，不默认在失败结果上继续叠加滤镜，也不自动推翻用户已采用版本。

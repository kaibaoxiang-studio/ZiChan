# 地貌、外景与建筑群

设计自然场景、室外建筑、街道、城市，或室内可见外景时读取。以当前资产已有地形、气候、结构和边界为依据，不顺带设计整个世界或新增独立场景。

## 自然形不是背景贴图

先确定大地形与主要方向，再描述分层、边界和地表分布：岩壁的层理与裂解、坡脚堆积、地面起伏、水岸转折、植被群落或积雪边缘。核心记忆点优先来自已有形态关系，而不是自动发光和巨型化。

| 环境类型 | 可深化的形态与材质 | 要保持的边界 |
| --- | --- | --- |
| 岩地、山地、峡谷 | 层面、断裂、倾斜板块、坡脚碎石和开口尺度 | 不把浅洞改成深地宫，不自动加钟乳石或晶体 |
| 林地、草地 | 植被疏密、树干与冠层、地被、空地及路径边界 | 物种与气候、季节相符；不因空场加入动物 |
| 沙地、干旱环境 | 地形脊线、沉积、风蚀、土岩交界 | 不为荒凉任意加尸骨、废墟或灾难史 |
| 雪原、冻土 | 风压积雪、岩面霜层、冰釉、避风堆积与暴露面 | 普通冰雪不等于蓝色冰洞或发光魔法冰 |
| 水岸、湿地 | 岸线、浅深关系、湿干过渡、真实基底与植被带 | 水体与地形衔接，不把每个潮湿地点都覆盖浓雾 |

上述为可用检查项，不需全部写入每个场景。不要把任何地貌—建筑表格当成唯一可行解；架空文化也须遵守项目已确认的资源与技术边界。

## 建筑与地形相接

建筑不应像孤立模型贴在任意平地。仅在资产允许范围内明确基座、地面落差、路径、既有台阶、岸边或岩壁的接合关系；让建筑沿原有地形组织，或保留已明确的人工整地。

可见屋顶、墙体、开口和入口与气候及材料体系协调；自然边界可以参与围合与框景。未知时提出有限可见设计，不编造开山工程、水渠系统、桥梁、码头或额外聚落作为理由。

从室内看外景时，窗口位置、观察方向和可见范围限制信息。已知塔楼轮廓可作固定锚点，不能仅从一扇窗推定完整王城布局；外景不抢走室内核心功能区。

## 街道与建筑群

在原条目范围内组织已有街道、入口、节点和边界。主路径连续，转角、庭院、门前或停留区有疏密变化；道具沿真实边界布置，不均匀撒满地面。

- 建筑群共享主导屋顶、开口、材料与制作语言，按功能和地形改变体量与局部分段，不像同一个房子机械复制。
- 天际线由高低、尖圆、疏密和开口间隙形成节奏；焦点不必是最高建筑，不为满足“超高点”新增巨塔。
- 网格、放射、环状、沿地形生长等只是布局选项，不由文明名称自动决定，也不编造阶级分层。
- 设施、容器、标牌、家具与交通器物需核对时代、用途、归属和当前在场状态；泛用街道清单不能带入电话亭、广告屏或现代垃圾桶。
- 原表或剧本明确的文字照实保留；其他可见标识不要生成乱码，不发明专有店名、品牌、宗教口号或新机构。普通铺面在设计补全获准时，可用符合本场语言与用途的类别标识作为美术提案，不借招牌新设剧情店铺；严格清单、既定标识和固定基准优先。类别文字与铺面设施相互对应，不仅靠招牌声明地域，补全权限沿[世界观边界](worldbuilding-design.md#设计补全边界)。

## 天空与外部光色

天空承担时间、天气与空间背景。天际线和地平线的形态、天空亮度与地面照明相互协调；局部云层、空气与远景色阶服务原有主特征。

异世界不自动意味着双月、环带、巨行星、极光或永恒黄昏。此类天体、天象或异常周期须有明确设定或经用户确认，不能仅因奇幻标签添加。明确无月、无极光时保持缺席，不用这些元素制造记忆点。

具体光色读取 [色彩光影](color-light-atmosphere.md)；奇观尺度与可达性仅在适用时读取 [奇观设计](spectacle-design.md)。自然过程只写当前定格形态，不写镜头运动、环境持续动作、时长或音效。

## 外景核对

地貌是否具体且与原资产规模相符？建筑与地形是否有接合？植物和天气是否一致？路径与边界能否支持已写明的使用？天空是否增加新世界设定？远近细节是否有主次？只要求当前场景的可见外景，不自动新增地图、远景资产或城市场景版本。

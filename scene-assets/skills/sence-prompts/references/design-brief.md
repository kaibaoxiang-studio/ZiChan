# 内部场景设计底稿

复杂方案、多状态／视角复用或需重建布局锚点时读取，作为五维创作、事实边界和最终提示词的共同依据。简单新建只需按主动美术设计简记关键选择。它是内部工作记录，不是新增资产表、正式施工图或必须向用户提交的附加文件；局部任务沿用基准并更新相关项。

## 事实、提案与暂定锁定

每个影响画面的决定标明来源类别：资产表事实、剧本补充、用户已确认设计、本轮美术提案、冲突／未知。已确认设计与原文事实分开；知识库不能作为项目事实的来源。

“锁定”表示本轮各段提示词使用同一决定，不等于用户已经确认。未确认的设计称为“暂定锚点”，可以在后续授权优化中调整；已确认锚点改变时说明影响。

暂定锚点指允许补全的造型与布局，不授权推定剧情事实。关键物件在场时刻等未知项另记来源与待确认状态，按资产输入规则处理；只有用户允许相应状态探索时，才能记录为“探索稿暂定状态”。旧稿和基准图不能自行升级这类假设的确认等级。

## 从需求到设计选择

先分别记录明示事实、功能推导和设计空白，再形成场景概念；不要把先行扩写的造型当作事实清单。基础需求只锁定依据和必须成立的关系，不锁死未定的实现。主动美术方法按主入口读取 [电影场景美术设计](art-direction.md)。

概念记录需要包含具体主张、关键选择与可见落点。例如“哪种围合配哪种核心轮廓，留空在哪，机位为什么能读到”；不只填写情绪和形容词。必要时简记舍弃的实质不同构型及其功能／世界冲突，不强制候选数量或新增报告。

新建／完整重设计另简记相对同用途通用配置的可见差异、依据与功能理由、联合设计的收益和代价；具体判定沿主动美术设计的审查规则。底稿不以“有横竖对比”“有锚点”直接宣布审美通过，不新增外发评分表。

## 按当前任务记录

| 具体设计字段 | 对应维度与记录内容 |
| --- | --- |
| 资产与当前状态 | 原 ID、名称、子场景行、剧情时刻、内外、昼夜、季节、天气；在场／缺席的关键物件及依据。未提供的季节、天气等保留未知，不为填表补成事实 |
| 基础需求与设计空白 | 明示事实的来源、已有调度推导的必要关系、可主动设计的未定项；关键未知单列，提案不回写为原文 |
| 叙事功能与意图 | 维度一：本场功能和设计密度、主题／导演意图的依据与判断范围；一句话核心空间意图，以及已有静态取景需求 |
| 场景概念与关键选择 | 具体视觉主张、世界观视觉规则在构件上的落点、主形与功能的选择理由；必要的候选取舍，非抽象电影感宣言 |
| 核心识别形 | 维度一／三：主物与建筑的主体轮廓、尺度关系、构件节奏、与支撑特征的具体关系；哪些大形在主视点下可辨认。不能只记“庄严、孤独、华丽” |
| 功能布局与实体锚点 | 维度二／五：入口、门窗、主陈设位置与朝向、使用面、主次路线、接近与后撤余量、必要互见和原定障碍；各固定／暂定实体锚点的位置关系 |
| 取景与前期光源条件 | 维度二／三：相机位置、高度、方向、可见与画外区域；有效光源身份、空间位置及进入路径，主物／活动区受光与遮挡是否兼容。必要时另一个方向的内部文字核对 |
| 材质与工艺分工 | 维度三／四：主辅材料分别用于何处；承托、分块、厚薄、纹理方向、加工、连接及收口；装饰集中在哪些非操作区域，哪些表面保持可用与安静 |
| 实体配色与后期光影 | 维度三：项目画风、构件家族、配色来源及材料色落点、可见面积等级、身份色；实际受光覆盖、反射、衰减、冷暖、反差与主次视觉权重。HEX和编号仅内部保留 |
| 世界与表面状态可信度 | 维度四：时代地域或架空技术／文化边界、尺度与承托；维护程度、一般磨润、环境老化和事件痕迹各自的依据；必要考据点和证据状态 |
| 使用者与情感关联 | 维度五：已有使用者／公共群体及关系怎样落实到共享、分隔、取用和维护；情感物件的在场依据；无相关信息时记用途层面或不适用 |
| 保留与改动 | 本轮允许修改的项目、需保留项、影响到的已有视角或状态，以及待确认问题 |

条目只写相关信息，不强迫小场景填全表，五维不等于五份附加交付。叙事和人物条件按 [叙事意图与人物外化](narrative-and-character.md) 处理。未知的国别、罗盘方向、精确尺寸和历史不补成事实；未定相对布局可作为提案。依据与关键功能冲突时遵循资产输入和世界观规则。

新建／重设计形成内部配色方案；局部任务只更新受影响项。来源优先级沿主入口，需检索或补色时读 [色彩库检索与适配](palette-selection.md)。材料面积与光照覆盖分别记录，通常用等级或范围，小面积主物也可因位置、亮度和反差成为主焦点。底稿不默认另存为项目档案，测试提案不自动升级为确认设定。

## 底稿到提示词

先确定场景中的真实关系，再推导特定机位下的画面位置。例如暂定入口墙为观察基准，书桌位于入口前方并侧向开口墙；从门内斜侧观察时再说明书桌、窗与地图在画面里的位置。不能在不同段落分别给同一家具重新定位。

联合阶段记录“主物／使用区 → 取景中需要读到的形体 → 已有光源路径 → 遮挡和布局条件”；深化阶段在同一位置关系上完善工艺、颜色和受光层次。未定方案可在授权范围内互相校正，已确认结构不能为理想光域重排。若现有光源不足，保留限制，不以新增灯窗绕过边界。

用核心形和材料分工落实主张，再添加可见工艺与少量有依据的表面状态。所有新增造型、位置和普通装饰统一在提示词外注明“本轮美术提案”；不在每一句画面正文里反复写“拟定”。

对照底稿检查：入口能到操作面吗？主形与功能是否兼容？主材料和加工前后一致吗？光源位置能解释亮区及遮挡吗？目标氛围是否由具体明暗关系支撑？画面色是否被误写成实体换色，保护色是否被套色覆盖？当前状态是否混入后续事件？发现矛盾，更新相关底稿项后同步全文。仅改光色时只更新相关项，不反向移动空间锚点。

不能凭底稿声称空间实测或成图成功。无需等待用户确认每个普通细节才交付提案，但不能擅自保存成永久项目设定。

用户明确要求保存或更新项目档案时，按[连续性记录](continuity-record.md)提取复用字段；不把整份内部推演、舍弃方案或所有检查过程写入项目档案。

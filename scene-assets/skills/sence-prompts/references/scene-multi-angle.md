# 第三步：场景反打与其他角度

用户要求从已确定的场景图／光影氛围图生成反打图或其他角度的提示词时读取。本步设计静态观察位置与投影，交付用于图像模型的一条提示词；本 skill 不自行调用场景图像生成服务。阶段交接见[主入口](../SKILL.md#阶段基准交接)，写作见下方[第三步交付](#第三步多角度与反打提示词)。

## 共用基准与输入分工

版本、参考分工、冲突与产物身份统一按[阶段基准交接](../SKILL.md#阶段基准交接)处理。用户允许用原场景图先测试角度时，沿用该图当前光照并标为角度测试；色卡不能证明布局或添加光源。

## 生成前的空间推导

内部只记录影响本次角度的关系，无需另交规划图或长篇底稿：

1. **固定结构与实体**：用墙面、窗所在边界、桌端等固定参照识别相邻／对面关系，锁定开口归属、主物位置、朝向、承托、数量及通道。原画面左右只是投影，不作为房间坐标；未知数量不擅设唯一。保留已有尺寸，无尺寸时只用可支持的相对尺度。
2. **原机位与目标机位**：先确定原图从哪个区域朝哪里看，再按本次目标确定新观察点、朝向、俯仰与取景范围。推断机位时依据可见墙面与实体关系，普通选择标为本轮提案；如果不同解释会改变对面区域或关键开口归属，只补充相关资料。
3. **可行位置**：机位置于既有可用空间，检查墙顶、家具与遮挡。用户未锁定机位时，可在目标区域内调整位置或取景范围；不能靠穿墙／穿顶、扩大房间、缩小家具实现全景。指定机位确实冲突且需要改变用户目标时，说明限制并确认必要取舍。
4. **可见性**：逐一判断关键对象在镜头前、后、画外或被遮挡，正文只写易错关系。允许裁切，机位身后的物件不搬到背景。选取本角度实际可辨的固定锚点；与主图有共用锚点时可用于对照，不为强求共用锚点改变布局或视角。

### 新露出区域的证据与补全

| 资料条件 | 处理 |
| --- | --- |
| 原图、兼容的资产资料或已确认记录能确定的结构／实体 | 沿用其真实位置与关系，注明实际参考分工 |
| 有依据的普通背面或连续表面，如同一柜体背面、素墙与地板延续 | 按既有材料、构造与相对尺度有限补全，外围标为本轮提案，不增独立家具或剧情信息 |
| 不确定的门窗、出口、房间连接、关键边界或剧情物件 | 保持未知；影响目标取景或严格还原时补所需参考／确认。可合理出画且用户未要求展示时，选择可行取景并说明限制，不将“未知”写成“没有” |

单张图不能证明遮挡后的空间。严格复刻时不能将普通补全称为已核实；用户明确授权探索未知区域后可提出方案，但保留其提案身份，不覆盖已确认结构。

## 选角度与反打

反打将观察点移到原机位的对面区域，朝原机位所在方向看。必须用固定参照写清“从哪里朝哪里”；原地转向、左右镜像或任意换角度不能替代该关系。

角度依次遵从本次明确要求、适用的已确认项目偏好、当前取景用途。未指定时选择一条方案并简短标明提案：供人物对话或互动区背景使用时，优先平视或与原图相容的视高；需要交代家具布局与通路时，可采用斜俯视，包括约45°俯拍。无明确用途时，先考虑原图相容的视高与对面区域的可见性，不为一般角度选择暂停询问，也不固定套用45°。

采用约45°时，指镜头相对水平视线向下俯拍；不是水平方位转45°、画面倾斜或垂直顶视。俯拍角、机位高度与可见范围须相容，不能同时机械要求正常视高、全屋展示及高位俯拍。原图缺天花尺寸时不编造高度或声称相机位置已实测。

单张完整场景画面允许物件被遮挡或出画。只交用户所需角度；平面图、剖面图、去顶去墙图、环绕套图或白模不是默认产物。可靠平面／三维参考可按需要辅助，不作为强制前置步骤。

特殊构图或可见性难以确定时，按需读[构图辨识度](composition-and-identity.md)；复杂互动／通行关系读[走戏空间](staging-layout.md)，需要重建固定锚点的复杂方案读[设计底稿](design-brief.md)。仅补本次难点，不借换角度重做概念或加载全部新建设计专题。

## 光影连续性与简洁转写

保留同一时刻、天气、灯具开关、光源身份与真实位置、材料本色及生活痕迹。分别判断新角度中光源是否入画、仍照亮哪些真实表面、哪些被遮挡；光源出画不等于关闭，画面阴影方向与冷暖面积随投影改变。不锁定旧影子的屏幕方向，不为显露家具新增补光。

画面左右仅在空间推导成立且有必要时使用，不把内部分析转成全屋清单。遇到机位反转、镜头后方物件或未知背面难以转写时，按需读[反打完整示例](prompt-calibration-examples.md)，只借用推导方法，不复制布局。

## 第三步多角度与反打提示词

先完成上方空间推导与选角，再按“观察方向、机位角度、取景范围、关键固定关系、自然遮挡、光源连续”转写。实际图像基准用简洁依赖稿；无图文字基准用自足生成稿，共同取舍沿[提示词交付](prompt-delivery.md)。不同时锁定本次需要改变的旧机位、透视或景别。

正文外简短指明资产、实际基准及当前状态；补充参考说明分工，普通机位／背面补全注明提案身份。以下骨架可合成自然段落，替换全部占位项，只展开易错固定关系，不逐项列全屋的新画面左右。

```text
依据【实际基准图】，生成同一【场景名称】从【原机位对面的具体区域】朝【原机位所在方向】观看的反打场景图。摄影机位于【既有可用位置】，采用【本次选定且相容的视高与俯仰】，呈现【主要对象、背景及空间关系】。输出一张完整的【室内／室外】静态场景画面。

保持原有空间尺度、边界关系及陈设的实际位置、尺寸和朝向。【本场易错的墙面归属、邻接或已知数量；无则删去。】【必要遮挡或画外关系；无则删去。】【有依据的新露出区域；无则删去。】取景服从既有空间，允许自然遮挡和裁切，不为完整展示而移动、复制陈设、扩大空间或透视穿墙。

保留基准图的材质本色、物件状态、生活痕迹和当前光照条件，光源仍位于原有空间位置，受光面的可见程度、反光与遮挡随新视角自然变化。保持原有画风与画幅比例，仅改变观察机位。
```

普通角度替换为本次观察点与方向，不保留反打的对面关系；采用约45°时明确向下俯拍，其余据实写出。本模板依赖实际参考图，文字稿须完整合并身份、布局、材料、状态、光照与新机位，不靠“保持不变”省略；缺图、参考冲突与未知背面仍按上方规则处理，不填成无门素墙。

## 交付与成图反馈

交付前核对：版本与状态对应；反打观察方向成立；机位和取景相容；固定墙面、实体关系与相对尺度未改；遮挡和画外关系明确；未知区域处理有依据；光源位置与开关连续；提示词类型与实际参考匹配。

目标是一条可直接生成所需角度的提示词。若后续提供成图，按[实际图像对照](verification.md#第三步多角度与反打回归)检查有证据的关系，区分生成偏差、基准矛盾和未定区域；用户要求修正时，只处理相关问题。文字检查不保证一次成图或全空间成立。

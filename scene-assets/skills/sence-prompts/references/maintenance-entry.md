# 技能维护入口

仅当用户要求修改／维护本技能或检查维护设施时读取；普通场景生成、改光、反打和局部任务不读取。不在安装目录直接修改再覆盖源码，不沿用工作区其他旧输出。

本公开发布包不记录维护者的个人电脑路径。用户要求维护时，先确认实际维护源码库；ZiChan 插件发布目录为 `scene-assets/skills/sence-prompts/`，不等同于下面的独立维护库，也不意味着安装缓存可直接充当维护源码。

技能源码在该库的 `skill/`，维护工具在库根 `scripts/maintain.py`，不是安装技能的 `scripts/`。先核对候选目录的 `maintenance/project.json`：`repository_id` 应为 `sence-prompts-maintenance-20261023`，再读 AGENTS.md、maintenance/workflow.md、状态与交接，检查 Git 和源码／安装差异。

目录移动、复制到其他机器或候选身份不符时，向用户确认实际源码库；不要创建同名新库、自动找一个旧副本覆盖、恢复未知配置或假称已找到源码。技能内普通生成和文件检查仍能独立运行。

仅验证场景输出沿[验证规则](verification.md)及[测试索引](../tests/index.md)，不强制先取得源码库。修改技能时遵循已定位源码库的检查、备份与发布流程；定位正确不等于授权安装或删除。

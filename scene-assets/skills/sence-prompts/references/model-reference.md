# LIRA 场景模型配置参考

本文件翻译整理用户提供的《LIRA SKILL (1).md》中的场景相关模型分工和参数。以下“来源配置”描述的是该文件的设置与经验，不代表已验证的当前产品规格；用户选择目标模型后，以其当前界面、官方说明或项目实测为依据。不因本文件自行切换用户的模型、调用服务或执行图像编辑。

## 来源分工

| 场景任务 | 来源文件的模型分工 | 使用原则 |
| --- | --- | --- |
| 场景、环境、建立空间关系的全景、电影静帧、环境概念图 | Higgsfield Soul Cinema | 用户采用 LIRA 的电影写实流程时可参考；用户未指定工作流时先写通用中文提示词 |
| 原场景图局部修改 | Nano Banana Pro（NBP） | 来源作为首选，以原图为基准，修改内容尽量具体，明确完整保留项 |
| 完成场景图的纹理修复 | Seedream 4.5 | 来源仅用于墙面、织物、石材等纹理，不承担物件位置和建筑结构改造 |
| 前述方法未解决的细微局部修改 | GPT Image 2 | 来源将其作为后续选择；约束修改区域，保留其余设计，不继承未经验证的模型优劣结论 |
| 同一地点的反向或其他视角 | GPT Image 2；使用 NBP 时补充逐项布局描述 | 明确新机位与主要物件的新画面位置，不把换视角等同于镜像 |
| 整体场景重新设计 | 来源回到 Soul Cinema 重新生成 | 是否重新生成由修改范围决定，不以小修模板承载整个场景重做 |

这些不是每次都必须执行的串行步骤。例如，纯纹理任务只需要相应纹理提示词，无需依次使用所有模型。

## 来源参数记录

| 模型 | 原文件列出的参数或参考能力 |
| --- | --- |
| Soul Cinema | 质量档位 1.5k／2k；画幅 1:1、4:3、3:4、16:9、9:16、3:2、2:3、21:9；一张参考图；文件还提到可加入带 Soul ID 的人物 |
| NBP | 分辨率 1k／2k／4k；常规画幅及 21:9、4:5、5:4；最多十四张参考图 |
| Seedream 4.5 | 基础档最高约 4K、高档约 6K；多参考图；本流程仅采用其纹理修复角色 |
| GPT Image 2 | 分辨率 1k／2k／4k；低／中／高质量档位；本流程用于局部修改与场景视角调整 |

以上数字仅保留为原文记录。输出具体设置前确认目标平台的支持项；未确认时不把这些参数当作可直接执行的设置。场景默认为空场，不主动引入人物一致性功能。

## 画幅与正文分离

原文件将电影宽银幕环境图设为 21:9，标准视频配套图设为 16:9，质量示例为 2k。仅在用户采用这些用途和设置、目标平台支持时参考；主文件仍以用户指定的画幅为准。

在生成设置中单独写画幅、分辨率、质量和参考图用途。中文正文可以使用“宽幅全景”“纵向构图”等画面描述，但不夹入画幅数字、分辨率或未经确认的专用参数语法。只有目标平台和用户明确要求正文参数时才适配。

## 来源经验的使用边界

原文件认为 Soul Cinema 已有电影纹理与自然颗粒，建议保持质感描述简短；认为场景角度应使用直接、容易理解的空间描述；认为局部修改要锁定其余设计，纹理修复要限制在表面。这些可作为提示词设计参考。

原文件关于“某模型一定保持像素不变”“某模型全局效果差”“所有模型都没有负面提示词字段”等说法不作为执行保证。按当前平台和实际结果调整，也不把其中偏向电影写实的经验用于覆盖二维、三维或其他已确认的项目画风。

# 材质与工艺设计

生成、优化或审查材质方案时读取。目标是让表面体现所属世界的建造与制作方式，而不是将材料名称换得更稀有。沿用已核对的项目材料边界；器物归属或技术范围未知时，按需读[世界观与设计边界](worldbuilding-design.md)，不把互链当作每次重读要求。纹理修复仅沿基准改善表面，不套用下述重新选材与构造设计。

## 从材料名到可见设计

对画面中的主要建筑表面和核心陈设，补足与它们实际相关的层次：

| 层次 | 要说明的可见信息 |
| --- | --- |
| 材料与用途 | 承重、围护、铺地、包覆、接触面或装饰；原文材料保留，新增选择有理由 |
| 加工 | 凿面、磨平、抛光、锻打、浅刻、染色、编织等；处理如何改变轮廓、纹理和受光 |
| 构造 | 分块、拼板、厚薄、纹理方向、承托及相邻材料的连接；不只给一张贴图 |
| 收口 | 包边、压条、嵌缝、铆接、榫接、折边或圆钝边缘；采用符合项目工艺的做法 |
| 表面状态 | 粗细、哑光与局部光泽、保养、氧化或接触磨润；按真实使用位置分布 |
| 画面作用 | 材料如何区分功能区、强调主物、引导视线，及其在当前全景中的可辨认程度 |

这是设计检查，不要求给所有小物写满六项。将重要信息变成自然描述，不用大量技术词替代可见形态。

## 构造与装饰层次

构造细节解释主体怎样形成和接合，装饰细节发展其视觉语言，两者不是使用磨痕的替代名称。先按场所身份与工艺选择取景可辨的中尺度落点，再细化表面；构造仍需成立，但不能只用接缝和支架完成全部美术设计。

构造可通过墙顶分层、窗洞厚度、框架节奏、柜体端板、家具足部、拼接与包边等体现主形；装饰可通过已有或允许提案的浅刻、浮雕、彩绘、织绣边饰、分格、器物组合等建立身份与美感。并非每场都采用，也不绑定某种文化的固定清单。所选细节写清载体、制作或形态、依附位置及与主体的关系：例如浅刻收在屏风框内侧，织绣沿帷幔边缘呼应框架节奏，而不是全屋贴同一纹样。

装饰分布与场所规格、实际用途及取景一致：主构件与外围可有不同密度，大片安静材料面衬托局部精细处，普通陈设成组而不争抢焦点。器皿、织物及壁面装饰可承担审美，不要求都兼作工具；不以装饰许可增添专属信物、宗教身份或新剧情物件。已明示的雕梁画栋、绣边或成套器物不能被“避免过饰”抹去，朴素、无饰或严格清单也不能被“细节丰富”改成奢华。

装饰轮廓、浅刻与织纹的明暗由真实照射、遮挡和材料响应产生，不靠统一锐化、发光金边或无来源轮廓光。局部纹理修复只改善获准表面，不借此加线脚、雕花、包边、构件分层或陈设；获准构造／装饰调整时也只改变本次范围。

## 场景材料组合

材料深化接续已选场景概念，在同一方案中服务主形、核心造型和使用面；不是先任意丰富选材再把它固定为基础需求。先说明“哪个构件需要哪种加工和连接”，再选许可材料。若只换材质名称、追加金边而轮廓与构造仍通用，应回到获准设计范围内深化分段、承托或组合关系，不能只增加形容词。局部纹理任务不因此改造主形。

先选择服务场景身份的主材料，令大面积表面保持秩序；再用结构连接、接触面、软质织物或局部金属形成对照。不同功能区通过同一材料的不同加工，或有限的材质变化建立联系和区别。

材料选择考虑项目已知的获取、加工、使用环境与维护方式，但不据材料名称直接判断文明高低或财富。例如精细木构可以华贵，精确土建也可以有秩序；有依据的贸易或技术例外保留，未知时不编造供应历史。

- 不默认所有王宫都铺亮白大理石，也不把全屋改成同一种黑色镜面石。沿用项目已有材料，但房间可以有不同组合与表面处理。
- 原文指定大理石浴池时，保留石材，可深化石纹选配、块面分割、厚实池沿、内外加工差异和基座连接。未经授权，不把“大理石浴池”改成水晶或龙骨池。
- 龙鳞、翼骨等文化意象优先落实为构件节奏、雕刻分区或金属连接的形态，不暗示使用真实龙骨、龙鳞，更不新增魔法能力。
- 天然纹理服务几何关系。例如石纹顺着池沿或墙面展开，木纹顺着桌板延伸；不在每个表面重复完全相同的图案，也不要求天然纹理毫无差异。
- 关键表面有主次：结构轮廓和大块拼接在全景中可读，浅刻和织纹在中景补充，细微磨痕在近处成立。不要让成败依赖全景里看不见的小划痕。
- 冷硬与柔软、粗面与磨润、深材与浅材的对照应有用途，不把每个表面都设为最亮、最复杂、最粗糙或最高反光。
- 同项目可复用门窗分段、连接件和材料处理作为构件家族，再改变主陈设及局部节奏；复用不等于每间房相同。材料数量由设计需要决定，不固定限制为两三种，也不将三维性能指标写进静态提示词。

实体颜色与照明颜色分开。自然材料、涂饰、染织和釉色都可形成配色，不能只为换主色而替换原文明示的材料。具体色彩组织与光源规则见 [色彩光影](color-light-atmosphere.md)。

## 工艺与功能一起设计

构件的厚薄、高低、跨度、边缘和承托关系，应与实际用途及场所规格匹配。涉及接触、检视、交接、操作或取用时，核对使用面是否连续、接近是否可达，以及构件是否造成非预期遮挡。

材料名称和“高档、厚实、精整”等形容词不能代替构造选择，也不默认通过加厚、放大、加高或增加围合提升规格。需要厚重、防护、台阶或高低分隔的既定设计仍须保留。尺寸不足时用适用的相对比例与功能关系表达设计目标，不编造测量结果，不宣称通过人体工学或施工验证。

普通功能面的设计补全优先考虑接触、放置与通行：装饰尽量用于外侧、背板、框架、壁面和非接触边缘，工作面留出可用区域，新增构件不制造绊阻或尖锐接触。原文明示的湿滑、破损、粗硬、起伏或危险构造优先保留，不为平顺、清理方便而磨平、修复或换材；按走戏空间规则说明实际功能与限制。

华贵场景通过材料选配、定制构件、复杂但有秩序的连接和维护体现规格。朴素场景通过地方材料、可靠连接、修补方式和使用纹理体现个性。并非所有环境都需要贵重材料。

光照说明材料的差异：粗石接收宽而弱的亮面，磨润木材形成有方向的柔光，金属收口出现局部高光，织物保留柔和暗面。避免无依据的整体湿亮、塑料反射，或靠浓雾与深黑遮掉材质；已有暴雨、浸水等状态下的湿表面按实际暴露范围保留。

## 描述示例

以下是可调整的美术提案，不是所有项目的默认选材：

“石墙”可深化为：“深灰砌石保留疏密有序的凿面，厚石窗洞采用更细磨的块面收口；接缝略内收，粗墙与平整窗框形成尺度清楚的对照。”

“实木书桌”可深化为：“宽木板拼成深褐桌面，纹理沿长边延伸；前沿磨成圆钝接触面，侧梁保留浅刻，黑铁连接件承担支撑，窄银饰只收在连接端部，不占用摊开文件的区域。”

“大理石浴池”可深化为：“浅石池沿以连续的带状石纹选配，接缝避开主要手扶位置；内壁细磨平顺，外壁保留浅刻凹槽，与暗色池座以窄退台衔接，装饰不突出至进出池体的一侧。”

## 材质检查

遮住“高级、皇家、稀有”等词，描述是否仍有可见的加工和连接特征？各主要表面是否承担不同的视觉角色？实际接触、放置、坐卧和行走面能否使用？是否保留原文材料与世界观？新选材和工艺注明“本轮美术提案”。没有成图时只检查文字，不能声称材质效果或使用性能已被实测。

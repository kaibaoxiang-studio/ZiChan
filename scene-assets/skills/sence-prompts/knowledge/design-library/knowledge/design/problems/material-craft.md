# 材料、工艺节点与使用痕迹

性质：原创美术提案方法，不是材料性能、结构或热安全认证。相关案例：DES-006，其次 DES-001、DES-004。具体世界工艺未知时，不把候选节点当作已经可制造的事实。

## 以构件为单位，不以材质名为单位

每项选择沿这条链说明：`构件用途 → 已定/候选材料 → 加工 → 接合与承托 → 可见表面 → 使用历史 → 受光表现`。只描述在本轮尺度下有作用的细节，不为每一块远景石头填写表单。

| 构件职责 | 可深化的细节 | 不宜替代的判断 |
| --- | --- | --- |
| 主体结构/围护 | 分块、厚度表现、砌缝或板缝、转角收口 | 换稀有材料不自动解释承重 |
| 行走面 | 连续铺面、拼接边界、平整使用区 | 强烈起伏和凸饰不能冒充装饰性锚点 |
| 触碰/取用面 | 边缘倒修、局部光泽、握持部位 | 不把每处都做成油亮镜面 |
| 核心强调部位 | 卷边、嵌接、分瓣、少量精细分段 | 全体鎏金不能代替制作关系 |
| 异材交界 | 接触面、包边收口、分段连接位置 | 不加悬浮细线或无承托板件 |

## 可选分支

原定单材：保持材料，分配不同尺度的分块、粗细加工和局部光泽；原文已定表面处理同样保持。允许少量搭配：先选一个功能明确的收口位置，再解释连接，不为了“丰富”凑三四种材料。

同属木作也不能只写“精雕木材”：桌框支承与桌面厚度、长席端板与背板分段、门框横楣与立框关系，各自表达不同职责。具体榫接若没有工艺依据，写可辨的接合关系而非确定榫型。

石材不只“大理石换黑曜石”：宽面分块与边缘磨修可以建立同材层级；纹理在单块内有走向，接缝不是无限连续贴图。天然纹理与人工刻纹分开，不把每条纹路都写成同样深的沟槽。

## 使用痕迹有原因，亦可没有

先核对维护和使用状态。经常接触的边缘可有局部光泽，长期通行带可有相应磨耗；是否明显取决于材料和时间。新建、严密维护或不常使用空间不强制做旧。灰尘、烟熏、腐蚀和裂纹不能互相替代，也不因“真实感”同时出现。

热源周边的材质与痕迹必须有设定或普通物理依据；没有烟熏历史不自动写大片黑垢。热源附近不要用未知耐热的精细包覆、黏接或垂落织物装点。无法核实性能时保留为待确认条件。

## 提示词落点与检验

用“哪个部位、怎样分段、在哪里连接、受光怎样不同”取代连续材质名。例如已定木长席可写：“端板收住分段靠背，坐面由下方框架承托，接近端头的触碰边细修；大面纹理低干扰，细工只沿端部收边出现。”此为候选描述，须符合资产与加工许可。

看图检查至少一个重要节点：两种表面是否真有交界？承托是否可见？纹理是否吞掉主体？痕迹是否落在有解释的位置？二维可见连接不能证明内部结构可靠；无法看清时记为未知，不据此宣称工程成立。

# 配色、材质与光域联动

性质：原创设计目标与评审方法，不是生成模型能精确兑现的色度/照度规范。相关案例：DES-001、DES-005、DES-006。默认只为场景提示词提供配色设计，不输出色卡图或色卡生成提示词。

## 把色彩落在实体上

先区分材料固有色、光源颜色、照明后的呈色和整体影像处理。内部配色可记录：`色彩角色 / 实体载体 / 可见面积目标 / 表面反射特征 / 所处光域`。颜色数量随材料与场景需要决定，不固定四种，也不强制每种等面积。

例如“低干扰底色落在主体墙地，辅助色落在既有家具大面，强调色集中在核心边缘或许可光源附近”。这是分工，不指定绿金、冷暖或比例。需要比例时以当前机位的可见面积作为参考口径，明确只是目标；不能以整座建筑材料用量代替画面占比。换视角后占比可变化，材料身份不随之改色。

## 从光源到区域，而非从气氛词到光源

记录已有光源位置、遮挡、可照到的实体和衰减方向，再决定主读区、行动区与背景怎样分工。唯一火源不能变成全场均匀暖光；夜间窗洞不能凭空产生日光。弱光反射可解释少量可读性，不承诺无有效光时所有远端清晰明亮。

行动区并非必须最亮，但应满足本轮用途所需的可见性；若剧本故意近乎不可见，保留该意图并明确定位/读图限制。低对比、胶片感或柔和氛围均不等于所有区域同灰。

## 按症状选择调整位置

| 症状 | 先排查 | 在授权范围内的候选调整 |
| --- | --- | --- |
| 全场灰扑扑 | 面面同亮？材质全哑灰？薄雾覆盖全部？ | 明确光域衰减与实体底色，减少无依据的全场灰雾；不盲目增饱和 |
| 核心消失 | 体量太小、背衬同纹、被遮挡还是过曝？ | 对应改轮廓间隔、允许的受光关系或取景；不只追加“更亮” |
| 每处抢眼 | 强调色与细工是否遍布全场？ | 把强调载体集中在本轮主读区，辅助区保留使用信息 |
| 光色不属于世界 | 光来自什么？材料为什么发亮？ | 去掉无依据的自发光和霓虹效果；不改已确认特殊能力 |
| 材质失真 | 所有面同湿亮？颜色被强光吞掉？ | 分别描述粗糙、细修和局部反光，保留主体轮廓与表面层次 |

## 验证要分开

先看彩色图的面积与主次，再用灰度辅助观察明暗层级，最后查光源—受光面的对应；三者不能由单一色卡代替。高光反射不必与材料固有色一致；不以局部像素色值反推全部材料身份。

保持同一项目配色身份时，记录主要材料与强调载体，而非强迫每个机位维持完全相同的颜色比例。没有真实测试时，只能记为光色设计目标，不升级验证状态。

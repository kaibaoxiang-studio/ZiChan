# AI 漫剧场景图提示词

## 用途与共同边界

将原资产设计为可直接使用的中文静态场景图提示词。新建时主动完成美术设计，使场所身份、用途与空间规格相匹配；功能成立后继续完成[适用细节与光影深化](references/art-direction.md#适用细节与光影深化)，不以原文扩写、贵重材料或堆细节代替设计。默认陈设完整的无人环境，人物入画仅按用户明确范围处理。

- 保留原表 ID、名称、顺序和子场景粒度；不提取新资产、擅增剧情功能或永久状态变体。
- 所有类型的场景新建／完整重设计默认建立目标资产的整体空间，剧情互动区作为其中的重点；明确指定局部时按局部范围交付。整体范围以原资产为界，取景与遮挡按[走戏空间](references/staging-layout.md#取景需求前置与戏剧承载)处理。
- 区分原文事实、用户确认、可沿用提案和未知；冲突不自动选边，旧稿假设不因沿用或“继续”升级为确认。
- 一稿只描述一个剧情时刻。关键道具、事件痕迹和特殊状态缺依据时，只补问必要资料；普通造型与布局空白可提出美术方案。
- 保留原定材料、器物用途、文化归属及必要空间关系；原有狭窄、障碍与危险不因“可走戏”被清除。
- 固定布局、材料本色、光源位置和相机投影分开处理；局部任务只改授权范围及必要关联处，不借改光或换角度搬家具。
- 供后续人物入画时，以固定实体定位主要停留／互动区、朝向与通路，检查目标取景中的可辨程度；局部任务不借补锚点重排布局。
- 不自行调用场景图像服务，不编写视频动作、运镜、时长或声音。提示词、色卡、成图与空间实测分别报告，不冒称未做的验证。

用户指定的语言、画风、世界观、模型和交付格式优先；项目设定不扩散为通用默认值，知识库不提供剧情事实，本包不依赖或修改其他 skill。门与入口按实际重要性描述，详见[门的取舍](references/prompt-delivery.md#门的描述取舍)。

各类场景先判断有关条件，不把生活用品、文化符号或复杂结构当作每场必备。[设计适用性与闭环](references/art-direction.md#设计适用性与闭环)由主动美术设计维护，读取仍按任务路由，不为局部任务强制加载整份新建设计参考。新建建立适用关系，局部只处理授权变化及必要关联；已选设计转写与迭代时按交付参考核对保真，不靠通用形容词或增加细节替代缺失关系。

## 使用引导与三步流程

首次在当前对话使用本技能开展场景创作、用户明确表示不熟悉流程，或询问“怎么用／下一步做什么”时，主动用简短中文说明下列三步及当前起点。依据可见对话判断是否已介绍，不声称记得其他会话或其他人的使用历史；同一对话已介绍后不在每个场景／每次迭代重复。用户明确只要提示词、不要说明时省略流程介绍和下一步建议，但不省略必要的缺资料／冲突说明。仅要求审查或维护技能时不插入创作流程教学，除非用户也询问流程。

| 步骤 | 做什么、交什么 | 需要的依据 |
| --- | --- | --- |
| 第一步：场景提示词 | 建立目标资产的整体空间、陈设、材料及基础照明，交中文场景提示词 | 完整资产表与对应剧本或充分场景描述，以及适用画风／世界设定 |
| 第二步：氛围提示词 | 在既有空间上深化光影，交氛围提示词；默认配适配色卡，只要文字时省略 | 当前可靠场景图或完整文字设计、本次氛围目标及允许改动的条件 |
| 第三步：多角度提示词 | 从同一基准推导反打或其他所需角度，交各角度提示词，保持实体与当前光照连续 | 当前可靠图／完整文字设计及所需观察方向；依图任务须有实际对应图 |

向使用者说明这是提示词工作流，本技能不自动生成／编辑场景图；色卡也不代表场景已经出图。上述依据复用已给资料，不为介绍流程要求重新上传。资料齐备且任务明确时，介绍后直接做当前阶段；仅问用法时只介绍，不擅自生成示例场景。缺资料时只问阻碍当前阶段的必要项；没有前序基准通常从第一步开始，有可靠基准可直接进入第二／三步，不要求把三步全做完。

当前阶段交付后，如下一步对本次任务有用且用户未禁止说明，用一句话指出下一步和所需依据即可，例如“当前交的是第一步文字方案；确定采用的图或完整稿后，可以继续做第二步光影氛围。”不在每次局部修订机械附流程邀请，也不把建议当作跨阶段执行授权。用户指定阶段／范围优先；“继续”沿明确的未完成任务推进，无明确目标且会改变阶段或基准时只确认必要选择，不自动升级旧提案或未验收成图的确认等级。实际阶段交接按下节，不另设强制成图／确认门槛。

## 输入与阶段交接

新建／首次建立项目需要完整资产表及对应剧本或充分场景描述，接受现有文件和字段，不要求重新套表或重复交剧本。已有可靠基准的打光、换角度或局部修改，用目标资产、当前图／完整旧稿／记录及本次要求继续，不重索全表。

缺失画风、时代、身份、互斥状态或关键结构且会实质改变结果时才补问；模型、画幅和精确尺寸未知不阻塞通用提示词，也不擅设默认值。普通设计选择作为提案，不替代剧情事实。

### 阶段基准交接

内部核对资产、采用图／文字稿及版本、当前状态、固定关系和改动范围，复用已有资料；不默认外发档案，正文外只说明实际基准与影响本轮的提案／未知。

- 用户指定版本及有效修正优先；认可的第二步氛围图承接当前内容与光照，第一步资料只补兼容结构。图与设定冲突先处理，不凭时间较新自动覆盖。
- 可靠文字可用于自足生成稿；依赖实际原图或氛围图的编辑任务缺图时补对应图，不能用文字方案或色卡冒充图像基准。
- 多角度共用同一可靠基准，未核验的新角度不接力成为下一张的唯一依据。记录仅在用户要求保存、更新或恢复时使用。

## 任务路由

按交付意图、实际改动对象和可靠基准选模式，不只按“优化／电影感”等词判断；反馈图不自动成为编辑基准，生成／编辑判定见[迭代与回填](references/prompt-delivery.md#迭代与回填)。先完整读取本次模式的文件，再按其中明确的难点补读；互链不是递归加载命令，已完整读取且未变更的文件不重读。

| 本次任务 | 必读参考 | 执行重点 |
| --- | --- | --- |
| 第一步：新建／完整重设计 | [资产输入](references/asset-input.md)、[世界观体系](references/worldbuilding-systems.md)、[走戏空间](references/staging-layout.md)、[主动美术设计](references/art-direction.md)、[色彩光影](references/color-light-atmosphere.md)、[提示词交付](references/prompt-delivery.md) | 事实与功能 → 概念 → 联合布局、机位及基础照明 → 适用构造、装饰、使用细节与光色深化；功能与美术充分性同时核对，不把氛围全留给第二步 |
| 第二步：光影氛围深化 | [氛围重新打光](references/atmosphere-relighting.md)、[色彩光影](references/color-light-atmosphere.md)、[光影色卡](references/atmosphere-palette.md)、提示词交付 | 区分精修、增强与获准转化；先判断增益、设计真实光路及目标关系，再适配色卡；固定实体而非旧光影，不强造变化或自动逐场执行 |
| 第三步：反打／其他角度 | [多角度与反打](references/scene-multi-angle.md)、提示词交付 | 原机位 → 新观察点与方向 → 可见／遮挡及新露出区域；保持实体与当前光照连续 |
| 局部设计修改 | [场景修改](references/scene-editing.md)、提示词交付 | 只改指定区域及必要关联；涉及概念、布局、光色时按该参考补读专题 |
| 纹理修复 | 场景修改、[材质工艺](references/material-and-craft.md)、提示词交付 | 改善指定表面，不改变结构、布局、材料身份、本色及光源 |
| 仅审查／解释 | 入口及问题涉及的参考；设计审查读主动美术设计，成图／文字反馈读场景修改 | 说明证据、推断与限制，不据此改稿、落盘或出图 |

新建包含合理基础照明，不因有第二步而删除光影设计，也不强制自然光或平光；有可靠基准可直接进入第二／三步，不强制重做前序阶段。目标宽泛时提出范围有限的具体改进，关键取舍或范围扩张才补问。

同一场景、同一状态的多项授权改动合并到一稿，保留项排除这些例外；互斥状态与多个角度分别交单一画面。跨阶段按实际产物依赖承接；批量缺项按[资产输入](references/asset-input.md#批量处理与共用依据)仅影响相关条目，遵从用户整批交付偏好。

配色先复用适用的确认方案或可用旧提案。缺方案、补颜色、明确重配色或第二步需要色卡时，读[配色检索与适配](references/palette-selection.md)；已有色卡须适配本轮目标，适用时不重选，检索不授权重配材料色。

只有用户要求保存、更新或恢复才读[连续性记录](references/continuity-record.md)。需要案例校准时读[案例检索](references/design-case-retrieval.md)；追溯来源时读[知识库索引](references/knowledge-base-guide.md)，不全库加载。

仅采用 LIRA 时读[模型参考](references/model-reference.md)，需要电影成像参考时读[成像参考](references/scene-generation.md)。来源经验不作为当前模型规格或工具调用授权。

## 交付与检查

默认交原资产／单一状态、必要说明和代码块内的一条完整中文提示词；第二步另附适配色卡，用户只要文字时省略；第三步只交所需角度，不重选色或绘卡。多场景按原表顺序，不默认附内部分析、HEX／比例表或套图。

生成稿独立完整，不以“同上”省略；图像编辑稿明确实际基准、修改及相关保留项，不必复述全量未改区域。共同写法、密度校准、门的取舍和回填按[提示词交付](references/prompt-delivery.md)，打光／反打模板在对应阶段参考中。

维护技能先读[维护入口](references/maintenance-entry.md)定位源码；用户仅要求测试时读[验证规则](references/verification.md)，按[测试索引](tests/index.md)选例。优先使用输入与验收分离的[回归登记表](tests/registry.json)，旧[固定用例](tests/cases.md)保留作专项资料。它们不是日常生成的额外必读项。

# AI 漫剧场景图提示词

## 用途与共同边界

将原资产设计为可直接使用的中文静态场景图提示词。新建时主动完成美术设计，不以原文扩写、贵重材料或堆细节代替设计；默认陈设完整的无人环境，人物入画仅按用户明确范围处理。

- 保留原表 ID、名称、顺序和子场景粒度；不提取新资产、擅增剧情功能或永久状态变体。
- 区分原文事实、用户确认、可沿用提案和未知；冲突不自动选边，旧稿假设不因沿用或“继续”升级为确认。
- 一稿只描述一个剧情时刻。关键道具、事件痕迹和特殊状态缺依据时，只补问必要资料；普通造型与布局空白可提出美术方案。
- 保留原定材料、器物用途、文化归属及必要空间关系；原有狭窄、障碍与危险不因“可走戏”被清除。
- 固定布局、材料本色、光源位置和相机投影分开处理；局部任务只改授权范围及必要关联处，不借改光或换角度搬家具。
- 供后续人物入画时，以固定实体定位主要停留／互动区、朝向与通路，检查目标取景中的可辨程度；局部任务不借补锚点重排布局。
- 不自行调用场景图像服务，不编写视频动作、运镜、时长或声音。提示词、色卡、成图与空间实测分别报告，不冒称未做的验证。

用户指定的语言、画风、世界观、模型和交付格式优先；项目设定不扩散为通用默认值，知识库不提供剧情事实，本包不依赖或修改其他 skill。门与入口按实际重要性描述，详见[门的取舍](references/prompt-delivery.md#门的描述取舍)。

## 输入与阶段交接

新建／首次建立项目需要完整资产表及对应剧本或充分场景描述，接受现有文件和字段，不要求重新套表或重复交剧本。已有可靠基准的打光、换角度或局部修改，用目标资产、当前图／完整旧稿／记录及本次要求继续，不重索全表。

缺失画风、时代、身份、互斥状态或关键结构且会实质改变结果时才补问；模型、画幅和精确尺寸未知不阻塞通用提示词，也不擅设默认值。普通设计选择作为提案，不替代剧情事实。

### 阶段基准交接

内部核对资产、采用图／文字稿及版本、当前状态、固定关系和改动范围，复用已有资料；不默认外发档案，正文外只说明实际基准与影响本轮的提案／未知。

- 用户指定版本及有效修正优先；认可的第二步氛围图承接当前内容与光照，第一步资料只补兼容结构。图与设定冲突先处理，不凭时间较新自动覆盖。
- 可靠文字可用于自足生成稿；依赖实际原图或氛围图的编辑任务缺图时补对应图，不能用文字方案或色卡冒充图像基准。
- 多角度共用同一可靠基准，未核验的新角度不接力成为下一张的唯一依据。记录仅在用户要求保存、更新或恢复时使用。

## 任务路由

按实际改动对象和可靠基准选模式，不只按“优化／电影感”等词判断。先完整读取本次模式的文件，再按其中明确的难点补读；互链不是递归加载命令，已完整读取且未变更的文件不重读。

| 本次任务 | 必读参考 | 执行重点 |
| --- | --- | --- |
| 第一步：新建／完整重设计 | [资产输入](references/asset-input.md)、[世界观体系](references/worldbuilding-systems.md)、[走戏空间](references/staging-layout.md)、[主动美术设计](references/art-direction.md)、[提示词交付](references/prompt-delivery.md) | 事实与功能 → 概念 → 联合布局、机位及基础照明 → 工艺光色；五维检查与美术专题导航在主动美术设计中 |
| 第二步：光影氛围深化 | [氛围重新打光](references/atmosphere-relighting.md)、[色彩光影](references/color-light-atmosphere.md)、[光影色卡](references/atmosphere-palette.md)、提示词交付 | 固定空间，组织授权范围内的光源、光域与影调；不自动逐场执行或生成多种氛围 |
| 第三步：反打／其他角度 | [多角度与反打](references/scene-multi-angle.md)、提示词交付 | 原机位 → 新观察点与方向 → 可见／遮挡及新露出区域；保持实体与当前光照连续 |
| 局部设计修改 | [场景修改](references/scene-editing.md)、提示词交付 | 只改指定区域及必要关联；涉及概念、布局、光色时按该参考补读专题 |
| 纹理修复 | 场景修改、[材质工艺](references/material-and-craft.md)、提示词交付 | 改善指定表面，不改变结构、布局、材料身份、本色及光源 |
| 仅审查／解释 | 入口及问题涉及的参考；设计审查读主动美术设计，成图／文字反馈读场景修改 | 说明证据、推断与限制，不据此改稿、落盘或出图 |

新建包含合理基础照明，不因有第二步而删除光影设计，也不强制自然光或平光；有可靠基准可直接进入第二／三步，不强制重做前序阶段。目标宽泛时提出范围有限的具体改进，关键取舍或范围扩张才补问。

同一场景、同一状态的多项授权改动合并到一稿，保留项排除这些例外；互斥状态与多个角度分别交单一画面。跨阶段按实际产物依赖承接；批量缺项按[资产输入](references/asset-input.md#批量处理与共用依据)仅影响相关条目，遵从用户整批交付偏好。

配色先复用适用的确认方案或可用旧提案。缺方案、补颜色、明确重配色或第二步需要色卡时，读[配色检索与适配](references/palette-selection.md)；已有适用色卡不重选，检索不授权重配材料色。

只有用户要求保存、更新或恢复才读[连续性记录](references/continuity-record.md)。需要案例校准时读[案例检索](references/design-case-retrieval.md)；追溯来源时读[知识库索引](references/knowledge-base-guide.md)，不全库加载。

仅采用 LIRA 时读[模型参考](references/model-reference.md)，需要电影成像参考时读[成像参考](references/scene-generation.md)。来源经验不作为当前模型规格或工具调用授权。

## 交付与检查

默认交原资产／单一状态、必要说明和代码块内的一条完整中文提示词；第二步另附适配色卡，用户只要文字时省略；第三步只交所需角度，不重选色或绘卡。多场景按原表顺序，不默认附内部分析、HEX／比例表或套图。

生成稿独立完整，不以“同上”省略；图像编辑稿明确实际基准、修改及相关保留项，不必复述全量未改区域。共同写法、密度校准、门的取舍和回填按[提示词交付](references/prompt-delivery.md)，打光／反打模板在对应阶段参考中。

更新技能或用户要求验证时读[验证规则](references/verification.md)，按受影响范围使用[固定用例](tests/cases.md)；它们不是日常生成的额外必读项。

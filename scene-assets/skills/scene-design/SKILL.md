# 场景设计

先读 [知识索引](../../knowledge/index.md)，按任务加载本轮 reference。

读取 [设计规则](../../references/design.md) 与证据。先区分原文事实、风格板可见观察、推导和创作选择；视觉基准需操作者批准。逐场景定主空间、活动路线、尺度参照、材料光向、前中后景和连续性不变量。中式幻想方向已批准时才读 [尺度知识](../../references/knowledge/chinese-fantasy-scale.md)，源案例的仙人人数、画幅和工具参数不当默认。用 CLI 提交设计卡并等待操作者批准。

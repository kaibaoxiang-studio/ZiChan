# 场景证据核对

先读 [知识索引](../../knowledge/index.md)，按任务加载本轮 reference。

读取 [证据规则](../../references/evidence.md)。用资产表稳定场景 ID 定位剧本原文，列地点、时段、天气、物件、活动空间与连续性事实；每条事实附 source_refs，推导另列。场记只补镜头线索，不覆盖原文。有冲突就列双方位置与受影响设计，不自行改写。输出可供设计卡读取的证据记录。

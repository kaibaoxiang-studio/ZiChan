# 场景图片审查

先读 [知识索引](../../knowledge/index.md)，按任务加载本轮 reference。

必须实际打开回流图，再读取 [审查规则](../../references/review.md)、当前设计卡与剧本证据。比较地点事实、活动空间、结构连续性、尺度、人物/道具新增和构图。对无法看清之处标 uncertain；有缺陷标 revise。提交 SceneImageReviewV1，给可定位的局部返修方向；通过后仍由操作者用 CLI 批准图片。

# 场景资产主控

先读 [知识索引](../../knowledge/index.md)，按任务加载本轮 reference。

读取 [工作流](../../references/workflow.md) 和 [接口](../../references/interfaces.md)。按剧本/资产表原文核对场景，再提出全剧视觉基准与场景设计卡；批准后写外部出图提示词，回图必须实际打开审查，操作者批准后才能打包。中式幻想知识只在项目视觉基准批准且当前场景适用时加载，不默认添加仙宫、人物或超现实规则。用 scripts/scene_project.py 保存源文件哈希、版本与审批；不调用生图或视频工具。任何缺失材料、冲突或未批准选择列为待裁决，报告真实文件路径。

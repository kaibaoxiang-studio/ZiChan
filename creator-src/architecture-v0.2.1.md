# 角色资产插件 0.2.1 增量设计

## 版本边界

在 0.2.0 的 17 项能力上做补丁发布，不增加新能力，不改变已有项目的批准状态。新重点人形设计使用 `CharacterDesignCardV2.1`；已有 V1/V2 卡继续读取。新专项提案用 `CharacterSpecialistProposalV1.1`，旧 V1 可读。头像提示词的新提交默认要求 3:4；已批准旧提示词与图不因升级自动失效。

## 问题与责任链

1. 设计层缺口：当前 V2 只要求 `appearance{}` 与 `costume{}` 对象，空泛短句可以通过。新卡加六组 `visual_details` 及十专项 `specialist_coverage`（已用专项需指出具体落地字段），设计稿 Markdown 同步呈现。专项新提案每选项至少两条有部位和位置/结构的 `design_elements`。CLI 做结构门槛；人工判断可画性、历史依据和美感。
2. 渲染层缺口：分别为设计、群像、皮肤、服装材料、提示词、回图审查、修图发布七份知识快照。共同规则区分油光/蜡感、真实微纹理、布料物理、光色和噪点；选角照、摄影和 PBR 按媒介条件选用。与已有无场景背景审批规则兼容。
3. 头像画幅：`CharacterPromptPackageV1.aspect_ratio` 默认 3:4，所有候选文字明确写比例。其他比例需 `aspect_ratio_explicit_user_override:true` 与用户决定依据。回图目视核像素比例和取景，外部工具不能直出时由操作者裁切最终图再审查。

## 来源与发布

《拒绝脸谱化人物设计-知识库.zip》25 个 Markdown 成员的归档/成员 SHA 在 `knowledge/archive-manifest.json`；原文和提取文本只存忽略的 `.harness/library/character-assets-0.2.1/`。本轮用户的质感实操说明融入共同规则和七份定点快照。README、Skill 路由、知识索引、接口、CLI、样例均同步更新。使用 Harness Creator 重建、验证、打包，再本机安装并推送仓库。

## 验收重点

- 宋也的概括衬衫句不能独自填完 V2.1 设计卡；具象示例作为待审提案，不写进用户项目。
- 新卡缺脸、发、体态、皮肤、剪裁、材质、饰件或十专项覆盖时拒绝；旧卡通过兼容检查。
- 新专项选项缺 `design_elements` 拒绝；旧提案兼容。
- 头像默认 3:4 通过，1:1 无明确用户覆盖失败。
- 没有回图时不宣称去油/去噪成功；重建与外部增强不得说成无损保证。

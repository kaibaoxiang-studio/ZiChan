# 面部装饰与妆容的叙事交接

适用：角色已有原生痕迹、剧本出现妆容/面绘/伤痕，或身份设计缺少近景可见的表达时。先决定**是否需要**；自然面容和不化妆是完整的设计决定。

1. 将面部信息分为三层：稳定原生标记（已写明的痣、胎记、旧疤等）、主动施加的妆容或装饰（眼妆、唇色、面绘、穿戴物）和随剧情变化的临时状态（新伤、泪痕、花妆、灰尘）。每项写部位、左右、范围、边缘、色与质地、近景可读尺度、持续时段。
2. 每项都须附剧本场次、已批准选择或明确待审提案。写清“这个细节说明哪段经历、行动或社会关系”，但不能从痣的位置、眼线角度、肤色或伤疤推断人格、道德或心理诊断。为美观而加的新伤疤、纹身、宗教符号和面部装饰不能偷偷进入头像。
3. 先与已有 2–3 个主锚点及发型、头颈饰品比较。如果抢焦点，缩小、退为次要或不采用。面部记忆点专项管稳定结构与头颈物件；本专项管妆面和面部表面状态；跨界同一物件只指定一个主责。
4. 基础头像、九宫格和全身模卡继承相同的稳定面部层；妆容若为剧情状态，只在对应变体服饰图与执行图中使用。表情格默认不逐格换妆；有明确剧情情绪转折和用户批准时才生成独立状态表。新伤、化妆脱落与愈合逐状态列连续性，不把后期状态投回早期身份基线。
5. 审查回图时核对左右位置、尺寸、色域、材质、是否有模型新加斑点/伤痕以及状态跳变。外观正确但叙事依据缺失，仍回设计卡处理。

来源：《面部装饰与妆容设计知识库.zip》模块 1、2、4、5 的分层记录、动态联结和生产检查。人格与面部符号的固定对应关系仅作为创意讨论，不作因果规则。

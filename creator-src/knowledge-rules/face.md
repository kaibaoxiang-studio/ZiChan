# 五官与面部差异化专项知识快照

**适用**：多人都是鹅蛋脸、细鼻梁、同眼距与刀削下颌；头像只靠发型或妆容区别；真人写实角色过度美颜。

1. 先定颅面的大结构：脸长宽、额部、颧骨、下颌宽窄和转折，再定眉骨与眼窝、眼距与眼型、鼻根/鼻翼/鼻尖、口宽/唇形/唇峰。三庭五眼是描述比例的坐标，不是每人都应符合的美人模板。
2. 从剧本事实、年龄、亲缘提示、总控的人物定位和视觉方向提出一套完整推荐，真正影响人物形象的分歧再给备选；说明正面、四分之三侧面和缩略图的辨识。具体骨相没有唯一生活因果时，明确标为原创设计选择，不从性格、圈层或经济水平推定脸型。为近邻角色避免重复同一组脸型 × 眉眼 × 鼻口，但可保留有意的家族相似。
3. 普通面孔也要具体：宽鼻翼、平颧、厚眼睑、略宽眼距或短圆下颌等都可自然出现。不要为了“破美型”给人物疾病、疤痕或丑化特征。
4. 小幅不对称可作为活人质感；与面部记忆点专项区分：这里负责结构，痣疤与面饰由后者处理。参考演员只能提取用户指明的年龄感/神态/结构方向，最终面孔保持原创。
5. 不从脸宽、眼型、鼻梁或所谓“可信感”断言道德、攻击性、智力、族群本质或性格。若利用社会印象作叙事误导，必须标为创作策略。

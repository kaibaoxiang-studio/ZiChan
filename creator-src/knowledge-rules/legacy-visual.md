# 旧 Skill 差异化方法吸收快照

**适用**：群像描述过于笼统、相近角色只换衣服、儿童或老年变体沿用成人面孔时。

1. 从旧 Skill 的“占用表”提取方法：记录角色、远看轮廓、脸型、眉眼、鼻口、头发结构、体型和服饰识别点；新角色对照最近邻，避免复制整组结构。
2. 从“群像面部去同质化”提取方法：群像整体描述要落到成员之间不同的脸型/下颌、眉眼、鼻口、头发块面与体态，不只写“长相各异”。人数按原文；不为凑矩阵虚构具名角色。
3. 从“年龄阶段锚点”提取方法：幼童、学龄儿童、青少年、成年和老年通过比例、软组织、脸部成熟度与服装尺码体现，不用单一年龄数字或一层皱纹代表。
4. 不继承旧 Skill 的固定四视图、强制面部“互斥三锚”、硬编码国籍/人种外观、特殊场景安全改写或“配角让开主角”的美型等级。优先遵守本插件已批准设计卡、剧本事实及现有头像→表情/全身→执行表流程。

**证据位置**：`novel-characters-visual.zip/novel-characters-visual/SKILL.md` 的“年龄阶段锚点”“群像面部去同质化”“本剧造型对照/占用表”“卡司骨相对比”“群像怎么写”。其许可信息缺失，仅作方法研究并独立写规则，不复制原段落与模板。

# 皮肤肌理与质感专项知识快照

**适用**：回图出现磨皮、蜡像感、全员同一肤色/光滑度；角色年龄和生活环境无法从皮肤读出。

1. 写稳定基底与局部差异：肤色深浅与冷暖、额鼻颊的光泽变化、毛孔分布、细纹、干燥/出油、日晒与色沉。真实皮肤不是全脸同一色块，也不需要把每个毛孔夸成病灶。
2. 年龄、环境、劳动、护理资源只作为有依据的候选因果。老人不必全脸沟壑；年轻人可有痘印和局部粗糙；户外人物晒痕的范围需符合衣物遮挡。配角不因戏份少而更脏或更廉价。
3. 将临时汗、水、血、泥与稳定身份肌理分开。只在剧本状态或独立变体需要时加入；头像基底不自动加战斗污损。
4. 疤、痣、纹身与面部记忆点专项协调：本专项负责表面物理与光照表现，是否新增、位置及身份连续性由面部记忆点与操作者批准决定。
5. 提示词用可观察的具体质感而非“超真实 8K 无瑕皮肤”。回图在脸部放大检查纹理是否随结构与光照变化；过度锐化、统一磨皮都应记录。

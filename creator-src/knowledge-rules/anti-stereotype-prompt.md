# 角色提示词的真实质感控制

**适用**：已批准设计卡足够具体，但生图提示词遗漏可见结构，或皮肤/服装油亮塑料化。

1. 先从设计卡抽取当前画幅可见的脸、发、体态、衣装结构和 3–5 个关键识别锚点；抽象类型词不能代替设计。头像默认 3:4 竖版，明确头顶、双耳、肩线和上胸安全边界；不擅改已批准背景。
2. 质感词按实际缺陷选择：`natural skin texture`、`subtle tonal variation`、局部 `visible pores`、`low specular highlights`；布料写材料、厚薄、垂坠和褶皱；光线写软硬、方向、冷暖关系。负面词只在工具支持且确有风险时少量使用，避免与纪实轻微颗粒冲突。
3. 纪实选角照、影视摄影和 3D PBR 按项目批准媒介选用。摄影器材/焦段/光圈是风格意向，不能保证物理精确；虚化不得吞掉要核验的细节。资深设计师身份句不是替代造型方案的魔法词。
4. 明确背景权限：若角色资产图没有获批准场景，只用无场景中性背景和不暗示天气地点的核对光。课程“先带场景生成”的建议不能覆盖当前审批边界。

**证据位置**：《拒绝脸谱化人物设计-知识库.zip》M3-3、M6-0、M6-1、M6-2、M6-4、M6-5、M6-6。课程词块是候选语汇，不是固定全套必贴。

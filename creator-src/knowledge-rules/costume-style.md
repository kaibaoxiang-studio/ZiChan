# 服饰款式专项知识快照

**适用**：只给角色写“古希腊长袍”“贵族服”“战士装”，衣服品类、长短、松紧和层次无法落到画面。

1. 先决定可见品类和穿着组合：内层/外层、上衣/下装或袍裙、长短、松紧、领口/袖型/摆型与鞋。款式回答“穿什么、整体外轮廓是什么”；具体缝线、结构线和活动余量交剪裁专项。
2. 同一世界可共用衣装语法，但不同职业、资源、场合和身体尺度会让层次、长度和松紧不同。先满足行动与气候，再考虑叙事焦点；不是每个重要角色都要最复杂。
3. 比较组要在同制服或同阶层条件下仍可辨，衣服不能完全替代脸和体态区分。关系角色可故意共享某款式，需解释为何相似。
4. 为特定历史、民族、宗教名词和穿法另查可靠出处；知识库中的时代/阶层列表是检索线索，不是证据。虚构混搭标明设计选择。

**证据位置**：《服饰款式设计知识库.zip》`模块1_款式基础/01_什么是款式-衣服的基本版型.md`、`02_宽松vs修身的视觉区别.md`、`04_长vs短的视觉区别.md`；`模块3_款式与身份职业/01_不同职业的人穿什么款式.md`；`模块4_款式与世界观/01_不同世界观的人穿什么款式.md`。宽松/紧身与某种人格的一一对应不作事实规则。

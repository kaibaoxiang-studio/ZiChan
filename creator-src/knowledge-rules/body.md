# 形体体态专项知识快照

**适用**：主角与配角体型均为修长健美、年龄只靠面部表现、全身图体态不可信、同框比例无法辨认。

1. 分开写骨架/身高尺度、体重分布与软组织、肌肉使用痕迹、头肩腰胯及上下身比例、静态重心、惯常站坐走姿。只选对角色身份和镜头有解释力的差异；不要求每人极端体型。
2. 年龄段用可见比例与组织状态落实。儿童肩胯、四肢、头身关系须适龄；成年人也允许短壮、圆肩、微胖、纤细、宽胯或瘦削等真实分布。孕产、伤残、疾病等不可由职业/道德臆造。
3. 从工作方式、训练、资源、旧伤和场景动作推导体态时标为推导或提案。剧本写明的跛行、负重、怀孕等优先；未知不硬加。展示站姿和动势，但稳定设计卡不把一瞬动作当永久体态。
4. 与相近角色并列比肩线、重心、背部弧度、腿身关系和惯常步态。让差异在同制服、去色和中景仍成立；服装剪裁要服务原有身体，而非把所有人修成标准比例。
5. 非人按真实肢体、关节、尺度和运动方式重建，不套人类头身比。使用相对尺寸时给同框参照，避免绝对数值假精确。

# 服饰饰品专项知识快照

**适用**：服装需要扣件、腰带、手饰、挂件、袋具或身份饰品，且需与服饰焦点、行动和资产表道具协调。

1. 本专项主要负责锁骨以下与衣身、腰、手、肩背相接的穿戴物：扣件、带扣、肩扣、臂环、戒指、腰挂、可穿戴袋具。耳饰、头饰、面饰、颈部到锁骨上方的项链由面部记忆点专项主责。跨区域饰品由主控指派唯一主责。
2. 先问是否需要饰品。若需要，写位置、尺寸、材质、重量、固定方式、正背面可见性、运动时是否碰撞，并核对功能：闭合衣服、携带物品、礼仪、身份或已写明的情感意义。
3. 饰品不是随机主角徽章。来自剧本的护符、徽记、武器配件与资产表道具 ID 对齐；无依据的宗教/族群图腾、遗物故事、职衔标志只作为提案，需查文化含义与获批。
4. 服装复杂时减少焦点，服装简洁时也不必强行加饰。与群像比较组检查是否所有主角都戴同一类金属环；相似可作为阵营共性，个体差别放在形态或位置。

# 发型专项知识快照

**适用**：发型看似与别的角色只换颜色、与脸型不相容、从头像到背面不稳定，或需要符合时代与生活方式的可执行发式。

1. 先锁头颅与发际线、发旋/发流、发量密度、发质，再设计头发外轮廓。记录前额、两侧、后脑三块体积及分缝、长度、束发位置和发尾走向。用可见形状描述，避免“清爽长发”“精致卷发”等空泛词。
2. 询问谁打理、用什么束发工具、在劳动/航海/战斗/礼仪中如何维持。时代文化限制或戏剧情境未知时只出可替代提案，不宣称历史准确。
3. 与比较组核对头部剪影、发际、厚薄、贴颅或蓬松、卷直、分缝与束发方式。优先改变结构组合；不把发色或夸张呆毛当唯一差异。年长角色可有发量变化，但不默认秃或白。
4. 发饰先说明固定点和拆卸状态，再与锁骨以上饰品专项协调。后脑必须有实际束口、结、发量和可见背面；多视角不得变成另一种发型。
5. 只为有叙事或造型理由的角色建议标志性发束。一个主识别点足够时不叠加挑染、长鬓与夸张发饰；现实主义项目控制夸张幅度。

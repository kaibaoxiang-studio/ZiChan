# 逐状态妆造与真实质感

来源：用户提供《AI角色妆造_提升角色质感_完整教程》。采用“身份稳定、状态变化”的方法；不采用教程中男女固定妆容分工，也不搬运它的侠客、贵妃、庭院等例子为项目默认设定。

1. 读取已批准身份脸、人物状态与剧本动作。把妆造拆成**稳定身份**（骨相、发际和原生肤色）、**主动施加**（底妆、眉眼、唇、发饰、衣装）、**临时状态**（汗、泪、尘、损伤）；每项标出现依据与连续性。
2. 逐状态写底妆覆盖程度、眉形/眼妆/唇色或明确无妆、发束/发饰固定方式、衣装与妆面的色温关系；没有依据的特殊妆面不硬加。任何性别都按角色和场景需要设计。
3. 皮肤有局部微纹理和真实光学反应；限制大片镜面高光、蜡感、过度磨皮与脏糊噪点。避免“零噪点”抹掉真实纹理。柔光要有方向和硬度，不把戏剧性暖光默认加给每个状态。
4. 回图比较头像：是否换脸、发际漂移、眼鼻口比例变化；再核对本状态妆面完整度和衣装对应。看不清则标 uncertain，不替换身份锚点。

交付包括“现状→设计干预→可见部位→依据→下状态保留/消失”的短矩阵。不得让状态妆面承载未经确认的新剧情。

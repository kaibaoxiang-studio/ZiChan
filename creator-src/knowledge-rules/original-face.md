# 原创面部结构与身份锁定

来源：用户提供《原创AI角色捏脸_不用参考图_完整教程》。采用结构设计法，舍弃教程中的固定性别/性格脸型映射与背景示例。

1. **先定轮廓**：写脸长宽、颧宽、下颌转折、颏长及软组织分布，区分正面与 45°。不靠“好看”“清冷”等抽象词替代骨点。
2. **再定比例**：写发际—眉、眉—鼻底、鼻底—颏的相对关系，眼距、眉眼距、鼻口距；比例服务年龄感及独特性，但不由比例推断人格。
3. **五官主次**：选 1–2 个结构主锚点，其他维持安静；逐项写眉眼、鼻、口的形状、位置与不对称。不拼接某真人全脸或复制单张参考图；若参考局部，注明每张只借什么结构。
4. **自然表面**：按年龄和环境写局部毛孔、轻微色差与绒毛，控制镜面高光和磨皮；不为“真实”机械添加斑、疤或污损。
5. **锁定与验证**：头像批准后保存脸型与比例为身份不变量；换装和状态妆面不改变骨相。对比正面、45° 和表情九宫格，检查是否仍为同一人。

产物要有可画的量词、形状和部位；不是“精致五官”。

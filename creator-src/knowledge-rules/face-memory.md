# 面部记忆点与锁骨以上饰品知识快照

**适用**：面部结构已成立但缺少近景稳定识别，或头饰、耳饰、项链、颈部物件需要与头发和领口协调。

1. 先盘点无需新增物件的识别点：独特眉峰、唇形、耳形、表情纹和轻微不对称。再考虑痣、疤、纹身及饰品。无原文依据的伤疤、胎记、纹身要作为单独提案，未经批准不进入身份不变量。
2. 为提议的面部/头颈识别点说明位置、大小、正侧背的可见程度和剧本中的持续性。避免多处抢同一视觉焦点；“没有饰品”也可保留头颈轮廓。
3. 耳饰、头饰、颈链需写固定方式、重量/运动、与发型和领口的连接关系，以及何时佩戴/卸下。重要道具要与资产表 ID 对齐，不能凭空给出剧情遗物或宗教符号。
4. 与发型专项协调发饰落点；与服饰饰品专项协调项链、披肩、扣件等越过锁骨的元素。主责按最清楚的镜头识别区域确定，避免两边独立新增相同饰品。
5. 意外生成的痣疤和头饰不因“效果好”自动纳入正式身份；先做可采纳提案，操作者批准后更新设计卡，再重新审图。

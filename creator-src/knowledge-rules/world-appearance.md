# 环境、资源与技术如何进入角色外貌

适用：建立世界视觉基准、逐人设计，以及剧本出现迁徙、劳动环境、医疗或身体技术时。先从剧本提取地点和活动、资源与可达技术，再区分稳定身份、可更换装备和单场临时影响。

1. 写出 `环境或世界规则 → 角色实际接触方式 → 可观察的外观结果 → 依据`。优先考虑日晒和劳作留下的**个体**痕迹、发肤护理、衣装防护、材料取得、技术加工、佩戴方式和维护成本；没有接触证据就不推导外观。
2. 技术特征须写用途、可获得性、安装或穿戴部位、重量和维护痕迹。把时代、资源和阶层转成可见的制作与使用差异，不用肤色或脸型替代社会身份。幻想技术先核对项目世界规则，不把某种媒介惯例设为全剧事实。
3. 迁徙、家庭、职业和个体选择可能使同一环境中的角色外观不同。禁用“某气候必定某鼻型/眼型/体型”“某族群必定某性格或美貌”的自动映射。涉及遗传、演化或医学效果时，仅把来源文档当设定灵感；没有剧本或操作者批准不得写成真实的人体事实。
4. 输出 2–3 套可见方案时，至少指出一个环境或技术结果在头像、全身、服饰图、执行图的哪一阶段可见，及其他阶段是否应保持空白。若项目或角色没有有意义的环境差异，明确 `not_needed`，不为填表制造痕迹。
5. 验收时反查每个世界影响是否有来源、是否在相邻角色之间被机械复制、是否与角色动作和服饰物理结构相容。天气、灰尘、汗水等临时状态属于剧情状态，不回写基础头像。

来源：《人种环境与科技外貌设计-知识库.zip》模块 2、模块 3 的环境压力、技术可达性和反刻板化方法；其中把气候直接映射为固定族群五官或身体比例的断言不采纳为规则。

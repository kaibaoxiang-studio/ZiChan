# 通用图片方法在角色局部修图中的用法

这是发给外部出图操作者的修图文字。每轮只针对一项可见错误，同时完整重申角色身份和其他区域的不变量。目标图与辅助参考必须分别编号。

1. 先看原图和审查报告，定位具体格位、目标文字或区域。写清“只改变 X”，再列出“保持 Y、Z”；不要用抽象的“优化一下”替代可视差异。
2. 对错字，给出正确汉字、所在格位、字数和是否需要保持原字号与位置；其他文字及人物形象保持不动。完成后逐字复核所有格位，防止局部编辑带来新错字。
3. 对身份漂移，已批准头像为强参考；只修目标图的脸型、发型、年龄感或标记等错误锚点。服装和背景如已通过，写成保留项；修后重新审查整张图的身份、服装与裁切。
4. 对无头服装格，目标只针对左下格的上缘裁切；不得因去头而丢失颈肩以下的服装结构、双手、腿或鞋。其他三格按原批准图保留。
5. 对服装或材质局部问题，参考图仅提供获批准的可见特征。不得顺带更换脸、姿态、世界画风或未批准的变体。若一次局部修图无法可靠解决，提出重新生成目标阶段图的方案，并要求全图重审。

修图循环为：原图证据与差异 → 单项修图指令 → 外部修图 → 回流图片 → 全图重新审查 → 操作者批准。提示词里的“不变”是目标，不保证模型像素级维持。

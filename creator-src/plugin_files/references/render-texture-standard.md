# 角色真实质感与回图修复

## 分开判断两类问题

先看设计本身：移除“高冷、漂亮、霸气”等标签后，是否仍有可画的面部、发型、体态、衣装结构和生活逻辑？再看渲染：是否出现整脸镜面高光、蜡像磨皮、统一塑料布料、错误光色或脏糊伪影？设计空泛应回设计卡补细；渲染错误才改光线、材料词或局部图片。两类问题可同时存在，审查报告分别写明。

## 提示词质感选择

- 写脸部和皮肤的**区域与强度**：鼻翼/双颊可见细微毛孔，鼻梁保留微弱自然反射，额头与颊侧有轻微色调变化；按人物年龄、妆容和镜头距离调整，不全脸铺等量毛孔/绒毛。可用 `natural skin texture`、`subtle tonal variation`、`low specular highlights`。`matte skin` 仅在当前方案需要哑光时使用，不把真人皮肤抹成粉墙。`subsurface scattering` 仅在 3D/PBR 或明确渲染需求中低强度使用。
- 按部位写材料：例如细密毛呢的短绒与厚重下坠、旧棉布的软折、磨暗金属的局部反射。说明纤维/表面、厚薄、垂坠、褶皱和磨损；磨损要有剧本或获批准的生活依据。不要用“8K/超清/真实材质”替代。
- 光线写软硬、方向和色温关系，并与已批准背景分离。中性背景仍可有不暗示地点的柔和方向光；`soft overcast daylight` 会引入天气含义，只有背景/光线已获授权才使用。雕塑感阴影只在不牺牲面部识别的情况下选择。
- 反向词只针对看见或预计的错误少量使用，如 `plastic texture`、`waxy skin`、`excessive shine`。并非所有工具都有独立负面提示词栏；没有时改用正向结果描述。不要同时要求“全部无颗粒”和“保留纪实轻微相机颗粒”，也不要让“smooth surfaces”覆盖皮肤微纹理。
- 选角照、电影摄影、3D PBR 是按项目基准选择的表现路径。`unretouched casting photo` 可以表达未磨皮；PBR 的 roughness/normal maps 是 3D 资产技术语汇。具体相机型号、焦段、光圈只能作为光学风格意向，不能保证模型遵守器材物理；浅景深不得让本阶段必须核对的面部和衣装细节失焦。提示词开头的“资深设计师”身份句可选，不能代替具体造型。

## 回图诊断与修复阶梯

1. 实际查看图片的高光位置、微纹理、布料分层、光线方向/色温、面部与衣装边缘；只在看得到时报告。区分真实摄影的轻微颗粒与脏纹、涂抹、伪影。需要清洁资产底图时，要求干净无场景背景和清晰边缘，保留皮肤与织物微结构。
2. 轻度油亮：在保留身份和光位的前提下，局部降低鼻梁/颧骨过强镜面高光并恢复自然色差。轻度脏糊：只修受影响区域，核对眼、发、衣缝和饰件是否被抹掉。
3. 外部工具如有智能超清/去噪，可先在复制件上低强度试验并对照身份、结构、材料细节；“强度约 1”不是跨工具通用值，也不保证无损。该插件仅提供建议和复核记录，不宣称已运行工具。
4. 严重涂抹时，可提议以经批准原图为身份/姿势锚点，另做干净线稿或灰模重建材质；这是**备选重建方案**，可能改脸、手和衣缝，必须按新图完整复核和操作者批准。若外部生成会话携带脏图上下文，可从已批准母图开启新会话；不设固定修改次数门槛。
5. 从有场景母图抽资产时，先记录/保存原图光位、色温和材质关系，再按当前角色资产图的**已批准背景规则**生成或去背；不因为教程建议“先保留场景”而擅加剧情地点。去背后对比面部体积与服装阴影，不把丢失的光影伪装为已保留。

# 剧情驱动的表情资产

从剧本情绪转折、人物关系与可选场记的近景需求中选 9 或 16 个可见表情。至少覆盖自然状态及剧情真正使用的情绪，不为了填满格子添加不属于角色的夸张表演。每格说明表情名、对应场次/来源、面部可见变化与力度；同一角色的脸型、年龄、发型和标记保持稳定。

输出一张规则网格的 GPT Image 2.5 提示词，要求每格**图内直接写中文表情名**。提示词中给出从左到右、从上到下的格位与文字清单。文字易出错，所以回流审查逐格核对：格数、顺序、标签字形、重复/漏字、表情是否与标签一致。任一标签错误都不能发布定稿；修图指令只针对错误格位和文字，不重画已正确的人脸。

表达方式服从角色性格。克制型人物的“愤怒”可以是颌部紧绷和目光变化，不必变成怒吼；疲惫、紧张、释然等要有能拍到的区别。表情资产只解决面部情绪参考，动作图鉴留给后续扩展能力。

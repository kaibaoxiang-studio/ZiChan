# 群像差异化总控 v0.2

## 目标和先后顺序

让同剧角色在同一视觉世界中可辨，并保持真实人物的分布：可以漂亮、英俊、普通、粗粝、年长或带生活痕迹，但不能默认全员精致、对称、修长、无毛孔。剧本明示和操作者已批准的形象先于本框架；差异不是为了强制每人有疤、怪发色或极端体型。

1. **全剧基准之后、全员轻规划之前**：从角色关系与同框情况建立比较组。优先比较年龄接近、功能相似、服装制式相同、对手/亲属/同行的角色；亲属可以共享家族特征，双胞胎或伪装可以故意相似。
2. **全员轻规划时**：做角色 × 识别轴矩阵，至少记录远景轮廓、脸部结构、体型与惯常姿态、头发块面、服装色块五轴；非人形按可见结构替换不适用轴。允许“待定”，但不得以“各不相同”“英俊”“漂亮”代替可画的描述。每行保留原文事实、推导和未批准设计提案的来源状态。
3. **逐人设计前**：对照最可能混淆的 2–3 人，找出共享轴与真正需要改变的轴。优先改变有身份、生活方式和世界工艺依据的结构；服饰颜色与配件不能替代脸、发、体态全部同型的问题。
4. **设计卡定稿前**：说明该角色与比较组在哪些可见轴不同，以及差异如何跨头像、全身、背面和变体保持。若视觉方向故意相似，写明叙事用途与可保留的最小区分点。
5. **头像/全身回图后**：并排看已批准角色参考图，检查设计是否真的落地。缩略图、去色、遮挡衣服、同制服四种检查按可用图片执行；没有图就标“未验证”，不称测试通过。

## 防模板脸与真实度审查

- 检查是否反复出现相同脸型、颌线、眉眼距、鼻口比例、发际线、发量和体型；只换发色/服装的脸仍算疑似撞脸。
- “普通相貌”是独立而具体的结构组合，不等于肮脏、病态、贫穷或无设计。配角允许精致；主角也可以有不符合传统审美的结构。戏份不决定美丑。
- 年龄用相应骨骼、软组织、姿态和皮肤表现，不能只写年龄数字或加皱纹。劳动、气候、资源只在来源支持或批准时留下痕迹。
- 面部不对称可以极轻，不强制添疤、痣、胎记、疾病、纹身；这些是稳定身份资产，一旦新增须明确提案与批准。鼻梁、脸宽、唇形等不推断性格、道德或族群本质。
- 色彩心理、体型人格和脸宽攻击性等课程说法仅可作为经操作者选择的叙事编码候选，不是现实人物事实，也不是自动分配规则。历史或特定文化服装结论需另核查可靠来源。

## 冲突处理与交接

总控给各专项的是问题，不是“给每人都来一个亮点”。专项默认返回一个有依据的具体推荐，重要分歧才给备选，并说明近邻区分、可行性和待审处；普通项可由主控实际执行规范，复杂项独立会诊，见 [专项合同](specialist-contract.md)。若发型与头饰、领口与项链、肤色与服装色块互相抢焦点，总控选择主次并请操作者确认；正式提示词只采用已确认设计；头像preview可按 [阶段规则](phased-design.md) 引用冻结未批草案，实际审查与明确确认后才可同图转正，不能提前作下游锚点。已经批准的角色锚点不能为了新角色随意改写，先调整新角色；需要改旧卡时走原审批与下游失效流程。

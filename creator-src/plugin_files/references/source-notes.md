# 来源、采用与限制

此文件记录**方法研究输入**，不是要求安装源 Skill 或复制原课程。完整机器收据见根目录 `sources.lock.json`；知识使用情景见 `knowledge/index.md`。原始 DOCX、ZIP、RAR 和用户具体剧本/图片不进入插件包或 GitHub 仓库。

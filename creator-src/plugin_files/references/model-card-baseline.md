# 模卡式基础形体图与正式服装的阶段边界

## v0.2.6 衔接

新项目前三类图仍是身份与形体模卡；正式衣装由获批穿衣风格圣经、各状态服饰文字快照及唯一 9:16 四格执行图承接。下文“服饰设计图”条目仅适用于 v2 历史项目。


本规则适用于**人形角色**的头像、9/16 格表情表和单独全身图。三者用于比较脸、发、皮肤与身体比例，不作为剧情服装定稿。人物的职业服、时代服饰、饰品和换装仍按已批准设计卡制作，v3 在逐状态文字设计与唯一执行图中呈现，v2 则在服饰设计图和后续执行图中呈现。模卡着装只改变本阶段的展示方式，不删除设计卡中的服装事实，不改变身体比例或身份标记。非人形按已批准形态制作；儿童、身体遮盖需求或与剧情身份不可分的穿戴，采用覆盖充分的例外方案并记录依据。

| 阶段 | 默认模卡处理 | 可用的退路或差异 |
| --- | --- | --- |
| 头像，3:4 | **以脸为主体的头肩近景**：完整头部、双肩可见，下沿可延伸至上胸，取景不固定在锁骨；同轮候选保持同一取景与着装模式（phased默认一套推荐，complete保持原候选合同）。若服装完全不入画可用 `face_only`，不得呈现裸体躯干 | 上胸入画时直接用男角色白色无图案纯色背心、女角色白色运动背心，无须先尝试 `face_only`；生成或审查受阻后也可整组改用背心，并记录切换原因。不把被拒图视作合格图 |
| 9/16 格表情表 | 沿用已批准头像的头肩至上胸取景与着装模式；各格一致 | 若头像已采用背心，表情格沿用同款。若从 `face_only` 切换为背心，记录原因并重新审查整张表，不在格间混用 |
| 单独全身图，9:16 | 男角色：白色无图案纯色背心、无图案短裤、赤脚；女角色：白色运动背心、黑色运动短裤、赤脚。正面自然站姿，头、双手、双脚完整 | 不借头像的“服装不入画”做裸身全身图。身体比例、肤色、发型、稳定标记照设计卡；单纯为了填满 9:16 不能拉伸腿身 |
| 服饰设计图（仅 v2） | 每个资产表状态各一张已批准的正式造型，含对应鞋履、饰物和有依据的妆面；是执行图的服装锚点 | 不沿用模卡着装，状态间不混装 |
| 执行资产表 | 已批准的**角色正式服装/变体**，包括对应鞋履和饰物 | 不复制基础全身图的模卡背心、短裤和赤脚；单独按设计卡验收服装结构及前后连续性 |

“男/女”衣型以角色已批准设定与操作者选择为准，不根据脸部或身体猜测性别。角色不适用上述两套衣型时，先记录符合年龄、形态、身体覆盖需求与角色设定的中性或定制方案及依据。默认模卡不凭空添加珠宝、工作牌、剧情道具或时代服装；若遮住不可缺少的身份标记，在不改变角色事实的前提下调整取景或提交例外方案。

新的人形提示词包用 `reference_attire` 记录模式：`face_only`、`white_tank`、`white_sports_tank`、`white_tank_shorts_barefoot`、`white_sports_tank_black_shorts_barefoot` 或 `approved_exception`。头像与表情只用前三项或例外；全身只用两项全身组合或例外。`face_only` 的每条提示词明确“服装不入画”，不要求“锁骨以上”；背心模式写明对应衣型与白色，不要求退路依据即可作为头像初选。全身模式还须写明短裤与赤脚。从已批准的 `face_only` 头像切换到背心表情表时填写 `reference_attire_basis`；`approved_exception` 同时填写 `reference_attire_basis` 和 `reference_attire_description`，写清哪项剧本事实、已批准决定或保护性覆盖需求使默认模式不适用。验收项核对模卡着装、跨候选/格位一致性和与正式服装的阶段边界。已有批准的旧包保持可读，新提交按此合同校验。

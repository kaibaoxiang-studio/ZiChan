# 回流图片审查与发布门槛

只有实际读到的图片才能给视觉结论；没有图片时只评价文字和合同。审查报告使用 `CharacterImageReviewV1`，分别列剧本事实冲突、身份漂移、版式问题、中文标签问题、其他阻断项和可提议纳入的新细节。无法从画面判定的材质或背面，不假定通过，标为待核实。

当同剧已有其他角色定稿图时，头像和全身图还需并排核对近邻角色：脸长宽/颌线、眉眼鼻口组合、发结构、体型体态、皮肤真实度是否与设计卡一致并有可见区分。只换衣服或发色而同脸同体型应列为差异化缺陷。无近邻图时只能报告“群像实图比较未执行”，不能声称已通过群像辨识测试。请区分设计卡本身撞型与生成图未执行设计：前者重开设计审批，后者走局部修图与回图复核。

按顺序核查：①与剧本原文事实；②与设计卡身份不变量；③与上一步已定稿图片；④本阶段构图/格位；⑤图中文字；⑥服装、饰物、手脚、配色和材质是否跨格漂移；⑦背景是否在当前任务或已批准记录范围内。头像审查更重脸部；表情逐格看标签与表演；全身看头到鞋及脸部连续性；执行表按 `references/execution-sheet.md` 四格核查。未经批准的地点、建筑、地貌、天气或参考图环境属于待修问题；若改变角色事实或妨碍识别，则阻断定稿。

把问题分为：**阻断**（认错人、改写明确事实、未批准换装/年龄、严重裁切、错中文标签、2×2 核心布局失败）、**待修**（可局部纠正且不影响身份）、**建议**（审美偏好或可采用的新细节）。只在阻断和其他缺陷均为空时报告 `pass`；`uncertain` 不能由系统自动放行。视觉审查通过后仍需操作者明确批准，审批记录绑定图片哈希、审查报告哈希、操作者和时间。

被选定的头像是后续身份锚点。新头像取代旧头像时，下游表情、全身与执行表都须重新核对；表情重选不应无故推翻全身图，但执行表须重审。保留失败图和旧提示词作历史，不把偏差自动写成新设定。

对于经批准的 2D→3D 呈现，并排检查源图与回图：先核身份锚点和服装结构，再核材质、体积及灯光。新增毛发、皮肤纹理、饰件或海报参考图的人脸/服装如无批准依据，列为偏差；只是渲染媒介变化且身份不变时不必新建角色变体。详见[媒介转换知识快照](knowledge/character-image-prompt/hedgehog-2d3d.md)。

按 `01-通用图片生成` 方法区分参考图与待编辑图后，回流审查要核对“角色身份是否从身份锚点继承”“服装/风格参考是否越权带入其他内容”。图内文字按提示词原样文字清单逐格核对，含顺序、字形、漏字、重复与多余标签。每次局部修图后都审查完整图片，因为模型可能修改了未指定区域。

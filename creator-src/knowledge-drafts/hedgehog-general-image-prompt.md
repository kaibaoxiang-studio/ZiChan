# 通用图片方法在角色资产提示词中的用法

本规则只给外部出图操作者提供文字提示词，不调用生图工具。设计卡、全剧视觉基准和已批准图片决定内容；通用图像 Skill 的例子只提供表达方法。

1. 先判断任务是新图还是修已有图。头像、表情、全身和执行表是新图时，已有图按“身份/服装/风格”等参考角色列出；若是修图，明确哪张是待编辑原图，不能把参考图误写成编辑目标。
2. 把本阶段用途写在最前，再依次写主体与身份锚点、各参考图的单一职责、可变画面要素、构图/画幅、文字和保留条件。设计卡已具体时只整理，不补故事、道具或色板；留白项只有经操作者批准才能变成创作选择。
3. 每张参考图按编号写“取什么、不取什么”。已定稿头像主要固定脸和身份；服装参考只借已批准的结构与材质；风格参考只借媒介笔触或渲染；执行表参考只借版式。复合参考要标出冲突时以哪张图和哪份设计卡为准。
4. 中文图内文字逐项列出原样字符和格位，要求不得增删或改写，并将“逐格比对”写进验收。表情标签和执行表说明文字尤其如此；出图后仍须人工查看，不能因提示词正确就判成图正确。
5. 同一角色的头像候选只改变已允许的取景、轻微表情或光线；不要把示例提示词里的陌生角色、背景、商标或营销文案搬进剧本项目。全身图明确头、双手和鞋完整；执行表仍以本插件四格合同为准。

可复用的提示词小框架：`本阶段产物与用途 → 人物身份锚点 → 图1/图2职责 → 当前允许的变化 → 取景/光线/材质 → 图内原样文字 → 必须保留与禁止新增 → 回图核对点`。字段按当前阶段精简，不把 API 参数当提示词字段。

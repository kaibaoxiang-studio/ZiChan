# 纹样组织与符号边界

整理自用户资料《08-道具装饰性纹样与符号应用》及《07-道具雕刻镶嵌与装饰细节设计》。这些是设计启发，不是对文化、工艺或阶层的普遍结论。

## 从主题到图案

几何、植物、动物、抽象符号与徽记是可选母题。按用户设定与载体选择，不将某一类图案固定分配给某个种族、阶层或文明。

提炼少量辨识特征，再决定保留自然曲线、几何化或混合表达。对称、重复、直线化不是强制步骤；用户需要写实或非对称纹样时也可以成立。

母题的形态语言与身份寓意分开：视觉上像叶片，不代表用户世界观已经存在自然教派；新符号的含义必须标为设计提案。

## 图案在载体上的组织

- 核心标识：适合承载需要被读出的身份或主题，注意已有识别符号不能擅自替换。
- 带状纹样：顺着现有长条或边缘组织节奏，转折处说明如何衔接，不新增边框构件。
- 局部底纹：帮助丰富区域，但可保留留白，避免遮蔽功能与主要识别信息。
- 单独点缀：在指定位置提供呼应，不为了平衡布局扩展到未授权区域。

曲面、长条或小面积区域需要调整图案尺度与方向，不必直接拉伸到失去识别特征。依据实际观看距离决定简化程度；没有图像时不声称小尺寸识别已测试。

原资料的“最多两种纹样”“三级装饰全部齐备”等不是硬限制。使用多少由风格、区域与用户目标决定，关键是每种图案有明确作用。

## 不把图案设计等同于新结构

平面线条、色块与已有纹理中的图案表达可以先作为视觉方案。雕刻、浮雕、镶嵌、镂空等是不同的结构或工艺选择，不因名字中有“纹样”就获得实施授权。

工艺线宽、固定方式或材料兼容性只能先列视觉可行性建议；制造图和工程验证属于单独需求。不要保证“阴刻必不影响强度”“浅浮雕必不改变轮廓”。

功能区不必一律空白，但任何新增表现都应不妨碍已有握持、摩擦、开合或连接；若存在冲突，先说明取舍。

## 含义与来源

保留用户提供的真实文字、既有符号及含义；改造或替换必须在本次范围内。装饰性虚构字符标为虚构，不编造读音、翻译或历史出处。

真实文化符号的含义与用法可能依语境变化，不能仅凭外观或阵营气质下结论。精准考据需要可靠来源；原创设计也不等于已经证明无近似标识或完成权利审查。

# 时代文化与装备体系专项

用于确定同一项目的时代/文化边界、装备族群、阶层差异，以及职业或日常用品的设计依据。不是通用兵器史，也不是现实武器制造说明。

来源：用户提供的《武器装备史与文化体系知识库.zip》。原资料为简短分类与风格提纲，未完成历史、地域和作品案例核验；这里不沿用其未经核实的年代表或绝对分类。第 2、3 节提炼原资料的设计维度；第 1、4、5 节为整理补充的执行方法。来源映射与证据记录见 [知识来源、证据与待补项](knowledge-sources.md)。

## 1. 先明确考据模式（P0—P1）

考据模式与“写实、动漫、国风”等成图风格不同。只在会影响当前设计时确认，不要求先编完整文明史。

| 模式 | 如何使用参考 | 当前缺口的处理 |
|---|---|---|
| 历史还原 | 依据明确时期、地区、用途和来源选择形制、材质与佩用方式 | 对影响当前设计的判断做针对性核验；不足时标注待核实，不宣称考据通过 |
| 历史启发 | 提取某种结构、工艺或文化线索；清楚说明保留和改动 | 允许探索，区分借鉴与原物事实，不将混合设计标为史实 |
| 自创/混合体系 | 以用户世界观和既有定稿建立内部规则，记录借鉴来源与例外 | 不以现实时代单一标签否决已确认的魔法、贸易、传承或技术设定 |

用户已经明确模式时直接沿用。未明确且暂不影响轮廓探索时，可以标注模式假设继续，不能默认整项目必须严格复原。

按需在项目约束卡补充：

```text
考据模式：历史还原 / 历史启发 / 自创或混合；来源或假设
时代与地域：仅记录已知范围，不从作品标题猜测朝代
群体与用途：阵营、职业、阶层、军用/礼仪/生活等
生产与流通：与本件相关的材质、工艺、维修或取得方式
共享语言：本套装备已有的形态、材质、符号和等级表达
例外：传承、贸易、缴获、伪装、魔法等已有设定
参考职责：哪份资料约束形制，哪张图只参考风格或尺度
未核实点：影响当前判断的缺口，不扩大为整库考据任务
```

## 2. 从体系到单件（P1—P2）

- 先看用户已有角色、场景与装备定稿，提取共享的制造方式、材质分区、连接形式和识别符号。只制定当前一组资产需要的规则，不自动为全世界生成装备清单。
- 区分制式、精英、礼仪、个人改装与传承物。等级差异可以通过工艺、保养、材质或符号体现，不默认等级越高就越复杂、越金亮。
- 单件设计同时核对用途、携带/佩用方式和群体归属。职业身份不是武器类型的唯一决定因素，礼物、缴获与伪装可能构成已确认例外。
- 文化借鉴落在具体形态与来源上，不仅贴一个地区标签或纹样。没有依据时不把某一大陆、宗教或族群概括为单一材质、工艺或“原始/粗糙”风格。
- 同体系保持家族相似性，不要求所有道具同剪影、同材质或同徽记数量。相似性与单件识别度的通用方法调用项目已有世界观/阵营和轮廓参考。

## 3. 按品类选择需要查的内容

本表是核查问题，不提供未经验证的历史答案。基础比例、可动结构、材质等继续使用项目原有专项；涉及严格年代或文化归属时，需要具体资料。

| 品类 | 影响外观的重点 | 需避免的自动推断 |
|---|---|---|
| 剑、刀、斧、锤、矛、戟 | 用途与握持、刃/打击端、护手和柄、连接、鞘或携带关系 | 从名称推固定朝代、固定护手或单/双手使用；从地区推直/弯刃 |
| 弓与弩 | 弓体/发射结构、弦、握持、装箭方式、箭与携行配套 | 混用按材料、弧形或机构定义的分类；把近似译名当成不同品类 |
| 盔甲与盾 | 防护区域、活动关系、分片/连接、握持/系带、内衬、携带和标识 | 所有盾必须有纹章或金属包边；所有盔甲都符合一条线性时代演变 |
| 现代/幻想火器 | 时代与用途的外观证据、持握和携带、相关可见功能件 | 所有枪都必须有同一种弹匣或配件；从影视案例证明真实年代 |
| 职业工具 | 完成哪种工作、操作端/持握端、工具组合、收纳和维护 | 医生、侦探或工匠都只使用一套固定符号化工具；用错误角色归类证明职业 |
| 日常用品 | 时代/地区相关形制、材质、容量/操作、制作和保养痕迹 | 旧时代物品必须破旧；所有生活物件都要磨损或装饰 |
| 交通工具与载具内部 | 用户范围、内外设计对应、关键操作/承载区域、时代线索 | 默认纳入道具表、扩建整套场景，或仅靠几个按钮定义未来科技 |

盔甲、家具、坐骑和载具先沿用项目资产分类。归角色、场景或独立资产时，只提必要的交互/接口要求，不自动改类或增加正式 ID。

现代火器专项仅用于视觉外观与叙事使用关系，不由此扩展为可制造的武器机构、实用改装或性能方案。

## 4. 参考使用与可见表达（P2—P3）

- 选一件原物或一组可靠同类作结构依据时，记录具体对象、时期/地域、出处、借鉴部位与改动；仅有风格图片时只声明风格职责。
- 同一道具可有不同职责的参考，不能默认一张图同时证明年代、尺寸、材质与结构。图片中不可见的背面和内衬仍需补全。
- 只把与当前道具相关的时代文化选择转成提示词中的可见描述，例如连接方式、鞘体轮廓、装饰分布或加工痕迹；“某朝风格”不能代替这些描述。
- 尺寸区分资料测量值、设计建议与角色尺度。未经验证的单张透视图不作为精确测量证据，资料中的常见尺寸不当作所有品类的唯一标准。
- 磨损按使用、保存和剧情状态设计；新制、礼仪、精心保养或特殊材质物件可以没有明显磨损。
- 真实文字、纹章或宗教符号使用其已确认内容和用途；需要虚构时明确为虚构，不以混合符号伪称真实文化依据。

## 5. 按已选模式审核（P4—P5）

- 历史还原：分开记录图像是否符合已选方向、相关史实是否已核实。图片好看或用户选中，不能把待核实记录改成已核实。
- 历史启发：检查选定借鉴点、改动和功能是否按方案呈现，不用未经选择的复原要求返工。
- 自创/混合体系：检查内部装备语言、角色交互和已确认例外是否一致，不把现实时代惯例当成世界观硬限制。
- 派生视角保持本件已锁定的形制、连接、材质和标识；状态变化不自动更换文化体系。明确的改装或变形按相应版本/状态规则处理。
- 发现资料疑点时只标记受影响判断，必要时暂缓依赖该点的定稿；其他道具与不依赖该点的探索可继续。

严格考据缺资料时，最小下一输入是能支持当前判断的具体原物图、出处或用户取舍，不要求用户一次补齐整部武器史。

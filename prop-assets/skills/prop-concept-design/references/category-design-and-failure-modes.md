# 分品类设计要点与常见失败

整理自用户道具设计知识库的《04-分品类设计专项》六篇（近战冷兵器、枪械火器、容器与随身装备、防具与盾牌、远程冷兵器、光源道具）。

`workflow.md` 的 P1 品类路由只给到"优先部件、轮廓、握持关系"这一层。本文件补的是更高频、更具体的层次：每个品类的核心识别锚点、必有的结构，以及出图时最常崩的地方。

这些是设计启发与失败模式清单，不是历史形制或工程标准。写词和审核时按当前品类取用，不需要全部齐备。

**Codex 适用边界**：“必有结构”仅用于本件适用的识别与交互检查，不自动添配件或否决剧情、文化形制和用户已确认的例外；画面不可见的结构标为待核对，不声称已验证内部机构。局部专项不扩大授权改动区域。

## 通用用法

1. **P2 方案比较时**：用"核心识别锚点"检查方案有没有丢掉品类可读性。
2. **P3 写词时**：把"必有结构"写进 Prompt，把"常见失败"写进负面提示。
3. **P4 审核时**：按品类的失败清单逐条过——这一层比"部件是否完整"更具体，能直接定位问题。

## 近战冷兵器

**三段式**：握持端—护手/格挡端—工作端。不是所有兵器都要配齐护手，但握持与工作端是必需的。

**核心识别锚点**：剑需要清晰的刃部轮廓与护手结构；锤/斧需要工作端显著大于柄部；杖需要长杆+顶端的两段式。

**常见失败**：
- 护手过小，起不到格挡作用
- 柄过细或过粗，握不住
- 锤头与柄的连接处没有加固，看起来一敲就断
- 在刃口做凸起雕刻（影响切割）
- 刀身弯曲、重心失衡

## 枪械火器

**三段式**：枪管组件—机匣主体—握持供弹组件。

**核心识别锚点**：枪管与握把同时存在；长枪械需有枪托与弹匣。

**常见失败**：
- 枪管弯曲、瞄准具错位
- 扳机位置手指够不到
- 弹匣角度不对，供弹逻辑不通
- 附件遮挡瞄准视线
- 中世纪世界观出现现代枪械结构（科技树错位）

## 容器与随身装备

**核心结构**：主体腔体—开合密封结构—便携结构。

**核心识别锚点**：必须有清晰的盖身分割，不能是实心块；液体容器必须有密封结构。

**常见失败**：
- 只有闭合外观，没有合页、锁扣，不知道怎么开
- 内部容量远小于外观，壁厚不合理
- 提手位置偏心，提起后倾斜
- 液体容器没有密封结构，一拿就洒
- 背包背带过细，不符合承重逻辑

## 防具与盾牌

防具是"被动承受"，设计重心与武器完全不同：**第一问题是它保护哪里、怎么不碍事，装饰是第三位。**

**核心结构**：
- 防具：防护分区 + **关节活动空间** + 系带固定结构
- 盾牌：盾面—盾心（正面凸起）—握把/臂带—包边—**背面结构**

**覆盖率与身份**：全身覆甲、甲片致密 → 重装正规军；覆盖核心区四肢灵活 → 常规兵；只护要害大量裸露 → 斥候游侠。覆盖率是比"厚重""华丽"更有效的风格控制词。

**常见失败**：
- 画成贴在身上的装饰板，没有厚度与分片
- 护甲贴合身体曲线，像紧身衣而不是包裹结构
- 全封闭头盔没有观察孔，眼睛被蒙住
- 盾牌只有正面图案，背面是空白
- 板甲接缝没有活动余量，抬手穿模
- 装饰繁复到无法实战，却标为正规军装备

**写词示例**：`肩甲为分段叠片结构，肘部留有弧形的活动间隙，胸甲由两侧皮革绑带收束，背部有金属搭扣`

## 远程冷兵器（弓·弩·箭袋）

**弓**：弓臂—弓弦—握把。弓臂中段粗、两端渐细，必须是连续弹性结构。

**弩**：横向弩臂 × 纵向弩身，两者**垂直**——这是弩区别于弓的核心识别特征；后部有弩机与扳机。

**箭袋**：必须**露出箭羽**，否则看起来像水壶。

**长弓 vs 反曲弓**：唯一区分点是反曲弓弓臂的 **S 形弯曲**与两端回勾。

**常见失败**（按严重程度）：
1. **弓弦缺失、或画成粗绳**——最高频、最致命的错误。弦必须是**一条细而绷直的直线**，从一端弓梢拉到另一端
2. 弓臂均匀粗细，没有中段加粗
3. 反曲弓不反曲，和长弓没有区别
4. 弩臂画成弓的大弧，失去横向结构特征
5. 弩没有弩机，像"带托的弓"
6. 箭袋没有露出的箭羽

**写词示例**：`一条细而绷直的弓弦连接两端弓梢`——这一句必须单独写，不能省略。

## 光源道具（灯笼·火把·提灯）

**双重身份**：既是道具又是光源。光的来源必须可见、可解释。

**必备结构**：发光体被结构包覆（火焰在灯罩内、灯泡在罩内、光核在框架内）+ 通风/散热/供电结构 + 提梁/挂环 + 底座。

**火把**：握柄足够长（火焰与手有安全距离）、燃烧头明显粗大、**燃烧头焦黑炭化而下部干净**。

**灯笼**：顶部提梁 + 骨架形成的格栅 + 透光罩（纸/纱/玻璃）+ 底座。

**常见失败**：
- 整个灯笼骨架都在发光，光没有来源
- 灯笼没有提梁，不知道怎么拿
- 火把握柄短，火焰烧手
- 只在光源本身加特效，周围环境全黑
- 燃烧头与握柄的痕迹一样重，没有冷热分区
- 奇幻光源没有任何承载结构，纯粹悬空

**光的三层结构**（写词要点）：核心层（过曝）→ 过渡层（光晕、散射）→ **投射层**（墙面光斑、人物受光）。第三层最常被漏掉，导致"灯笼很亮但周围是黑的"。

**写词示例**：`方形木骨架纸灯笼，顶部圆形提梁，暖黄色灯光从纸面透出，骨架形成清晰的格栅阴影，灯光在周围暗色墙面形成一圈柔和光晕`

## 品类失败清单的用法边界

这些是高频错误，不是每个方案必然出现。审核时若发现问题，说明它违反了可见的结构或设计逻辑，不说"所有弓都必须有弦那样的写法"，也不把某一件的失败推广成品类规则。

品类锚点用于保证可读性，不限制差异化创新——但差异不应破坏核心功能与识别。

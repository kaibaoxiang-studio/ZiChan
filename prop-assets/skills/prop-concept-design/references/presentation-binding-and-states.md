# 呈现、绑定与状态推进

整理自用户道具设计知识库的《视角透视与图面规范》《道具与角色绑定：挂载收纳与手持》《道具状态矩阵》《道具出场时序与状态推进》，以及《剧本道具信息补全规范》的三档权限部分。

本文件补三处流程空白：写词时的视角与焦段、挂载与收纳的统一描述、状态从"有哪些"到"按什么顺序推"。

**Codex 适用边界**：以下尺度、焦段、配套件、状态弧线与镜头规则是按需设计参考，不是工程验证或改写剧本的授权。正交图不套透视焦段；不强制所有武器配鞘、所有核心道具走完整损耗弧线，也不自动新增镜头或正式资产。A/B/C 补全权限仅在当前用户范围内成立，补全仍标为提案并遵守主流程的用户确认与锁定条件；叙事明确的跳变、常亮、缺席或配套例外优先于通用建议。

## 一、视角与焦段

### 正交图与呈现图是两件事

- **正交投影**：无透视，用于精确传递尺寸（三视图）
- **呈现图**：有透视，用于传递设计与气质（主视觉、概念图）

常见错误：用透视图画三视图（侧面永远量不准），或用正交图当主视觉（像工程图纸）。

### 焦段决定道具读起来多长

这是"同一件道具每次出图长短不一"最常被忽略的成因。

| 焦段 | 效果 | 适合 |
|---|---|---|
| 广角（<35mm） | 近大远小夸张；长条物被拉长，圆形物变形 | 戏剧性、空间压迫感 |
| 中焦（50—85mm） | 接近人眼，形变小 | **产品图、参考图、设定图** |
| 长焦（>135mm） | 压缩纵深，显得更平更紧凑 | 剪影展示、排版干净 |

具体影响：广角会拉长剑的刃部、让护手显小、放大锤头、让瓶身鼓胀。

**规则：要忠实呈现比例必须用中长焦；广角只用于有戏剧张力的镜头。**

写词：设定图 `中焦镜头（约 85mm），透视克制，比例忠实`；场景图 `广角镜头（约 24mm），轻微透视变形，空间纵深强`。避免只写"透视感强"——模型会给一个过度的广角，比例全乱。

### 视角高度的叙事作用

眼平=客观中性；略仰=威压重要；大仰角=宏大神圣；略俯=客观可观察；大俯角=渺小被遗弃。

同一个设计在"验货"场景用眼平、在"英雄登场"用仰拍，是同一个道具讲两个故事。

### 视角词库

| 需求 | 写法 |
|---|---|
| 主视觉 | `四分之三视角，俯视约 15 度，中焦，纯白背景` |
| 结构展示 | `正视图，平视，正交投影风格，无透视变形` |
| 侧面 | `正侧视图，平视，正交投影风格` |
| 戏剧性 | `低角度仰拍，广角镜头，轻微透视拉伸` |
| 参考图 | `中焦 85mm，四分之三视角，纯白背景，画面留有标注空间` |
| 转面图 | `正面、侧面、背面、四分之三视角横向排列，等高齐平` |

视角词放在提示词最末尾，作为独立短句；太靠前会被材质/风格词盖过。

### 参考图版式必备要素

主体占 60—75% 并留白、比例参考尺（或手部/人形剪影）、色卡条（主色/辅助色/点缀色）、方向指示、纯色或中性灰背景。信息区集中在边缘，不占用主体空间。

## 二、挂载、收纳与手持

道具大部分时间不在手上。分镜里出现最多的状态是"挂载"。

### 道具的四种存在状态

手持 / 挂载 / 收纳 / 陈设或遗落。一件重要道具通常要设计四个状态，不只是一个"拿着它的样子"。

### 挂载点与尺寸上限

| 挂载点 | 适合 | 尺寸上限 | 取用 |
|---|---|---|---|
| 左腰 | 主武器鞘、长刀 | 全长 ≤100cm（鞘底不拖地） | 快（右手交叉拔） |
| 右腰 | 短武器、小刀、水壶 | ≤40cm | 快 |
| 后腰 | 备用、隐藏武器 | ≤40cm | 中（反手） |
| 后背斜挂 | 长剑、双手剑、斧 | ≤150cm | 慢（过肩） |
| 后背竖挂 | 法杖、长枪、箭袋 | ≤180cm | 中 |
| 胸前/肩带 | 小包、药瓶 | ≤手掌大 | 快 |
| 腿侧 | 匕首 | ≤30cm | 快 |

这些是视觉合理性的参考区间，不是人体工学验证。

### 朝向决定能不能拔出来

长剑左腰：**柄朝右前、鞘尖朝左后**；双手剑后背：**柄从右肩后探出**；匕首腿侧：柄朝上。
反面：剑挂腰间但柄朝后——拔不出来。

### 收纳结构

鞘必须有**拔出间隙**和鞘口锁扣；挂环通常在鞘口下方约 1/5 处；鞘口是磨损最重处。
枪套/刀套必须露出手柄或设计快开结构。

### 握持时的遮挡关系

被手挡住的部分不需要做太多细节。单手握着时握柄中段被遮挡，护手、刃身、柄尾才是细节重点。

### 体型适配

握柄直径**不能只按身高等比缩放**——身高 1.5 倍的人，手掌长度往往只有 1.3 倍。

写词：`由约 2 米高的巨人族使用，握柄相应加粗，全长约 1.2 米`；`由 1.3 米的矮人族使用，整体缩小约 30%，但握柄直径只缩小 15%`。

## 三、状态：从矩阵到弧线

`workflow.md` 的 P5 要求"状态须有剧情或用户依据"。本文件补两个执行层：一个道具可能有哪些状态、这些状态按什么顺序推。

### 状态矩阵

把"功能状态 × 损耗状态"交叉，✔ 的格子就是需要出图的清单。

功能状态：收纳 / 待机 / 使用中 / 关闭 / 打开。
损耗状态：全新 / 正常使用 / 破损 / 残骸。
特殊状态：激活 / 熄灭 / 沾附 / 改装 / 遗弃。

**关键认知**：传统概念稿只画"完好待机"，但道具在实际作品里出现最多的往往是挂载、使用中、受损。设计时先填矩阵，再决定每种状态要不要出图。

状态数量按重要度裁剪，不要求每件都做全矩阵。

### 状态弧线

重要道具有自己的轨迹，四个要素：**起点**（登场状态）、**转折点**（状态变化的时刻）、**终点**（结尾状态）、**缺席段**（离开画面/视线的时间）。

优先级：主角核心道具必须有完整弧线；重要的配角标志性道具至少一个转折点；一般功能道具只有起止；环境道具无弧线。

### 五种推进事件

1. **取出**（收纳→待机）：拔剑、掏出、开箱。镜头价值高，是道具第一次露脸
2. **使用**（待机→使用中）：挥砍、开火、点燃
3. **受创**（完好→破损）：被砍中、摔落。**价值极高，最有叙事**
4. **损毁**（破损→残骸）：彻底断裂、爆裂。往往伴随情绪高潮
5. **转手**（状态不变，归属改变）：赠予、抢夺、继承

另有清洗/修补、遗落/藏匿两种特殊事件。

### 四条排布规则

1. **一次变化至少一个镜头**——变了但没给镜头，观众不知道
2. **变化前给一次基线镜头**——否则观众没见过它完好的样子，后面变化无从对比
3. **变化的镜头要够近**——远景看不清，转折时刻必须降到近景/特写
4. **递进不是跳跃**——从全新到残骸一次完成会突兀

### 六种高频时序错误

- **消失的鞘**：拔剑后鞘去向不明
- **自动愈合的痕迹**：上一镜沾血破损，下一镜恢复如初
- **无来源的崭新**：一路磨损但观众没见过它新的样子
- **过早的破损**：没到高潮就坏了，高潮无牌可打
- **无意义的改变**：每次出镜都改细节，像好几件道具
- **状态没有结算**：结局没有交代道具的去向

### 每个状态写一份锚点词组变体

锚点部分逐字不变，只替换状态描述。用可见描述，不用故事描述：

- ✅ `刃身靠近护手处有一处崩口，崩口边缘露出未氧化的新钢`
- ❌ `这把剑曾经斩杀过敌人，留有战痕`（模型读不懂"曾经"，只画一把旧剑）

## 四、信息补全的三档权限

这一部分与 [主流程](../SKILL.md) 的来源原则配合使用：来源原则规定"不把补全伪装成剧本事实"，本表规定**补到什么程度**。

| 档位 | 判据 | 内容 | 动作 |
|---|---|---|---|
| **A 直接补** | 有唯一合理答案，或任一答案都不影响剧情 | 尺寸、材质（功能约束内）、结构、磨损形态、挂载位置与朝向、握持方式、配套件（鞘/套）、状态清单 | 直接定，标"设计补全" |
| **B 推断并标依据** | 需要选择，但选项被剧本事实约束 | 阵营风格的具体落法、装饰层级、使用年限、使用者性格的体现 | 给方案，写明依据剧本哪一句 |
| **C 只提醒** | 剧本没给前提 | 象征意义、为什么是它、谁给的、何时破损、是不是伏笔 | 不填内容，列"待确认"并说明缺什么会影响什么 |

**口诀**：唯一的或无关紧要的 → A；需要选但剧本能约束 → B；没有前提的 → C。

### 四种最常见缺失

1. 有名字没样子（"他拔出宝剑"）→ A 档全套补
2. 有功能没结构（"打开机关盒"）→ 结构是 A；里面是什么是 C
3. 有出场没状态（全篇只有一种样子）→ 损耗节拍可推断（A），破损对应哪个剧情点是 C
4. **有一件没配套**（只写剑，没写鞘和挂哪）→ A 档，最容易被忘

### A 档缺省顺序

尺寸 → 先查品类标准区间，再按体型与身份修正
材质 → 功能优先，主体默认按品类，材质总数默认不超过三种
损耗 → 未提示则"正常使用级"
装饰 → 默认一处，位于视觉焦点区；配角默认无装饰
配套 → 武器默认配鞘 + 挂带
颜色 → 阵营色系 → 材质固有色 → 点缀色克制

### 越权的典型表现

- 替角色赋予情感：剧本"他放下刀"→ ❌"刀柄缠着亡妻的发丝"
- 替剧情埋设伏笔：剧本"桌上有一把钥匙"→ ❌"柄上刻着与第12场宝箱相同的符号"
- 改变叙事地位：剧本"守卫的长矛"→ ❌"传世神兵"
- 自行解决剧本矛盾：自行补"后来又找回来了"

### 叙事道具识别

读到以下信号，把该道具标为"叙事道具"，外观**不做任何 A 档自由补全**：
被反复提及、有特写描写、与情感动作绑定（抚摸/擦拭/攥紧/摔碎）、有专属来历、在关键转折前后出现、被赠予抢夺丢失找回、与另一道具成对。

理由是：外观本身可能就是叙事的一部分。只补最必要的结构信息，其余标"待确认"。

**麦高芬的悖论**：要足够吸引人去争抢，又不能特殊到一眼看出是关键道具。这个平衡只有编剧能定，助手只负责按约定做外观。

## 使用边界

视角、焦段、挂载、状态这些都是视觉设计建议，不声称已验证人体工学、机械强度或镜头实际效果。状态推进涉及剧情时，只按剧本已有依据排布；剧本没写的转折点只能作为提案。

# 批量道具 Prompt 表

用于“剧本／资产道具表 → 道具 Prompt 表”的整表交付。输出是包含视觉设计的完整出图词，不是只把道具名称和原描述搬到新表。

## 1. 三种输入都能开始

| 输入 | 如何确定范围 | 来源边界 |
|---|---|---|
| 剧本＋资产表 | 默认以表内道具为范围，对照剧本补用途、动作与明确外观 | 保留原ID；表外发现单列候补；冲突不自动裁决 |
| 只有道具资产表 | 按指定道具工作表、栏目或条目生成 | 保留原ID；剧情未提供就不编造集场、动作或经历 |
| 只有剧本 | 在用户指定文本范围提取画面中实际需要的道具，建立工作清单 | 无原ID时用明确标注的工作编号；纯台词提及与身份疑点分开，不冒充正式资产清单 |

读取真实文件结构，不要求用户先转换固定格式。记录已处理范围；未读完的剧本不能声称覆盖整剧。只有表时不强求补剧本，只有剧本时不强求补表；未提供道具图不构成阻碍。

已有图片、用户明确要求与选定方案可直接作为约束。统一视觉风格优先采用用户描述或参考；若未知且不阻碍提案，选一个与已知世界观相容的暂定表达并在表前说明，不把它当成已确认全剧风格。

## 2. 直接把必要设计写进整表

1. 确定工作清单，保留原ID、名称、状态及父子关系；重复出现不重复造新资产，同名或别名身份不清时列疑点，不静默合并。
2. 从已有来源提炼用途、交互与明确外观。把材料、颜色、结构等未写明内容作为设计补全，不把补全伪装成剧本事实。
3. 按 [P2 轻量设计定向](workflow.md#p2-概念方向) 给每件道具形成设计。先根据剧本可定位的实际画面出场统计排序：频率最高的前十个基础道具各形成三套有实质区别的候选方向，交给用户选择；其余道具形成一套推荐方向，直接写入完整 Prompt。三案差异应落在轮廓、比例、关键结构或造型语言，不得只改颜色、纹样或光效。先想清识别线索、结构/工艺重点和适用的项目共同语言，再写词；结论汇入设计说明，不增加必填列。尺寸与参照的来源边界见下文。

   出场频率默认按剧本可定位的最小稳定叙事单元（通常为场次；若有可靠拍次信息则用拍次）统计资产在实际画面中出现的单元数。同一资产同一单元内重复出现不重复计数；跨单元持续出现分别计数。台词提及和仅由连续性推测的延续单独记录，不与画面出现混算。资产表顺序不等于频率排名。剧本未完整读取、场次边界不明或出现次数无法可靠核对时，必须标“频率待核”，不得声称已确定前十；可按用户指定名单或暂定推荐深度继续，并说明依据。若第十名处出现并列，先展示并列范围，再用公开、可解释的辅助规则裁决名额（如交互/连续性复杂度、剧情转折承载度或用户优先级），明确辅助规则不属于频次事实，并记录未入选的并列项。低频道具因剧情关键、交互复杂或用户明确优先级需要三案时，也记录为例外。
4. 在同一项目风格下，按下文固定结构写逐行完整提示词。普通道具可简洁，关键道具可深化，不强制每件豪华装饰、做旧、发光或全部专项齐备。
5. 检查清单覆盖、身份与状态关系、明确约束、设计互相兼容和提示词可复制性，再交付表格。

要求整表意味着可以把未确认设计提案写成具体出图词，不意味着提案已经定稿。三案资产在用户选择前只交候选方向，不把任一案写成已确认主视觉；一案资产可将推荐提案直接写成完整 Prompt，但状态仍为“设计未确认”。关键身份、功能或明确外观冲突只阻碍相关条目：保留该行、注明原因，必要时暂空其完整Prompt，不用相互矛盾的词凑齐全表；其他条目继续。

## 3. 表格约定

默认字段如下，可适配团队已有模板，不要求用户补填这些列：

| 字段 | 内容 |
|---|---|
| 道具ID／工作编号 | 保留原ID；自行工作编号明确标注，不改号 |
| 道具名称 | 沿用来源名，有别名另注 |
| 状态／图类型 | 常态三视图＋一个小幅局部特写＋白模尺度参照及关键尺寸（同一张资产图），或用户另行指定的图类型；与同一基础道具关联 |
| 剧情用途／使用者 | 仅写来源支持的信息，未知写未提供 |
| 设计说明 | 简述轮廓、结构、材质、配色与必要纹样，写明关键尺寸、单位、来源或建议属性及白模参照方式；重点道具说明识别线索、结构/工艺重点与项目语言，普通道具可说明采用简洁形制的理由；分开写明确要求和本次设计补全 |
| 设计深度／频率依据 | 标记“三案候选·待用户选择”或“一案推荐·可进入Prompt”；记录剧本出场统计范围、计数口径或“频率待核”，以及低频例外理由 |
| 完整Prompt | 每行一段可直接复制的完整出图词，包含共同风格与该行关键限制 |
| 保持／排除项 | 便于审核的摘要；执行所需关键限制同时写入完整Prompt |
| 来源／疑点 | 可定位的表行或集场，关键冲突与未定假设；不编造页码 |
| 交付状态 | 如“Prompt已完成·设计未确认”“已有方向·待出图”“待澄清”；不写已生图或资产定稿 |

默认每个基础道具对应一行常态三视图资产图Prompt，正面、侧面、背面、一个小幅局部特写、白模尺度参照及关键尺寸合在同一图中，不因展示分区另造资产或状态ID。上游明确列出的状态也应有可追踪行；基础造型未锁图时，可写继承同一文字方案的状态草案，并标注“待主视觉锁定后核对”，不能冒充图像一致性已验证。用户只要常态表时，其他状态列为未纳入本次范围。

一行只表达一个图目标；同一常态的三个观察方向、特写和白模尺度参照属于同一目标，不把常态、破损、启动、开合混在不同视图中。白模持握或佩戴只解释尺寸与接触关系，不添加剧情表演、真实角色、新状态、更多视角或模型参数；软质物件因接触产生的必要形变只在尺度区表达，不改变基础结构。

完整Prompt按目标描述道具身份、可见造型与结构、关键尺寸与白模参照、材质和固有色、必要纹样与表面特征、统一风格和展示条件。默认中文，不强制双语；不得只写“同上”“按该行设计说明”“参考所有图片”。有图时点明实际参考及用途，无图时不假定必须上传一张不存在的道具图。

### 固定结构提示词

道具资产图统一使用“专业影视道具资产设定板（Prop Sheet）”作为交付目标。每行Prompt先使用以下固定正文，仅替换道具名称：

```text
生成一张专业影视道具资产设定板（Prop Sheet），采用统一网格分区排版，白色或浅灰色背景。上方主体区从左到右展示【道具名称】的正面、侧面、背面，主体区明显大于下方辅助区；下方分为一个小幅局部细节特写区和一个白模尺度参照区，特写不独占整行、不压过主体。三个视图采用相同单位比例，整体造型、颜色、材质、比例和关键结构保持一致。尺度区使用与本件道具相适配的哑光中性白模作大小对照，道具保留自身颜色与材质。用简洁尺寸线或图注标明本件关键尺寸及单位，建议值明确标注“建议尺寸／待确认”。各分区清晰、留白整齐，主体完整、互不遮挡，仅保留必要的视图标签与尺寸信息，无额外装饰性文字或水印。
```

随后按以下顺序补全，并合成一个可直接复制的完整单元格；不让用户自行拼接固定前缀和设计字段：

```text
道具设计：【明确本件的轮廓、部件、相对比例、材质、固有色、纹样及本次状态。】
尺寸与尺度参照：【写明本件关键数值、单位和测量对象／状态，注明来源或“建议尺寸／待确认”；指定白模手握持、手指佩戴、头模佩戴或人体站立对照等一种适用方式，写清接触位置与相对大小。】
局部细节特写：【只指定一个部位，以及该部位需要看清的材质或结构。】
视觉风格：【沿用本项目的已确认风格；未知时使用明确标注的暂定提案。】
视图与一致性：【按本件形态明确正面、侧面、背面的观察方向，以及部件数量、位置和当前状态等保持项。】三视图采用相同单位比例，不为填满分区强行缩放成相同宽高；特写只放大对应部位，不改变设计。白模尺度区与主视图保持同一道具设计及尺寸关系，白模无肤色、彩绘或首饰，不把道具本身变成白模。柔和均匀照明，主视图区不出现人物或手；仅尺度区允许白模参照，无真实人物或肤色手，无叙事场景。【补充该道具的必要排除项，不重复或抵触固定正文的布局要求。】
```

- 设定板用于表达剧情中的具体资产，包括有来源的幻想材质、微光道具或生物资产；不要求改成写实金属、可制造物件或取消已知魔法表现，生物不画成道具模型或雕像。
- 三视图为资产展示规范，不自动承诺精确工程正交、制造尺寸或三维结构验证；“设定板”不等于已具备制作参数的“规格板”。相同单位比例不是相同外接框宽高。背面与内部未由来源给出时，补全仍是未确认提案。
- 仅保留必要视图标签、关键尺寸及其建议属性，不添加装饰性文字；不因此删除道具本体已有的标记或用户确认的正文。尺寸数字、单位、对应部位与建议标签须和表内方案核对；图像生成不能保证字形和数值正确，必要时另行排字并在交付前校核，不把待排字版本记为尺寸标注已完成。道具正文只沿用已确认文本，不自行编写内容。
- 柔性道具（鞭、链等）在三视图中保持同一摆放形态和部件数量，改变观察方向，不重新盘绕；薄片文件保持页数、叠放关系，侧面展示纸层厚度，背面不新增无依据正文。
- 项目内沿用同一背景、排版和风格。固定的是展示结构，具体造型与特写部位按道具填写；不强制所有道具共用一种材质、颜色、纹样或效果。
- 用户单独要求一张单体主视觉、某个状态或修图时，目标覆盖本默认模板；不强行加三视图。模板中的“生成”是交给外部出图工具的指令，交付Prompt不等于授权自动生图。

### 尺寸与白模参照

- 沿用剧本、资产表或用户明确提供的尺寸，记录出处；来源冲突不静默取值。未提供时，依据用途提出关键数值并标“建议尺寸／待确认”，同步写入设计说明和完整Prompt，不伪称剧本事实或人体标准。确实不足以提出合理值时，列明缺口，不编数值凑齐。
- 只选影响识别和交互的尺寸，例如长／宽／高、直径或戒指内径，不扩展成制造参数表。柔性鞭链区分展开总长和当前摆放外接尺寸；粉末等无固定外形的物质以明确的展示容器或承载范围说明尺度，新增载体仍须标设计补全，不虚构重量或容量。
- 小型握持物用白模手，戒指用白模手指，发簪、眼罩等佩戴物用适用的白模头部，大型资产用白模人体站立对照；按需选择，不要求一件道具同时配齐多种模型。已知角色体型或手型则遵循；未知时白模比例是设计假设，不伪称通用标准或人体工学验证。
- 白模只提供直观尺度，不能替代关键数值；关键数值也不能证明图像具备测量精度。三视图共享单位比例，特写和尺度区可为阅读单独缩放，但尺度区内道具与白模的相对关系必须一致，不把两者分别缩放来填格。
- 默认上方三视图为主体，下方小特写与尺度参照为辅；不设所有品类通用的硬性百分比。可按长短、厚薄调整格宽与留白，但不能为填版把特写放成另一幅主视觉，也不照搬参考图中的多状态栏目。

## 4. 交付与结束

默认在回复中给可读表；用户指定文件格式时导出新文件。长表可分批写入同一输出表，并报告总清单、本次完成、待澄清与尚未处理条目；用户授权整表时，不因每批结束再次索要相同授权。

交付前逐条对账：范围内每件道具是已写词、待澄清还是未纳入；检查遗漏、重复、状态混写和原ID不对应的问题。默认道具资产图的完整Prompt必须包含固定正文、三个方向、一个明确的小幅特写部位、关键尺寸与单位及其来源／建议属性、适用的白模尺度参照和同图一致性要求；尺寸无法确定等例外须显式说明。检查主次布局及表、词中的尺寸一致，不残留禁止一切手模或尺寸标注的冲突约束。不要用“已完成”掩盖未处理条目。

另外检查设计说明中的关键形态决策是否已写进完整 Prompt，特写是否对应同一设计重点。格式齐全不能代替设计判断；对辨识度和审美的评价说明理由，未出图时不声称视觉效果已通过。

交付表格后即完成本轮提示词任务；可说明后续由团队出图回流，但不强制先提供单件图片，不自动生图、锁定设计或启动所有派生任务。

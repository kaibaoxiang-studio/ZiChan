# 神话与魔法道具专项

适用于传说武器、神器、符咒、活体/生物道具，以及同一道具的能力启动或变形。先保留道具的基础品类，再叠加特殊能力；普通器具不因进入本专项就自动发光、古老或拥有传说。

来源：用户提供的《神话武器与魔法道具知识库.zip》。本文件是设计启发的整理，不是神话原典或作品设定考据。第 1、2、4 节提炼原资料；第 3、5 节为使流程可执行而补充的方法。章节对应和待核实项见 [知识来源、证据与待补项](knowledge-sources.md)。

## 1. 按当前问题调用

| 当前问题 | 本专项的作用 | 使用节点 |
|---|---|---|
| 它属于何种道具，承担什么剧情功能 | 区分武器、圣物、文字载体、活体等；明确承载与操作关系 | P1 |
| 如何形成特殊身份，而非普通物件加光效 | 选择轮廓、关键部件、材质或叙事线索上的区别 | P2 |
| 能力怎样变成可见描述 | 写明局部变化、范围、效果与保持项 | P3 |
| 回流是否符合已确认设计 | 对照选定方向，不按“够不够神圣/邪恶”强制返工 | P4 |
| 启动、破损或变形后是否仍是同一道具 | 核对状态依据、部件对应和身份连续性 | P5 |

材质、剪影、配色、磨损与符号的通用方法仍调用项目已有基础参考；本专项只补充特殊能力和叙事品类的判断，不重复定义全部审美规则。

## 2. 品类设计入口

| 品类 | 优先确定 | 可探索的表达 | 不默认要求 |
|---|---|---|---|
| 圣剑、魔剑与其他传说武器 | 基础攻击/握持关系、归属、区别于制式装备的特征 | 特殊护手、刃部形态、材质分区、铭记或受损线索 | 圣剑必为金银且对称；魔剑必黑紫、尖刺或不对称 |
| 弓、枪与长柄武器 | 拉弓/装箭或握持/刺击关系；箭、枪尖是否为独立效果 | 张力、末端焦点、能力沿结构传播的线索 | 必须超长、超大、多尖或始终发光 |
| 巨型武器 | 与角色的尺度、持握/携带和使用方式 | 夸张比例、支撑关系、重量或特殊驱动力的视觉线索 | 使用者必须壮、动作必须迟缓或外观必须粗糙 |
| 法杖、魔杖与权杖 | 施法或仪式用途、操作位置、视觉焦点 | 顶端核心、杆身纹路、握持区、材质对比 | 必须有宝石、固定长度、发光或某种属性配色 |
| 圣物与神器 | 戒指、镜、书、器官等基础载体；佩戴、持有或使用关系 | 身份符号、封印、容纳结构、传承与争夺的可见线索 | 必须小、贵重、精致、古老或不是武器 |
| 符咒、卷轴与魔法书 | 载体、展开/贴附方式、是否需可读内容 | 已确认文字、虚构符号、版式、折痕、印记 | 字必须看不懂、纸必须旧、卷轴必须用羊皮纸 |
| 有生命道具 | 自主性、行为、与操作者的关系；表现生命的必要线索 | 局部运动、声音对应动作、表面响应、器官或非拟人表达 | 必须有脸/眼睛、生物材质或诡异气质 |
| 生物武器 | 与宿主的连接、组织分区、是否可脱离 | 生长方向、有机结构、甲壳或组织纹理 | 必须湿滑、恐怖、没有金属或不能精致 |
| 变形/组合道具 | 形态用途、对应部件、转换机制与不变量 | 接口、关节、收纳关系；魔法重构时保留身份线索 | 所有变形都必须有机械关节；每个形态必须同剪影 |

这些是探索入口，不是从品类名推导剧情事实。例如“圣物”不自动意味着被争夺，“活体”不自动意味着会说话。

## 3. 能力与状态补充

这是流程方法补充。先提取剧本、表和用户已有设定，仅对当前设计需要的信息使用以下字段；缺失的世界观内容保留未知或提出可选方案，不为了填表编造能力。

```text
能力/用途：已知效果；来源位置或明确标注为设计提案
触发与操作者：动作、条件、权限；不明确则保留待确认
作用对象/范围：只记录来源明确或当前画面表达必需的部分
限制/代价：已有设定；未规定时不自动添加诅咒、耗能或伤害
必要状态：状态名称、进入/退出依据、剧情或用户是否需要展示
视觉变化：变化部位、形态/材质/光效及其范围
身份保持：跨状态不变的部件、比例、标识或其他识别线索
未决项：哪些只影响局部出图，哪些会改变能力或道具身份
```

状态可包括常态、启动、施用、耗尽/失效、恢复或破损，但只列有依据且实际需要的项，不要求每件神器都有完整循环。失效不等于破损，启动不等于换资产。

跨形态设计区分两种机制：机械变形需表达运动、连接和收纳关系；魔法重构按已确认规则表达形态关联，不凭物理常规否决，也不自动赋予“凭空生成”能力。

## 4. 能力、角色与叙事的视觉转译

- 先决定能力是否需要在常态暴露。隐藏身份、突然觉醒等剧情允许朴素外观；不能因为没有光效就判定缺少魔法感。
- 将能力转成具体位置和变化，例如哪一条纹路亮起、哪一部分展开、效果从哪里出现。属性颜色只是候选表达，不把火/冰/雷与固定颜色绑定。
- 本体固有色、表面响应、自发光与外部效果分开描述。它们可以形成统一或有理由的对比；效果不应无意遮住关键结构。
- 角色绑定可通过尺度、使用习惯、符号或经历体现；不要求武器与服装同色，也不从体型或性格直接限定装备类型。传承、拾获与伪装都可能造成有意义的反差。
- 来历、诅咒、传承、修补与缺损只有在来源明确时才作为事实。可以建议相应视觉线索，但不为增加故事感自动补写打造者、战绩、名字或秘密。
- 作品案例只借鉴经确认的局部特点，不让作品名称代替完整提示词，不直接复制其整套标志性造型；不能把虚构案例当成真实神话来源。

## 5. 主视觉与派生核查

本专项增加的核查只针对已确认要求；审核等级和用户定稿仍按 [分阶段工作规则](workflow.md) 执行。

- P3：注明本次表现哪个状态；提示词中写清本体、变化部位和效果层，不能只写“神圣神器”“魔法气息”。
- P4：检查特殊特征是否真的出现、是否妨碍必要交互、是否违背隐藏能力等剧情要求。不能以“特征少于三个”“不够华丽”判为阻断问题。
- P5：逐项注明基准版本、允许变化及对应部件。非变形状态不无声更换轮廓或材质；明确要求的变形则按已确认形态关系检查，不能用常态剪影误判全部变形。
- P5：复杂转换只有在剧情或下游需要时才补过渡示意，不因资料提及变形而自动生成动画、内部工程图或全部形态。
- 生物/宿主交互中，道具参考负责道具，角色参考负责角色身份与尺度；未确认连接结构先作为补全提案，不把图中看不见的部分记为已证明。

缺少魔法规则时仍可做标注假设的方向探索；依赖具体触发或形态的派生项暂留待确认，不冻结无关道具。

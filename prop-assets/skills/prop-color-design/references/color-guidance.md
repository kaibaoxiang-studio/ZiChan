# 配色层级与材质兼容

整理自用户资料《05-道具固有色与配色设计规范》。以下是经过边界调整的视觉设计启发，不是必须遵守的色彩标准，也不构成修改项目的授权。

## 色彩先有任务，再有层级

主色建立整体调性，辅助色帮助阅读已有部件关系，点缀色强调用户需要的焦点。同色或无彩方案也可完成这些任务，不必额外添加三种色相。

原资料中的主色70%以上、辅助色15—25%、点缀色5—10%、最多3—4种颜色只是构图示例。按实际区域与风格调整，不为凑比例改变分区；高饱和、大面积对比或多色设计也不应仅因不符示例而被否决。

## 候选关系

- 同色相的明度或饱和度变化：保持统一，用差异区分已有区域。
- 邻近色：让过渡连贯，仍需要检查主体与焦点是否可读。
- 对比色：突出焦点或冲突感，强弱与面积取决于用户目标，不限定只能小面积使用。
- 无彩加彩色：把注意力集中到指定区域，不等同于任何特定文明或资产等级。

避免将“更换气质”仅写成一串颜色名；解释颜色落在哪些现有部位、为什么这样分配。

## 保留材料与色彩依据

天然材料颜色与涂装颜色不是同一层。金属可以有鲜艳涂装，但当用户锁定裸金属或原有表面处理时，不能默认靠新增涂层实现任意颜色。

环境反射、阴影与已有自发光单独考虑，不把蓝色高光直接变成蓝色主体，也不把新的发光能力当成配色变化。

阵营专色、危险标识或剧情依赖的辨识色，有用户资料时才是约束；没有资料时仅为设计建议。不要推定阶层、稀有度或魔法属性必须绑定某种颜色。

## 检查与取舍

在实际用途和观看距离下比较主体、功能区与焦点是否易读。可以从明度层级检查，也可保留依赖色相的表达；不把灰度可读性当作所有风格的唯一标准。

没有图片时只能解释预期效果，不能声称视觉测试已通过。已有图像的屏幕颜色、建议HEX与最终生成色可能不同；精确颜色复现属于另行明确的要求。

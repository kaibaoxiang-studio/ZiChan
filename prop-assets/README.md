# 道具资产插件 · prop-assets

从剧本、道具资产表或两者一起，交付包含逐件设计说明和可直接复制完整提示词的道具 Prompt 表。与角色资产插件并列，独立维护；不依赖角色插件的 Harness，不自动生图，也不锁定某个图像模型。当前版本：**v0.2.0**。

## 入口与交付

| 技能 | 适用需求 | 本轮交付 |
|---|---|---|
| [prop-concept-design](skills/prop-concept-design/SKILL.md) | 剧本／道具表转 Prompt 表，或指定设计阶段 | 整表、设计方案、主视觉提示词、图片回流审核或交付索引 |
| [prop-material-design](skills/prop-material-design/SKILL.md) | 保持造型，设计或调整材质 | 部位材质与表面处理提案 |
| [prop-color-design](skills/prop-color-design/SKILL.md) | 保持造型材质，整件或局部换色 | 部位配色提案 |
| [prop-pattern-symbol-design](skills/prop-pattern-symbol-design/SKILL.md) | 指定表面的纹样、徽记或虚构符号 | 图案形态、布局与含义提案 |
| [prop-silhouette-proportion-design](skills/prop-silhouette-proportion-design/SKILL.md) | 保持用途与关键交互，调整外形 | 轮廓与比例提案 |

四个专项可脱离主流程独立使用，不要求每件道具逐个调用。文字提案不等于设计已确认；没有真实图片回流，不标记图片通过或资产定稿。主流程默认按剧本实际画面出场频率分流设计深度：频率最高前十个道具给三套候选方案供用户选择，其余给一套推荐方案。用户可选择交互式逐件模式：一次展示一件、等待用户回复、记录资产ID与选择后再进入下一件；“重做”只作用于当前件。频率按场次（或剧本可定位的稳定叙事单元）统计实际画面出现，台词提及和连续性延续另列；频率待核时明确标注，不以资产表顺序代替。

## 默认资产图格式

默认交付目标为“专业影视道具资产设定板（Prop Sheet）”。每行完整 Prompt 以以下正文开头，仅替换道具名称：

```text
生成一张专业影视道具资产设定板（Prop Sheet），采用统一网格分区排版，白色或浅灰色背景。上方主体区从左到右展示【道具名称】的正面、侧面、背面，主体区明显大于下方辅助区；下方分为一个小幅局部细节特写区和一个白模尺度参照区，特写不独占整行、不压过主体。三个视图采用相同单位比例，整体造型、颜色、材质、比例和关键结构保持一致。尺度区使用与本件道具相适配的哑光中性白模作大小对照，道具保留自身颜色与材质。用简洁尺寸线或图注标明本件关键尺寸及单位，建议值明确标注“建议尺寸／待确认”。各分区清晰、留白整齐，主体完整、互不遮挡，仅保留必要的视图标签与尺寸信息，无额外装饰性文字或水印。
```

随后补齐本件设计、关键尺寸与单位及其来源／建议属性、适用的白模参照、一个特写部位、项目风格与具体视图的一致性要求，合成一个可直接复制的单元格。白模按品类选择手、手指、头部或人体，无肤色、彩绘或首饰，只有参照模型变白；主视图区不混入人物或手。尺寸缺失时提出标注“建议尺寸／待确认”的设计值，不伪称来源事实。相同单位比例不等于将各视图强行缩放为相同宽高，白模也不能代替数值；设定板不承诺制造尺寸或工程验证。用户单独指定单视图、状态图或修图时，以该要求为准。字段与细则见 [批量 Prompt 表规则](skills/prop-concept-design/references/prompt-table.md)。

示例请求：“根据这份剧本和资产表，为前五个道具制作 Prompt 表，按原 ID 输出。”用户指定 Excel 或 CSV 时按要求导出新文件，不覆盖原表；未指定时可交可读表格。

## 全流程与边界

按需进入项目约束、道具需求、概念方向、主视觉提示词、图片回流与基准锁定、视角／状态扩展、交付整理。只要求 Prompt 表时，交付整表即可结束，不强制等图片或逐件选方向。

保留资产表原 ID，区分剧本事实、用户要求、设计补全和待确认项。外部图片生成、费用与工具授权不由本插件自动取得；生成提示词不等于执行生图。

## 团队交接

插件根目录为本目录，入口清单为 `.codex-plugin/plugin.json`；版本号以入口清单为准。若生成安装包，文件名应使用对应版本号，例如 `dist/prop-assets-0.2.0.zip`。这是插件文件交付，不代表已经在接收者的客户端安装或注册。本次不修改个人插件市场配置。

基础验收：用一份小型剧本／道具清单请求 Prompt 表，核对原 ID、范围覆盖、设计补全标记，以及每行正／侧／背＋小幅特写＋白模尺度参照＋关键尺寸的完整提示词，检查尺寸的来源／建议属性及表词一致性；再用局部换色请求确认专项保持其他设计。实际图片的布局、尺度表达、一致性和可用性需要另行出图回流验收，结构校验不能替代该验收。

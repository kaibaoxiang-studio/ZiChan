# 场景回图审查

实际打开回流图片后才作视觉判断。并排查看剧本证据、已批准设计卡和参考图；按下列顺序记录：①地点/时段/天气等原文事实；②主结构与活动空间；③连续性不变量；④尺度关系与前中远景；⑤材料、光向和画面中新增人物/道具。看不到的背面或材料不报“已通过”，记为待核实。

若使用中式幻想情景，另看空间异常是否按已批准设计出现、主体轮廓是否清楚、场景是否误变成普通旅游景点、建筑是否形变、尺度参照是否可信。源案例中的人数、性别和服装不能作为审查标准。

报告 `SceneImageReviewV1`：`pass|revise|uncertain`，分列事实冲突、连续性、空间/尺度、版式与可保留的新细节。阻断项或不确定项不能自动批准；操作者批准应绑定图片哈希与审查报告哈希。局部返修时说清目标区域、唯一改动、保留项及回图复查点；每次回图重新检查整张图。

# 空间调度与实体锚点

性质：原创设计方法与待验证假设，不是建筑规范或已验证的多视角一致性方案。先遵守 [设计补全边界](../../../GUIDE.md#设计补全边界)，再按需读案例 DES-001—DES-005。

## 从动作需求得到空间关系

资产表给出有什么，剧本单一状态给出需要怎样使用。先写动作的起点、终点、朝向和途中必须经过的区域，再组织空间；不从某种宏大构图反推剧情。

| 使用需求 | 需要表达的关系 | 常见失败 |
| --- | --- | --- |
| 两人对话 | 两处可站/坐面、相向视线、各自侧向实体参照 | 两人只能站在同一狭缝；背靠高构件挡住对方 |
| 多人对峙 | 双方区域、中间接近面、既有入口到各区的路线 | 中央摆件封路；双方位置完全重合 |
| 接近主位 | 入场、停留、前场、主位边界依次相接 | 高台只有观赏面，没有既定上下路径 |
| 取物与落座 | 取用面、身体转向面、椅后起身面、绕行面 | 空场看似有路，椅子拉出或柜门打开后堵路 |
| 绕行或退出 | 路线接回已知出入口；必要时原路返回 | 为顺畅而擅添侧门、密道或新出口 |

行动面是否够用，应以项目角色、动作、服装/道具条件检验；未知时写相对关系与待核对项，不编造安全净宽。剧情未要求的动作只是备选设计用途，不写成已发生的事实。

## 给锚点一份最小定义

每个重要位置记录：`实体名称 / 场景固定方向 / 可用侧或面 / 相对其他实体 / 识别特征 / 遮挡风险`。只选实际需要的少量锚点，不强制每场凑齐固定数量。

例如有既定主位基座时：“基座前左角；‘前’朝向主入口；站立面位于角外的平整前场，处于近侧柱列末柱内侧；基座转角和末柱脚共同识别。”若转角不可站立，就不能把它称作站位面。

优先级：固定建筑/大型固定设施边缘 → 已确认位置稳定的家具端部 → 清晰且非重复的铺面交界。火焰、光斑、阴影、烟雾、散落书本和暂置物不作唯一锚点。家具在剧情中会移动时，记录其当前状态，不称为跨状态固定锚点。

## 换视角的约束

场景方向与画面方向分开：“主位左侧”以面向主位定义，镜头换边后不能改名为另一处。跨图保存的是实体连接、朝向与邻接关系；画面左右和占比允许变化。

当前机位应让关键锚点及其可用面可读。全景只交代路线，近景只交代局部时，不要求一张图同时承担所有任务。已有构件的非对称关系可以区分重复柱脚；没有可区分关系时记为定位不足，不自动增加雕像、徽记或新道具。

## 如何检验

先画原创关系示意，再做“入口—站位—接近—返回”的文字走查。文字示意不等于真实平面，也不能证明净宽可用。

有生成图后，在单独评审副本标出锚点、站位面、可见通路与不确定遮挡；标注不进入交付的无人背景。多视角测试比较相同实体的邻接和连通，不以风格相似判定几何一致。二维图看不清的区域标为未知，需要白模/多视角等进一步证据；不得直接记为通过。

提示词把关系写成自足中文，不把内部 A1/A2 编号当作模型理解的设施名。角色站位是空间预留，成图仍不生成角色。

# 反打与提示词密度校准示例

全部为合成教学资料，不属于真实项目，不代表已看过或生成图片。仅在空间转写或密度取舍有难点时读取；示例中的房型、机位、家具和光照都不是默认配置。

## 示例一：从文字基准推导反打

### 可靠输入

独立资产 EX01“阅档室”，用户已确认如下文字设计；完整项目表不必为换角度重新提供。架空前工业时代，写实概念绘画，无人日景，维护完好。长方形室内，近端短墙为入口侧，远端短墙为书架侧；窗在窗侧长墙，另一长墙为实墙。深褐橡木桌居中偏实墙，长边平行窗墙；座椅位于桌与实墙之间，面朝窗墙，椅后留有余量。桌窗侧通道连接入口与书架；桌远端和书架间有横向停留面。桌面无道具；书架内书籍成组收置。浅灰砌石围护、黑铁内嵌连接件，接触边细磨，木面哑光。唯一照明为窗侧日间漫射光，桌窗侧较亮，实墙及书架低处自然较暗。原机位位于入口内靠窗侧，正常视高，朝书架看。

本次请求：从书架侧朝入口反打，平视，供后续桌侧交流背景使用；不加人物，不改场景设计。

### 推导与取舍

| 关系 | 本次判断 |
| --- | --- |
| 原机位 → 新机位 | 入口内窗侧朝书架 → 书架前、桌远端的窗侧通道朝入口；不是原地转向或镜像 |
| 桌与椅 | 从桌远端看向近端；桌仍偏实墙，椅仍在实墙侧，允许桌体挡住椅子下部 |
| 书架 | 在新机位身后，不应复制到入口背景；无需为证明保留而强行入画 |
| 固定定位 | 桌远端与窗侧通道形成可辨参照；不加标线或新道具 |
| 光照 | 窗仍在同一实体墙，原受光区域不因相机反转而搬到对面；屏幕上的明暗位置可变 |

相机位置为本次提案；原布局与材料是本示例已确认输入。实际执行时这些分析留在内部。

### 可交付的自足生成稿

```text
架空前工业时代的写实概念绘画，陈设完整的无人阅档室，日间、维护完好。长方形浅灰砌石室内，入口侧与书架侧为相对的两面短墙，窗侧长墙有原有窗洞，另一长墙为实墙。深褐橡木长桌居中偏实墙，长边平行窗墙；座椅在桌与实墙之间，面朝窗墙，椅后留有余量。桌窗侧通道连接入口与书架，桌远端与书架之间留有横向停留面。桌面无道具，远端书架内书籍成组收置；木面哑光，黑铁连接内嵌，石面粗砌、接触边细磨。

摄影机位于书架前、桌远端的窗侧通道，正常视高平视，沿通道朝入口侧观察。桌远端及其窗侧桌沿构成近处参照，桌身向入口方向延伸；座椅仍在实墙侧，部分下部可被桌体遮挡。背景为入口侧空间；书架处于镜头后方，不复制到入口侧。取景集中于桌侧通道及邻接停留面，不强求全屋展示。

唯一照明来自原窗侧的日间漫射光，桌窗侧受光较亮，实墙侧自然较暗，木面反射柔和；浅灰石和深褐木本色保留。光源和陈设位置不因反打改变，阴影与反射按新视角自然呈现。
```

### 实际图像输入时的转写

只有用户实际提供并指定可靠场景图、且兼容资料足以确定上述布局时，才使用下方依赖稿。“用户提供的阅档室基准图”是条件示范，不是本文件附带的图片；没有实际图时采用上面的文字生成路径。真实图与示例不符时按真实基准推导，不覆盖成示例布局。

```text
以用户提供的阅档室基准图为依据，将机位移到书架前、桌远端的窗侧通道，正常视高平视，朝原入口侧观察，生成同一日景阅档室的反打。取景以桌远端、窗侧桌沿和通向入口的通道为主，背景为入口侧空间。

保持房间尺度、窗墙归属及桌椅实际位置和朝向；座椅仍处于桌与实墙之间，允许桌体遮挡其下部。远端书架在新机位身后，不复制到入口背景。保留陈设、材料本色、表面状态及原日间漫射窗光；受光和反射按新观察方向呈现，保持原画风与画幅，不镜像或移动家具来凑全景。
```

## 示例二：未知背面不靠提示词补成事实

独立变体 EX02：其余沿示例一，但资料只记录“原机位从近端朝书架”，没有近端边界及入口位置。本次要求严格还原反打，必须完整展示近端墙和真实入口，不允许设计补全。

应交必要问题，而非正式成图稿：

> 请补充近端墙及入口位置的参考图或布局说明；当前资料不足以严格还原这部分。其余桌椅、窗墙、材料和日光关系可以沿用，不必重新提供全项目资产表。

不能把未知近端写成素墙、默认中央门或镜像书架。用户允许不显示未知区域时，才按可行机位提出局部取景；用户允许设计探索时，才标明新结构是提案。二者都不能继续声称严格还原了未见区域。

## 示例三：同一设计的信息密度

沿示例一已确认的全部设计，保持原机位，只校准文字密度，不重新设计。以下冗长稿是专门构造的教学反例，不是历史输出或真实失败记录。

### 冗长稿

```text
架空前工业时代的写实概念绘画，无人的阅档室，日间，维护完好，画面有精致的电影感、丰富的细节、优美的质感和优秀的品质。长方形浅灰砌石室内，入口在近端短墙，书架在远端短墙，窗侧长墙有窗，另一长墙为实墙。深褐橡木桌居中偏实墙，长边平行窗墙，桌子是一张很有质感的深褐木桌，木桌位置靠近实墙一侧，长边沿窗墙方向。座椅在桌与实墙之间、面朝窗墙，坐席背后有余量；桌窗侧通道连接入口和书架，桌远端与书架间有横向停留面，这样就能支持后续交流和空间调度，通路也具有良好的可用性。桌面无道具，书架内书籍成组收置。黑铁连接内嵌，石面粗砌、接触边细磨，哑光木面有自然细纹、细微纹理、细腻材质和丰富质感。
摄影机在入口内靠窗侧，正常视高朝书架看，桌身、桌窗侧通道及远端停留面可辨；使用精致构图、优美构图和专业构图。唯一照明为原窗侧日间漫射光，桌窗侧较亮，实墙侧及书架下层较暗，木面反射柔和，浅灰石和深褐木本色保留。窗光从窗侧照入，使窗侧桌面更亮，另一侧更暗，具有电影感、明暗层次和优质光影。不要无关文字、无关标线、无关装饰、无关物品、无关新增内容。
```

### 有效稿

```text
架空前工业时代的写实概念绘画，陈设完整的无人阅档室，日间、维护完好。长方形浅灰砌石室内，入口在近端短墙，书架在远端短墙；窗侧长墙有原窗洞，另一长墙为实墙。深褐橡木桌居中偏实墙，长边平行窗墙；座椅位于桌与实墙之间，面朝窗墙，椅后留有余量。桌窗侧通道连接入口和书架，桌远端与书架之间为横向停留面。桌面无道具，书架内书籍成组收置；黑铁连接内嵌，石面粗砌、接触边细磨，木面哑光细纹。

机位在入口内靠窗侧，正常视高朝远端书架看，取景交代桌身、窗侧通道和远端停留面的连接。唯一照明为原窗侧日间漫射光，桌窗侧较亮，实墙侧及书架下层自然较暗，木面反射柔和，保留浅灰石和深褐木本色。
```

两稿保留同一关键设计。有效稿合并了重复桌位与光照句，删去质感同义词、导演理由和无关负面词；保留了桌椅朝向、椅后余量、停留面连接、材料工艺、单一光源与观察方向。仅压缩成“无人阅档室，木桌书架，电影窗光”会丢失这些关系，不算合格短稿。若用户要细节版，增加当前画面可辨的制作信息，而不是把已删除的重复句加回去。

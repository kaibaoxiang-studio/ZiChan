# 验证与回归检查

更新 skill、用户要求测试，或需要评估一次设计优化是否有效时读取。不把本文件设为每次局部修改的额外流程，不自动调用图像生成服务。

按[测试索引](../tests/index.md)选择受影响用例；单项合成资料见[固定用例](../tests/cases.md)，跨阶段变更另跑[连续流程输入](../tests/chain-inputs.md)。先使用原始输入生成实际结果，再检查判定条件。连续流程的[验收条件](../tests/chain-assertions.md)与执行输入分开，旧用例仍在同一文件中，执行时只取对应资料与请求，不把判定段当作输入。

输出和结论存放在测试工作目录，不覆盖原始用例、不回填真实项目。索引只用于选例，不要求每次全跑，也不替代下方的证据层次和具体检查方法。已具备可靠基准的局部任务不重复索取全表，缺实际图片的编辑请求不伪称有图。

## 分清验证层次

- 文件检查：入口、元数据、引用、模板和压缩包是否有效。通过只能证明交付文件完整。
- 文字回归：以明确输入生成实际提示词，检查资产与状态、设计边界、主形、空间关系、材料和光照是否落实。只阅读规则、搜索关键词或写自评表不能替代生成结果。
- 出图验证：用户要求且实际生成或提供图像后，检查画面辨识度、材质、物件、光照和布局执行。单张图不能证明所有遮挡区域或物理走戏已成立。
- 空间实测：只有真实尺寸、平面方案、三维预演或相应证据支持时，才能讨论对应碰撞与调度验证。

这些层次分开报告，不以低层通过代替高层通过。主执行者的文字回归不称为独立评测；是否使用独立 agent 或图像工具按当前可用工具、用户授权和技能约束处理。

### 可复用文件检查

用本包[检查脚本](../scripts/check_skill_files.py)，只需 Python 3.9+ 标准库，不绑定作者路径，也不写入被检查目录。检查入口及必要字段、Markdown 本地文件／图片引用与标题锚点；跳过代码示例、远端链接和系统缓存，不把它称为完整 YAML／Markdown 解析或出图验证。可从任意目录传入技能根目录；省略根目录时检查脚本所在包。

```sh
python3 /absolute/skill/scripts/check_skill_files.py /absolute/skill
python3 /absolute/skill/scripts/check_skill_files.py /absolute/skill --compare /absolute/before --allow-change references/prompt-delivery.md
python3 -B /absolute/skill/tests/test_check_skill_files.py
```

`--compare` 对照修改前的完整快照，逐文件检查新增、删除与内容变化；每个获准修改用一次 `--allow-change`，每个获准新增用一次 `--allow-add`，删除旧文件仍报告错误。无快照时只能证明现有引用完整，不能证明所有原始文件都保留。返回码 0 为检查通过，1 为发现问题，2 为路径／参数错误；JSON 中列明具体项。脚本正反例测试只证明检查器行为，不代替文字回归，完整技能格式校验另按创建工具执行。

## 代表性文字用例

更新后选择与变更有关的实际场景，用原有完整资产表和对应片段；也可使用明确标记的合成完整测试表，但不把测试 ID 或造型回填进真实项目。普通修改不要求每次跑全部用例。

| 用例方向 | 重点检查 |
| --- | --- |
| 家具互动密集的室内 | 未知相对位置能否作为提案设计；入口、坐席后撤、侧向接近和核心陈设能否共存 |
| 日常生活体系与归属者 | 世界技术、地点范围、功能分区和家具设施相容；使用面、维护与取用关系明确，人设倾向有可见选择，不默认小单间、性别模板或全屋现代家电；公共／自然及局部任务按适用范围处理 |
| 世界观体系与空间运作 | 依地点角色选择关系，不填满全部体系；既检查合理补全能否支撑实际运作，也检查没有越界新增。普通设施和已确认技术例外落实到使用、承托与维护，不只换物件外壳；不擅增制度、身份、能力、其他房间或剧情状态，严格清单及局部边界保留 |
| 不同文化归属的公共空间 | 能否在同项目材料体系内拉开主形；没有借用其他阵营徽记或混入后续破坏 |
| 极暗自然场景 | 是否保持有限可读而非强行清亮；没有添加月光、灯具、晶体、人物或视频内容 |
| 保持布局的局部／纹理修改 | 是否只读相关路径、沿用固定锚点，没有借修复重做空间或配色 |
| 固定基底的光色调整 | 氛围是否落实到受光范围与亮暗空间关系；没有借改氛围移动家具、改昼夜或添光源 |
| 跨场景色彩职责与保护色 | 共享色彩关系是否落到具体对象；功能色与身份色未被统一滤镜替换，不强制相同占比 |
| 同项目双场景统一与差异 | 固定同一项目条件和不同用途，分别生成完整提示词；比较构件、工艺、材料／颜色职责的共性与主形、布局、焦点的差异，不跨场复制专属物件／符号 |
| 无色卡的内部选色与默认交付 | 按来源优先级复用；缺方案、缺颜色或明确重配色时查询并适配少量条目，输出完整提示词而非色卡／HEX清单；不照抄原比例、导演灯具或情绪 |
| 未确认旧配色与补色边界 | 可用旧稿保留提案身份而不自动重选或定案；缺一项仅补一项，不替换其余颜色；有冲突先确认而非重检索选边 |
| 无图的文字局部迭代 | 是否交付合并后的完整生成稿，核心旧设计未遗漏；只改变授权的光色或纹理，不引用未知旧图 |
| 关键状态未知及旧稿继承 | 是否澄清道具在场时刻，而非擅自增删；未经状态探索许可不交含假设的正式稿，沿用不升级确认等级 |
| 原定障碍或危险环境 | 湿滑、狭窄、受阻等事实是否保留；不为走戏整平、清除或擅加安全设施／新路线 |
| 换视角与原表子场景 | 新投影是否服从固定布局；合并父级下各子行是否独立对应，范围、顺序与状态不被擅改 |

记录实际输入、采用的文件、输出及发现的问题。对比新旧版本时尽量固定资产、时刻、风格和修改目标，评价可见设计与关系，不用字数增加或形容词多少证明进步。

涉及体系补全边界时，按受影响范围选用例 Q 的约束场景及用例 R 的正向／边界变体；不只验证“没有乱加”，也检查设施、使用与交接关系是否真正补足。压缩检查以实际提示词为准：内部作用说明转成空间关系后，关键身份、状态、锚点和光源仍须成立；规则写了“精简”不算输出已经精简。

色彩库文件检查须核对索引与条目的色值一致、相对引用完整、查询可运行且拒绝无效输入。将skill复制或解包到临时目录后至少运行一次查询，确认不依赖独立知识库或Downloads目录。文字回归另生成实际结果：按受影响范围覆盖无项目配色、已有确认配色、可用未确认旧方案、只换视角、极暗环境及不允许重新配色的局部任务；不能用检索测试通过代替场景设计回归。

光色测试先检查不依赖人物、表演、镜头和声音的空场表达；若只生成文字，只评价这些关系是否明确，不宣称氛围成图成立。用户提供或要求出图时再检查主次、暗部、保护色与布局执行。不同次生成的图片若构图、物件或机位不同，只能比较整体方向，不能当作同一底图严格前后调色对照；文字提案也不能证明生成模型锁住了布局。

## 第二步光影氛围回归

采用[用例 RL](../tests/cases.md#用例-rl第二步光影氛围)的可靠文字基准进行文本自测；实际原图编辑另需可访问的图片，不把合成文字当成已看过的图像。保存完整输出后检查光源、路径、覆盖、材质响应和亮暗区域关系，不以出现“温馨／悬疑”或六个标题判定通过。

覆盖仅现有光源深化、明确授权昼夜与开关变化、缺实际原图、未知画外光源、极暗条件与纯纹理边界。重点是锁定实体与机位但允许阴影／反光更新；不新增光源或天气来实现氛围，不清空生活用品、不加事件痕迹，不把主要锚点全照亮当作硬要求。第一步仍输出合理基础照明，不强制自然光或自动附第二步四套稿。

多氛围测试应分别保存单一方案，固定可靠基底，只比较明确获准的光影变化。未提供或生成图片时，结论仅为文字规则与输出检查，不称完成二次打光、严格图像对照、视频氛围测试或独立评测。

涉及第二步色卡时，使用[固定用例 CP](../tests/cases.md#用例-cp色卡与打光联合交付)，实际运行本地绘卡并查看图片：色块纯色、等宽等高、白底、中文标签完整，不标比例；色值与输入一致，色卡职责与实际提示词对应。绘卡脚本还须验证无效色值、过长文字和已有输出不会生成假成功或覆盖文件。库检索与绘卡应能在临时副本运行。检查默认保留材料本色、授权重配对象、新增灯具例外、无图／只要文字及第一步不附卡边界。色卡排版通过不等于场景打光执行通过，图片编号必须对应实际输入，色卡不参与场景元素增删。

## 第三步多角度与反打回归

用[用例 MA](../tests/cases.md#用例-ma第三步多角度与反打)保存实际文字输出后，先按任务判定机位：反打的观察点须在对面、朝原机位方向。角度遵从本次要求与已确认项目偏好；未指定时依据用途选择，采用约45°时须明确向下俯拍。普通换角度按本次位置、朝向与俯仰判定，不以反打或45°要求退回正确的普通机位。共用检查：墙面拓扑、家具固定位置与相对尺度不为构图改变；镜头后方的唯一物件不复制到背景；允许遮挡和画外，不强行全物件展示。输出采用简洁大纲，只展开必要关系，不默认逐件画面位置清单、规划图、全套视角、重绘色卡或二次修补流程。

文字基准仍交自足完整稿，有图才采用依赖原图的简洁编辑模板；缺已认可氛围图不拿白天原图冒充，存在相互冲突的参考不擅自选边。光源位置与状态保持，阴影／反光的当前投影可以变化，不要求新旧画面左右和色彩面积相同。另重跑用例 E 与一个第二步边界用例，检查第三步没有覆盖既有无图换角度及光影深化规则。

新增决策回归采用 MA-F 至 MA-I：覆盖对话背景未指定角度、已确认俯拍偏好、关键背面未知及文字氛围版本交接。未知关键开口不填成素墙或新增门窗；普通材质延续无需全表。区分文字氛围方案与实际图像，后续角度不回退到过时的昼夜／灯具状态，也不自动升级提案确认等级。

实际图像检查须取得真实基准图、目标反打结果和必要的兼容资料，再按固定实体比较：

| 检查对象 | 对照方式与证据边界 |
| --- | --- |
| 机位与观察方向 | 判断是否从对面区域朝原机位方向观察；用墙面与锚点证明，不能只看是否左右互换 |
| 墙面与开口 | 核对相邻／对面关系、门窗归属及新增开口。原图未覆盖的区域标为无法核验，不能据此认定正确或不存在 |
| 家具、数量与遮挡 | 对照同一物件的贴墙、朝向、承托和邻接关系；正常出画／遮挡不判为删除，重复入画或跨区域移位需指出证据 |
| 尺度与通路 | 比较可见的相对尺度、接合和通道；正常透视缩短不判为尺寸变化，单张透视图不用于精确实测 |
| 光源与影调 | 对照当前时间、开关、真实光源位置及照射路径；光源出画仍可照明，阴影的屏幕方向与冷暖面积可变 |
| 材质与当前状态 | 对照材料身份、本色、关键物件与生活痕迹；受光色变化不自动判为换材或重配色 |

有问题时指出具体关系，区分生成执行偏差、资料冲突与资料不足；必要修正回到本次共用基准，避免用错误反打继续接力。按证据报告“符合／存在偏差／无法核验”，无需强制生成表格或审美评分。文字通过不代表反打已成图、一遍成功、全空间或三维实测通过。

## 五维设计验收

更新创作框架后，除原有资产、状态和修改范围硬约束，再对实际输出检查：

- 主题叙事：本场功能是否由具体空间选择支撑，设计密度是否相称；没有片段之外的主题、未来状态或导演意图臆断。
- 空间戏剧：主视点、使用面、动线、互见与实体锚点协调；需要时内部核对另一方向，未假称分镜全覆盖或无死角。
- 统一美学：复用项目工艺、配色和光影关系，保持各场功能差异；未复制固定比例或人物情绪滤镜。
- 真实感：材料承托、尺度和器物归属可信，老化与事件痕迹有依据；资料不足不宣称精确考据、施工或空间实测通过。
- 人物情感：已有使用者关系落实到空间，而非新增信物、角色、性格刻板模板；无相关依据可记用途层面或不适用。

按本次变更选择受影响的代表性用例：关键戏剧空间、过渡／自然空间、私人空间无信物依据、局部修改不扩大范围等，不为小改动固定跑满所有类型。涉及统一美学时另生成同项目双场景并列比较；涉及布局／光影协同时检查前期光源路径与主形／使用区遮挡；底稿字段变化时检查具体形体、材料分工及已知／未知天气是否保留。只列五维标题不算行为回归，主执行者自检不称独立测试。

双场景测试固定共用材料、构件语言、色彩职责与来源身份，允许用途、规模、时刻及有效光源有据不同。检查统一是否来自共享规则而非两场同模板，差异是否来自主形与功能而非只换名称／滤镜；未指定重新选色时不因比较换掉旧配色。资料不足可使用标明的合成完整资产表，不能把合成场景或测试提案当成真实项目定案。文字并列结果只说明描述中的共性与差异，成图统一仍需实际图像验证。

## 主动美术设计回归

这类框架更新另检查基础需求是否先分成事实、功能与空白，再发展概念，而不是先丰富原文并固化提案。对实际完整输出追踪：主形和空间有什么实质选择、为什么属于当前世界、核心资产获得什么定制造型、制作节点和光色落在何处。去掉华丽、电影感、颗粒和小纹样后，仍应能复述设计；不能用篇幅增长判定提升。

用不同规模／用途的新建场景检查主动设计是否默认发生，同时用一个仅纹理或换视角任务检查没有越权重设计。涉及特殊火焰、水体等造型时，区分普通形态设计与新增能力；局部旧提案不升级事实。记录实际输入与成品，主执行者检查不称独立评审，不把文字结果宣传为稳定电影级成图。

针对用户指出的设计失败，保留其实际输入和缺陷作为专项回归，覆盖原问题；资料不在本包时，不假装已取得或用简单合成用例宣称该缺陷已修复。将具体场景的历史问题留在对应项目测试记录中，不不断追加为所有场景的默认规则。

审查结果按主动美术设计的“可见差异—设计理由—联动收益与代价”指出实际正文证据和未解决项。已有文字回归若只证明描述具体、边界保留，应保留该有限结论，不升级为辨识度或电影级效果通过。有对应旧稿时固定输入和目标作比较；没有可靠旧稿时明确只有新稿检查，不杜撰历史输出或称严格前后对照。文字测试未解决的遮挡、光照执行和火形稳定性列为后续成图检查项，不由自评表代替。

## 结果与修正

先检查硬约束：资产对应、来源事实、当前状态、空场、修改范围与成品所需基准。再检查设计：一句话主形能否具体复述；布局是否支撑原定功能及阻碍；材料是否有分工和连接；照明是否能解释当前画面；普通提案与剧情未知是否分开。已知缺陷的旧输出可留作历史记录，但必须纠正过宽的通过结论，不能继续当作合格基准。

有问题时只修改相关规则并重跑受影响用例，不为单次样例累积跨项目硬指标。不设未经验证的“审美合格分数”，不将自评或合成样例通过宣传为稳定生成质量保证。

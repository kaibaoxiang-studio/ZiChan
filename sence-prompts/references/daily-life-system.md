# 世界观下的日常生活体系

涉及住宅、个人生活、生活设施或归属者倾向时，在事实整理后、导演调度前读取并判断；已有基准的局部任务只处理受影响关系。公共、生产和自然地点先用[世界观体系](worldbuilding-systems.md)判断，不默认读取住宅细节。日常生活体系包含生活需求、行为习惯、空间组织、设施器物和使用状态。按实际场景选择适用项，内部推敲后只交付必要的可见结果。

## 世界观与地点范围

先依据时代、地域、技术与能源、文化习惯、经济条件、居住人数和地点用途，判断日常需求怎样被满足；再选择空间与器物。电视、冰箱、洗衣机等可在适用的现代世界中作为普通设施提案，娱乐、储食与清洁在其他世界中采用已有技术和文化支持的方式。不要只换器物外形却保留不相容的功能或能源，也不因奇幻标签自创魔法设施。

“某人房间”可能指独立卧室、合租私人区、开放式单间或整套出租住宅。结合资产表的粒度、剧本中的进出、相邻区域、共享设施及用户要求判断，不能仅凭名称默认成小卧室。已确认范围优先；范围未定时可以提出有依据、边界有限的住宅形式，集中标为本轮美术提案。只有歧义影响剧情关键互通、已定边界或资产对应时才补问，不能把未确认方案说成原设定。

原资产涵盖整套住宅时，可以设计其中正常的起居、睡眠、厨房、卫浴等分区；仍交付同一资产，不拆出新条目。目标仅为已有卧室或公共起居区时，其余功能可由住宅其他区域承担，不能为了完整性新开房间、挪用别人的区域或改变已确认结构。必要功能不必全部在当前画面出现，不要求卧室同时容纳整套家电。

## 日常需求的适用范围

| 需求 | 推导的空间、设施与器物关系 |
| --- | --- |
| 饮食与家务 | 采购物品落点、储食、备餐、烹饪、用餐、清洁、洗衣晾晒与废物处理；功能按真实区域衔接 |
| 休息与身体照料 | 睡眠、梳洗、换衣、护理与康复；床侧取放面、衣物与梳理区关系及使用便利 |
| 工作与学习 | 生产、办公、阅读、练习、工具取用、资料保存与成果展示；按实际工作建立操作面和收纳 |
| 娱乐与信息 | 观看、游戏、音乐、兴趣活动、通信与外界信息获取；器物面向使用位置，技术符合世界观 |
| 社交与共同生活 | 接待、交流、共同用餐、共享物品及私人／公共区域划分；来访者的停留与进出 |
| 个人表达与情感 | 审美、收藏、纪念物、身份与文化习俗；普通装饰可提案，专属信物及关系仍需依据 |
| 收纳与维护 | 常用与备用物的层级、补充、整理、维修；根据取用频率和物品用途布置 |
| 环境调节与安全 | 采光、通风、温湿度、遮阳、隔音、隐私、财物保管及进出控制；不自动添新开口或机关 |
| 出行与内外联系 | 鞋帽、随身物及交通工具相关收置；住处与楼道、庭院或街道的必要连接 |

这些是推导维度，不是每场都要填满的设备清单。公共、商业与工作场景按服务对象、参与关系、运作和维护选择功能，不套私人卧室配置；自然环境无明确使用者时只处理已有穿行、停留与环境条件，不添住居用品。特殊医疗、仪式、安保或技术设施不能仅因需求类别而自行添加。

## 归属者的个人倾向

结合已有性别、年龄、职业、性格、生活方式、经济条件与用户偏好，主动选择属于当前归属者的空间倾向。性别和年龄可以参与织物、色彩、用品、造型与装饰选择，但不单独决定布局、整洁程度或兴趣。人物资料少时可提出有限的普通审美方案，不虚构癖好、人生经历、家庭关系或隐藏身份物证。

个人倾向同时落实到空间组织、家具组合、收纳方式、用品与配色；不能只靠一件性别化装饰证明归属。可提出柔和细致、鲜明随性、利落实用等具体方向，再写对应区域和物件；这些是本轮设计判断，不是人格与装修的一一映射。同项目不同住处共享时代及文化家族，检查具体使用组织和局部视觉选择是否有区别，避免所有人物房间均用同一套灰棕家具与灰蓝床品。用户已确认的共同美术风格仍优先，不为差异强制重配色。

## 从需求到可用空间

内部按“适用需求 → 在哪里满足 → 由什么设施支持 → 怎么使用和维护 → 与相邻区域怎样连接”推导。先安排功能分区，再选择核心家具、设施及日用品，并与剧情互动区、机位、光源一起校正。

家具家电写必要的使用关系：电视与观看坐席朝向相合；冰箱与储食、备餐区邻接，保留开门取物面；衣柜前能开柜换衣；梳理或工作台有使用位置和用品落点；床侧可取放；清洗设施与适用供排水区域相容。只需足以解释画面的条件，不在提示词中展开工程管线、设备参数或施工方案。原有狭窄、危险及受阻状态仍保留。

尺寸未定时，以功能数量、家具尺度、剧情参与人数和通行关系推导适当规模，普通出租住宅不默认狭小。原文“最小的一套”仅是相对描述，不是小卧室面积；个别资产的大小不扩散成其他资产的条件。分开处理住宅规模、当前区域和镜头取景，不能靠超广角或把家具缩小解决拥挤；已有明确的小空间也不能扩大。

先确定主要互动面与正常使用余量，再安排支撑家具和成组日用品，避免“设施齐全”却柜门打不开、坐席无法后撤或走道被堵。锚点来自实际家具、墙角及分区边界，按取景与人物入画后的遮挡检查；不用家电、杂物的数量代替定位设计。

## 提示词取舍与检查

首次场景图按用途交代主要分区及连接，可以通过邻接关系、局部开口或画外延续表现住宅纵深，门仍按重要性描述。无需一张图展示整套住宅、每种生活需求或全部家具；局部背景与固定机位按其范围执行。

保留能解释使用者与生活方式的重要组合、设施位置、关键使用面、普通用品和少量生活细节；款式、数量、小纹样等次要内容可由图片模型补全。生活感可以来自整洁收置、织物褶皱、局部磨润，事件痕迹继续核对所选时刻。新增设施是否在场、开关及使用状态按来源区分，已有设施的换新、损坏与搬入不能从其他场次提前推定。

交付前检查：地点范围有依据或明确提案吗？必要需求是否被当前区域或合理画外区域支撑？设施符合世界观和维护条件吗？归属者倾向落到了可见设计吗？功能、互动、通行、照明与取景是否相容？只有文字时不宣称空间实测或成图效果已验证。

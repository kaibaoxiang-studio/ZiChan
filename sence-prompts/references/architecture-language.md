# 建筑语言与结构可信度

选择或深化建筑风格、解决构件杂乱或结构看似无法成立时读取。将两个库的建筑语言、线条、构件与结构方法转为视觉设计参考，不当作建筑史结论或工程验算。

## 风格要落实为构造

沿用项目已有文化、技术、气候和材料边界。没有明确建筑风格时，可以依据这些条件提出方案，不能仅因“西幻”自动选择哥特，也不因场景豪华就全部改成巴洛克。

用当前建筑的事实锚点及本轮允许设计的可见构件形成一套语言。普通门窗分段、壁面分层、顶面承托与家具端部可主动提出，不必等待原文逐项列出；不变更已定边界、用途或剧情关键开口：

- 体量与围合：平展或竖向、开敞或包围、轴向或偏置。
- 开口与承托：门窗轮廓、厚薄、分段、柱墙和上方结构的衔接。
- 构件节奏：重复间距、主次梁柱、边带、框架和局部变化。
- 接触与装饰：材料连接、可用边缘、纹饰区域及密度。
- 维护与规格：加工精细度、定制程度、保养或合理修补。

“粗犷”可以是大块面与凿面，不等于随便搭；“精致”可以是收口秩序，不等于每面镀金；“仪式感”也要保留实际功能。

## 可选的构件语言

以下是造型取向，不是所有建筑必须具备的清单。只有匹配项目或获准作为提案时才用；具体历史项目需要另行核实，不能凭本表冒称历史准确。

| 取向 | 可取用的可见语汇 | 注意边界 |
| --- | --- | --- |
| 古典取向 | 柱梁节奏、门楣、基座、轴线；适用时用拱券或穹顶 | 不混称所有古典建筑；不绑定民主、善良等阵营性质 |
| 哥特取向 | 尖拱、束柱、肋状顶面、分段高窗、竖向节奏 | 扶壁等构件与规模和结构相称，不把每间小屋都教堂化 |
| 巴洛克或洛可可取向 | 曲面、涡卷、分层壁面与雕饰框架 | 两者不等同；轴线或局部非对称都须有依据，装饰避开使用面 |
| 中式木构取向 | 梁柱、屋檐、构件承接、院落与层次 | 不把全部中式建筑等同飞檐，不向未允许的西幻房间移植斗拱 |
| 日式木构取向 | 木框分格、屋檐、轻隔断及室内外过渡 | 不将禅意、极简或榻榻米设为全部日本建筑的固定特征 |
| 伊斯兰建筑取向 | 适用的拱、内院、几何纹饰、瓷砖与穹顶 | 地域时期差异很大；宣礼塔等具有明确宗教用途的构件不随意添加 |
| 地方材料与聚落取向 | 土、木、石、纤维的搭接、围合与修补 | 不把部落或贫民空间写成没有审美；图腾与文化归属必须明确 |
| 现代或工业取向 | 结构框架、板面分缝、大开口、外露连接 | 钢、玻璃、混凝土和设备须在项目技术范围内 |
| 装饰艺术取向 | 阶梯块面、几何线带、纵向分段、局部金属饰条 | 不默认黑金配色；不能只凭配色移植现代建筑和设施 |
| 科幻、赛博或复古未来取向 | 功能面板、模块、层叠界面、对应时代想象的器物 | 仅限相应项目，不自动增加霓虹、全息屏、雨夜或密集电缆 |
| 废土与回收建造取向 | 旧构件、兼容的加固、异材连接与维修层次 | 资产确为该状态才使用；杂乱不意味着没有支撑和通行 |
| 有机形态取向 | 分枝、弧线、连续曲面、类似生长的构件分段 | 造型像骨不等于真骨材料，更不等于活建筑或自行发光 |

融合时有一个可读的主导语言，次要来源落实到有限构件或材料。文化交流、改建等缘由已有依据时可解释；未知时只标为设计提案，不编造战争、殖民或宗教历史来给混搭补理由。不按固定占比或风格数量验收。

## 线条与结构秩序

横向带可以稳定大块面，竖向构件可以强调高度，弧线可以围合操作区，斜向体量可以顺地形。这些是可选视觉效果，不是“曲线等于女性”“尖角等于邪恶”的规定。

让线条来自柱、梁、门窗、家具或材料分段；纹饰延续结构节奏，不能用平面花纹代替建筑造型。尖锐装饰留在非接触边缘，握持、坐卧、通行面依照功能处理。

## 可见的支撑与连接

检查顶面、厚重体量、门窗开口、台阶和主家具是否有可理解的承托、接合与落地关系。大开口周边、转角和悬挑若是主特征，需要说明可见的构件关系，不靠“建筑合理”一句带过。

- 结构与项目材料加工能力一致，不能将薄木板描写成无支撑石拱的替代物。
- 不将“木不能大跨”“混凝土不能复古”等简化禁用表当成工程真理，也不凭文字保证结构安全。
- 不为解释支撑增加未批准的楼层、地下室、复杂管线或新设施。缺少决定性结构信息时说明待确认项。
- 现实重力框架内的方案以连续承托和落地关系增强可信度。超现实结构只能依照已有规则；需要新能力时请求确认，不能自编魔法使其成立。
- 相邻空间内外对应：厚墙窗洞与外墙厚度不矛盾，屋顶和入口方向不随图变化；未知的外部不凭室内视角推定完整城堡。

材质细化见 [材质与工艺](material-and-craft.md)，功能比例见 [走戏空间](staging-layout.md)，按主入口选读而非递归加载。建筑取向不能覆盖原文材料、陈设和剧情状态；各构件使用同一底稿的尺寸关系与材料分工。

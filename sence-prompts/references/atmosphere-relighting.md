# 第二步：场景光影氛围深化

用于第一步场景图已认可后的重新打光与氛围强化，也适用于可靠已有场景的同类请求。联合设计静态光影与[适配色卡](atmosphere-palette.md)，交付色卡图及提示词；不自动生成场景图、修改资产表或进入视频制作。光影细节方法见[色彩光影](color-light-atmosphere.md)，写作与模板见下方[二次打光交付](#第二步二次打光提示词)。

## 基准、状态与授权

输入通常是实际原图、目标资产或可靠地点标识、对应剧情／氛围要求与本次允许改变的条件。已有资料直接使用，不重复索取完整表。用户只说“强化光影”时，默认保留当前昼夜、天气、光源身份与位置，在有效光源内设计明暗、柔硬、覆盖与影调；非剧情关键的普通灯具可在氛围重打光范围内提出开关方案，明确为本轮提案，固定或剧情指定状态不改。

明确要求改为夜晚、夕阳或开关某盏灯时，按授权更新相应条件；夜晚不自动等于月光，夕阳不自动确定未知窗向。新增或移动灯具、设定画外街灯／走廊灯、特殊光源与天气变化均须有有效依据或本次明确许可。缺少条件时先用现有条件形成可达方案，只有目标依赖这些变化时才询问必要选择。若空间条件不足以实现预期，说明限制，不偷换光源或改装修。

原图的可见结构、实际灯具和光照迹象可以作为本次编辑基准，但不能从一个亮斑认定未知画外光源、从图中出现某道具确认其剧情在场时刻。资料冲突、关键道具与特殊状态仍按[资产输入](asset-input.md)处理；图像或旧稿中的假设不因沿用而升级为项目事实。

没有实际图像而只有完整旧稿时，可输出完整文字光影深化稿，并说明未经图像核查。用户指定“基于原图编辑”却未提供可访问原图时，请补图，不编造图片编号、不交伪称已看图的编辑成品。局部光影方案可以独立提出，不宣称完成第二步成图。交接第三步按[阶段基准交接](../SKILL.md#阶段基准交接)：当前只交了提示词或色卡时，其身份仍是方案；实际氛围图可用后才能作为图像反打基准。

## 固定与可变项

先选定本次模式：默认光影氛围深化，材料本色固定；只有明确要求配色与光影调整时，列出允许重配色的对象。新增／移除元素或特殊状态变化也列为本次例外，保留约束排除这些例外，不泛称所有数量／状态不变。下表为默认模式，例外只在授权范围覆盖相关项。

| 固定基准 | 随授权打光更新 |
| --- | --- |
| 相机位置、画幅、透视、景别、景深与前景虚焦；空间边界、开口、家具位置、形状及非照明物件状态 | 光源强弱、柔硬、受光覆盖，以及本次允许调整的灯具开关、时间或光源条件 |
| 材质身份、固有色、已有纹理、生活痕迹与实体锚点 | 阴影方向／软硬、反光、间接光、局部呈现色与整体影调 |

“材质不变”不等于反光亮度不变，“构图不变”不等于原阴影逐像素不变。不能同时要求重新打光与保留全部旧影子。不开柜、挪窗帘、搬家具、变门的开闭来制造光线；涉及这些实体状态变化时需另有授权。暗处细纹不可见不等于删除生活痕迹，不为显露它们重新做旧或全面补光。保留原有画风，颗粒、光晕与锐度不作为每次必须新增的效果。

## 从剧情目标到光影方案

先核对原图中主要使用面、通道、固定参照，以及可见开口、灯具、遮挡和材料；未知外部条件保留未知。然后用已有剧情或用户目标确定视觉重点，缺剧情时按所需氛围提出有限光影方案，不编造等候者、来客、威胁或事件。

剧情与氛围均未指定、只要求“强化光影”时，依据当前照明和空间用途，提出一套克制的光影层次优化：让主要使用面、材质与前后空间关系更清楚，不自动选择温馨、孤独或悬疑，也不更改昼夜、天气和光源身份／位置。正文外说明这是本轮打光提案，不推断作者意图；灯具开关遵守上文边界。无需为一般影调选择暂停询问，只有达到目标必须改变既定条件或在实质互斥方向间选择时，才问必要问题。

在固定布局内联合设计：

1. 光源主次：哪一来源主导，哪些维持、减弱或关闭；不用固定三点布光或每角落一盏灯的模板。
2. 照射路径：来源经已有开口／遮挡抵达哪些表面，哪里产生直接光、柔化光或间接反射；光域不能任意穿越实墙和高柜。
3. 空间明暗：主要亮区、次亮区和间隔暗区怎样相接或分隔，前后距离怎样被看见；调整光域，不通过移动实体制造距离。
4. 材质与影调：保留必要亮部纹理，暗部按实际照明呈现色阶或轮廓；冷暖落在具体区域，反射随材质和距离变化，不用整图滤镜代替打光。

“强化”指光影关系更明确，不默认更暗、更硬、更高反差、更饱和或加烟雾。根据目标保留柔和、低反差的方案。主视觉不必最亮；灯罩或窗外高亮不能吞掉关键使用面。

先指出本场要改善的具体层次，例如使用面与背景难分、亮窗抢焦点或暖光范围过散，再将改动落到现有光源及表面。柔硬、光色和照射范围须与原光源及遮挡条件相容；阴天漫射窗光不因“更戏剧性”改成锐利太阳束，固定灯罩不通过改造外形取得硬光。目标受现有条件限制时，交可达的层次方案并简述限制；仅当目标必须依赖新增或改造条件时补问。多氛围版本比较的是获准光影关系，不能靠挪家具或换材制造差别。

后续人物入画的需求只转为空场中的受光覆盖、亮暗衔接和实体锚点可辨程度。检查主要停留面、操作面及必要连接通道，不能为看清人物而凭空补光，或要求每条路线全程等亮。锚点原来不可见或有效光线不足时说明限制，不搬动参照、不改机位。提示词不添加人物、脸部补光假象、动作、表情、声音或运镜。

## 第二步二次打光提示词

完成上述光影与色卡的联合设计后，按“参考分工与授权 → 原图保留边界 → 色卡职责映射 → 光源与路径 → 材质与明暗 → 整体氛围”组织稿件，不要求六个标题或六段。共同信息取舍沿[提示词交付](prompt-delivery.md)，每个重要氛围判断落实到有效光源、受光表面或亮暗关系。

有实际原图时可按需合并下方模板；选定唯一模式、替换全部占位项，仅保留相关条件。正文外简短说明资产、单一状态、实际基准及授权例外；未经要求不指定新机位、焦距、景深或画幅。无图文字稿须完整合并旧设计，不用本模板冒充原图编辑。无色卡或用户只要文字时删除色卡引用，仍写全光色与路径；图片编号遵从实际输入顺序，不凭空编号。

```text
【实际色卡引用】仅用于光色与影调，【实际场景原图引用】作为空间与内容基准。读取色卡颜色、名称与本场用途，不将色块、文字、白底或排版复制到场景中。本次仅调整【明确的光影及配色范围】，另获准【时间／灯具开关／增删元素等具体例外；无则删去】。

保持原图摄影机位置、构图、画幅、透视、景别、景深、前景遮挡与空间结构。除上述获准例外外，保留人物及物件数量、位置、形状、材质、状态、生活痕迹和已有文字。【默认保留材料本色；获准重配时改为列明可改对象及其目标颜色】，不重排陈设或改造装修结构。

将【适用色名与具体职责】分别落到【有效光源、受光面、背光区、保留材料或局部重点】。环境基调体现于适用大面积表面及受光关系，不统一染色；强调色仅用于适用的少量重点。参考相对冷暖、明度与饱和度关系，不强制用齐或等面积分配，不以色块明度规定曝光、灯光强度或逐像素颜色。

【当前或获准改变的时间条件】。以【具体位置与身份的光源】为主，呈现【强弱、柔硬与光色】；【其他有效光源】按【保持／减弱／关闭】处理。光线经过【已有开口和遮挡】，落在【主要受光表面】，向【其他区域】自然衰减。

【亮部表面】保留必要纹理，【背光区域】呈现【实际可读层次】，邻近【材料】获得【克制反射】。冷暖分别落在【具体区域】，亮区与暗区形成【相接或分隔关系】，整体呈现【适用的反差与饱和度】。保留【主要停留面旁原有实体参照】在有效光照下的必要辨识，不全屋补亮。

颜色随材料、受光与距离自然过渡，保留物体边界；有人物时保持自然肤色，无人时不添加人物。营造【目标氛围】，避免【本场易出现的光影偏差】，保持原有画风。输出应用本次色卡与打光方案后的场景图，除明确许可变化外，原始内容不变。
```

模板末尾的出图要求只交给图片模型，不表示本 skill 已执行。锁定实体不锁定旧阴影与反光，不用“其余同上”代替相关保留边界；不删除已有标识，不堆通用负面词。多氛围仅在用户要求时分别交单一方案，说明差异来自哪组获准光影关系。默认一张色卡配一条合并稿，不拆成独立涂色与打光指令。

## 案例与交付

需要区分相近氛围时，按需读[客厅四氛围案例](../knowledge/lighting/living-room-atmospheres.md)。它们提供有前提的关系，不是默认四套版本、固定配色、必需门光或当前模型配置。

默认交原资产／采用基准与单一状态、必要光影提案说明、一张适配色卡图，以及一条代码块内的完整色卡应用与打光提示词。实际原图与色卡均可用时明确各自引用关系；用户只要文字时省略绘卡，完整表达光色职责。有可靠文字基准但无图时仍可配色卡交文字深化稿，不虚构第二张图片；缺必要原图或授权时先处理依赖，不用绘卡冒充完成场景编辑。只复述与保留边界及受光有关的主要物件，不重新罗列全屋。不默认交 HEX、比例、四套版本、视频脚本或场景出图结果。

交付前核对：每个重要光斑、阴影和反射有来源与路径；改动与保留项无矛盾；时间与开关有授权；实体色与受光色分开；必要锚点在目标照明下的可读程度不夸大。提示词不能保证模型保持像素一致；只有实际成图后才能判断氛围和空间执行，流程与文件验证不代替成图验收。

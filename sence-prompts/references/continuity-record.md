# 可选场景连续性记录

仅在用户要求保存、更新或恢复项目美术档案时读取。此文件定义记录格式，不授权默认创建项目文件，也不要求用户每次另交档案。

## 记录位置与来源

优先更新用户指定的现有项目档案及其格式；没有既有格式时使用下方轻量字段，存放在当前项目的明确位置。档案不写回通用 skill 的知识库。若已有记录与本次资料冲突，保留来源、指出具体分歧，不以较新的生成时间自动判定事实有效。

记录版本只表示文档修订。一次确认只适用于用户明确认可的项目，不因“继续”“换个角度”或旧图存在就将全部提案定案。用户有明确确认设计的表述时记录原意和对应条目；确认日期未知不补造。

## 最小复用字段

| 字段 | 保存什么 |
| --- | --- |
| 项目、资产、基准版本 | 原 ID／名称／子场景行，采用的图或提示词文件及版本；不编造原资产 ID |
| 阶段与产物身份 | 第一步设计、第二步氛围或第三步角度；采用的是文字方案、色卡、实际场景图还是反打结果，各自文件与用途。记录实际有过的认可／核验情况，未成图不记为完成图像阶段 |
| 固定布局与识别形 | 入口墙等相对参照、开口、主物位置及朝向、主形、必要空地与互见关系；不用画面左右代替真实布局 |
| 材料与实体色 | 主辅材料、可见加工、各色对应实体与位置、功能／身份色 |
| 世界条件与功能关系 | 本场所依赖的已知技术、环境、用途与范围；实际采用的分区、设施及使用关系。只存关键决定及来源，不填满所有体系，不把提案升级为制度或项目事实 |
| 状态与光源 | 剧情时刻、昼夜天气的已知项、关键物件及事件状态、有效光源身份与位置；未知保持未知 |
| 本次视点 | 相机位置／朝向及主要投影关系，独立于固定布局保存 |
| 决定的身份与依据 | 各关键项分别标为原表事实、剧本补充、用户确认、本轮提案或待确认，附表内位置／场次／原请求等简短依据 |
| 改动与影响 | 本轮修改、被替代的决定、受影响视角／状态、仍待解决的问题 |

字段可合并，简单场景不填空表。允许用户只保存最终提示词，但说明仅保存正文可能丢失来源和确认等级；不因此强制追加档案。

## 轻量阶段交接模板

用户要“记住这个版本／保存后继续”，且没有既有格式时，优先采用下面的短记录；复杂世界条件或多状态关系再按上表补充。不要求用户填模板，也不默认每次交付或落盘。每条关键决定用“事实／用户确认／提案／未知”注明来源身份，不能用一句“全场已确认”覆盖混合来源。

```text
资产与采用版本：【项目、原 ID／名称／子场景；本次采用的版本及明确依据】
可用产物：【文字主稿、实际场景图、色卡或角度稿的真实位置／用途；缺项明确写未提供】
固定设计：【关键围护与锚点、实体位置／朝向、通路、材料本色；逐项简标来源身份】
当前状态与光源：【本时刻状态、光源身份／位置／开关及有效变化；未知项不补造】
本次机位与改动：【从哪里朝哪里、俯仰；本次允许变化与未改项，区别于固定布局】
待办与派生影响：【待确认项、需要复核的旧角度及其采用基准；无实际核验不记已通过】
```

短记录是恢复索引，不是完整提示词的替代。需要恢复详细设计时，指向真实保存的完整主稿；没有主稿时保存恢复所必需的设计正文，不为凑短记录而丢失关键关系。文件名或记录标题含“夜景／最终／已认可”不证明图像存在、阶段完成或全部设计获确认。

## 恢复和更新

恢复时先核对项目、资产、采用版本和所选状态，再读取本次所需锚点。暂定设计可作为基准继续迭代，剧情未知仍按资产输入规则处理。按[阶段基准交接](../SKILL.md#阶段基准交接)核对产物身份；缺实际氛围图时，不能仅凭档案中的方案名称声称已恢复图像基准。更新时只改本轮涉及字段，保留有效来源；布局或光源／状态变化时标明需要同步哪些旧角度，不声称已自动重写未处理版本。

恢复索引指向的图或主稿不可访问时，复用记录中足够且有来源的文字关系；依赖实际图像的任务仍补对应图，不拿同名文件或较新输出自动替代。版本冲突只补问采用依据，不重索全表。

更新后按真实改动追踪派生影响：材料变化影响涉及该表面的角度，布局／开口变化影响相关投影与遮挡，昼夜／灯具变化影响沿用旧照明的角度。旧稿标为“沿旧基准／待同步或复核”，不删除历史，也不默认重写所有角度；未涉及的状态或独立条目不一概作废。一次角度稿修正不自动升级为共用布局基准，按用户采用意图与已有核验情况确定。

档案记录不能证明像素一致、空间实测或成图验证。交付完整生成稿时仍写出必要内容，不用“参见档案”替代提示词正文。
